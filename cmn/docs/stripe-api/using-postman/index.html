Using Postman to Connect to the Stripe API

什么是 Postman？​

Postman 是一个用于 API 开发的协作平台。开发者可以使用 Postman 来开发、管理、测试和文档化 API。其用户友好的界面使 API 协作变得简单，因此它成为跨职能团队的理想平台。

设置 Postman​

  1. 下载并安装 Postman 应用程序。
  2. 打开 Postman 应用并完成设置流程。

  1. 在页面顶部的搜索栏中输入“Stripe”，然后选择 Stripe Developers APIs。

  1. 在“集合”选项卡中，找到最新的集合，并点击 Fork 按钮将其添加到您的集合中。

生成密钥​

Stripe 服务器使用 Bearer 令牌授权来验证和授权 API 请求。要进行此设置，您需要创建一个 Stripe 账户。

  1. 访问 https://dashboard.stripe.com/ 并按照页面上的说明创建您的账户。
  2. 密钥位于仪表板的首页。点击它将其复制到剪贴板。
    备注

    出于安全考虑，请勿与其他用户共享您的密钥。

  3. 返回 Postman 应用。
  4. 点击 环境 > 添加 (+)。
  5. 在“名称”字段中输入环境名称（例如，Stripe API）。

  1. 在 变量 单元格中输入 secret_key。

  2. 在 当前值 单元格中，粘贴从 Stripe 仪表盘复制的密钥。

  3. 点击 保存。

  4. 要将环境设置为 Stripe API 环境，请点击工作区右上角的 环境 下拉菜单。

Stripe 服务器现在将对您的 API 请求进行身份验证和授权。

连接先决条件​

要连接到 Stripe API，您需要基础 URL：https://api.stripe.com
