TypeScript SDK Sui 区块链文档

Sui TypeScript SDK 的分步教学系列，旨在简化开发人员的入门流程。本教程涵盖了与 Sui 区块链交互的完整工作流程——从环境设置到执行链上交易——展示了优先考虑清晰度和快速价值实现的教学方法。

📄️SuiClient——您应用的“邮局职员”

SuiClient 在 Sui 应用架构中的作用，负责处理您的应用与 Sui 区块链网络之间的通信。

📄️如何获取对象数据

一篇关于如何从 Sui `devnet` 获取对象数据的教程。

📄️使用写入操作发送交易

本教程将介绍如何使用 SuiClient 执行写入操作，以发送一笔转移 Sui 代币的交易。

📄️API 参考 - getObject

SuiClient 方法 `getObject` 的 API 参考文档，该方法用于从区块链中检索特定对象的详细信息。

📄️API 参考 - multiGetObjects

SuiClient 方法 `multiGetObjects` 的 API 参考文档，该方法可在单次网络请求中检索多个对象的详细信息。

📄️API 参考 - getOwnedObjects

SuiClient 方法 `getOwnedObjects` 的 API 参考文档，该方法用于检索特定地址拥有的对象列表。
