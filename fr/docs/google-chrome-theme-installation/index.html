Installation et application d'un thème dans Google Chrome

Vous pouvez personnaliser Google Chrome pour qu'il corresponde à l'esthétique de votre choix. Ce guide présente les étapes à suivre pour installer un nouveau thème sur votre navigateur.

Prérequis​

  • Une connexion internet stable.
  • La dernière version de Google Chrome

Instructions​

Méthode 1 :​

  1. Ouvrez Google Chrome

  2. Cliquez sur l'icône de menu Débordement (ou l'icône Kebab, yum!).

  3. Sélectionnez Paramètres

  1. Cliquez sur Apparence

  1. Cliquez sur Thème pour accéder au Chrome Web Store. Vous pouvez rechercher ou parcourir un nouveau thème à appliquer au navigateur.

À titre d'exemple, ce guide utilise le thème Mountain Crows.

  1. Après avoir sélectionné votre thème, cliquez sur Ajouter à Chrome. Une bannière confirme l'installation. Pour revenir au thème précédent, cliquez sur Annuler.

  1. Pour sélectionner un nouveau thème, répétez les étapes 1 à 6. Pour rétablir le thème par défaut, cliquez sur Rétablir le thème par défaut dans le menu Apparence.

Méthode 2 :​

Ce raccourci est disponible lorsque la page Nouvel onglet est votre page d'accueil par défaut.

  1. Ouvrir Google Chrome
  2. Sur la page Nouvel onglet, cliquez sur Personnaliser Chrome ou sur l'icône du crayon .

  1. Cliquez sur Changer de thème pour accéder au Chrome Web Store. Vous pouvez rechercher ou parcourir un nouveau thème à appliquer au navigateur.

À titre d'exemple, ce guide utilise le thème Corbeaux de montagne.

  1. Après avoir sélectionné votre thème, cliquez sur Ajouter à Chrome. Une bannière confirme l'installation. Pour revenir à votre thème précédent, cliquez sur Undo.

  1. Pour sélectionner un nouveau thème, répétez les étapes 1 à 4. Pour rétablir le thème par défaut, cliquez sur Rétablir le thème par défaut dans le menu Apparence.

Note pour les utilisateurs de Linux​

Google Chrome peut s'adapter à vos paramètres GTK ou Qt dans le menu Apparence. Pour revenir au thème par défaut, cliquez sur Utiliser classique.

Vous pouvez désormais surfer sur le web dans le style le plus cool, votre style.
