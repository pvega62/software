Documentation TypeScript SDK Sui Blockchain

Apprenez à utiliser TypeScript pour lire et écrire des données de la blockchain Sui.

📄️ Le SuiClient - l'employé de poste de votre application

Le rôle du SuiClient dans l'architecture de l'application Sui, gérant la communication entre votre application et le réseau blockchain Sui.

📄️ Comment récupérer des données d'objets

Un tutoriel sur la façon de récupérer les données d'objets du `devnet` Sui.

📄️ Utilisation de l'opération d'écriture pour envoyer une transaction

Un tutoriel sur la façon d'effectuer une opération d'écriture en utilisant le SuiClient pour envoyer une transaction qui transfère des jetons Sui.

📄️ API Reference - getObject

Documentation de référence API pour la méthode `getObject` du SuiClient, qui récupère les détails d'un objet spécifique de la blockchain.

📄️ API Reference - multiGetObjects

Documentation de référence API pour la méthode `multiGetObjects` du SuiClient, qui récupère les détails de plusieurs objets en une seule requête réseau.

📄️ API Reference - getOwnedObjects

Documentation de référence API pour la méthode `getOwnedObjects` du SuiClient, qui récupère une liste d'objets possédés par une adresse spécifique.
