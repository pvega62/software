Lancer votre premier balayage

Vous avez créé votre profil de configuration. Il est temps de lancer votre premier balayage d’emploi automatisé.

Lancer le balayage​

Ouvrez votre terminal dans le dossier qui contient votre clone sweepy. Si vous avez fermé le terminal depuis l’étape précédente, rouvrez-le et revenez dans sweepy :

Terminal
cd sweepy

Lancez le moteur avec votre profil :

Terminal
sweepy --profile profiles/paralegal_nyc.yaml

Sweepy inclut paralegal_nyc.yaml dans le dossier profiles. La forme courte fonctionne aussi :

Terminal
sweepy --run

--run réutilise le dernier profil que vous avez enregistré.

astuce

Si vous avez créé votre profil avec l’assistant, Sweepy l’a enregistré sous profiles/alex_rivera_paralegal.yaml. Le nom combine votre nom et votre premier intitulé de poste. Utilisez ce chemin à la place du modèle prédéfini.

Sweepy affiche des messages de progression en temps réel pendant son travail. Vous n’avez rien à faire. Regardez et attendez.

Un balayage prend quelques minutes, selon votre débit Internet, l’état du cache et le nombre de plateformes.

Étapes du balayage​

ÉtapeCe qui se passeCe qu’il faut surveiller
Chargement du profilLit votre fichier de configuration YAMLConfirme que vos intitulés et votre lieu correspondent à votre profil
DécouverteEnvoie des requêtes de recherche à chaque plateforme de suivi des candidaturesIndique combien d’offres brutes chaque plateforme a renvoyées
VérificationContrôle chaque lien, puis retire les offres mortesConserve les offres invérifiables et les marque unverified
NotationExtrait les termes de votre CV et note chaque posteAffiche le nombre de termes et la plage de scores
GénérationConstruit le répertoire de fiches PDF, l’export CSV et tout autre format activéAffiche les chemins où le moteur enregistre vos rapports
Remarque

Sweepy supprime une offre quand la plateforme renvoie un 404 dur ou une page soft-404, et quand la connexion échoue. Les limites de débit, les blocages de bots, les erreurs serveur passagères et les délais d’attente ne prouvent rien sur l’offre. Ces cas renvoient 401, 403, 408, 425, 429, 500, 502, 503 ou 504, ou aucune réponse du tout. Sweepy conserve l’offre dans le balayage et la marque unverified.

Localiser vos fichiers​

Quand le balayage se termine, ouvrez le dossier results dans votre installation Sweepy.

Terminal
Get-ChildItem results

Le répertoire affiche des fichiers horodatés à la date et à l’heure du jour. Le nom de fichier enregistre l’heure d’exécution au format 24 heures. Windows affiche l’heure du fichier dans votre fuseau horaire local, donc les valeurs peuvent différer de quelques heures :

Sortie du terminal
    Directory: C:\Users\Alex\sweepy\results

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a---          10/21/2026 1:06 AM          19065 paralegal_nyc_2026-10-21-050656.pdf
-a---          10/21/2026 1:06 AM         215694 paralegal_nyc_2026-10-21-050656.csv
Ouverture rapide sous Windows

Double-cliquez sur le fichier PDF dans l’Explorateur de fichiers, ou lancez cette commande dans votre terminal pour l’ouvrir immédiatement :

Terminal
start results\paralegal_nyc_2026-10-21-050656.pdf

Lancer des balayages quotidiens​

Sweepy prend en charge les balayages quotidiens. Lancez la même commande chaque matin pour capter les nouvelles offres :

Terminal
sweepy --run

Chaque exécution qui trouve de nouvelles offres horodate le nom de fichier avec la date et l’heure, donc une nouvelle exécution n’écrase jamais vos résultats précédents. Quand rien de nouveau n’apparaît, l’exécution affiche No new postings since your last sweep et laisse results intact. Au fil du temps, votre dossier results constitue un historique complet de votre recherche d’emploi.

Automatiser les balayages quotidiens

Sous Windows, vous pouvez créer une tâche planifiée pour lancer le balayage chaque matin à 8 h 00. Sous macOS/Linux, utilisez une tâche cron. La référence de la ligne de commande couvre les deux approches.

Vous avez terminé votre premier balayage automatisé. Ouvrez maintenant le PDF. Examinez les scores de compatibilité et les badges de couleur.
