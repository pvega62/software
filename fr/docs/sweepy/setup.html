Configurer Sweepy

Vous avez installé Sweepy ! Il vous faut maintenant un profil pour commencer vos recherches. Ce guide vous aide à créer ce profil et à lancer votre première recherche.

Un profil de configuration définit votre lieu de recherche cible, les postes à rechercher ainsi que le CV utilisé pour évaluer ces postes.

Un profil est un petit fichier texte au format YAML. Il organise les données grâce à des indentations, des points-virgules et des sauts de ligne. Vous n’avez pas besoin d’écrire de code : si vous pouvez lire une liste de courses, vous pouvez lire ce fichier.

Option A : Lancer l'assistant de configuration interactif​

L'assistant de configuration crée un profil opérationnel à partir de réponses simples. Il ouvre la page de recherche avant le questionnaire et génère le fichier de configuration à votre place.

Exécutez cette commande :

Terminal
sweepy --setup

L’assistant affiche son bannier, puis l’interface de lancement. La ligne d’état située en dessous des éléments de l’interface indique le profil chargé ; par exemple, Current profile: Alex Rivera / 4 titles / Ready. Si aucun profil n’a encore été chargé, la ligne affiche Current profile: none loaded / build one to start.

L’interface de lancement présente six éléments. Le bouton “Start Sweep” exécute le profil chargé. Le bouton “Load Profile” ouvre une recherche enregistrée. Le bouton “Build Profile” lance une nouvelle recherche et pose des questions en français simple. Les options “Sweep Settings” permettent de gérer le classement des résultats, les informations affichées et l’historique des recherches. L’onglet “Sweepy's Toolbox” contient des fonctionnalités pour modifier les profils, gérer les moteurs de recherche, les agrégateurs de données, activer/désactiver le mode débogage, obtenir de l’aide, consulter les journaux d’activité récents, convertir des documents et mettre à jour l’application. Le bouton “Exit Sweepy” enregistre vos modifications et ferme l’assistant.

La référence aux commandes énumère les options (ou « flags ») associées à chaque commande.

Réexécutez sweepy --setup à tout moment pour créer un nouveau profil ou modifier un profil existant. L’assistant écrit dans le fichier ainsi nommé et ne modifie pas les autres profils.

Pour sauter l’étape de création et modifier directement un profil enregistré, utilisez le paramètre --profile :

Terminal
sweepy --setup --profile profiles/paralegal_nyc.yaml

Option B : Modifier le fichier de configuration manuellement​

Pour saisir vos propres réglages, copiez le modèle fourni et ouvrez-le dans un éditeur de texte simple comme Notepad ou VS Code. Évitez les logiciels de traitement de texte, qui remplaçent les guillemets droits par des guillemets courbes et altèrent la structure du fichier.

  • Windows
  • macOS / Linux
Terminal
copy config.sample.yaml profiles\alex_rivera_paralegal.yaml
notepad profiles\alex_rivera_paralegal.yaml
Terminal
cp config.sample.yaml profiles/alex_rivera_paralegal.yaml
open profiles/alex_rivera_paralegal.yaml    # macOS
# or: nano profiles/alex_rivera_paralegal.yaml   # Linux

Profil d'Alex​

L’assistant enregistre ce fichier dans le répertoire profiles/alex_rivera_paralegal.yaml. Les lignes commençant par # sont des commentaires ; Sweepy les ignore. Si vous omettez une section ou une valeur, Sweepy y mettra automatiquement une valeur par défaut.

profiles/alex_rivera_paralegal.yaml
# ─────────────────────────────────────────────────
# Sweepy — Alex's Paralegal Profile
# ─────────────────────────────────────────────────

# Your name (appears in the PDF report header)
name: "Alex Rivera"

# ─── Job Search Settings ──────────────────────────
search:
  # List every job title you want to find.
  # The engine searches for ALL of these titles simultaneously.
  titles:
    - "Paralegal"
    - "Legal Assistant"
    - "Litigation Support Specialist"
    - "Legal Secretary"

  # Your target city and state.
  location: "New York, NY"

  # Set to true to ONLY see remote roles.
  # Set to false to see remote, hybrid, and on-site roles.
  remote_only: false

  # Set to false to exclude hybrid positions.
  include_hybrid: true

  # Minimum annual salary filter (optional).
  # Leave as 0 or remove this line to skip salary filtering.
  min_salary: 65000

# ─── Resume Settings ─────────────────────────────
resume:
  # The full path to your resume PDF on your computer.
  # On Windows, use double backslashes (\\) or forward slashes (/).
  path: "Alex_Rivera_Resume.pdf"

  # Must-have skills to prioritize for the match percentage.
  must_have_skills:
    - "Westlaw"
    - "LexisNexis"
    - "e-discovery"
    - "Contract Review"
    - "Legal Research"

  # How heavily to weigh keyword matches when scoring roles.
  # 1.0 = standard weight. Increase to 2.0 if you want
  # exact skill matches to dominate the score.
  keywords_weight: 1.5

# ─── Platform Settings ────────────────────────────
# Set each platform to true or false to enable or disable it.
platforms:
  greenhouse: true
  ashby: true
  lever: true
  workable: true
  aggregators: false   # Free feeds like Remotive, Adzuna

  # Optional: custom ATS endpoints or company career domains
  custom:
    - name: "SmartRecruiters"
      domain: "smartrecruiters.com"
      enabled: true
    - name: "Breezy HR"
      domain: "breezy.hr"
      enabled: true

# ─── Export Settings ──────────────────────────────
export:
  # Comma-separated list of output formats.
  # Options: pdf, csv, json
  format: "pdf,csv"

  # Where to save the output files.
  # The engine creates this folder if it does not exist.
  output_dir: "results"
attention

Sur Windows : utilisez des doubles barres obliques (\\) ou des barres obliques simples (/) dans les chemins indiqués par YAML. Une seule barre oblique (\) perturbe le formatage des fichiers.

✅ Correct : "C:\\Users\\Alex\\Documents\\resume.pdf" ou "C:/Users/Alex/Documents/resume.pdf"

❌ Incorrect : "C:\Users\Alex\Documents\resume.pdf"

Vous pouvez créer autant de profils que vous le souhaitez ; conservez-en un différent pour chaque variante de titre de poste ou ville ciblée. Changez entre eux instantanément à l’aide du symbole --profile.

Option C : automatisation avec l'application de bureau Antigravity​

Google Antigravity est une application desktop gratuite conçue pour les agents IA. Elle se connecte à Sweepy via le protocole Model Context Protocol (MCP), vous permettant de rechercher des emplois en mode conversationnel sans ouvrir de terminal.

Pourquoi exécuter Sweepy via MCP ?​

  • Analyse des compétences requises. Gemini lit l’intégralité des descriptions de poste et identifie les compétences manquantes, tandis qu’une recherche via terminal ne prend en compte que les mots-clés exacts.
  • Utilisez votre quota préétabli. Les recherches s’effectuent avec votre crédit Google standard, vous évitant ainsi d’avoir besoin de souscrire à des API externes.
  • Gérer les recherches depuis la conversation. Décrivez les rôles cibles à travers une question posée dans le cadre d’une conversation ; Antigravity génère alors le profil correspondant ainsi que le rapport PDF final.

Configuration rapide​

Pour installer Sweepy avec Antigravity, il vous faut deux éléments : le serveur MCP pour les outils de recherche et l’application permettant d’utiliser la raccourciature /sweepy.

Méthode 1 : Demandez à l'agent​

Ouvrez l’application Antigravity, lancez une conversation et envoyez la question suivante :

“Préparez Sweepy pour moi : enregistrez son serveur MCP local en cours d’exécution sous python <PATH_TO_SWEEPY>/server.py et installez la compétence depuis <PATH_TO_SWEEPY>/skills/sweepy.”

Antigravity génère les fichiers de configuration et les ajoute à votre système.

Méthode 2 : configuration manuelle​

Suivez ces étapes pour configurer l’application vous-même :

  1. Ajoutez le serveur MCP :

    • Dans Antigravity Desktop, ouvrez Paramètres (icône en forme d'engrenage) > Serveurs MCP.
    • Ajouter le serveur Sweepy :
      • Nom : sweepy
      • Commande : python
      • Argumentations : ["<PATH_TO_SWEEPY>/server.py"]

  2. Installez cette compétence. Le fichier correspondant à cette compétence active la raccourciature du menu /sweepy.

    • Ouvrez le dossier « Skills » de votre ordinateur :
      • Windows : Appuyez sur Win+R, puis saisissez %USERPROFILE%\.gemini\config\skills.
      • macOS : Dans le Finder, appuyez sur Cmd+Shift+G, puis saisissez ~/.gemini/config/skills.
    • Copiez le dossier “sweepy” depuis le dossier “sweepy/skills/sweepy” directement dans le dossier “skills”.
    • Redémarrez l’application de bureau Antigravity.

  3. Effectuez votre recherche : Saisissez /sweepy dans la chatbox, ou demandez directement :

    Créez un profil à partir de mon CV à l’adresse C:/path/to/resume.pdf en recherchant des postes de rédacteur technique à distance, puis lancez ma première recherche.

Pour configurer d’autres applications comme VS Code, consultez la référence d’intégration avec MCP.

Vérifiez où Sweepy recherche des offres d'emploi​

Les requêtes couvrent par défaut quatre systèmes de suivi des candidats publics : Greenhouse, Ashby, Lever et Workable. Elles incluent également le site de recrutement Built In NYC à New York. L’agrégateur récupère les données de LinkedIn, Indeed et Glassdoor ; ces sources sont activées lorsque votre profil le permet (via le paramètre python-jobspy).

Des moteurs de recherche supplémentaires peuvent être ajoutés. L’utilisation d’OpenRoles nécessite une liste d’entreprises ; Apify nécessite également un fichier “APIFY_TOKEN”. L’utilisation de JobDrop peut entraîner des conflits avec d’autres dépendances de l’application. L’option “Télécharger des moteurs de recherche” de l’assistant d’installation les installe automatiquement.

La page Sources et plateformes présente les moteurs optionnels, les fichiers de démarrage (seed files), les entrées relatives aux plateformes personnalisées ainsi que les mises en garde concernant la compatibilité.

Votre profil est prêt ; il est maintenant temps de lancer votre première recherche.
