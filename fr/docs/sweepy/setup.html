Configuration de Sweepy

Vous avez installé Sweepy ! Il vous faut maintenant un profil.

Un profil de configuration indique à Sweepy les offres d’emploi à rechercher et le CV à utiliser pour les évaluer. Il définit également votre lieu de travail souhaité.

Un profil est un petit fichier texte au format YAML. YAML, qui rime avec « camel », organise les données à l’aide d’indentations, de deux-points et de sauts de ligne. Vous n’avez pas besoin d’écrire de code : si vous savez lire une liste de courses, vous savez lire le YAML.

Option A : Lancer l’assistant de configuration interactif​

L’assistant de configuration crée un profil fonctionnel à partir de réponses simples. Il ouvre la page de démarrage de la recherche avant le questionnaire et rédige le fichier de configuration à votre place.

Exécutez cette commande :

Terminal
sweepy --setup

L’assistant affiche sa bannière, puis le tableau de bord. La ligne d’état sous les vignettes indique le profil chargé, par exemple Profil actuel : Alex Rivera / 4 titres / Prêt. Si aucun profil n’est encore chargé, elle affiche Profil actuel : aucun profil chargé / créez-en un pour commencer.

Le tableau de bord affiche six vignettes. Lancer Sweep exécute le profil chargé. Charger un profil ouvre une recherche enregistrée. Créer un profil lance une nouvelle recherche et pose des questions en langage clair. Paramètres de Sweep permet de contrôler le classement, les fiches et l’historique. Boîte à outils de Sweepy regroupe la modification des profils, la gestion du moteur, la gestion de l’agrégateur, le bouton de débogage, l’aide, les journaux récents, la conversion de documents et les mises à jour. Quitter Sweepy enregistre vos modifications et ferme l’assistant.

La référence des commandes répertorie les options associées à chaque entrée.

Relancez sweepy --setup à tout moment pour créer un nouveau profil ou modifier un profil existant. L’assistant écrit dans le fichier qu’il nomme et ne modifie pas vos autres profils.

Pour ignorer l’assistant de configuration et modifier directement un profil enregistré, utilisez l’option --profile :

Terminal
sweepy --setup --profile profiles/paralegal_nyc.yaml

Option B : Modifier le fichier de configuration manuellement​

Pour saisir directement vos paramètres, copiez le modèle d’exemple et ouvrez-le dans un éditeur de texte brut tel que le Bloc-notes ou VS Code. Évitez les traitements de texte, qui remplacent les guillemets droits par des guillemets courbes et corrompent le YAML.

  • Windows
  • macOS / Linux
Terminal
copy config.sample.yaml profiles\alex_rivera_paralegal.yaml
notepad profiles\alex_rivera_paralegal.yaml
Terminal
cp config.sample.yaml profiles/alex_rivera_paralegal.yaml
open profiles/alex_rivera_paralegal.yaml    # macOS
# ou : nano profiles/alex_rivera_paralegal.yaml   # Linux

Profil d’Alex​

L’assistant enregistre ce fichier dans profiles/alex_rivera_paralegal.yaml. Les lignes commençant par # sont des commentaires : elles expliquent chaque paramètre, et Sweepy les ignore. Sweepy remplit par défaut toute section ou tout paramètre que vous omettez.

profiles/alex_rivera_paralegal.yaml
# ─────────────────────────────────────────────────
# Sweepy — Profil d’assistant juridique d’Alex
# ─────────────────────────────────────────────────

# Votre nom (apparaît dans l’en-tête du rapport PDF)
name: "Alex Rivera"

# ─── Paramètres de recherche d’emploi ──────────────────────────
search:
  # Énumérez tous les intitulés de poste que vous souhaitez trouver.
  # Le moteur recherche TOUS ces intitulés simultanément.
  intitulés :
    - « Assistant juridique »
    - « Assistant de direction juridique »
    - « Spécialiste de l’accompagnement en contentieux »
    - « Secrétaire juridique »

  # Votre ville et votre État cibles.
  location : « New York, NY »

  # Définissez cette option sur « true » pour ne voir QUE les postes à distance.
  # Définissez-la sur « false » pour voir les postes à distance, hybrides et sur site.
  remote_only : false

  # Définissez cette option sur « false » pour exclure les postes hybrides.
  include_hybrid : true

  # Filtre de salaire annuel minimum (facultatif).
  # Laissez la valeur 0 ou supprimez cette ligne pour ne pas appliquer de filtre de salaire.
  min_salary : 65000

# ─── Paramètres du CV ─────────────────────────────
resume:
  # Chemin d'accès complet au fichier PDF de votre CV sur votre ordinateur.
  # Sous Windows, utilisez des doubles barres obliques inversées (\\) ou des barres obliques (/).
  path: "Alex_Rivera_Resume.pdf"

  # Compétences indispensables à privilégier pour le calcul du pourcentage de correspondance.
  must_have_skills:
    - "Westlaw"
    - "LexisNexis"
    - "e-discovery"
    - "Contract Review"
    - "Legal Research"

  # Poids à attribuer aux correspondances de mots-clés lors de l'évaluation des postes.
  # 1,0 = poids standard. Augmentez cette valeur à 2,0 si vous souhaitez
  # que les correspondances exactes de compétences priment dans le score.
  keywords_weight: 1,5

# ─── Paramètres des plateformes ────────────────────────────
# Définissez chaque plateforme sur « true » ou « false » pour l’activer ou la désactiver.
platforms:
  greenhouse: true
  ashby: true
  lever: true
  workable: true
  aggregators: false   # Flux gratuits tels que Remotive, Adzuna

  # Facultatif : points de terminaison ATS personnalisés ou domaines de carrière d’entreprise
  custom:
    - name: "SmartRecruiters"
 domain: "smartrecruiters.com"
 enabled: true
    - name: "Breezy HR"
 domain: "breezy.hr"
 enabled: true

# ─── Paramètres d'exportation ──────────────────────────────
export :
  # Liste des formats de sortie séparés par des virgules.
  # Options : pdf, csv, json
  format : "pdf,csv"

  # Emplacement d'enregistrement des fichiers de sortie.
  # Le moteur crée ce dossier s'il n'existe pas.
  output_dir : "results"

Sous Windows : utilisez des doubles barres obliques inversées (\\) ou des barres obliques (/) dans les chemins d'accès YAML. Une seule barre oblique inversée (\) perturbe le formatage YAML.

✅ Correct : "C:\\Users\\Alex\\Documents\\resume.pdf" ou "C:/Users/Alex/Documents/resume.pdf"

❌ Incorrect : "C:\Users\Alex\Documents\resume.pdf"

Utilisation des profils prédéfinis​

Sweepy inclut des profils prédéfinis prêts à l’emploi dans le dossier profiles/. Ces quatre profils couvrent les recherches courantes :

FichierParcours professionnelIntitulés recherchés
paralegal_nyc.yamlDroitAssistant juridique, Assistant de direction juridique, Spécialiste de l’assistance en contentieux, Secrétaire juridique
frontend_developer.yamlIngénierie logicielleDéveloppeur front-end, Développeur React, Ingénieur UI
tech_writer.yamlRédaction techniqueRédacteur technique, rédacteur UX, concepteur de contenu
template_custom.yamlToutes les carrièresExemples de intitulés que vous pouvez remplacer. Chaque configuration est accompagnée d’un commentaire.

Pour utiliser un profil prédéfini, indiquez son nom de fichier lorsque vous lancez une analyse :

Terminal
sweepy --profile profiles/frontend_developer.yaml

Vous pouvez créer autant de profils que vous le souhaitez. Enregistrez-en un différent pour chaque variante de intitulé de poste ou chaque ville que vous ciblez. Passez instantanément de l’un à l’autre à l’aide de l’option --profile.

Option C : Automatisation avec un assistant de chat​

Un assistant de chat peut créer des profils et lancer des balayages à votre place. Sweepy intègre un serveur MCP (Model Context Protocol) ; l’assistant peut ainsi lire et modifier vos profils directement. Le guide d’intégration MCP couvre la configuration client pour Antigravity, Claude Desktop et VS Code, tandis que la référence des outils MCP répertorie tous les outils de Sweepy.

Consulter tous les paramètres​

La référence de configuration répertorie tous les paramètres acceptés par un profil, de debug et resume.tracks à sources.* et report.*. Gardez-la ouverte pendant que vous modifiez votre profil.

Vérifier où Sweepy recherche des offres d’emploi​

Par défaut, Sweepy interroge quatre systèmes publics de suivi des candidats. Ce groupe comprend Greenhouse, Ashby, Lever et Workable. Il interroge également Built In NYC, un site d’offres d’emploi new-yorkais. Les flux agrégateurs provenant de LinkedIn, Indeed, Glassdoor et ZipRecruiter passent par python-jobspy lorsque votre profil les active.

Des moteurs optionnels ajoutent des sites d’offres d’emploi. Les options disponibles sont HireHunt, OpenRoles, JobDrop et Apify. OpenRoles nécessite une liste d’entreprises avant de fonctionner. Apify nécessite un APIFY_TOKEN. JobDrop entre en conflit avec la version de dépendance de JobSpy. L’option Télécharger les moteurs d’offres d’emploi de l’assistant de configuration permet de les installer.

La page Sources et plateformes traite des moteurs optionnels, des fichiers d’amorçage, des entrées de plateformes personnalisées et des mises en garde concernant la compatibilité.

Votre profil est prêt. Il est temps de lancer votre premier balayage.
