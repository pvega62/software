Référence de la ligne de commande

Sweepy s’installe avec une seule commande : sweepy. Tapez-la et appuyez sur Entrée. Ajoutez des options si la commande nécessite plus de paramètres par défaut. Chaque profil, chaque opération de nettoyage et chaque rapport commence ici.

Terminal
sweepy

Alex utilise deux de ces commandes chaque matin : d’abord --run pour effectuer le nettoyage avec le dernier profil enregistré, puis --logs pour obtenir un rapport en cas d’anomalie lors de l’exécution.

Remarque

Exécutez chaque commande depuis le dossier sweepy. Si vous avez fermé votre terminal depuis la dernière étape, rouvrez-le et exécutez d’abord cd sweepy.

Référence des commandes​

Exécutez sweepy sans aucune option pour ouvrir l’interface d’administration. Les tableaux ci-dessous regroupent toutes les options par tâche qu’elles effectuent.

Forme de la commande

Exécutez pip install -e . depuis le dossier sweepy ; les pages suivantes présentent la forme abrégée de cette commande. Si votre shell ne trouve pas sweepy, rouvrez le terminal ou exécutez plutôt python swee.py.

Balayages et profils​

ParamètreFonctionnalité associée
--runEffectue un nettoyage avec le dernier profil enregistré.
--profile <path>Exécute une opération de balayage à partir d’un profil identifié par YAML.
--setupOuvre l’interface de recherche pour effectuer des recherches ou configurer des profils.
--non-interactiveCrée ou met à jour un profil en se basant sur des paramètres spécifiques (des “flags”), plutôt que sur des questions posées à l’utilisateur. Utilisez cette fonction en conjonction avec --setup.

Remplacements ponctuels​

ParamètreFonctionnalité associée
--no-dedupeGarde les publications dupliquées provenant de différents forums lors de la même opération de balayage.
--include-seenAffiche également les publications issues d’une opération de balayage précédente.
--reset-historyEfface les publications qui ont déjà été prises en compte pour le profil en cours.

Documents​

ParamètreFonctionnalité associée
--docx <path>Convertit un fichier identifié par DOCX en format PDF, puis quitte l’application.
--convert <path>Convertit un document compatible en format PDF à côté du fichier source, puis quitte l’application.

Moteurs de recherche d'emploi​

ParamètreFonctionnalité associée
--list-enginesListe tous les moteurs de recherche, les plateformes qu’ils consultent et leur état d’installation.
--install-engines [names]Télécharge tous les moteurs disponibles (ou seulement ceux que vous spécifiez).
--allow-engine-conflictsInstalle un moteur dont le paramètre d’installation (« pin ») entre en conflit avec un moteur déjà installé ; ignore ce paramètre. Associez cette action à --install-engines.

Mises à jour et version​

ParamètreFonctionnalité associée
--updateTélécharge la dernière version du logiciel Sweepy et réinstalle toutes ses dépendances.
--check-updateIndique s’il existe une version plus récente de Sweepy.
--versionAffiche la version du logiciel ainsi que ses dépendances.

Journalisation​

ParamètreFonctionnalité associée
--debugActive le journal de débogage sous logs/.
--log-dir <dir>Déplace le dossier contenant les journaux de débogage.
--logsAffiche les entrées les plus récentes du journal de débogage.

Valeurs de configuration en mode sans interface graphique​

Ces paramètres sont ajoutés lors de l’utilisation de --setup. Chaque valeur doit être accompagnée du bon paramètre correspondant ; --name, --titles, --location et --resume sont obligatoires à moins que le profil ne les fournisse déjà.

ParamètreFonctionnalité associée
--sources <names>Active ces moteurs (séparés par des virgules).
--jobspy-sites <sites>Configure les tableaux JobSpy (séparés par des virgules).
--hirehunt-sources <sources>Configure les sources d’information HireHunt (séparées par des virgules).
--jobdrop-sites <sites>Configure les tableaux JobDrop (séparés par des virgules).
--openroles-companies <slugs>Définit les noms d’entreprise pour OpenRoles (séparés par des virgules).
--apify-actor <actor>Définit l’ID de l’acteur Apify.
--timeout <seconds>Définit le délai d’attente par source.
--cache-ttl <seconds>Définit la durée de vie du cache de découverte.
--no-cacheDésactive le cache de découverte.
--history-days <days>Définit le nombre de jours avant que une publication signalée ne puisse réapparaître.
--no-historySignale chaque publication à chaque exécution.
--job-tracking / --no-job-trackingActive ou désactive les colonnes de suivi des tâches CSV.
--name <name>Définit le nom du profil.
--titles <titles>Définit les titres cibles, séparés par des virgules.
--location <location>Définit l’emplacement cible.
--resume <path>Définit le chemin du CV.
--portfolio <value>Ajoute un portefeuille à partir duquel extraire des éléments ; accepte une URL, un fichier PDF local, du texte ou un fichier Markdown. Répétez cette instruction pour plusieurs sources, et ajoutez le préfixe TRACK= pour associer chaque valeur à une seule piste de suivi de CV.
--portfolio-track <track>Définit la trajectoire de résumé pour les valeurs de --portfolio sans préfixe TRACK=.

Prenez en charge d’abord les poignées de balayage --logs, --version, --update, --check-update, --list-engines et --install-engines, puis convertissez les documents. Ensuite, exécutez l’opération --setup ; enfin, effectuez le balayage final. Une seule tâche est exécutée par commande.

Exécutez votre dernier profil avec --run​

Sauvez un profil une seule fois, puis effectuez l’opération de nettoyage avec une seule commande courte. Sweepy conserve le dernier profil sauvé dans la variable profiles/.last_profile et l’utilise à nouveau.

Terminal
sweepy --run

La commande sélectionne le profil selon l’ordre suivant :

  1. Si aucun de ces profils n’existe, Sweepy génère une erreur et vous renvoie vers la valeur par défaut (profiles/.last_profile).

  2. Créez un nouveau profil en utilisant profiles/ :​

  3. profiles/custom_profile.yaml, then profiles/paralegal_nyc.yaml, then config.sample.yaml.

Lorsque aucun de ces éléments n’existe, Sweepy génère une erreur et vous dirige vers --setup.

Créer un profil avec --setup​

Le guide d’utilisation ouvre l’interface de recherche et crée pour vous un profil identifié par le code YAML.

Terminal
sweepy --setup
Carreau du lanceur (Launchpad)Ce qu’il fait
Lancement de la rechercheDéclenche une recherche en utilisant le profil que vous avez sélectionné. La ligne d’état vous avertit tant que vous n’avez pas ouvert de profil.
Charger un profilPermet de sélectionner un profil enregistré à utiliser pour la prochaine analyse.
Boîte à outils de SweepyOuvre les options listées ci-dessous.
Créer un profilPose des questions en français simple, puis enregistre un nouveau profil.
Paramètres de balayagePermet de modifier la pondération des mots-clés, les limites de cartes, le style des rapports, le comportement de l'historique et les colonnes de suivi des tâches dans le fichier CSV.
Quitter SweepyEnregistre vos modifications et retourne à l’interpréteur de commandes.

Sweepy's Toolbox contient les actions restantes :

Vous pouvez relancer l’assistant à tout moment pour créer un nouveau profil ou modifier un profil existant. Vos profils précédents ne seront jamais supprimés. La page Configuration de Sweepy vous guide pas à pas dans chaque étape.

Convertir un document au format PDF (bonus)​

L’outil de Sweepy permet de convertir un document même en l’absence de profil. Choisissez Convertir un document en PDF (bonus), puis indiquez le chemin du fichier à convertir.

EntréeCe que fait Sweepy
.docxRéécrit le texte en utilisant les bibliothèques python-docx et reportlab, puis utilise Microsoft Word pour la mise en forme finale.
.docEffectue la conversion via Microsoft Word, qui nécessite la bibliothèque docx2pdf.
.txt, .mdAffiche le texte avec des titres et des listes à puces.
.pdfFait passer le fichier ou le copie dans le chemin de sortie que vous avez spécifié.

Sweepy affiche une alerte en cas d’erreur de chemin et réouvre l’interface d’interaction utilisateur. Une erreur de frappe vous ramène à l’écran d’aide (l’« assistant »).

Accéder directement à un profil​

Ajoutez --profile pour ouvrir un profil afin de le modifier sans utiliser l’interface d’assistant.

Terminal
sweepy --setup --profile profiles/paralegal_nyc.yaml

L’assistant préremplit l’écran d’examen avec les valeurs actuelles du fichier sélectionné.

Créer un profil sans invites​

Si vous avez besoin de la même configuration sur toutes les machines, utilisez un script ; ajoutez --setup --non-interactive et spécifiez chaque valeur comme paramètre.

Terminal
sweepy --setup --non-interactive `
  --name "Alex Rivera" `
  --titles "Technical Writer,UX Writer" `
  --location "New York, NY" `
  --resume C:\Users\Alex\sweepy\resume.pdf `
  --sources jobspy,openroles `
  --openroles-companies figma,stripe,notion `
  --timeout 120 --no-cache

Sweepy vérifie chaque composant activé avant d’écrire le fichier. En l’absence d’une valeur nécessaire (par exemple, le nom de l’entreprise pour OpenRoles), il affiche Error: et s’arrête avec le code d’erreur 1. Sans la valeur --profile, Sweepy génère le nom du fichier à partir de votre nom et de votre premier titre ; par exemple, le profil d’Alex sera enregistré dans le dossier profiles/alex_rivera_technical_writer.yaml. Pour mettre à jour un fichier existant, utilisez --profile <path>.

Mises à jour de Sweepy​

Téléchargez le code le plus récent et réinstallez les dépendances nécessaires.

Terminal
sweepy --update

Sweepy récupère le fichier distant désigné par origin, met à jour la branche courante et exécute la commande python -m pip install -r requirements.txt. Il refuse d’effectuer la mise à jour si des modifications non committées sont présentes dans les fichiers locaux ; privilégiez donc la vérification en lecture seule pour savoir si une mise à jour est disponible.

Terminal
sweepy --check-update

Mettre à jour Sweepy depuis l’outil de gestion de Sweepy effectue la même opération.

Répertorier et installer les moteurs​

Listez chaque moteur, les plateformes qu’il lit, ainsi que son état d’installation.

Terminal
sweepy --list-engines

Téléchargez les moteurs optionnels.

Terminal
sweepy --install-engines all

L’ensemble des moteurs définis par all ignore le moteur JobDrop tant que JobSpy détient une donnée contradictoire ; installez JobDrop séparément en utilisant --allow-engine-conflicts.

Terminal
sweepy --install-engines jobdrop --allow-engine-conflicts

L’installation d’un moteur de traitement des données le désactive automatiquement. Vous pouvez l’activer dans le profil sources.enabled ou l’inclure via la commande --sources lors d’une configuration sans interface graphique. La commande s’arrête avec un code d’erreur (1) en cas d’échec de l’installation. Les moteurs disponibles sont listés séparément.

Lancez un balayage avec --profile​

Conservez un profil pour chaque ville ou type de rôle, puis pointez --profile vers le profil approprié ; Sweepy s’occupe du reste.

Terminal
sweepy --profile profiles/paralegal_nyc.yaml

Remplacez ce nom de fichier par le vôtre propre. Utilisez --run lorsque vous souhaitez que Sweepy réutilise le dernier profil que vous avez enregistré.

astuce

Conservez un profil pour chaque ville ou type de rôle ; modifiez le nom du fichier pour changer de recherche.

Paramètre de remplacement pour une exécution​

Les commandes --run et --profile acceptent trois paramètres de configuration supplémentaires. Chacun d’eux s’applique uniquement à la commande spécifiée et n’affecte pas les autres profils.

Terminal
sweepy --run --no-dedupe
sweepy --run --include-seen
sweepy --run --reset-history

Lorsque deux fichiers décrivent le même rôle, --no-dedupe conserve les informations de tous les fichiers concernés. L’opération history.retention_days affiche uniquement les nouvelles annonces, tandis que --include-seen inclut également les annonces cachées dans le rapport. Exécutez --reset-history pour supprimer ces informations obsolètes sans effectuer de nettoyage complet.

Que se passe-t-il pendant un balayage ?​

Chaque exécution suit les mêmes cinq étapes, dans le même ordre.

ÉtapeCe qui se passe
1. Chargement du profilLa plateforme lit votre fichier YAML et vérifie les paramètres.
2. Exploration des donnéesLes outils de collecte (scrapers) sont lancés sur vos plateformes activées pour récupérer les informations.
3. ValidationLes liens inactifs et les redirigements de type 404 sont supprimés ; les éléments que la vérification ne peut pas confirmer restent dans le processus.
4. Analyse des donnéesLe CV ou le fichier DOCX est analysé pour détecter les doublons de termes, puis un conseil d’application (Application Tip) est généré pour chaque poste.
5. Création des fichiersDes fichiers PDF, CSV et JSON sont créés, avec une date de création affichée. Le fichier png est également inclus dans les formats d’exportation pour les images de page.

Le terminal affiche l’avancement de chaque étape (de [1/5] à [5/5]) pendant l’exécution. L’action Lancer votre première opération de collecte de données montre le résultat complet.

Convertir un fichier DOCX en PDF avec --docx​

Donnez le fichier --docx à Sweepy ; celui-ci le convertit en PDF et quitte l’application.

Terminal
sweepy --docx path/to/resume.docx

Sweepy vous demande ensuite où stocker le fichier PDF résultant.

Terminal output
Where should the PDF go? (leave blank to save next to the DOCX):

Appuyez sur Entrée avec une réponse vide ; le fichier PDF sera alors créé et placé à côté de la ligne DOCX, sous le même nom de base. Si vous souhaitez l’enregistrer ailleurs, entrez un chemin complet. Dans tous les cas, Sweepy affichera la ligne PDF saved: ainsi que l’emplacement final du fichier PDF.

Remarque

Sweepy réconstructuit d’abord le PDF à partir du contenu de la ligne DOCX. Si votre ordinateur dispose de Microsoft Word, il utilisera également la ligne docx2pdf pour une meilleure correspondance visuelle.

Convertissez n'importe quel document avec --convert​

La commande --convert s’exécute sans aucune demande d’information de la part de l’utilisateur et enregistre le PDF à côté du fichier d’origine. Elle peut être utilisée pour des fichiers désignés par les lignes .docx, .doc, .txt, .md ou .pdf.

Terminal
sweepy --convert path/to/resume.docx
Terminal output
PDF saved: C:\Users\Alex\sweepy\resume.pdf

Le résultat conserve le nom du fichier source et inverse l'extension ; ainsi, notes.md devient notes.pdf dans le même dossier. Un fichier source nommé .pdf existant déjà à cet emplacement, Sweepy affiche This file is already a PDF: et laisse le fichier à sa place.

EntréeCe que fait Sweepy
.docxRéécrit le texte en utilisant les bibliothèques python-docx et reportlab, puis utilise Microsoft Word pour la mise en forme finale.
.docEffectue la conversion via Microsoft Word, qui nécessite la bibliothèque docx2pdf.
.txt, .mdAffiche le texte avec des titres et des listes à puces.
.pdfNe modifie pas le fichier et affiche son emplacement.

En l’absence d’un fichier ou s’il n’est pas pris en charge, la commande Error: affiche un message d’erreur et s’arrête avec le code 1. Cela garantit la sécurité de l’utilisation de cette commande dans des scripts ou des tâches planifiées.

Une fois que le PDF est créé, pointez resume.path dans votre profil vers ce fichier et exécutez une opération de balayage.

Vérifiez votre version avec --version​

Utilisez cette commande pour confirmer que l’engine et ses bibliothèques sont correctement installés.

Terminal
sweepy --version
Terminal output
Sweepy v3.1.0
Python 3.13.1 | pymupdf 1.28.2 | reportlab 5.0.1
Ready to sweep.

Si pymupdf ou reportlab affiche MISSING, réinstallez vos dépendances. L’installation décrit cette étape.

Activer la journalisation de débogage​

Les journaux de débogage enregistrent les actions de l’engine, étape par étape. Activez-les à l’aide d’un flag, d’une configuration de profil ou d’une variable d’environnement.

MéthodeOù l’avez-vous définiePériode de validité
Flag --debugAjoutez-le à votre commande dans le terminal.Valable uniquement pour cette exécution.
debug: trueAjoutez-le à votre profil YAML.Valable pour toutes les exécutions jusqu’à ce que vous le supprimiez.
SWEEPY_DEBUG=1Définissez-le comme une variable d’environnement.Valable pour toutes les exécutions jusqu’à la fermeture du terminal.

Ajoutez ce flag à n’importe quelle commande de nettoyage (sweep).

Terminal
sweepy --debug --profile profiles/paralegal_nyc.yaml

Ou activez le journal de débogage de manière permanente dans votre profil.

profiles/paralegal_nyc.yaml
# Write a rotating debug log under logs/ on every run.
debug: true

Ou définissez plutôt la variable d’environnement.

Terminal
$env:SWEEPY_DEBUG = "1"
sweepy --profile profiles/paralegal_nyc.yaml

Sur macOS ou Linux, remplacez la première ligne par export SWEEPY_DEBUG=1.

Sweepy enregistre les journaux d’activité dans le répertoire contenant l’application (logs/). Pour les envoyer ailleurs, utilisez --log-dir.

Terminal
sweepy --debug --log-dir C:\Users\Alex\sweepy-logs --profile profiles/paralegal_nyc.yaml

Pour lire les dernières entrées sans ouvrir de fichier, exécutez la commande correspondante.

Terminal
sweepy --logs
Remarque

La commande --logs affiche les données contenues dans No debug logs found. Run Sweepy with --debug to enable logging. jusqu’à ce qu’un fichier de journal de débogage soit créé.

Planifier des exécutions quotidiennes​

Les équipes de recrutement publient de nouvelles offres d'emploi tout au long de la semaine. En exécutant la même commande chaque matin, vous pourrez les repérer dès leur publication.

Terminal
sweepy --profile profiles/paralegal_nyc.yaml

Quand une opération se déroule, Sweepy écrit des fichiers de rapport. Sweepy insère le profil, la date et l'heure dans le nom de chaque fichier de rapport, comme dans paralegal_nyc_2026-10-08-081500.pdf et paralegal_nyc_2026-10-08-081500.csv. Une opération qui passe par MCP ajoute mcp au nom, comme dans paralegal_nyc_mcp_2026-10-08-081500.pdf, afin de distinguer les deux chemins. La date et l'heure proviennent de l'horloge en export.timezone, qui est par défaut en local. On peut la configurer en UTC, un nom IANA tel que America/New_York, ou un décalage comme -05:00 pour marquer les fichiers avec une autre zone. Ce marquage empêche qu'une opération ne覆se l'autre, donc results conserve toute l'historie de vos recherches.

Sweepy ne prend en compte que les nouveaux posts et conserve ces informations pendant quatre jours par défaut. Si aucune nouvelle donnée n’est trouvée lors d’une analyse matinale, l’outil affiche simplement le message No new postings since your last sweep sans générer de nouveau fichier de rapport. Le même comportement est observé lorsque tous les liens découverts sont déjà expirés.

Planification sous Windows​

  1. Ouvrez Task Scheduler depuis le menu Démarrer.
  2. Sélectionnez Créer une tâche de base et donnez-lui un nom du type Sweepy morning sweep.
  3. Sélectionnez l’option Journalière, puis choisissez une heure de début.
  4. Pour l’action, choisissez Lancer un programme.
  5. Définissez Programme/Script comme votre exécutable Python. Exécutez (Get-Command python).Source dans PowerShell pour afficher ce chemin.
  6. Définissez Ajouter des arguments comme le chemin complet de swee.py ainsi que le profil "C:\Users\Alex\sweepy\swee.py" --profile profiles\paralegal_nyc.yaml.
  7. Définissez Start in sur votre dossier sweepy. Le moteur recherche les fichiers profiles et enregistre les results dans ce dossier.

Planification sous macOS et Linux​

  1. Ouvrez votre fichier crontab avec crontab -e.
  2. Ajoutez une ligne qui exécutera la tâche à 8h00 du matin, selon l’heure de votre région.
Terminal
0 8 * * * cd /path/to/sweepy && python3 swee.py --profile profiles/paralegal_nyc.yaml

La partie cd est importante. Le moteur lit la valeur profiles et écrit la valeur results par rapport au dossier depuis lequel il est lancé. Utilisez la valeur python3 pour installer les paquets de Sweepy. Testez-le avec la valeur python3 -c "import swee".

attention

Une exécution planifiée se déroule hors fenêtre de terminal ; les paramètres de session précédentes ne s’appliquent donc pas. Exécutez la commande manuellement une première fois pour vérifier son fonctionnement avant de la programmer.
