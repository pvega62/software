Lancer Sweepy depuis un assistant IA avec MCP

Un assistant IA peut lancer Sweepy à votre place. Vous décrivez le poste recherché, et l'assistant appelle Sweepy en votre nom sans vous demander de taper des commandes dans le terminal.

Cette connexion utilise le Protocole de Contexte de Modèle (MCP). MCP est un langage commun qui permet à un assistant IA d'utiliser des outils installés sur votre ordinateur. Sweepy inclut un serveur MCP intégré dans server.py. Il fonctionne via le transport stdio, ce qui lui permet de communiquer localement avec votre client sans ouvrir de port réseau.

Remarque

MCP est facultatif. Sweepy fonctionne entièrement depuis des commandes de terminal sans aucun assistant IA. Le serveur ajoute une couche conversationnelle au-dessus du même moteur. Il apporte également le jugement et l'intelligence du modèle à la notation et au filtrage déterministes que Sweepy effectue déjà.

Avant de vous connecter​

  • Terminez l'Installation pour que Python et les dépendances de Sweepy soient en place. Les packages mcp et anyio sont fournis avec requirements.txt.
  • Notez le chemin absolu vers server.py. Collez ce chemin dans la configuration de votre client.
  • Redémarrez votre client IA après avoir modifié sa configuration MCP.

Outils disponibles​

Sweepy expose douze outils à votre assistant. Chacun renvoie un payload JSON et déclare des indicateurs de lecture seule, destructif, idempotent et monde ouvert.

OutilCe qu'il fait
create_profileConstruit, valide et enregistre un profil YAML à partir d'un CV PDF ou DOCX.
run_sweepExécute le pipeline en cinq étapes en arrière-plan et stocke les fiches déterministes.
get_sweep_statusAttend la fin d'un balayage en cours et signale sa progression.
get_jobsRenvoie les fiches de la session en cours, classées par score.
submit_judgmentsRemplace les champs déterministes d'une fiche par le jugement de votre assistant.
import_jobsAjoute les emplois vérifiés par votre assistant ailleurs.
render_reportGénère le PDF de fiches de la session en cours.
get_resultsLit le résultat du balayage le plus récent depuis le disque.
export_reportRecrée les fichiers PDF, PNG, CSV ou JSON à partir d'un balayage existant.
clear_historySupprime les offres signalées pour un profil.
convert_documentConvertit un document compatible en PDF.
convert_docxConvertit un CV DOCX en PDF.

La référence des outils MCP va plus loin dans les détails. Elle liste chaque paramètre, valeur par défaut, payload et indication de comportement.

Choisir les moteurs de recherche d'emploi​

Lorsque vous omettez sources_config, create_profile active les moteurs JobSpy et ATS intégrés. Il active également les moteurs optionnels disposant d'une installation fonctionnelle et de valeurs par défaut valides. L'outil renvoie enabled_engines et engines_not_enabled, pour que vous puissiez voir quels moteurs tournent et lesquels nécessitent encore une configuration.

OpenRoles recherche uniquement les tableaux d'entreprises que vous listez. Ajoutez des slugs d'entreprises avant de l'activer. Apify peut entraîner des frais. Activez-le si vous le souhaitez. Sweepy n'installe pas automatiquement les packages optionnels. Vous n'avez pas besoin de sélectionner des moteurs pour chaque recherche. Choisissez explicitement uniquement quand un moteur nécessite une configuration, un consentement à un service payant, ou une contrainte de recherche.

Passez sources_config lorsque vous choisissez des moteurs explicitement. Sweepy conserve cette sélection au lieu d'ajouter d'autres moteurs. Ce JSON sélectionne deux moteurs :

{
  "enabled": ["jobspy", "openroles"],
  "openroles": {"companies": ["figma", "stripe"]}
}

Flux d'outils en un seul appel et hybrides​

Sweepy fonctionne selon deux schémas. Choisissez celui qui correspond au niveau de décision que vous souhaitez confier à l'assistant.

Flux en un seul appel. Votre assistant configure et exécute tout, et le moteur note chaque poste selon le chevauchement de mots-clés du CV.

create_profile -> run_sweep -> get_results -> export_report (facultatif)

Flux hybride avec état. Votre assistant examine chaque fiche et fournit son propre jugement avant la génération du rapport.

run_sweep -> get_jobs -> submit_judgments -> render_report

Un balayage actif peut continuer à tourner après un délai d'attente du client. Lorsque run_sweep renvoie sweep_status: "running", appelez get_sweep_status avec le job_id retourné jusqu'à ce qu'il signale completed. Continuez ensuite avec get_jobs.

astuce

Vous n'avez pas besoin d'un LLM pour obtenir un rapport fonctionnel. L'outil run_sweep seul génère le PDF complet de fiches à partir de champs déterministes, exactement comme un balayage depuis le terminal.

Chaque fiche affiche l'une de deux étiquettes de score :

  • NN% KEYWORD OVERLAP provient du moteur déterministe. Il compare le texte de votre CV avec chaque offre.
  • NN% MATCH provient de votre assistant. Il apparaît lorsque vous appelez submit_judgments avec une valeur match_pct.

get_jobs renvoie resume_documents, le texte analysé de chaque piste de CV, à côté des fiches. Votre assistant note ce texte de la même façon que l'ATS de l'offre l'analyse, puis enregistre ce qu'un analyseur perdrait dans concerns.

Vérifier et compléter les résultats du balayage​

Traitez chaque résultat de balayage comme un ensemble de départ, puis vérifiez chaque correspondance par rapport à l'offre. Après run_sweep, inspectez skipped_sources et signalez les échecs de source. Passez en revue les postes avec get_jobs, puis comparez chaque offre avec votre CV et vos préférences déclarées avant que votre assistant soumette un jugement LLM.

Lorsque votre assistant dispose d'outils web ou de recherche, demandez-lui de vérifier les postes prometteurs sur les pages carrières des employeurs ou leur ATS. Il peut également rechercher des postes pertinents que Sweepy a manqués, ajouter des offres vérifiées et non dupliquées via import_jobs, et inclure ces postes dans le rapport avec render_report. Votre assistant ne doit pas inventer d'offres ni compléter les détails manquants par des suppositions.

Le vérificateur d'URL de Sweepy garde certaines URLs comme non vérifiées lorsqu'un hôte bloque l'accès, limite les requêtes ou expire. Un 403 ou 429 ne prouve pas qu'une offre a expiré. Confirmez l'annonce sur une source d'employeur accessible si possible, ou traitez-la comme non vérifiée. Si votre assistant n'a pas d'outil de recherche, ou si les sources restent inaccessibles, signalez que les résultats peuvent être incomplets. Évitez de répéter un balayage avec des paramètres inchangés après une erreur.

Connexion à Antigravity ou Claude Desktop​

Ajoutez Sweepy au fichier de configuration MCP de votre client, nommé mcp_config.json ou claude_desktop_config.json selon le client :

mcp_config.json
{
  "mcpServers": {
    "sweepy": {
      "command": "python",
      "args": [
        "/path/to/sweepy/server.py"
      ]
    }
  }
}

Remplacez /path/to/sweepy par le chemin absolu de votre dossier Sweepy, puis redémarrez le client. Une fois enregistré, vous pouvez demander du travail comme ceci :

  • "Crée un profil Sweepy pour Alex qui recherche des postes de Rédacteur Technique à distance à New York. Le CV se trouve à path/to/resume.pdf."
  • "Lance un balayage avec le profil rédacteur et montre les 5 meilleures correspondances."
  • "Régénère le PDF du dernier balayage pedro_writer et enregistre-le sur le Bureau."
  • "Convertis path/to/notes.md en PDF à côté du fichier original."
Écrire en dehors du dossier Sweepy

Chaque outil d'écriture reste dans votre dossier Sweepy par défaut. Une demande d'enregistrement sur le Bureau échoue jusqu'à ce que vous définissiez la variable d'environnement SWEEPY_ALLOW_EXTERNAL_WRITES à 1.

Connexion à VS Code​

VS Code se connecte aux serveurs MCP sans extension supplémentaire :

  1. Ouvrez la Palette de Commandes et exécutez MCP: Add Server.
  2. Choisissez Command (stdio), puis saisissez python comme commande. Ajoutez le chemin absolu vers server.py comme argument.
  3. Nommez le serveur sweepy, puis choisissez la destination de configuration.
  4. Vérifiez que les outils Sweepy apparaissent dans le panneau de chat, puis appelez-les depuis là.

Pour un fichier limité à l'espace de travail, ajoutez .vscode/mcp.json à votre projet. Le format VS Code utilise un objet servers de niveau supérieur :

.vscode/mcp.json
{
  "servers": {
    "sweepy": {
      "type": "stdio",
      "command": "python",
      "args": [
        "/path/to/sweepy/server.py"
      ]
    }
  }
}

Installer la compétence /sweepy​

Sweepy fournit une compétence /sweepy pour Copilot CLI, Claude Code, Antigravity et autres outils en ligne de commande qui lisent les compétences. Copiez le dossier fourni dans le répertoire de compétences de votre outil :

Terminal
cp -r skills/sweepy ~/.claude/skills/sweepy   # adaptez au chemin des compétences de votre outil

Enregistrez le serveur MCP de la section précédente, puis redémarrez votre outil. La compétence documente trois flux principaux :

  • Démarrez un nouveau scraping en appelant create_profile, puis run_sweep.
  • Consultez les résultats d'un scraping en appelant get_results pour les meilleures correspondances et les guides, ou get_jobs pour l'ensemble complet de fiches.
  • Exportez les résultats dans un fichier CSV en appelant export_report avec formats=["csv"].

La compétence couvre également le recours pour les outils en ligne de commande sans support MCP :

Terminal
sweepy --setup                         # assistant interactif de configuration de profil
sweepy --profile profiles/your_profile.yaml
sweepy --docx resume.docx              # convertit un CV DOCX en PDF
sweepy --convert notes.md              # convertit tout document compatible en PDF

Tout configurer avec un seul prompt​

Copiez ce prompt et collez-le dans n'importe quelle session IA en ligne de commandes ou chat IDE :

Configurez Sweepy sur cette machine. Effectuez ces étapes dans l'ordre :

1. Clonez ou téléchargez le dépôt Sweepy.
2. Exécutez `pip install -r requirements.txt` à la racine du dépôt.
3. Enregistrez `server.py` dans la configuration MCP comme serveur stdio. Utilisez la commande `python` et des arguments pointant vers `server.py`.
4. Copiez le dossier `skills/sweepy` dans le répertoire de compétences du CLI.

En savoir plus sur les patterns de prompts​

Le fichier AGENTS.md du dépôt documente le séquençage des outils, les conseils par outil et les patterns de prompts. Lisez-le si vous souhaitez une automatisation plus poussée que les flux présentés sur cette page.
