Découvrez Sweepy

Sweepy automatise votre recherche d’emploi en collectant les offres disponibles et en analysant votre CV. Il évalue ensuite ces offres en fonction de vos compétences et génère un rapport quotidien des correspondances.

Sweepy s’adapte à vos besoins grâce à un fichier de configuration ; vous pouvez sélectionner des catégories telles que « Paralégal », « Analyste » ou « Coordinateur ».

Connaissances de base avec Alex​

Tout au long de ce guide, vous suivrez Alex, qui vient de se diplômer en sciences politiques et cherche des postes de « Paralégal » ou d’« Assistant juridique » à **New York City ». Alex n’a jamais utilisé de terminal, n’a jamais écrit de code et n’a même jamais vu de fichier de type YAML.

Ce guide vous accompagne, ainsi qu’Alex, depuis la mise en place jusqu’à une recherche d’emploi entièrement automatisée. Sweepy évalue les offres les mieux adaptées à votre profil et crée un répertoire PDF que vous pourrez utiliser quotidiennement.

Remarque

Vous n’avez pas besoin d’expérience en programmation pour utiliser Sweepy ; ce guide explique chaque étape du processus.

Fonctionnalités​

Sweepy vous fournit tout ce dont vous avez besoin pour trouver plus rapidement votre prochain emploi.

  • La fonction de recherche multiplateforme permet de parcourir les systèmes de suivi des candidats Greenhouse, Ashby, Lever et Workable, qui hébergent des annonces d’emploi publiques. Elle lit également les annonces disponibles sur le site Built In NYC, ainsi que sur LinkedIn, Indeed, Glassdoor et ZipRecruiter une fois ces sources activées.
  • Évaluation intelligente des CV : Sweepy lit votre fichier PDF ou Word de CV et extrait vos compétences. Il dirige chaque offre d’emploi vers la catégorie de CV correspondante, puis évalue votre profil en fonction de ces critères. Le système fonctionne sans clés API ni services payants.
  • Filtrage des liens cassés : Sweepy vérifie chaque offre avant que vous ne la consultiez. Il supprime les offres dont le lien est indisponible (statut “perdu”, page 404 ou erreur de connexion). Les limites de fréquence d’utilisation, les blocages de bots et les erreurs de serveur font que ces offres sont marquées dans le rapport sous la forme unverified.
  • Rapports PDF quotidiens : Les résultats sont compilés dans un fichier PDF. Chaque page contient par défaut six informations sur les offres d’emploi, avec des liens cliquables, des plafonds salariaux indiqués et des badges codés par couleur.
  • Feuille de calcul pour le suivi du processus : Un fichier CSV est généré, contenant tous les champs des offres ainsi qu’un extrait de 1 000 caractères de chaque offre, accompagné d’un fichier JSON destiné à d’autres outils. Ce fichier CSV inclut des colonnes pour suivre l’avancement de l’offre (date de soumission, état, étape de l’interview, montant de l’offre, date de l’offre, date de suivi, contact et notes). Sweepy conserve les informations que vous saisissez pour les futures analyses du même profil. Le fichier CSV peut être ouvert avec Microsoft Excel, Google Sheets ou Notion ; le fichier PDF fournit une vue agréable des offres avec des liens pour postuler. La feuille de calcul enregistre l’ensemble du processus, y compris les informations dépassant le nombre maximal de lignes autorisé par le format PDF.

Comment cela fonctionne​

Une campagne de recrutement réussie suit cinq étapes.

  1. Chargez votre profil. Sweepy lit votre fichier de configuration, qui contient vos titres de poste, votre lieu de travail et l’emplacement de votre CV.
  2. Découvrez les postes disponibles. Sweepy parcourt les plateformes de recrutement et les flux d’offres d’emploi pour trouver des annonces correspondantes.
  3. Valider les liens. Sweepy vérifie chaque lien et supprime les publications qui renvoient un statut d’inaccessibilité (page 404 ou erreur de connexion). Les publications contenant des liens non vérifiables restent dans le processus de traitement, mais sont marquées comme telles. 0.
  4. Évaluation des correspondances. Sweepy analyse votre fichier de CV en PDF ou Word et calcule un pourcentage de correspondance pondéré pour chaque poste.
  5. Générer des rapports. Sweepy compile les résultats sous forme de fichiers PDF et CSV, ou les exporte sous format JSON.

Limitations​

Par conception, Sweepy couvre uniquement une partie limitée du marché du travail. Il est associé à un modèle linguistique via le serveur Model Context Protocol (MCP), qui gère les paramètres par défaut. Lorsque les résultats fournis par l’outil Solo et ceux du serveur MCP sont identiques, cette limitation affecte les deux versions de Sweepy.

Guide de planification des mises à jour​

Ce guide vous guide à travers quatre étapes :

  1. Installez Sweepy sur votre ordinateur. Voir Installation.
  2. Configurez un profil de recherche d’emploi personnalisé, comme celui d’Alex, un paralégal à New York. Voir Configuration de Sweepy.
  3. Exécutez votre première recherche d’emploi automatisée et observez son fonctionnement. Voir Première recherche.
  4. Lisez votre rapport PDF personnalisé et comprenez les résultats, les badges obtenus ainsi que les stratégies d’application. Voir Interprétation des résultats.
Où se trouve Sweepy

Sweepy est open source. Consultez le code source, signalez les problèmes rencontrés sur Issues, ou téléchargez un fichier ZIP depuis Releases. GitHub vous permet d’accéder à ces informations sans avoir de compte.
