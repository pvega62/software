Comprendre vos résultats

Vous avez effectué votre première recherche et généré vos fichiers de rapport quotidiens. Cette page vous guide à travers les données trouvées par Sweepy.

Ouvrez le rapport d'exemple provenant de la recherche de Alex en tant que paralégal. Il affiche six résultats pour une seule catégorie de CV. Utilisez-le comme référence pour suivre les étapes.

Lecture des rapports PDF​

Ouvrez le fichier PDF dans votre dossier results. Sweepy crée un répertoire avec 6 éléments par page, classés par ordre décroissant du pourcentage de correspondance.

Chaque élément représente une offre d’emploi active. Voici un exemple de résultat issu de la recherche d’Alex en tant que paralégal :

Score de correspondance​

L’algorithme analyse la description de l’emploi et la compare avec le texte extrait de votre CV ou de votre fichier Word. Le chevauchement des exigences représente 60 % du score total, tandis que le chevauchement des mots-clés représente les 40 % restants :

  • Le chevauchement des exigences mesure la partie de la description de l’emploi qui est déjà présente dans votre CV.
  • Le chevauchement des mots-clés mesure la proportion de termes de votre CV qui se retrouvent également dans l'annonce.

Un score de 75 % signifie que l’offre d’emploi et votre CV couvrent la plupart des mêmes critères évalués pour les deux indicateurs. Un critère indiqué comme obligatoire pèse le double d’un critère non spécifié, tandis qu’un critère souhaitable pèse la moitié.

Lorsqu’une recherche est effectuée, une étiquette « 75% KEYWORD OVERLAP » est affichée à côté du score. Cette étiquette représente le score global, et non la part de 40 %. Un modèle connecté via le Model Context Protocol (MCP) peut définir son propre pourcentage ; dans ce cas, l’étiquette affichée est « 75% MATCH ». La fiche d’exemple montre l’étiquette d’un agent. Le guide de notation explique la formule complète utilisée pour calculer le score.

get_jobs retourne le texte analysé de chaque section d’un CV présentée dans resume_documents. Le modèle lit ce fichier au lieu de votre liste de mots-clés, puis l’évalue selon la manière dont un système de suivi des candidats analyse ce contenu. Un terme situé à l’intérieur d’une table, d’un en-tête, d’une image ou d’une barre latérale pèse moins que le même terme dans une section standard.

astuce

Le badge keywords_weight indique la section de votre CV vers laquelle l’annonce d’emploi a été dirigée par le système Sweepy. Si votre profil spécifie une section particulière, le système enverra l’annonce correspondante. Pour les profils contenant un seul CV, le nom du fichier CV sera utilisé comme nom de la section.

Le badge [SUBMIT: <resume track>] indique le « resume track » vers lequel Sweepy a acheminé la mission. Lorsque votre profil définit resume.tracks, le moteur envoie chaque offre d’emploi vers le « resume track » qui partage le plus de termes avec celle-ci. Le badge s'affiche dans la couleur de cette piste. Un profil à CV unique utilise le nom du fichier du CV comme nom de piste.

Rémunération et avantages​

La rubrique « Rémunération » affiche une fourchette formatée lorsque Sweepy détecte des données salariales. Les métadonnées de Greenhouse, les fourchettes salariales de Lever et les échelons de rémunération d’Ashby fournissent des champs structurés. Le site d’offres d’emploi new-yorkais « Built In NYC » indique le salaire dans chaque annonce, et Sweepy le récupère. Workable ne transmet pas de données salariales ; Sweepy extrait donc le premier chiffre fiable figurant dans le texte de l'offre d'emploi.

Les fiches indiquent l’unité de temps de travail utilisée : les postes à temps partiel sont désignés par « $45 - $55 / hour », ceux à temps plein par « $8K - $10K / month », et ceux annuels par « $85K - $110K ». La fonctionnalité « Sweepy » ignore les informations relatives aux bonus, aux participations au capital, aux tours de financement ou aux indemnités. Définissez dans votre profil que seules les informations structurées soient affichées (paramètre « search.salary_from_description: false »).

Le badge « Soumettre »​

Les cartes deux à quatre présentent les scores des matchs, le taux horaire, l’échelle de salaires, ainsi qu’une carte pour laquelle Sweepy n’a pas trouvé de données sur les rémunérations](./sample_report_cards.png "Ouvrez l’image en haute résolution")

Le filtre search.min_salary compare les salaires annuels. Sweepy convertit un taux horaire en fonction de 2 080 heures de travail par an, ainsi qu’un taux mensuel en fonction de 12 mois. Il supprime ensuite tous les postes dont le salaire annuel maximal est inférieur à search.min_salary.

Les avantages sont toujours affichés sous la forme Not disclosed, sans modèle. Un modèle connecté via MCP écrit les deux lignes via submit_judgments et peut fournir des données de paiement qui n’ont jamais été publiées par le conseil d’administration.

Conseils d’application et guide pratique​

Une suggestion pour chaque carte et le tableau de stratégie de clôture ont des objectifs différents : chaque carte affiche sa propre suggestion, et le rapport se termine par un tableau de stratégies.

Conseil d'utilisation : ce message s'affiche sur chaque fiche. Le responsable du recrutement sélectionne les trois termes communs entre l'offre d'emploi et votre CV, puis les mentionne dans une seule phrase. Lorsqu'aucun terme ne se recoupe, le conseil se transforme en instruction générique.

Application Tip lines
Highlight your Litigation Support, document management, court filings experience in your application.
Tailor your cover letter to the core responsibilities listed in the role.

Un modèle peut remplacer la ligne submit_judgments par le champ alignment.

Playbook apparaît une fois par rapport, après la dernière fiche de la dernière page. Le titre est APPLICATION STRATEGY // DUAL RESUME ROUTING & WORKFLOW PLAYBOOK. Le tableau regroupe les rôles « amber » et les rôles « slate », puis indique le nombre de rôles couverts par chaque parcours de CV.

Via le MCP, un assistant peut remplacer ces informations par sa propre note stratégique. Transmettez ce texte à la fonctionnalité « render_report » sous forme de texte normal ; il sera affiché de manière similaire à ce que vous avez saisi. Les symboles & et < seront conservés tels quels, les sauts de ligne seront transformés en nouveaux paragraphes, et l’indication « **bold** » servira à mettre en évidence certains éléments. La fonctionnalité « Sweepy » enregistre cette note avec les données de la session de recherche. Les futures versions du rapport conserveront cette information.

Liens cliquables​

Chaque carte renvoie directement à l’annonce elle-même. Un lecteur intégré ouvre la page de carrière de l’employeur, tandis qu’un agrégateur affiche la source de l’annonce. En cliquant sur [Apply on <platform> Job Board], la page s’ouvre dans votre navigateur. Sweepy récupère les informations sur les rôles directement depuis les plateformes Greenhouse, Lever, Ashby, Workable et Built In NYC. Les moteurs optionnels openroles et jobdrop incluent également Workday.

Badge d’application et parcours de CV​

Sweepy analyse chaque annonce pour détecter les éléments nécessitant une réponse détaillée et ajoute un badge à chaque carte. Ce badge indique l’importance des efforts requis avant d’ouvrir le lien.

  • Les cartes Slate correspondent aux candidatures standard ou aux demandes de postulation rapide. L’application demande l’envoi d’un CV et des informations de contact de base. La traitement de ces candidatures prend généralement quelques minutes.
  • Les cartes Amber nécessitent des réponses écrites détaillées. L’application exige des exemples de portefeuille, une lettre de couverture ou des textes personnalisés sur l’entreprise.
Stratégie de gestion du temps

Utilisez les badges pour gérer votre rythme de travail : soumettez entre cinq et dix candidatures de type Slate pendant une pause de 15 minutes. Réservez les candidatures de type Amber pour des moments où vous disposez d’une heure entière pour rédiger des réponses adaptées.

Utilisation de l’exportation CSV​

En plus du fichier PDF, le moteur génère un fichier CSV associé. CSV signifie « Comma Separated Values » (valeurs séparées par des virgules) ; ce fichier contient des données brutes sous forme de tableau.

Le format PDF est adapté à la lecture et à l’ouverture des liens. Le format CSV permet le suivi des données. Chaque ligne du fichier CSV contient les informations de la fiche ainsi qu’un extrait de l’offre d’emploi. La fonctionnalité « Sweepy » limite cet extrait à 1 000 caractères et respecte les règles de formatage des cellules de Notion (maximum de 2 000 caractères). Les colonnes « badge », « match_score », « min_amount », « max_amount », « currency », « key_matches », « missing_skills » et « playbook » affichent les mêmes informations que le PDF (badges, pourcentages, plafonds salariaux, conseils pour la candidature). Le fichier CSV inclut également des postes qui dépassent la limite de 24 fiches imposée par le format PDF.

Suivi dans Microsoft Excel ou Google Sheets​

Le fichier CSV se termine par huit colonnes de suivi : date_applied, status, interview_stage, offer_amount, offer_date, follow_up_date, contact et notes. Remplissez-les au fur et à mesure que votre processus avance. Faites un double-clic sur le fichier .csv pour l’ouvrir dans Excel, ou téléchargez-le dans Google Sheets.

Sweepy lit les données exportées précédemment pour le même profil et copie vos entrées dans le fichier le plus récent. Un rôle que vous avez marqué comme Appliqué lundi reste indiqué comme Appliqué vendredi. Les correspondances se font en fonction du lien de publication ; un lien remplacé conserve donc les mêmes informations relatives au rôle, à l’entreprise et à la localisation. Vous pouvez désactiver ces colonnes en utilisant export.tracking: false dans le profil, ou depuis les Paramètres de nettoyage (Sweep Settings).

Importer dans Notion​

L’application Notion ajoute les lignes du fichier CSV à une base de données complète. Elle ne met jamais à jour les données existantes ; importez donc un fichier unique pour suivre les modifications ultérieures directement dans Notion.

Pour importer le fichier CSV dans une base de données Notion :

  1. Ouvrez votre espace de travail Notion.
  2. Créez une page et sélectionnez Tableau ou Panneau de contrôle sous Commencer.
  3. Ouvrez le menu ... dans la base de données affichée en plein écran, choisissez Fusionner avec un fichier CSV, puis sélectionnez le fichier que vous avez généré.
  4. Associez chaque colonne du fichier CSV à une propriété de Notion. Notion créera une propriété pour chaque en-tête ; les en-têtes qui correspondent à des propriétés existantes seront utilisés pour remplir ces nouvelles propriétés.

Notion ne peut pas créer de relations, de résumés ou de formules à partir d’un fichier CSV.

Votre tour d'horizon quotidien​

Vous avez installé Sweepy et configuré votre profil de recherche. Vous avez également lu vos premiers rapports de résultats.

Vous disposez maintenant de tout ce dont vous avez besoin pour automatiser votre recherche d’emploi. Exécutez la recherche chaque matin, puis postulez pour les candidatures qui vous intéressent le plus.

Bonne chance.
