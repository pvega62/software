Installer Sweepy

Trois éléments sont nécessaires sur votre ordinateur avant de lancer Sweepy :

  1. Python : le langage de programmation qui fait tourner le moteur.
  2. Git : un outil qui télécharge le code du moteur depuis Internet.
  3. pip : un gestionnaire de paquets qui installe les bibliothèques supplémentaires du moteur. Les programmes d’installation officiels de Windows et macOS incluent pip. Les distributions Linux ajoutent pip via le gestionnaire de paquets du système.
Remarque

Ce guide détaille chaque étape pour une personne qui n’a jamais ouvert de terminal. Si vous avez déjà Python 3.10+ et Git, passez directement à l’étape 3.

Étape 1 : ouvrir votre terminal​

Un terminal, aussi appelé invite de commandes, est une fenêtre textuelle où vous tapez des commandes. Vous y saisissez des instructions pour votre ordinateur au lieu de sélectionner des icônes.

  • Windows
  • macOS
  • Linux

Appuyez sur la touche Windows, tapez PowerShell, puis sélectionnez Windows PowerShell.

Terminal
Windows PowerShell
Copyright (C) Microsoft Corporation. All rights reserved.

PS C:\Users\YourName>

Appuyez sur Command + Espace, tapez Terminal, puis appuyez sur Entrée.

Terminal
Last login: Mon Oct 19 14:40:23 on ttys000
yourname@MacBook-Pro ~ %

Appuyez sur Ctrl + Alt + T pour ouvrir une fenêtre de terminal sur la plupart des distributions Linux.

Terminal
yourname@ubuntu:~$

L’invite se termine par un curseur clignotant. Ce curseur indique que votre terminal attend une commande.

Étape 2 : vérifier et installer Python​

Sweepy exige Python 3.10 ou une version plus récente. Vérifiez si vous l’avez déjà.

Tapez cette commande dans votre terminal et appuyez sur Entrée :

Terminal
python --version

Sur macOS et Linux, la commande est python3 --version.

Si vous voyez Python 3.10.x ou une version supérieure, Python est déjà installé. Passez à l’étape 3.

Si vous voyez un message d’erreur comme 'python' is not recognized ou une version inférieure à 3.10, suivez les étapes d’installation ci-dessous.

  • Windows
  • macOS
  • Linux
  1. Ouvrez la page de téléchargement de Python pour Windows.
  2. Sélectionnez le lien de téléchargement Windows installer (64-bit) le plus récent.
  3. Exécutez le fichier téléchargé.
  4. Cette étape est essentielle. Sur le premier écran de l’installateur, cochez la case « Add python.exe to PATH » en bas. Cette case ajoute Python au PATH, où le terminal le trouve.
  5. Sélectionnez Install Now et attendez la fin de l’installation.

Confirmez ensuite l’installation dans une nouvelle fenêtre de terminal :

Terminal
PS C:\Users\YourName> python --version
Python 3.13.1
attention

Si vous omettez « Add python.exe to PATH », votre terminal ne reconnaît pas la commande python. Désinstallez Python, puis réinstallez-le avec la case cochée.

  1. Ouvrez la page de téléchargement de Python pour macOS.
  2. Téléchargez le programme d’installation macOS 64-bit universal2 le plus récent.
  3. Ouvrez le fichier .pkg téléchargé et suivez les invites d’installation.

Confirmez ensuite l’installation dans une nouvelle fenêtre de terminal :

Terminal
yourname@MacBook-Pro ~ % python3 --version
Python 3.13.1

Lancez ces deux commandes dans votre terminal :

Terminal
sudo apt update
sudo apt install python3 python3-pip python3-venv
astuce

Sur Fedora ou Red Hat Enterprise Linux, remplacez apt par dnf : sudo dnf install python3 python3-pip.

Confirmez ensuite l’installation dans une nouvelle fenêtre de terminal :

Terminal
yourname@ubuntu:~$ python3 --version
Python 3.12.3

Les onglets Windows, macOS et Linux se terminent par la même vérification. Fermez votre terminal, rouvrez-le et lancez la commande de version. Un numéro de version 3.10 ou supérieur signifie que Python est prêt.

Étape 3 : télécharger Sweepy​

Télécharger les fichiers source de Sweepy

Choisissez une méthode. Utilisez Git, décrit ci-dessous, ou téléchargez un fichier ZIP depuis la page des versions de Sweepy.

Git copie les fichiers du projet sur votre ordinateur et enregistre leur historique. Cet historique permet à Sweepy de se mettre à jour seul. Les étapes ci-dessous utilisent Git.

  • Copie Git. Lancez sweepy --update ou l’outil de mise à jour de Sweepy's Toolbox pour récupérer chaque nouvelle version.
  • Copie ZIP. Téléchargez, décompressez et relancez pip install -e . pour chaque version. Les mises à jour automatiques restent désactivées, car un ZIP n’a aucun historique Git à récupérer.
  • Nom du dossier. Git crée un dossier sweepy. Un ZIP se décompresse dans un dossier comme sweepy-main, alors adaptez la commande cd plus loin dans cette étape.

Choisissez le ZIP pour un essai ponctuel. Choisissez Git si vous comptez continuer à utiliser Sweepy.

Vérifiez d’abord si Git est déjà installé :

Terminal
git --version

Si vous voyez un numéro de version comme git version 2.45.1, Git est installé. Si vous voyez une erreur, installez Git :

  • Windows
  • macOS
  • Linux
  1. Ouvrez git-scm.com/download/win.
  2. Téléchargez et exécutez le programme d’installation.
  3. Acceptez tous les paramètres par défaut et sélectionnez Install.
  4. Fermez et rouvrez votre terminal, puis vérifiez :
Terminal
PS C:\Users\YourName> git --version
git version 2.45.1

Lancez cette commande : macOS vous propose alors d’installer les Xcode Command Line Tools, qui incluent Git :

Terminal
yourname@MacBook-Pro ~ % git --version
xcode-select: note: install requested for command line developer tools

Suivez l’invite à l’écran pour installer, puis relancez git --version. Un numéro de version signifie que Git est prêt.

Terminal
yourname@ubuntu:~$ sudo apt install git

Vérifiez ensuite :

Terminal
yourname@ubuntu:~$ git --version
git version 2.45.1

Téléchargez maintenant Sweepy en lançant :

Terminal
git clone https://github.com/pvega62/sweepy.git

Cette commande crée un dossier sweepy sur votre ordinateur. Placez-vous dedans :

Terminal
cd sweepy
astuce

Git crée le nouveau dossier dans le répertoire où pointait votre terminal au moment de la commande. Sous Windows, une nouvelle fenêtre PowerShell démarre dans C:\Users\YourName\.

Étape 4 : installer les dépendances​

Sweepy s’appuie sur quelques bibliothèques supplémentaires :

  • pymupdf : lit et extrait le texte de votre CV PDF.
  • python-docx : lit et convertit les CV .docx.
  • python-jobspy : extrait les offres des sites d’emploi sans clé API.
  • beautifulsoup4 : analyse le HTML des sources Greenhouse, Lever, Workable et Built In.
  • reportlab : génère le rapport PDF mis en forme avec des liens cliquables.
  • requests : envoie des requêtes web pour vérifier si les URL répondent encore.
  • pyyaml et questionary : gèrent l’assistant de configuration interactif. prompt-toolkit fournit ses commandes clavier.
  • pandas : structure les données d’offres extraites et construit les exports tableur CSV.
  • mcp et anyio : font tourner le serveur Model Context Protocol optionnel qui relie Sweepy à un assistant IA.
Python 3.13

Si vous utilisez Python 3.13, installez d’abord les Microsoft C++ Build Tools et sélectionnez la charge de travail « Desktop development with C++ ». Python 3.13 est assez récent pour que certains paquets, comme pymupdf, se compilent depuis les sources et exigent ces outils. Ignorez cette étape avec Python 3.12 ou une version antérieure.

Les tests automatisés de Sweepy couvrent Python 3.10 à 3.12. Ces versions restent le chemin le plus simple.

Installez tous les paquets avec une seule commande :

Terminal
pip install -e .

Cette commande installe toutes les dépendances et enregistre une commande sweepy dans votre dossier Python Scripts. Rouvrez votre terminal une fois pour que le PATH prenne en compte le nouveau dossier. Ensuite, lancez sweepy --run au lieu de python swee.py --run. Lancez l’une ou l’autre forme depuis votre dossier sweepy.

Le texte défile pendant que Python télécharge et installe chaque paquet. L’installation se termine quand le curseur revient.

astuce

Vous avez reçu une erreur « command not found » pour pip ? Essayez plutôt pip3 install -e .. Sur certains systèmes, Python 3 utilise pip3 comme nom de commande.

Vérifier votre installation​

Lancez cette vérification rapide pour confirmer que tout est installé correctement :

Terminal
sweepy --version

Si votre shell ne trouve pas sweepy, rouvrez le terminal ou lancez plutôt python swee.py --version. Vous verrez :

Sortie du terminal
Sweepy v3.0.0
Python 3.13.1 | pymupdf 1.28.2 | reportlab 5.0.1
Ready to sweep.

Si ce message apparaît, Sweepy est prêt. Attendez-vous à des numéros différents sur votre machine. Sweepy affiche la version de son fichier VERSION, et pip installe les paquets correspondant à votre version de Python.

La deuxième ligne indique les versions de pymupdf et de reportlab.

Ensuite, configurez votre profil de recherche personnalisé.
