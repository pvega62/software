Utiliser Postman pour se connecter à l'API Stripe

À la fin de cette page, vous disposez d'une collection Stripe dupliquée avec Fork et d'un environnement Postman qui authentifie chaque requête avec votre clé d'API. Vous envoyez une requête pour confirmer que Stripe accepte la clé.

Postman envoie les requêtes et affiche les réponses. Un espace de travail partagé maintient votre équipe sur la même collection.

Prérequis de connexion​

Rassemblez ces éléments avant de commencer :

  • Un compte Postman.
  • Un compte Stripe avec accès au Stripe Dashboard.
  • Un accès réseau à https://api.stripe.com/, l'adresse de base des requêtes à l'API Stripe.

Configurer Postman​

  1. Téléchargez et installez l'application Postman.

  2. Ouvrez l'application Postman et terminez la configuration.

    Vous voyez la présentation de l'espace de travail, avec le champ de recherche en haut de la fenêtre.

  3. Saisissez « Stripe » dans le champ de recherche, puis sélectionnez l'espace de travail Stripe Developers.

    Le résultat affiche l'espace de travail Stripe Developers. La ligne en dessous indique Stripe Developers APIs.

  4. Sélectionnez l'icône Collections, puis choisissez la collection dont le nom contient la date la plus récente.

  5. Sélectionnez Fork pour ajouter la collection à votre espace de travail.

    Vous voyez la collection dupliquée sous Collections dans votre espace de travail.

Copier votre clé d'API​

Stripe authentifie chaque requête d'API avec une clé d'API, envoyée via HTTPS, et lit la clé dans un en-tête Authorization. Basic Auth et les jetons bearer fonctionnent tous les deux.

Votre compte contient déjà des clés : copiez une clé existante au lieu d'en générer une. Stripe recommande une clé d'API restreinte pour les nouvelles intégrations, car elle accorde uniquement les autorisations que vous choisissez. Une clé secrète fonctionne aussi et accorde un accès illimité. Les clés restreintes commencent par rk_, et les clés secrètes par sk_. Ces étapes couvrent les deux types.

  1. Accédez au Stripe Dashboard et créez votre compte.

  2. Ouvrez Developers > API keys et affichez une clé secrète, ou créez une clé restreinte avec les autorisations dont vos requêtes ont besoin.

  3. Sélectionnez la clé pour la copier dans le presse-papiers.

    Remarque

    Ne partagez jamais votre clé d'API avec d'autres utilisateurs.

  4. Revenez à l'application Postman.

  5. Sélectionnez Environments, puis sélectionnez Add (+).

  6. Saisissez un nom dans le champ Name, par exemple Stripe API.

  7. Saisissez secret_key dans la cellule Variable, puis collez la clé copiée dans la cellule Current Value.

  8. Sélectionnez Save.

  9. Ouvrez le menu déroulant Environment, puis choisissez Stripe API.

    Le menu déroulant affiche Stripe API. Postman ajoute votre clé à chaque requête.

Vérifier la connexion​

Envoyez une requête qui exige votre clé. L'endpoint de solde lit les données du compte. Une réponse 200 prouve que la clé fonctionne.

  1. Ouvrez la collection dupliquée et sélectionnez une requête GET, par exemple /v1/balance.

  2. Sélectionnez Send.

    Réponse réussie

    Une réponse 200 OK renvoie du JSON, ce qui confirme que Stripe a accepté la clé.

    Réponse d'erreur

    Une réponse 401 signifie que Postman n'a pas envoyé de clé valide. Vérifiez que le nom de la variable correspond à celui de la collection. Vérifiez aussi que Current Value contient la clé d'API et non la clé publique.

    Une réponse 403 signifie que la clé n'a pas l'autorisation requise pour cet endpoint. Accordez l'autorisation dans le Dashboard, ou utilisez une clé avec un accès plus large.
