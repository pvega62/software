إصلاح مشكلة ترميز/فك ترميز المصفوفات ذات الترتيب F في بروتوكول protobuf

سياق النموذج

التصحيحات المقدمة، وأداة إعادة إنتاج المشكلة، وعنوان المشكلة المذكور أدناه مأخوذة من تمرين تم إعطاؤه لي؛ رسالة الإرسال (commit message) ووصف طلب السحب (pull request description) هما من تأليفي.

بيان المشكلة​

يفشل ترميز/فك ترميز مصفوفات NumPy عندما تكون مرتبة حسب ترتيب F باستخدام بروتوكول protobuf.

الاختبار​

import numpy

from mcbackend.npproto.utils import ndarray_from_numpy, ndarray_to_numpy

arrC = numpy.array([
    [1,2,3],
    [4,5,6],
], order="C")

arrF = numpy.array([
    [1,2,3],
    [4,5,6],
], order="F")

assert arrC.strides != arrF.strides

numpy.testing.assert_array_equal(
    arrC,
    ndarray_to_numpy(ndarray_from_numpy(arrC)),
)
numpy.testing.assert_array_equal(
    arrF,
    ndarray_to_numpy(ndarray_from_numpy(arrF)),
)

رسالة الالتزام​

Fix encoding/decoding of F-ordered NumPy arrays

`bytes(arr.data)` materializes the buffer contents in C order, so encoding a
Fortran-ordered array pairs C-ordered bytes with Fortran strides. Decoding
then reads those bytes with the wrong strides and returns a scrambled array.

Record the memory order in a new `order` field of the `Ndarray` message, and
let `ndarray_to_numpy` transpose and reshape when that field reports "F".
Buffers encoded before 0.2.4 have an empty `order` field, so decoding them
yields C-ordered arrays.

Closes #63

طلب سحب​

ملخص​

عملية تبادل البيانات باستخدام بروتوكول Protobuf تتسبب في تلف مصفوفات NumPy التي تستخدم ترتيب البيانات بطريقة Fortran؛ حيث تعود المصفوفة بعد التشفير بقيم في مواقع خاطئة. لا يتم إظهار أي خطأ أثناء عملية التشفير، ويقبل المستخدم المصفوفة المشوهة.

Round-trip test
arrF = numpy.array([[1, 2, 3], [4, 5, 6]], order="F")
numpy.testing.assert_array_equal(
    arrF,
    ndarray_to_numpy(ndarray_from_numpy(arrF)),  # returns [[1, 3, 5], [2, 4, 6]] without the fix
)

السبب الجذري​

المتغير ndarray_from_numpy يخزن البيانات الخام بجانب معلومات ترتيب الخلايا في المصفوفة، وهاتان المعلومتان تشيران إلى تخطيطات ذاكرة مختلفة:

  1. عملية الترميز: يقوم المتغير bytes(arr.data) بتنظيم البيانات وفقًا لترتيب لغة C، لذا فإن المصفوفة المرسلة بترتيب Fortran تُحول إلى بتات بترتيب C.
  2. معلومات ترتيب الخلايا (Strides): يقوم المتغير ndarray_from_numpy بنسخ قيم المتغير strides دون تغيير، مما يحافظ على ترتيب البيانات وفقًا للغة Fortran.
  3. تفسير: تُطبق الدالة numpy.ndarray(buffer=..., strides=...) خطوات «فورتران» (Fortran strides) على البايتات المرتبة وفقًا لترتيب لغة C. وتؤدي هذه الإزاحات إلى تحديد عناوين خلايا خاطئة وإرجاع قيم خاطئة.

إصلاح​

تسجيل ترتيب البيانات في الذاكرة أثناء التشفير. وإعادة تشغيله أثناء فك التشفير.

  • يحصل كل من الرمز *protobufs/npproto/ndarray.proto والرمز المولد mcbackend/npproto/__init__.py على حقل نصي من نوع order (بترميز ٥) ضمن الرسالة Ndarray.
  • يكتب الملف mcbackend/npproto/utils.py order="CF"[arr.flags.f_contiguous] أثناء الترميز. يخزن المصفوفة المرتبة وفقًا لترتيب Fortran "F". أثناء عملية فك الترميز، تقوم ndarray_to_numpy بتبديل المصفوفة وإعادة تشكيلها عندما تكون nda.order == "F". تعمل هذه الخطوة على إعادة بناء تخطيط Fortran من البايتات المرتبة وفقًا لترتيب C.
  • يقوم الكود المشار إليه بـ mcbackend/test_npproto.py أيضًا بإضافة قيمة test_byteorders، والتي تُستخدم لتحديد معاملات تنفيذ العمليات على البيانات المخزنة في المصفوفة shape وorder.

الاختبارات​

يقوم الكود المشار إليه بـ TestUtils.test_byteorders بتحديد معلمات المتغيرات shape وorder معًا. كل من الأكواد المشار إليها بـ (5,)، *(2, 3)، (2, 3, 5)، و(5, 2, 1, 7) تُنفذ مرتين، مرة وفقًا لترتيب الذاكرة. في كل حالة، يتم التأكد من أن القيم الموجودة في المتغير *nda.order تطابق القيم الموجودة في المتغير *arr.flags.f_contiguous، ثم يتم إعادة المصفوفة عبر عمليات الترميز وفك الترميز.

لا تزال الدالة TestUtils.test_conversion تغطي أنواع البيانات التالية: int، و float، و scalar، و string، و object، و datetime.

ملاحظات​

  • تم رفع الإصدار إلى القيمة 0.2.4.
  • تتضمن وظيفة ndarray_to_numpy خطوة التناظر وتحتفظ بالطريقة الحالية للتعامل مع المخزن المؤقت ونوع البيانات.
  • المخازن المؤقتة (Buffers) المشفرة قبل علامة 0.2.4 تحتوي على حقل فارغ (order). فك تشفير أي من هذه المخازن ينتج عنه مصفوفة مرتبة بترتيب C.
