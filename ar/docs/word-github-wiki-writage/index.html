سير العمل من مايكروسوفت وورد إلى GitHub Wiki باستخدام Writage

مقدمة​

هذا دليل حول كيفية استخدام الأداة الإضافية Writage لمايكروسوفت وورد لكتابة وتحرير صفحات ويكي GitHub مباشرةً من وورد.

قد يكون هذا مفيدًا للكتّاب الذين يفضلون واجهة Word وميزاته المألوفة، مع الاستمرار في الاستفادة من إمكانيات التحكم في الإصدار والتعاون في GitHub.

Writage هي وظيفة إضافية لمحرر Markdown ل Microsoft Word. يسمح للمستخدمين بكتابة وتحرير مستندات Markdown مباشرةً داخل Word، مما يسهل إنشاء وتنسيق المحتوى لويكي GitHub.

سيظهر مستند Markdown الذي تم دفعه إلى مستودع الويكي كصفحة جديدة على الويكي.

المتطلبات الأساسية​

  • [الوظيفة الإضافية لبرنامج Microsoft Word] (https://www.writage.com/). :::ملاحظة تأتي Writage مع نسخة تجريبية مجانية لمدة 14 يومًا. بعد ذلك، سيتعين عليك شراء ترخيص. :::
  • [أحدث إصدار من Microsoft Word] (https://www.microsoft.com/en-us/microsoft-365/download-office).
  • أحدث إصدار من GitHub Desktop.
  • مستودع GitHub الحالي مع ويكي.

تعليمات​

إعداد الكتابة​

  1. اتبع مطالبات التثبيت لإعداد الوظيفة الإضافية Writage.

![رسم بياني يوضح عملية تثبيت Writage] (./media/03702a0000abd3bd3b3b4f499eac060250250660755.png)

Writage في Microsoft Word​

بمجرد تثبيت الوظيفة الإضافية Writage، يمكنك كتابة مستند Markdown وتحريره مثل مستند Word العادي. باستخدام Writage، يمكنك فتح ملفات Markdown الموجودة مباشرةً في Word، وحفظ مستندات Word كملفات Markdown.

تحويل مستند Markdown إلى ملف PDF​

  1. افتح مستند Markdown في Word.
  2. انقر ** ملف > حفظ باسم.**.
  3. حدد PDF في القائمة المنسدلة لنوع الملف.
  4. احفظ الملف في الموقع المختار.

استنساخ GitHub Wiki إلى GitHub Desktop​

لا يقوم GitHub Desktop باستنساخ GitHub Wiki تلقائيًا. سيتعين عليك استنساخه يدويًا.

  1. افتح الويكي وانسخ عنوان URL في الزاوية اليمنى السفلى من الصفحة.

    ![لقطة شاشة للصفحة الرئيسية لهذا الويكي] (./media/image-1.png)

  2. في GitHub Desktop، اضغط على CTRL+SHIFT+O لفتح مربع حوار "استنساخ مستودع".

  3. انقر على علامة التبويب URL.

  4. الصق عنوان URL الخاص بالويكي واضغط استنساخ.

    ![لقطة شاشة لمربع حوار استنساخ في GitHub Desktop] (media/d122bfeed3d1e921e921e4c42291d537a828.png)

دفع مستند Markdown إلى ويكي GitHub​

بمجرد أن تكتب مستند Markdown في Word، يمكنك دفعه إلى ويكي مستودع GitHub Repository دون الحاجة إلى نسخه ولصقه إلى محرر GitHub Markdown وتنسيقه هناك.

  1. احفظ مستند Markdown في مجلد الويكي الذي تم إعداده عند تثبيت GitHub Desktop.
  2. افتح تطبيق GitHub Desktop.
  3. حدد مستودع الويكي.
  4. التزم بالتغييرات (أضف ملخصًا).
  5. اضغط CTRL+P لدفع التغييرات إلى الويكي.

ملاحظة: أضف ملخصًا إلى الملف قبل أن يتم دفعه إلى الويكي. يصف الملخص بإيجاز التغييرات التي تم إجراؤها على المستند، مما يساعد المساهمين الآخرين على فهم التحديثات دون قراءة المستند بأكمله.

![لقطة شاشة لمربع حوار الالتزام في GitHub Desktop] (media/caffdbbb3233d43fbc83f51e5f63d99c9.png)

  1. افتح الويكي في متصفح للتحقق مرة أخرى من الويكي المحدث.

كرر الخطوات لدفع المستند إلى GitHub عند إنشاء مستند جديد أو تحرير مستند موجود.
