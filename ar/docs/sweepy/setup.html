إعداد Sweepy

لقد قمت بتثبيت Sweepy! الآن تحتاج إلى ملف تكوين؛ هذا الدليل سيساعدك في إنشاء ذلك الملف وبدء أول عملية بحث لديك.

ملف التكوين يحدد الموقع المستهدف، أسماء الوظائف التي تريد البحث عنها، والسيرة الذاتية التي سيتم استخدامها لتقييم تلك الوظائف.

ملف التكوين عبارة عن ملف نصي صغير بصيغة YAML؛ يتم تنظيم البيانات فيه باستخدام التبويبات وعلامات الفاصلة (:) وانقطاعات الأسطر. لا حاجة لكتابة أي كود؛ إذا كنت تستطيع قراءة قائمة المشتريات، فيمكنك قراءة محتويات ملف التكوين.

الخيار أ: تشغيل معالج الإعداد التفاعلي​

يقوم المساعد التفاعلي بإنشاء ملف تكوين من إجاباتك، ثم يفتح واجهة البحث ويكتب ملف التكوين نيابةً عنك.

اضغط على الأمر التالي لتشغيل المساعد:

Terminal
sweepy --setup

يقوم البرنامج بطباعة شعاره، ثم يعرض واجهة التشغيل (launchpad). تُظهر السطر الموجود أسفل الأزرار المستخدمة معلومات الملف المحمل، مثل Current profile: Alex Rivera / 4 titles / Ready؛ وفي حالة عدم وجود أي ملفات محملة، يتم عرض رقم Current profile: none loaded / build one to start.

تعرض لوحة التشغيل ستة مربعات. تعمل خيار Start Sweep على تشغيل ملف التعريف المحمّل. أما خيار Load Profile فيفتح عملية بحث محفوظة. ويبدأ خيار Build Profile عملية بحث جديدة ويطرح أسئلة بلغة إنجليزية بسيطة. تتحكم Sweep Settings في الترتيب والبطاقات والسجل. تحتوي Sweepy's Toolbox على تحرير الملف الشخصي وإدارة المحرك وإدارة أداة التجميع ومفتاح تشغيل/إيقاف التصحيح والمساعدة والسجلات الحديثة وتحويل المستندات والتحديثات. Exit Sweepy يحفظ التغييرات ويغلق المعالج.

يحتوي مرجع الأوامر على شرح لكل خيار متاح في واجهة البحث.

تلميح

يمكن إعادة تشغيل أمر sweepy --setup في أي وقت لإنشاء ملف تكوين جديد أو تعديل ملف تكوين موجود؛ يقوم “الساحر” بكتابة التغييرات في الملف الذي يحدده ولا يؤثر ذلك على الملفات الأخرى.

لتخطي خطوة البدء وتعديل ملف تكوين محفوظ مباشرةً، قم باستخدام العلامة --profile.

Terminal
sweepy --setup --profile profiles/paralegal_nyc.yaml

الخيار ب: تحرير ملف التكوين يدويًّا​

لإدخال إعداداتك مباشرةً، قم بنسخ القالب النموذجي وفتحه في محرر نص عادي مثل Notepad أو VS Code؛ تجنب استخدام برامج معالجة النصوص، لأنها قد تغير أشكال الاقتباسات وتتسبب في مشاكل في أوامر مثل YAML.

  • Windows
  • macOS / Linux
Terminal
copy config.sample.yaml profiles\alex_rivera_paralegal.yaml
notepad profiles\alex_rivera_paralegal.yaml
Terminal
cp config.sample.yaml profiles/alex_rivera_paralegal.yaml
open profiles/alex_rivera_paralegal.yaml    # macOS
# or: nano profiles/alex_rivera_paralegal.yaml   # Linux

ملف تعريف أليكس​

يقوم “الساحر” بكتابة محتويات هذا الملف في المسار profiles/alex_rivera_paralegal.yaml؛ الأسطر التي تبدأ بـ # هي تعليقات ولا يأخذها “Sweepy” في الاعتبار؛ كما يقوم “Sweepy” بتعيين قيم افتراضية لأي قسم أو إعداد لم تحدده.

profiles/alex_rivera_paralegal.yaml
# ─────────────────────────────────────────────────
# Sweepy — Alex's Paralegal Profile
# ─────────────────────────────────────────────────

# Your name (appears in the PDF report header)
name: "Alex Rivera"

# ─── Job Search Settings ──────────────────────────
search:
  # List every job title you want to find.
  # The engine searches for ALL of these titles simultaneously.
  titles:
    - "Paralegal"
    - "Legal Assistant"
    - "Litigation Support Specialist"
    - "Legal Secretary"

  # Your target city and state.
  location: "New York, NY"

  # Set to true to ONLY see remote roles.
  # Set to false to see remote, hybrid, and on-site roles.
  remote_only: false

  # Set to false to exclude hybrid positions.
  include_hybrid: true

  # Minimum annual salary filter (optional).
  # Leave as 0 or remove this line to skip salary filtering.
  min_salary: 65000

# ─── Resume Settings ─────────────────────────────
resume:
  # The full path to your resume PDF on your computer.
  # On Windows, use double backslashes (\\) or forward slashes (/).
  path: "Alex_Rivera_Resume.pdf"

  # Must-have skills to prioritize for the match percentage.
  must_have_skills:
    - "Westlaw"
    - "LexisNexis"
    - "e-discovery"
    - "Contract Review"
    - "Legal Research"

  # How heavily to weigh keyword matches when scoring roles.
  # 1.0 = standard weight. Increase to 2.0 if you want
  # exact skill matches to dominate the score.
  keywords_weight: 1.5

# ─── Platform Settings ────────────────────────────
# Set each platform to true or false to enable or disable it.
platforms:
  greenhouse: true
  ashby: true
  lever: true
  workable: true
  aggregators: false   # Free feeds like Remotive, Adzuna

  # Optional: custom ATS endpoints or company career domains
  custom:
    - name: "SmartRecruiters"
      domain: "smartrecruiters.com"
      enabled: true
    - name: "Breezy HR"
      domain: "breezy.hr"
      enabled: true

# ─── Export Settings ──────────────────────────────
export:
  # Comma-separated list of output formats.
  # Options: pdf, csv, json
  format: "pdf,csv"

  # Where to save the output files.
  # The engine creates this folder if it does not exist.
  output_dir: "results"
حذر

على نظام ويندوز: استخدم علامتي الاقتباس المتقاطعتين (\\) أو الاقتباس المستقيم (/) في مسارات الوصول إلى الملفات؛ استخدام علامة اقتباس واحدة (\) قد يتسبب في مشاكل في تنسيق الملف.

✅ الصيغة الصحيحة: "C:\\Users\\Alex\\Documents\\resume.pdf" أو "C:/Users/Alex/Documents/resume.pdf"

❌ الصيغة الخاطئة: "C:\Users\Alex\Documents\resume.pdf"

استخدام ملفات تعريف الإعدادات المسبقة​

يحتوي مجلد profiles/ على ملفات تكوين جاهزة للاستخدام؛ هذه الملفات تغطي عمليات البحث الشائعة.

الملفمسار الوظيفيالألقاب المطلوبة

frontend_developer.yamlهندسة البرمجياتمطور واجهة المستخدم الأمامية، مطور React، مهندس تصميم واجهة المستخدم

لاستخدام إعداد مسبق، قم بتمرير اسم الملف عند تشغيل أداة Sweepy.

Terminal
sweepy --profile profiles/frontend_developer.yaml
تلميح

يمكنك إنشاء عدد من الملفات حسب رغبتك؛ احفظ ملفًا مختلفًا لكل تنويع لقب وظيفي أو مدينة مستهدفة، وقم بالتبديل بينها فورًا باستخدام علامة --profile.

الخيار ج: الأتمتة باستخدام تطبيق Antigravity لسطح المكتب​

تطبيق Antigravity مجاني لوكلاء الذكاء الاصطناعي؛ يتصل بأداة Sweepy عبر بروتوكول Model Context Protocol (MCP)، مما يسمح بالبحث عن وظائف دون فتح سطر الأوامر.

لماذا يتم تشغيل Sweepy عبر MCP؟​

  • تحليل المؤهلات: يقوم تطبيق Gemini بقراءة وصفات الوظائف بالكامل وتحديد المهارات المفقودة، بينما يقوم تشغيل سطر الأوامر بمطابقة الكلمات المفتاحية بالضبط.
  • استخدام حصتك المخصصة: يتم استهلاك الحصة المخصصة لحسابك في Google داخل تطبيق Antigravity، مما يجنب الحاجة إلى اشتراكات خدمات خارجية.
  • *يتم توجيه عمليات البحث من خلال المحادثة. يتم وصف الأدوار المستهدفة في رسالة محادثية، ومن ثم يقوم برنامج Antigravity بإنشاء البروفيل والتقرير النهائي بصيغة PDF.

الإعداد السريع​

يتطلب إعداد برنامج Sweepy في برنامج Antigravity عنصرين رئيسيين: خادم MCP لأدوات البحث وأداة /sweepy لإنشاء اختصارات سريعة.

الطريقة 1: اسأل الوكيل​

قم بفتح تطبيق Antigravity لسطح المكتب، بدء محادثة، وأرسل الرسالة التالية:

"قم بإعداد برنامج Sweepy لي: سجل خادم MCP المحلي الخاص به (الذي يعمل على python <PATH_TO_SWEEPY>/server.py) وقم بتثبيت المهارات المطلوبة من مصدر <PATH_TO_SWEEPY>/skills/sweepy."

يقوم Antigravity بكتابة إعدادات النظام وإضافة ملفات المهارة إلى النظام الخاص بك.

الطريقة الثانية: الإعداد اليدوي​

اتبع الخطوات التالية لتكوين التطبيق بنفسك:

  1. أضف خادم MCP:

    • في سطح مكتب Antigravity، افتح الإعدادات (رمز الترس) > خوادم MCP.
    • إضافة خادم Sweepy:
      • الاسم: sweepy
      • الأمر: python
      • الوسائط: ["<PATH_TO_SWEEPY>/server.py"]

  2. قم بتثبيت المهارة. ملف المهارة يسمح باستخدام اختصار القائمة /sweepy.

    • افتح مجلد “Skills” الموجود على جهاز الكمبيوتر الخاص بك.
      • على نظام ويندوز: اضغط على Win+R، ثم أدخل %USERPROFILE%\.gemini\config\skills.
      • على نظام ماك أوس: في تطبيق البحث (Finder)، اضغط على Cmd+Shift+G، ثم أدخل ~/.gemini/config/skills.
    • انسخ المجلد sweepy مباشرةً من الموقع sweepy/skills/sweepy إلى المجلد skills.
    • أعد تشغيل تطبيق Antigravity.

  3. قم بالبحث الخاص بك: اكتب /sweepy في شريط الدردشة، أو اطلب ذلك مباشرةً.

    "قم بإنشاء ملف تعريفي من سيرتي الذاتية الموجودة في الموقع C:/path/to/resume.pdf، وابحث عن وظائف ككاتب تقني عن بعد، ثم قم بأول عملية بحث لديك."

لتكوين عملاء آخرين مثل VS Code، اقرأ دليل التكامل MCP.

تحقق من المواقع التي يبحث فيها Sweepy عن الوظائف​

المحركات الاختيارية للبحث: تتضمن الخيارات HireHunt وOpenRoles وJobDrop وApify؛ يتطلب OpenRoles قائمة بالشركات قبل البدء بالبحث، بينما يتطلب Apify معلومات من الموقع python-jobspy. قد يحدث تعارض بين خيار JobDrop واعتمادات تطبيق JobSpy؛ يمكن تثبيت هذه المحركات باستخدام خيار Download job engines في معالج الإعدادات.

توفر خيارات إضافية لإضافة أدوات مساعدة في عملية التنفيذ، مثل HireHunt، OpenRoles، JobDrop، وApify؛ حيث يتطلب OpenRoles قائمة بالشركات قبل التشغيل، بينما يتطلب Apify وجود ملف يحتوي على بيانات معينة (APIFY_TOKEN). قد يحدث تعارض بين خيار JobDrop واعتمادات برنامج JobSpy أثناء عملية التثبيت. يقوم خيار تنزيل أدوات التنفيذ (Download job engines) المتاح في واجهة الإعداد بتثبيت هذه الأدوات تلقائيًا.

تغطي صفحة المصادر والمنصات المعلومات المتعلقة بالأدوات الاختيارية، ملفات البدء (seed files)، إعدادات المنصات المخصصة، والتحذيرات المتعلقة بالتوافق بين الأدوات والمنصات.

لقد تم إعداد ملفك الشخصي بالفعل؛ حان الوقت لـتنفيذ أول عملية تنظيف لديك.
