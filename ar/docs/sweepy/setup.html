إعداد Sweepy

لقد قمت بتثبيت Sweepy! الآن تحتاج إلى ملف تعريف.

يحدد ملف التكوين لـ Sweepy الوظائف المطلوب البحث عنها والسيرة الذاتية التي سيتم تقييمها بناءً عليها. كما يحدد الموقع المستهدف.

ملف التكوين هو ملف نصي صغير بتنسيق YAML. لغة YAML، التي تتناغم مع كلمة «camel»، تنظم البيانات باستخدام المسافات البادئة والنقاطين وفواصل الأسطر. لا تحتاج إلى كتابة كود: إذا كنت تستطيع قراءة قائمة التسوق، فأنت تستطيع قراءة YAML.

الخيار أ: تشغيل معالج الإعداد التفاعلي​

يقوم معالج الإعداد بإنشاء ملف تعريف فعال بناءً على إجابات بسيطة. يفتح معالج الإعداد لوحة بدء البحث قبل الاستبيان ويكتب ملف التكوين نيابة عنك.

قم بتشغيل هذا الأمر:

Terminal
sweepy --setup

يعرض المعالج شعاره، ثم لوحة التشغيل. يُظهر سطر الحالة أسفل المربعات الملف الشخصي الذي تم تحميله، مثل الملف الشخصي الحالي: Alex Rivera / 4 عناوين / جاهز. وفي حالة عدم تحميل أي شيء بعد، يظهر الملف الشخصي الحالي: لم يتم تحميل أي ملف / أنشئ ملفًا للبدء.

تعرض لوحة التشغيل ستة مربعات. Start Sweep (بدء المسح) يقوم بتشغيل الملف الشخصي المحمّل. Load Profile (تحميل الملف الشخصي) يفتح بحثًا محفوظًا. Build Profile (إنشاء ملف شخصي) يبدأ بحثًا جديدًا ويطرح أسئلة بلغة إنجليزية بسيطة. Sweep Settings (إعدادات المسح) يتحكم في الترتيب والبطاقات والسجل. صندوق أدوات Sweepy يحتوي على تحرير الملف الشخصي، وإدارة المحرك، وإدارة أداة التجميع، ومفتاح تشغيل/إيقاف التصحيح، والمساعدة، والسجلات الحديثة، وتحويل المستندات، والتحديثات. الخروج من Sweepy يحفظ التغييرات ويغلق المعالج.

تسرد مرجع الأوامر العلامات المرتبطة بكل إدخال.

الخيار ب: تحرير ملف التكوين يدويًّا​

لكتابة إعداداتك مباشرةً، انسخ القالب النموذجي وافتحه في محرر نص عادي مثل Notepad أو VS Code. تجنب استخدام برامج معالجة النصوص، التي تستبدل علامات الاقتباس المستقيمة بعلامات الاقتباس المنحنية وتؤدي إلى تعطل لغة YAML.

  • Windows
  • macOS / Linux
Terminal
copy config.sample.yaml profiles\alex_rivera_paralegal.yaml
notepad profiles\alex_rivera_paralegal.yaml
Terminal
cp config.sample.yaml profiles/alex_rivera_paralegal.yaml
open profiles/alex_rivera_paralegal.yaml    # macOS
# أو: nano profiles/alex_rivera_paralegal.yaml   # Linux

ملف تعريف أليكس​

يقوم المعالج بكتابة هذا الملف في profiles/alex_rivera_paralegal.yaml. الأسطر التي تبدأ بـ # هي تعليقات: فهي تشرح كل إعداد، ويقوم Sweepy بتجاهلها. يقوم Sweepy بملء القيمة الافتراضية لأي قسم أو إعداد تتركه فارغًا.

profiles/alex_rivera_paralegal.yaml
# ─────────────────────────────────────────────────
# Sweepy — ملف تعريف أليكس كمساعد قانوني
# ─────────────────────────────────────────────────

# اسمك (يظهر في رأس تقرير PDF)
name: "Alex Rivera"

# ─── إعدادات البحث عن الوظائف ──────────────────────────
search:
  # قم بإدراج كل المسميات الوظيفية التي تريد البحث عنها.
  # يقوم محرك البحث بالبحث عن جميع هذه المسميات في آن واحد.
  المسميات:
    - "مساعد قانوني"
    - "مساعد قانوني"
    - "أخصائي دعم الدعاوى القضائية"
    - "سكرتير قانوني"

  # المدينة والولاية المستهدفتان.
  الموقع: "نيويورك، نيويورك"

  # اضبط القيمة على "true" لعرض الوظائف عن بُعد فقط.
  # اضبط القيمة على "false" لعرض الوظائف عن بُعد، والمختلطة، والوظائف في الموقع.
  remote_only: false

  # اضبط القيمة على "false" لاستبعاد الوظائف المختلطة.
  include_hybrid: true

  # فلتر الحد الأدنى للراتب السنوي (اختياري).
  # اترك القيمة 0 أو احذف هذا السطر لتخطي تصفية الرواتب.
  min_salary: 65000

# ─── إعدادات السيرة الذاتية ─────────────────────────────
resume:
  # المسار الكامل لملف PDF الخاص بسيرتك الذاتية على جهاز الكمبيوتر الخاص بك.
  # في نظام Windows، استخدم علامتي مائل عكسي مزدوجتين (\\) أو علامتي مائل أماميتين (/).
  path: "Alex_Rivera_Resume.pdf"

  # المهارات الأساسية التي يجب إعطاؤها الأولوية في حساب نسبة التطابق.
  must_have_skills:
    - "Westlaw"
    - "LexisNexis"
    - "e-discovery"
    - "Contract Review"
    - "Legal Research"

  # مدى أهمية مطابقة الكلمات المفتاحية عند تقييم الوظائف.
  # 1.0 = الوزن القياسي. قم بزيادته إلى 2.0 إذا كنت تريد
  # أن تهيمن المطابقات الدقيقة للمهارات على النتيجة.
  keywords_weight: 1.5

# ─── إعدادات المنصات ────────────────────────────
# اضبط كل منصة على «صحيح» أو «خطأ» لتفعيلها أو تعطيلها.
platforms:
  greenhouse: true
  ashby: true
  lever: true
  workable: true
  aggregators: false   # مصادر مجانية مثل Remotive و Adzuna

  # اختياري: نقاط نهاية ATS مخصصة أو نطاقات الوظائف الخاصة بالشركة
  custom:
    - name: "SmartRecruiters"
 domain: "smartrecruiters.com"
 enabled: true
    - name: "Breezy HR"
 domain: "breezy.hr"
 enabled: true

# ─── إعدادات التصدير ──────────────────────────────
export:
  # قائمة بتنسيقات الإخراج مفصولة بفواصل.
  # الخيارات: pdf, csv, json
  format: "pdf,csv"

  # مكان حفظ ملفات الإخراج.
  # يقوم المحرك بإنشاء هذا المجلد إذا لم يكن موجودًا.
  output_dir: "results"

:::تحذير في نظام Windows: استخدم علامتي مائل عكسي مزدوجتين (\\) أو علامات مائل أمامية (/) في مسارات YAML. علامة مائل عكسي واحدة (\) تفسد تنسيق YAML.

✅ صحيح: "C:\\Users\\Alex\\Documents\\resume.pdf" أو "C:/Users/Alex/Documents/resume.pdf"

❌ غير صحيح: "C:\Users\Alex\Documents\resume.pdf"

:::

استخدام ملفات تعريف محددة مسبقًا​

يتضمن Sweepy ملفات تعريف محددة مسبقًا جاهزة للاستخدام في المجلد profiles/. تغطي هذه الملفات الأربعة عمليات البحث الشائعة:

الملفالمسار الوظيفيالألقاب التي يتم البحث عنها
paralegal_nyc.yamlالقانونمساعد قانوني، مساعد قانوني، أخصائي دعم الدعاوى القضائية، سكرتير قانوني
frontend_developer.yamlهندسة البرمجياتمطور واجهة المستخدم، مطور React، مهندس واجهة المستخدم
tech_writer.yamlالكتابة التقنيةكاتب تقني، كاتب تجربة المستخدم، مصمم محتوى
template_custom.yamlأي مسار مهنيأمثلة على المسميات الوظيفية التي يمكنك استبدالها. كل إعداد مصحوب بتعليق.

لاستخدام إعداد مسبق، قم بتمرير اسم الملف الخاص به عند تشغيل عملية المسح:

Terminal
sweepy --profile profiles/frontend_developer.yaml
تلميح

يمكنك إنشاء أي عدد تريده من الملفات الشخصية. احفظ ملفًا شخصيًا مختلفًا لكل تباين في المسمى الوظيفي أو المدينة التي تستهدفها. قم بالتبديل بينها على الفور باستخدام علامة --profile.

الخيار ج: الأتمتة باستخدام مساعد الدردشة​

يمكن لمساعد الدردشة إنشاء الملفات الشخصية وتشغيل عمليات المسح نيابة عنك. يتضمن Sweepy خادمًا مدمجًا لبروتوكول سياق النموذج (MCP)، بحيث يقوم المساعد بقراءة ملفات التعريف الخاصة بك وكتابتها مباشرةً. يغطي دليل تكامل MCP إعداد العميل لبرامج Antigravity وClaude Desktop وVS Code، بينما يسرد دليل أدوات MCP جميع أدوات Sweepy.

الاطلاع على كل الإعدادات​

تسرد مرجع التكوين كل الإعدادات التي يقبلها الملف الشخصي، بدءًا من debug وresume.tracks وصولًا إلى sources.* وreport.*. احتفظ به مفتوحًا أثناء تعديل ملفك الشخصي.

تحقق من المواقع التي يبحث فيها Sweepy عن الوظائف​

يقوم Sweepy بالاستعلام عن أربعة أنظمة عامة لتتبع المتقدمين للوظائف بشكل افتراضي. تشمل هذه المجموعة Greenhouse وAshby وLever وWorkable. كما يستعلم أيضًا عن Built In NYC، وهو موقع إعلانات وظائف في نيويورك. تُعالج موجزات المجمّع من LinkedIn وIndeed وGlassdoor وZipRecruiter عبر python-jobspy عندما يتيح ملفك الشخصي ذلك.

تضيف المحركات الاختيارية لوحات إعلانات. الخيارات المتاحة هي HireHunt و OpenRoles و JobDrop و Apify. يتطلب OpenRoles قائمة بالشركات قبل تشغيله. يتطلب Apify APIFY_TOKEN. يتعارض JobDrop مع دبوس التبعية الخاص بـ JobSpy. يقوم خيار تنزيل محركات الوظائف في معالج الإعداد بتثبيتها.

تغطي صفحة المصادر والمنصات المحركات الاختيارية وملفات البذور وإدخالات المنصات المخصصة وملاحظات التوافق.

ملفك الشخصي جاهز. حان الوقت لـ تشغيل عملية المسح الأولى.
