تشغيل Sweepy من مساعد الذكاء الاصطناعي باستخدام MCP

يمكن لمساعد الذكاء الاصطناعي تشغيل Sweepy نيابة عنك. صف الدور الذي تريده، وسيتولى المساعد استدعاء Sweepy بدلاً من مطالبتك بكتابة أوامر في الطرفية.

يستخدم هذا الاتصال بروتوكول سياق النموذج (MCP). يمثل MCP لغة مشتركة تتيح لمساعد الذكاء الاصطناعي استخدام الأدوات المثبتة على جهاز الكمبيوتر الخاص بك. يتضمن Sweepy خادم MCP مدمجاً في server.py. يعمل عبر بروتوكول النقل stdio، لذا فهو يتواصل مع عميلك محلياً ولا يفتح أي منفذ شبكة.

ملاحظة

استخدام MCP اختياري. يعمل Sweepy بالكامل عبر أوامر الطرفية دون الحاجة إلى أي مساعد ذكاء اصطناعي. يضيف الخادم طبقة محادثة تفاعلية فوق المحرك نفسه، كما يضيف تقدير النموذج وذكاءه إلى عمليات التقييم والترشيح المحددة مسبقاً التي يجريها Sweepy بالفعل.

قبل البدء بالاتصال​

  • أكمل التثبيت حتى تكون بيئة Python وتبعيات Sweepy جاهزة. تأتي حزمتا mcp و anyio ضمن ملف requirements.txt.
  • دوّن المسار المطلق لملف server.py، حيث ستلصقه في إعدادات عميلك.
  • أعد تشغيل عميل الذكاء الاصطناعي بعد تعديل تكوين MCP الخاص به.

الأدوات المتاحة​

يتيح Sweepy اثنتي عشرة أداة لمساعدك. تُرجع كل أداة حمولة بتنسيق JSON، وتحدد خصائص القراءة فقط، والعمليات الإتلافية، والعمليات المتماثلة التأثير (idempotent)، والتلميحات المفتوحة.

الأداةوظيفتها
create_profileإنشاء ملف تعريف بصيغة YAML والتحقق من صحته وحفظه انطلاقاً من سيرة ذاتية بتنسيق PDF أو DOCX.
run_sweepتشغيل المسار المكون من خمس مراحل في الخلفية وتخزين البطاقات المحددة.
get_sweep_statusانتظار انتهاء مسح قيد التشغيل والإبلاغ عن تقدمه.
get_jobsإرجاع البطاقات المحفوظة في الجلسة الحالية، مرتبة حسب الدرجة.
submit_judgmentsاستبدال الحقول التلقائية في البطاقة بتقديرات مساعدك الذكي.
import_jobsإلحاق وظائف تحقق منها مساعدك في مكان آخر.
render_reportتصيير بطاقات الجلسة الحالية في ملف تقرير بصيغة PDF.
get_resultsقراءة أحدث نتيجة مسح من القرص.
export_reportإعادة إنشاء ملفات PDF أو PNG أو CSV أو JSON من عملية مسح سابقة.
clear_historyحذف سجل الوظائف المُعلن عنها لملف تعريف معين.
convert_documentتحويل أي مستند مدعوم إلى صيغة PDF.
convert_docxتحويل سيرة ذاتية بتنسيق DOCX إلى PDF.

يقدم مرجع أدوات MCP تفاصيل إضافية؛ إذ يسرد كل معامل، وقيمته الافتراضية، وحمولته، وتلميحات سلوكه.

اختيار محركات البحث عن الوظائف​

عند حذف sources_config، تُفعل أداة create_profile محركي JobSpy و ATS المدمجين تلقائياً. كما تفعل المحركات الاختيارية التي تحتوي على تثبيت صالح وإعدادات افتراضية صحيحة. تُرجع الأداة قائمتي enabled_engines و engines_not_enabled، حتى تتمكن من معرفة المحركات التي تعمل وتلك التي ما تزال بحاجة إلى ضبط.

يبحث OpenRoles فقط في لوحات الشركات التي تحددها؛ لذا أضف المعرفات الدلالية للشركات (company slugs) قبل تفعيله. قد يترتب على استخدام Apify رسوم مالية، فقم بتفعيله إذا رغبت في ذلك. لا يثبت Sweepy الحزم الاختيارية تلقائياً. لست بحاجة إلى تحديد المحركات في كل بحث، بل حددها صراحة فقط عندما يتطلب المحرك إعداداً خاصاً، أو موافقة على خدمة مدفوعة، أو قيداً محدداً للبحث.

مرّر sources_config عندما تختار المحركات بشكل صريح. يحتفظ Sweepy بهذا الاختيار بدلاً من إضافة محركات أخرى. يحدد هذا المثال بتنسيق JSON محركين اثنين:

{
  "enabled": ["jobspy", "openroles"],
  "openroles": {"companies": ["figma", "stripe"]}
}

مسارات الأدوات الفورية والهجينة​

يعمل Sweepy بنمطين رئيسيين؛ اختر النمط المناسب لمدى الصلاحيات والقرارات التي تريد إسنادها إلى المساعد.

المسار الفوري (One-shot). يقوم مساعدك بتكوين كل شيء وتشغيله، بينما يقيّم المحرك كل وظيفة بناءً على مدى تطابق الكلمات المفتاحية في السيرة الذاتية.

create_profile -> run_sweep -> get_results -> export_report (اختياري)

المسار الهجين المعتمد على الحالة (Hybrid stateful). يراجع مساعدك كل بطاقة ويقدم تقديره الخاص قبل تصيير التقرير النهائي.

run_sweep -> get_jobs -> submit_judgments -> render_report

يمكن للمسح المباشر مواصلة العمل في الخلفية حتى بعد انتهاء مهلة استجابة العميل. عندما تُرجع أداة run_sweep الحالة sweep_status: "running"، استدعِ get_sweep_status ممرراً إليها job_id الناتج حتى تشير إلى اكتمال العملية completed، ثم تابع باستخدام get_jobs.

تلميح

لست بحاجة إلى نموذج لغوي كبير (LLM) لإنتاج تقرير عملي؛ إذ تكفي أداة run_sweep وحدها لتصيير ملف PDF كامل لبطاقات الوظائف بناءً على الحقول المحددة، تماماً كما لو أجريت المسح عبر الطرفية.

تعرض كل بطاقة واحدة من تسميتي درجات التقييم:

  • NN% KEYWORD OVERLAP تأتي من المحرك المحدد؛ وتقارن نص سيرتك الذاتية بكل وظيفة معلنة.
  • NN% MATCH تأتي من مساعدك؛ وتظهر عند استدعاء submit_judgments مع تحديد قيمة match_pct.

تُرجع أداة get_jobs المتغير resume_documents، وهو النص المحلل لكل مسار سيرة ذاتية إلى جانب البطاقات. يقيّم مساعدك هذا النص بالطريقة ذاتها التي يحلله بها نظام تتبع المتقدمين (ATS) الخاص بالإعلان، ثم يسجل ما قد يغفله المحلل في حقل concerns.

التحقق من نتائج المسح واستكمالها​

تعامل مع نتيجة كل مسح كنقطة انطلاق أولية، ثم تحقق من كل وظيفة متطابقة بمقارنتها بالإعلان الفعلي. بعد تشغيل run_sweep، افحص قائمة skipped_sources وأبلغ عن أية أعطال في المصادر. راجع الوظائف باستخدام get_jobs، ثم قارن كل إعلان بسيرتك الذاتية وتفضيلاتك المعلنة قبل أن يرسل مساعدك تقييم النموذج.

إذا كان مساعدك مزوداً بأدوات تصفح الويب أو البحث، فاطلب منه التحقق من الوظائف الواعدة عبر صفحات التوظيف الخاصة بأصحاب العمل أو أنظمة ATS الخاصة بهم. يمكنه أيضاً البحث عن الوظائف المناسبة التي قد يكون Sweepy قد أغفلها، وإضافة الإعلانات المؤكدة غير المكررة عبر import_jobs، وتضمينها في التقرير باستخدام render_report. يجب ألا يختلق مساعدك إعلانات وظائف أو يملأ التفاصيل الناقصة عبر التخمين.

قد يترك مدقق الروابط في Sweepy بعض عناوين URL كعناوين غير مؤكدة عند حظر الوصول من قِبل المضيف، أو فرض قيود على معدل الطلبات، أو انتهاء المهلة الزمنية. لا يثبت رمز الخطأ 403 أو 429 انتهاء صلاحية الوظيفة المعلنة. تحقق من الإعلان عبر مصدر متاح لصاحب العمل متى أمكن، أو تعامل معه كإعلان غير مؤكد. وإذا لم تتوفر لمساعدك أداة بحث، أو ظلت المصادر غير متاحة، فأوضح أن النتائج قد تكون غير مكتملة. تجنب تكرار المسح بالإعدادات ذاتها دون تغيير بعد وقوع خطأ.

الربط مع Antigravity أو Claude Desktop​

أضف Sweepy إلى ملف تكوين MCP الخاص بعميلك، والذي يحمل الاسم mcp_config.json أو claude_desktop_config.json بحسب العميل المستخدم:

mcp_config.json
{
  "mcpServers": {
    "sweepy": {
      "command": "python",
      "args": [
        "/path/to/sweepy/server.py"
      ]
    }
  }
}

استبدل /path/to/sweepy بالمسار المطلق لمجلد Sweepy على جهازك، ثم أعد تشغيل العميل. بمجرد اكتمال التسجيل، يمكنك طلب تنفيذ مهام على هذا النحو:

  • "أنشئ ملف تعريف في Sweepy لـ Alex للبحث عن وظائف كاتب تقني عن بُعد في نيويورك. السيرة الذاتية موجودة في path/to/resume.pdf."
  • "شغّل مسحاً باستخدام ملف تعريف الكاتب واعرض أفضل 5 نتائج متطابقة."
  • "أعد إنشاء ملف PDF من آخر عملية مسح لـ pedro_writer واحفظه على سطح المكتب."
  • "حوّل path/to/notes.md إلى PDF واحفظه بجوار الملف الأصلي."
الكتابة خارج مجلد Sweepy

تبقى جميع أدوات الكتابة مقيدة داخل مجلد Sweepy افتراضياً. سيفشل أي طلب للحفظ على سطح المكتب ما لم تضبط متغير البيئة SWEEPY_ALLOW_EXTERNAL_WRITES على القيمة 1.

الربط مع VS Code​

يتصل برنامج VS Code بخوادم MCP دون الحاجة إلى أي إضافة إضافية:

  1. افتح لوحة الأوامر (Command Palette) وشغّل الأمر MCP: Add Server.
  2. اختر Command (stdio)، ثم اكتب python كأمر تشغيل. أضف المسار المطلق لملف server.py كمعامل له.
  3. سمِّ الخادم sweepy، ثم حدد موضع حفظ التكوين.
  4. تأكد من ظهور أدوات Sweepy في لوحة الدردشة، ثم يمكنك استدعاؤها من هناك.

بالنسبة لملف مخصص لنطاق مساحة العمل، أضف .vscode/mcp.json إلى مشروعك. يستخدم تنسيق VS Code كائن servers على المستوى الأعلى:

.vscode/mcp.json
{
  "servers": {
    "sweepy": {
      "type": "stdio",
      "command": "python",
      "args": [
        "/path/to/sweepy/server.py"
      ]
    }
  }
}

تثبيت مهارة /sweepy​

يوفر Sweepy مهارة /sweepy المخصصة لـ Copilot CLI و Claude Code و Antigravity وغيرها من أدوات سطر الأوامر التي تدعم قراءة المهارات. انسخ المجلد المرفق إلى دليل المهارات الخاص بأداتك:

Terminal
cp -r skills/sweepy ~/.claude/skills/sweepy   # عدل المسار ليلائم دليل مهارات أداتك

سجل خادم MCP كما هو موضح في القسم السابق، ثم أعد تشغيل أداتك. توثق المهارة ثلاثة مسارات أساسية:

  • بدء استخراج جديد عبر استدعاء create_profile ثم run_sweep.
  • عرض نتائج الاستخراج عبر استدعاء get_results لأفضل التطابقات وخطط العمل، أو get_jobs للحصول على مجموعة البطاقات الكاملة.
  • تصدير النتائج إلى ملف CSV عبر استدعاء export_report مع تمرير المعامل formats=["csv"].

تغطي المهارة أيضاً الحل البديل لأدوات سطر الأوامر التي تفتقر إلى دعم MCP:

Terminal
sweepy --setup                         # معالج إعداد ملف التعريف التفاعلي
sweepy --profile profiles/your_profile.yaml
sweepy --docx resume.docx              # تحويل سيرة ذاتية بتنسيق DOCX إلى PDF
sweepy --convert notes.md              # تحويل أي مستند مدعوم إلى PDF

ضبط كافة الإعدادات عبر توجيه واحد​

انسخ هذا التوجيه والصقه في أية جلسة سطر أوامر للذكاء الاصطناعي أو نافذة دردشة في بيئة التطوير المتكاملة (IDE):

اضبط Sweepy على هذا الجهاز مع تنفيذ الخطوات الآتية بالترتيب:

1. انسخ مستودع Sweepy أو نزّله.
2. شغّل `pip install -r requirements.txt` في المجلد الرئيسي للمستودع.
3. سجّل `server.py` في تكوين MCP كخادم stdio مستخدماً الأمر `python` مع توجيه المعاملات إلى `server.py`.
4. انسخ المجلد `skills/sweepy` إلى دليل المهارات في واجهة سطر الأوامر (CLI).

التعرّف على المزيد من أنماط التوجيه​

يوثق ملف AGENTS.md الموجود في المستودع تسلسل الأدوات، والإرشادات الخاصة بكل أداة، وأنماط التوجيه المختلفة. يُرجى مراجعته إذا أردت تحقيق مستوى أعمق من الأتمتة يتجاوز المسارات الموضحة في هذه الصفحة.
