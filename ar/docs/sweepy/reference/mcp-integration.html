شغّل Sweepy من مساعد ذكاء اصطناعي عبر MCP

يستطيع مساعد ذكاء اصطناعي تشغيل Sweepy لك. فتصف الوظيفة التي تريدها، ويستدعي المساعد Sweepy نيابةً عنك بدلًا من أن يطلب منك كتابة أوامر طرفية.

يستخدم ذلك الاتصال بروتوكول سياق النموذج (MCP). وMCP لغة مشتركة تتيح لمساعد الذكاء الاصطناعي استخدام أدوات مثبتة على حاسوبك. ويتضمن Sweepy خادم MCP مدمجًا في server.py. ويعمل عبر ناقل stdio، فيتحدث إلى عميلك محليًا ولا يفتح منفذ شبكة.

ملاحظة

MCP اختياري. ويعمل Sweepy بالكامل من أوامر الطرفية دون أي مساعد ذكاء اصطناعي. ويضيف الخادم طبقة محادثة فوق المحرك نفسه. ويضيف أيضًا حكم النموذج وذكاءه إلى الاحتساب والتصفية الحتميين اللذين ينفذهما Sweepy بالفعل.

قبل أن تتصل​

  • أكمل التثبيت ليصبح Python وتبعيات Sweepy في مكانها. وتصل حزمتا mcp وanyio مع requirements.txt.
  • دوّن المسار المطلق إلى server.py. ستلصق ذلك المسار في تهيئة عميلك.
  • أعد تشغيل عميل الذكاء الاصطناعي بعد تغيير تهيئة MCP فيه.

الأدوات المتاحة​

يعرض Sweepy اثنتي عشرة أداة لمساعدك. وتعيد كل أداة حمولة JSON وتعلن تلميحات القراءة فقط والتدمير والتكرارية والعالم المفتوح.

الأداةما تفعله
create_profileيبني ملفًا تعريفيًا بصيغة YAML من سيرة ذاتية بصيغة PDF أو DOCX ويتحقق منه ويحفظه.
run_sweepيشغّل خط المعالجة المكوّن من خمس مراحل في الخلفية ويخزّن البطاقات الحتمية.
get_sweep_statusينتظر مسحًا جاريًا ويبلّغ عن تقدمه.
get_jobsيعيد البطاقات المحفوظة في الجلسة الحالية، مرتبة حسب النتيجة.
submit_judgmentsيستبدل الحقول الحتمية في البطاقة بتقييم مساعدك.
import_jobsيضيف وظائف تحقق منها مساعدك في مكان آخر.
render_reportيعرض تقرير البطاقات بصيغة PDF من الجلسة الحالية.
get_resultsيقرأ أحدث نتيجة مسح من القرص.
export_reportيعيد بناء ملفات PDF أو PNG أو CSV أو JSON من مسح قائم.
clear_historyينسى الإعلانات المُبلَّغ عنها لملف تعريفي واحد.
convert_documentيحوّل مستندًا مدعومًا إلى PDF.
convert_docxيحوّل سيرة ذاتية بصيغة DOCX إلى PDF.

يقدّم مرجع أدوات MCP تفصيلًا أوسع. فهو يسرد كل معامل وقيمة افتراضية وحمولة وتلميح سلوك.

اختر محركات البحث عن وظائف​

عندما تحذف sources_config، يمكّن create_profile محركي JobSpy وATS المدمجين. ويمكّن أيضًا المحركات الاختيارية التي لها تثبيت صالح وقيم افتراضية صالحة. وتعيد الأداة enabled_engines وengines_not_enabled، لترى أي المحركات تعمل وأيها لا يزال يحتاج إلى إعداد.

يبحث OpenRoles في منصات الشركات التي تسردها فقط. أضف معرّفات الشركات قبل تمكينه. وقد يفرض Apify رسومًا. مكّنه إذا أردت. ولا يثبّت Sweepy الحزم الاختيارية تلقائيًا. ولا تحتاج إلى اختيار محركات لكل بحث. اختر صراحةً فقط عندما يحتاج محرك إلى إعداد أو موافقة على خدمة مدفوعة أو قيد بحث.

مرّر sources_config عندما تختار المحركات صراحةً. ويحتفظ Sweepy بذلك الاختيار بدلًا من إضافة محركات أخرى. ويختار هذا JSON محركين:

{
  "enabled": ["jobspy", "openroles"],
  "openroles": {"companies": ["figma", "stripe"]}
}

تدفقات الأدوات الأحادية والمختلطة​

يعمل Sweepy بنمطين. اختر النمط الذي يطابق مقدار ما تريد أن يقرره المساعد.

التدفق الأحادي. يهيّئ مساعدك كل شيء ويشغّله، ويحتسب المحرك كل وظيفة بتداخل كلمات السيرة الذاتية المفتاحية.

create_profile -> run_sweep -> get_results -> export_report (optional)

التدفق المختلط الحافي الحالة. يراجع مساعدك كل بطاقة ويقدم تقييمه قبل عرض التقرير.

run_sweep -> get_jobs -> submit_judgments -> render_report

قد يستمر المسح الحي في العمل بعد انتهاء مهلة العميل. وعندما يعيد run_sweep القيمة sweep_status: "running"، استدعِ get_sweep_status مع job_id المعاد إلى أن يبلّغ عن completed. ثم تابع بـ get_jobs.

تلميح

لا تحتاج إلى LLM للحصول على تقرير صالح. فأداة run_sweep وحدها تعرض تقرير البطاقات كاملًا بصيغة PDF من الحقول الحتمية، تمامًا كمسح طرفية.

تعرض كل بطاقة واحدة من تسميتَي النتيجة:

  • NN% KEYWORD OVERLAP تأتي من المحرك الحتمي. وهي تقارن نص سيرتك الذاتية بكل إعلان.
  • NN% MATCH تأتي من مساعدك. وتظهر عندما تستدعي submit_judgments بقيمة match_pct.

تحقق من نتائج المسح واستكملها​

تعامل مع كل نتيجة مسح كمجموعة بداية، ثم تحقق من كل تطابق مقابل الإعلان. وبعد run_sweep، افحص skipped_sources وأبلغ عن إخفاقات المصادر. راجع الوظائف بـ get_jobs، ثم قارن كل إعلان بسيرتك الذاتية وتفضيلاتك المعلنة قبل أن يقدم مساعدك تقييم LLM.

وعندما يملك مساعدك أدوات ويب أو بحث، اطلب منه التحقق من الوظائف الواعدة على صفحات الوظائف لدى جهة العمل أو نظام ATS لديها. ويستطيع أيضًا البحث عن وظائف مناسبة فاتت Sweepy، وإضافة إعلانات متحققة غير مكررة عبر import_jobs، وتضمين تلك الوظائف في التقرير بـ render_report. ويجب ألا يختلق مساعدك إعلانات ولا يملأ تفاصيل وظيفة ناقصة بتخمينات.

يُبقي مدقق الروابط في Sweepy بعض الروابط غير متحققة عندما يحجب مضيف الوصول أو يحد الطلبات أو تنتهي المهلة. فالرمز 403 أو 429 لا يثبت انتهاء إعلان. أكّد الإعلان من مصدر متاح لجهة العمل عندما يمكنك، أو تعامل معه كغير متحقق. وإذا لم يملك مساعدك أداة بحث، أو بقي المصادر غير متاحة، فبيّن أن النتائج قد تكون ناقصة. وتجنب تكرار مسح بالإعدادات نفسها بعد خطأ.

الاتصال بـ Antigravity أو Claude Desktop​

أضف Sweepy إلى ملف تهيئة MCP في عميلك، ويسمى mcp_config.json أو claude_desktop_config.json حسب العميل:

mcp_config.json
{
  "mcpServers": {
    "sweepy": {
      "command": "python",
      "args": [
        "/path/to/sweepy/server.py"
      ]
    }
  }
}

استبدل /path/to/sweepy بالمسار المطلق إلى مجلد Sweepy، ثم أعد تشغيل العميل. وبعد التسجيل، يمكنك طلب أعمال مثل هذه:

  • "أنشئ ملفًا تعريفيًا في Sweepy لأليكس يبحث عن وظائف كاتب تقني عن بُعد في نيويورك. السيرة الذاتية في path/to/resume.pdf."
  • "شغّل مسحًا بالملف التعريفي الخاص بالكاتب واعرض أفضل 5 تطابقات."
  • "أعد إنشاء ملف PDF من آخر مسح pedro_writer واحفظه على سطح المكتب."
  • "حوّل path/to/notes.md إلى PDF بجانب الملف الأصلي."
الكتابة خارج مجلد Sweepy

تبقى كل أداة كتابة داخل مجلد Sweepy افتراضيًا. ويفشل طلب الحفظ على سطح المكتب إلى أن تضبط متغير البيئة SWEEPY_ALLOW_EXTERNAL_WRITES على 1.

الاتصال بـ VS Code​

يتصل VS Code بخوادم MCP دون إضافة إضافية:

  1. افتح لوحة الأوامر ونفّذ MCP: Add Server.
  2. اختر Command (stdio)، ثم أدخل python كأمر. وأضف المسار المطلق إلى server.py كمعامل له.
  3. سمّ الخادم sweepy، ثم اختر وجهة التهيئة.
  4. أكّد ظهور أدوات Sweepy في لوحة المحادثة، ثم استدعها من هناك.

ولملف مقيد بمساحة العمل، أضف .vscode/mcp.json إلى مشروعك. ويستخدم تنسيق VS Code كائنًا أعلى المستوى باسم servers:

.vscode/mcp.json
{
  "servers": {
    "sweepy": {
      "type": "stdio",
      "command": "python",
      "args": [
        "/path/to/sweepy/server.py"
      ]
    }
  }
}

ثبّت مهارة /sweepy​

يوفر Sweepy مهارة /sweepy لـ Copilot CLI وClaude Code وAntigravity وأدوات سطر أوامر أخرى تقرأ المهارات. انسخ المجلد المرفق إلى دليل المهارات في أداتك:

الطرفية
cp -r skills/sweepy ~/.claude/skills/sweepy   # adjust to your tool's skills path

سجّل خادم MCP من القسم السابق، ثم أعد تشغيل أداتك. وتوثّق المهارة ثلاثة تدفقات أساسية:

  • ابدأ استخراجًا جديدًا باستدعاء create_profile، ثم run_sweep.
  • اعرض نتائج الاستخراج باستدعاء get_results لأفضل التطابقات وأدلة الاستراتيجية، أو get_jobs لمجموعة البطاقات كاملة.
  • صدّر النتائج إلى ملف CSV باستدعاء export_report مع formats=["csv"].

وتغطي المهارة أيضًا البديل لأدوات سطر الأوامر التي لا تدعم MCP:

الطرفية
sweepy --setup                         # interactive profile wizard
sweepy --profile profiles/your_profile.yaml
sweepy --docx resume.docx              # convert a DOCX resume to PDF
sweepy --convert notes.md              # convert any supported document to PDF

أعدّ كل شيء بمطالبة واحدة​

انسخ هذه المطالبة والصقها في أي جلسة سطر أوامر ذكاء اصطناعي أو محادثة بيئة تطوير:

Set up Sweepy on this machine. Complete these steps in order:

1. Clone or download the Sweepy repository.
2. Run `pip install -r requirements.txt` in the repository root.
3. Register `server.py` in the MCP configuration as a stdio server. Use the command `python` and args pointing at `server.py`.
4. Copy the `skills/sweepy` folder into the CLI's skills directory.
