مصادر الاستخراج ودعم المنصات

يجد Sweepy الوظائف بطريقتين. فهو يستعلم مباشرةً من أربع منصات ATS عامة ومنصة وظائف واحدة في نيويورك. ويستطيع أيضًا قراءة تغذيات المجمّعات عبر python-jobspy. وتسرد هذه الصفحة كل مصدر وتعرض كيفية توجيه Sweepy إلى مجالك.

المصادر الافتراضية​

يعمل Sweepy جاهزًا على خمسة مصادر حتمية بالإضافة إلى مسار مجمّعات واحد. وتستخدم المصادر الحتمية نقاط نهاية عامة يستطيع أي شخص فتحها. ولا تحتاج إلى حساب أو تسجيل دخول أو خدمة مدفوعة.

المصدرمفتاح التهيئةملف البذورنقطة النهاية
Greenhousesources.greenhouse.boardsdata/sources/greenhouse_boards.txtboards-api.greenhouse.io/v1/boards/{board}/jobs?content=true
Ashbysources.ashby.orgsdata/sources/ashby_orgs.txtapi.ashbyhq.com/posting-api/job-board/{org}
Leversources.lever.companiesdata/sources/lever_companies.txtapi.lever.co/v0/postings/{company}?mode=json
Workablesources.workable.slugsdata/sources/workable_slugs.txtapply.workable.com/api/v1/widget/accounts/{slug}
Built In NYCsources.builtinnyc.categoriesdata/sources/builtin_categories.txtbuiltinnyc.com/{category}
Glassdoorsources.jobspy.glassdoorلا يوجدعبر python-jobspy

قواعد الفتح​

يشغّل Sweepy مصدرًا حتميًا عندما يتحقق الإعدادان التاليان:

  1. تضبط sources.<name>.enabled على true.
  2. تضبط platforms.<name> على true حيث يوجد إعداد مطابق.

وكلا المفتاحين افتراضيًا true.

ضع هذه الاستثناءات في الحسبان:

  • Built In NYC ليس لديه إعداد platforms.builtinnyc. ويحترم المحرك sources.builtinnyc.enabled وحده. وتتضمن كل بطاقة الشركة ومكان العمل والموقع والأجر من صفحة الإعلان. اضبط sources.builtinnyc.detail_pages: true لقراءة نص الإعلان كاملًا أيضًا. وتتصدى Built In لتلك الصفحات بعد بضع طلبات، فيتوقف Sweepy عند أول تصدٍّ.
  • Glassdoor يعمل عبر python-jobspy ويحترم sources.jobspy.glassdoor. ولا يوجد مفتاح platforms.glassdoor، فيوقفه مفتاح sources ذلك وحده.

لإيقاف مصدر، اضبط أحد مفتاحيه على false.

إذا سبق ملفك التعريفي الإصدار v2.2.0​

تحذير

يعمل Greenhouse وLever الآن افتراضيًا. وغيّر Sweepy هذا السلوك في الإصدار v2.2.0. وتكتشف الملفات التعريفية القائمة الإعلانات الجديدة إلا إذا أوقفت تلك المصادر. ولم تتغير أي قيمة افتراضية لمفتاح.

توقف المفاتيح platforms.ashby: false وplatforms.workable: false وplatforms.greenhouse: false وplatforms.lever: false الآن مصادر البذور الحتمية تلك. وقبل الإصدار v2.2.0، كانت تصفي نتائج python-jobspy وحدها.

أوقف مصدرًا بـ sources.<name>.enabled: false أو بـ platforms.<name>: false.

كيف تعمل ملفات البذور​

يستخدم Sweepy ملفات البذور في data/sources/ كبدائل عندما يترك ملفك التعريفي قوائم المصادر فارغة.

  • القائمة الفارغة، مثل boards: []، تعود إلى ملف البذور المنتقى.
  • القائمة الصريحة تتجاوز البذور كليًا. فقائمتك تحل محل البذور، ولن يدمج المحرك الاثنين.

قائمتك هي الفائزة. وأنت تختار المنصات وفئات الوظائف.

أمثلة لمجالك​

أضف منصات ATS والمؤسسات والشركات والمعرّفات والفئات التي تهمك تحت قسم sources في ملفك التعريفي.

القانون​

profiles/paralegal_nyc.yaml
sources:
  ashby:
    orgs:
      - "crosby"
      - "normlaw"
      - "hargrove-firm"
      - "lawhive"
  workable:
    slugs:
      - "shegerianand-associates-1"
      - "harper-james"
      - "legalvision"
  builtinnyc:
    enabled: true
    categories:
      - "jobs/legal"
      - "jobs/legal/search/paralegal"

الكتابة التقنية​

profiles/tech_writer.yaml
sources:
  greenhouse:
    enabled: true
    boards:
      - "gitlab"
      - "cloudflare"
  ashby:
    orgs:
      - "modal"
      - "perplexity"
      - "replit"
  lever:
    enabled: true
    companies:
      - "spotify"
  workable:
    slugs:
      - "soda-data-nv"
  builtinnyc:
    enabled: true
    categories:
      - "jobs/technical-writer"

الرعاية الصحية والتقنية الحيوية​

profiles/healthcare.yaml
sources:
  workable:
    slugs:
      - "bask-health-1"
      - "atria-health"
  builtinnyc:
    enabled: true
    categories:
      - "jobs/healthcare"
تلميح

انسخ الكتلة الأقرب إلى مجالك، ثم استبدل بها الشركات التي تتابعها بالفعل. وتأتي رموز المنصات من عنوان الوظائف العام لدى الشركة.

المنصات المخصصة​

سجّل نطاقات ATS مخصصة تحت platforms.custom. ويقرأ المحرك كل رابط وظيفة يكتشفه ويقارنه بنطاقاتك. ويوجّه Sweepy التطابقات إلى دليل تقرير خاص بها.

profiles/paralegal_nyc.yaml
platforms:
  custom:
    - name: "LawCrossing"
      domain: "lawcrossing.com"
      enabled: true
    - name: "Indeed Legal"
      domain: "indeed.com/legal"
      enabled: true

يأخذ كل إدخال ثلاثة حقول:

الحقلمطلوبما يفعله
nameنعمالتسمية التي يعرضها Sweepy لهذه المنصة في التقارير.
domainنعمنطاق الويب أو المسار الذي يقارنه المحرك بكل رابط وظيفة.
enabledلااضبطه على false للإبقاء على الإدخال وتجاوز المطابقة. والقيمة الافتراضية true.

المحركات الاختيارية​

يتضمن Sweepy محركي ats وjobspy افتراضيًا. وتضيف المحركات الاختيارية منصات عندما تنزّلها.

المحركالمنصاتقبل أن تثبّت
hirehuntLinkedIn وIndeed وNaukri وShine وInternshala وUnstop وGoogle Careers وAmazon وMeta وApple وNetflix وMicrosoftلا شيء
openrolesمنصات Greenhouse وLever وAshby وWorkday التي تسميهامعرّفات companies
jobdrop33 منصة، منها Google وWellfound وWorkday وiCIMS وDice وUSAJobsمرّر --allow-engine-conflicts مع JobSpy
apifyLinkedIn عبر ممثل مُدارAPIFY_TOKEN وفوترة Apify

ثبّت كل محرك متوافق دفعة واحدة:

الطرفية
sweepy --install-engines all

تتجاوز مجموعة all محرك JobDrop لأنه يثبّت curl-cffi<0.8 بينما يحتاج JobSpy إلى curl_cffi>=0.16.2.

لتثبيت JobDrop وحده:

الطرفية
sweepy --install-engines jobdrop --allow-engine-conflicts

يشغّل خيار Download job engines في معالج الإعداد عمليات التثبيت نفسها. ثم اسرد المحرك تحت sources.enabled واضبط خيارات منصاته:

profiles/paralegal_nyc.yaml
sources:
  enabled: [jobspy, ats, openroles]
  openroles:
    companies:
      - "figma"
      - "stripe"

مقايضة النطاق الترددي​

تطلب منصات Greenhouse المحتوى الكامل في طلب واحد لكل منصة بإضافة ?content=true. فتصل الأوصاف والأقسام وبيانات الأجر الوصفية جاهزة للاحتساب. وتعيد بعض المنصات مئات الإعلانات، فقد يسحب مسح واحد عشرات قليلة من الميغابايتات عبر كل المنصات المدرجة في البذور.

ويُبقي Sweepy تلك الكلفة محدودة بثلاث طرق:

  • يرشّح الإعلانات مسبقًا حسب titles في ملفك التعريفي أثناء توحيد كل سجل.
  • يرسل طلبًا واحدًا لكل مصدر بذور في كل مرة، ولا يرسلها بالتوازي قط.
  • يتوقف لمدة SWEEPY_SOURCE_DELAY بين الطلبات، وقيمتها الافتراضية 0.2 ثانية.

تنتهي قوائم البذور الأصغر أسرع. وإذا بدا المسح بطيئًا، فقلّص قوائم البذور أولًا.

توافق المنصات​

لأن Sweepy يستخرج HTML عاديًا ويعمل دون متصفح بلا واجهة، تعيد بعض أنواع المنصات بيانات أقل من غيرها.

نوع المنصةأمثلةالتوافقتحذيرات
ATS العامةGreenhouse وAshby وLever وWorkable وSmartRecruiters وBreezy HRمدعومة بالكامليحلل Sweepy صفحات الوظائف القياسية المعروضة على الخادم ويفحص كل رابط بحثًا عن استجابة حية.
تطبيقات صفحة واحدة تُعرض على العميلWorkday على myworkdayjobs.com، وOracle HCMمحدودتعرض هذه المنصات صفحات الوظائف بجافاسكربت على العميل. ودون متصفح بلا واجهة، قد تفتقر حمولات HTML الأولى إلى الأوصاف.
بوابات محمية بمصادقةHandshake والشبكات الداخلية للشركاتغير مدعومةتتطلب هذه البوابات ملفات تعريف ارتباط جلسة أو بيانات اعتماد SSO.
مجمّعات مقاومة للروبوتمنصات بـ Cloudflare Turnstile أو PerimeterXمحدودة بحدود الطلباتقد تطلق طلبات HTTP المؤتمتة حجب HTTP 403 دون تبديل وكلاء.
ملاحظة

قد ترى إعلانات Workday في التقارير عندما تتضمنها تغذية مجمّع. ويتحقق Sweepy من الرابط ويحتسب الوظيفة من أي نص تحمله الحمولة.
