مقدمة إلى واجهة برمجة تطبيقات Pet Store

يقدم هذا المستند مرجعًا لواجهة برمجة التطبيقات (API) لخادم Pet Store نموذجي. تساعد هذه الطلبات المطورين على الاتصال بخادم Pet Store. استخدمها لإرسال أو طلب البيانات المتعلقة بالحيوانات الأليفة والطلبات في النظام.

باستخدام واجهة برمجة تطبيقات Pet Store، يمكن للمطور:

الحيوانات الأليفة

  • إضافة حيوان أليف جديد، أو البحث عن حيوان أليف بالمعرف، أو تحديث حيوان أليف موجود، أو حذف حيوان أليف في قاعدة البيانات.
  • تحديث حيوان أليف ببيانات النموذج.
  • تحميل صورة لحيوان أليف.
  • البحث عن الحيوانات الأليفة حسب الحالة أو العلامات.

المتجر

  • الحصول على مخزون الحيوانات الأليفة مصنفًا حسب الحالة.
  • تقديم طلب لشراء حيوان أليف.
  • البحث عن أمر شراء بالمعرف.
  • إلغاء أمر شراء.

المستخدم

  • إنشاء مستخدم أو إنشاء قائمة مستخدمين.
  • تسجيل دخول وتسجيل خروج المستخدم من النظام.
  • الحصول على مستخدم حسب اسم المستخدم، أو تحديث معلومات المستخدم، أو حذف مستخدم.

تستخدم هذه الأمثلة حيوانًا أليفًا نموذجيًا يُدعى Krypto برقم تعريف 210.

المتطلبات الأساسية للاتصال​

عنوان URL الأساسي لجميع طلبات واجهة برمجة التطبيقات هو https://petstore3.swagger.io/api/v3.

المصادقة​

للتحقق من صحة اتصالك بواجهة برمجة تطبيقات Petstore، استخدم OAuth 2.0 أو مفتاح واجهة برمجة تطبيقات مخصص. لطلب مفتاح، أرسل بريدًا إلكترونيًا إلى budbaker@bhavenpets.com.

خطر

لأغراض أمنية، لا تشارك مفاتيح واجهة برمجة التطبيقات (API) مع مستخدمين آخرين. إذا اشتبهت في حدوث خرق أمني، فاتصل بالمسؤول على الفور. يمكن للمسؤول إلغاء المفتاح القديم وإصدار مفتاح جديد.
