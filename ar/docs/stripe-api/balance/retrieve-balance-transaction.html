استرجاع تفاصيل معاملة رصيد

لا تتغير معاملة الرصيد بعد إنشاؤها بواسطة منصة Stripe؛ عندما تتغير حالة عملية الشحن أو يتم إتمام عملية الاسترداد، تقوم منصة Stripe بإنشاء سجل جديد لمعاملة الرصيد بدلاً من تعديل السجل القديم.

GET https://api.stripe.com/v1/balance_transactions/{id}

ثبات دفتر الأستاذ

لا تتغير معاملة الرصيد أبدًا بعد أن تقوم Stripe بإنشائها. وعندما تتغير حالة عملية تحصيل أو تكتمل عملية استرداد، تقوم Stripe بإنشاء معاملة رصيد جديدة بدلاً من تعديل المعاملة القديمة.

المعاملات المطلوبة​

  • cURL
  • Node.js
  • Python
cURL
curl -X GET https://api.stripe.com/v1/balance_transactions/txn_1NirD82eZvKYlo2CIvbtLWuY \
  -u "sk_test_51Mz0...:"
Node.js
import Stripe from 'stripe';
const stripe = new Stripe(process.env.STRIPE_SECRET_KEY);

const txn = await stripe.balanceTransactions.retrieve(
  'txn_1NirD82eZvKYlo2CIvbtLWuY'
);
console.log(`Net amount: ${txn.net} ${txn.currency}`);
Python
import os
import stripe

stripe.api_key = os.environ["STRIPE_SECRET_KEY"]

txn = stripe.BalanceTransaction.retrieve("txn_1NirD82eZvKYlo2CIvbtLWuY")
print(f"Net amount: {txn.net} {txn.currency}")

idنصإلزاميمعرف المعاملة المتعلقة بالرصيد، يبدأ بالرمز txn_.

معاملات الاستعلام​

المعاملالنوعإلزامي/اختياريالوصف
expand[]مصفوفة من السلاسل النصيةاختيارييقوم بتوسيع الكائنات ذات الصلة داخل النتيجة؛ يدعم استخدام expand[]=source لإرجاع كائن الشحن أو الاسترداد الكامل.

الاستجابات​

الكودالحالةالوصف
200موافقيعيد كائن معاملة الرصيد.
400طلب غير صحيحأرسل العميل معرّف معاملة غير صحيح أو معلمة توسيع غير صالحة.
401طلب غير صحيحأرسل العميل رقم معاملة غير صحيح أو معامل توسيع غير صالح.
404عدم التصريحمفتاح سري غير موجود أو منتهي الصلاحية.

خصائص الرد​

الخاصيةالنوعالوصف
idنصمعرف فريد لسجل المعاملة، مسبوق بـ txn_.
objectنصمعرف ثابت؛ يُرجع دائمًا قيمة balance_transaction.
amountعدد صحيحالمبلغ الإجمالي للمعاملة بأصغر وحدة نقدية؛ الأرقام الموجبة تمثل الأموال الواردة، والأرقام السالبة تمثل الاستردادات أو المدفوعات.
available_onتوقيتتوقيت من نظام يونكس الذي يشير إلى موعد توافر الأموال للدفع.
createdتوقيتتوقيت من نظام يونكس الذي يشير إلى موعد إنشاء حدث المعاملة بواسطة خدمة Stripe.
currencyسلسلة نصيةرمز عملة مكون من ثلاثة أحرف بأحرف صغيرة، مثل usd.
feeعدد صحيحإجمالي رسوم المعالجة التي تخصمها خدمة Stripe، بأصغر وحدة نقدية.
fee_detailsمصفوفة من الكائناتتفاصيل تفصيلية للمصاريف، تشمل نسب المعالجة الخاصة بخدمة Stripe ورسوم التطبيق.
netعدد صحيحالتأثير الصافي للمعاملة، حسب الفرق بين amount وfee.
reporting_categoryنصفئة تصنيفية للمعاملة، تشمل charge أو refund أو payout.
sourceنصمعرف المورد الأصلي للمعاملة (ch_، re_، po_)؛ يمكن توسيع هذا المعرف لعرض المعلومات الكاملة عن الكائن.
statusنصحالة التسوية؛ القيم هي available أو pending.

خاصية التكرارية والمطابقة​

  • لا تنطبق خاصية التكرارية على عمليات القراءة.
  • بالنسبة لمطابقة البيانات المالية، احسب إجمالي المبالغ المستحقة الدفع عن طريق جمع قيم net لجميع المعاملات، بدلاً من تتبع التكاليف مباشرةً.

نقاط النهاية ذات الصلة​

  • استرجاع الرصيد: عرض المبالغ النقدية المستحقة الدفع والمعلقة.
  • مفهوم تدفق الأموال: تفاصيل حساب الرسوم وجداول زمنية للتسويات.
