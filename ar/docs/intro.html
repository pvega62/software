مقدمة

مرحبًا بكم في مجموعة كتاباتي التقنية​

يجمع هذا الموقع عينات وثائق البرمجيات من مجموعة كتاباتي التقنية. يقوم Docusaurus بإنشاء كل صفحة من ملفات Markdown وMDX الأصلية. تشمل المجموعة دليل المطورين، مراجع لواجهات برمجة التطبيقات، بالإضافة إلى وثائق المنتجات؛ كما توضح كل عينة العملية التي تم من خلالها إنشاؤها.

تنقل بين عينات المجموعة​

يمكن تصفح العينات حسب نوع المنتج أو المجال المستخدم:

دليل المطورين والأنظمة​

  • تثبيت وتطبيق تصميم خاص على متصفح Google Chrome. دليل تفصيلي لتخصيص المتصفح يشمل علامات تبويب تفاعلية وتصميمًا يتكيف مع أحجام الشاشات المختلفة.
  • تدفق العمل من Microsoft Word إلى موقع ويكي على GitHub باستخدام أداة Writage: دليل لكتابة ملفات بصيغة Markdown في برنامج Word، ثم تحويل التعديلات إلى موقع ويكي عبر تطبيق GitHub Desktop.
  • استخدام Postman للاتصال بواجهة برمجة التطبيقات (API) الخاصة بـ Stripe. دليل لتأكيد الهوية وإرسال طلبات API باستخدام Postman.
  • إنشاء خادم وهمي باستخدام Postman: دليل عملي لتكوين الخوادم الوهمية لاختبار تكاملات الويبكوت ومخططات واجهات برمجة التطبيقات.
  • توجيه سجلات تطبيق السحابة إلى خط أنابيب معالجة البيانات. إجراء تشغيلي لاستيراد وتصفية بيانات الأداء الخاصة بتطبيقات السحابة.
  • كيفية الحصول على بيانات الكائنات. دليل يشرح كيفية إجراء استعلامات قراءة باستخدام مكتبة Sui TypeScript SDK.
  • استخدام عملية الكتابة لإرسال المعاملات. دليل للمطورين حول كيفية توقيع وبث المعاملات القابلة للبرمجة.

وثائق بحث الوظائف باستخدام أداة Sweepy​

أداة Sweepy: تقوم بفحص أنظمة تتبع المتقدمين ومنصات الوظائف، ثم تقييم كل إعلان وفقًا للسيرة الذاتية؛ هذه الأداة مفتوحة المصدر وتتضمن مجموعة من الوثائق المكونة من 14 صفحة، تشمل تعليمات التثبيت وإعداد الملفات الشخصية وتصدير البيانات بصيغة PDF أو CSV، بالإضافة إلى وثائق حول خادم بروتوكول سياق النموذج (Model Context Protocol – MCP) الذي يتم تشغيله بواسطة مساعد الذكاء الاصطناعي.

البدء في استخدام أداة Sweepy​

  • مقدمة عن أداة Sweepy: شرح لوظيفة الأداة ومراحل عملية البحث، بالإضافة إلى كيفية تقييم السير الذاتية بواسطة الأداة.
  • تثبيت أداة Sweepy: خطوات تثبيت الأداة على أنظمة ويندوز وماك ولينكس باستخدام لغة بايثون ومكتبة Git ومستودعات الكود.
  • إعداد أداة Sweepy: إنشاء ملفات إعداد البحث باستخدام أداة المساعد أو ملفات من نوع YAML.
  • تشغيل أول عملية بحث باستخدام أداة Sweepy: خطوات تنفيذ عملية البحث من إنشاء ملفات الإعداد حتى عرض نتائج البحث.

قراءة النتائج​

  • فهم النتائج: شرح تفاصيل تنسيق النتائج المعروضة في ملفات PDF، نسب المطابقة بين المتقدمين والوظائف، وأعمدة تتبع البيانات في ملفات CSV.
  • السير الذاتية ونتائج المطابقة: يشرح تنسيق السير الذاتية لأغراض التحليل، بالإضافة إلى خطوات حساب نسبة المطابقة بين محتوى السيرة الذاتية ومتطلبات الوظيفة.
  • كيف يقوم Sweepy بتقييم السير الذاتية: يوضح المعايير المستخدمة في تحديد نتائج التقييم، وما لا يمكن لهذا النظام قياسه من جوانب السيرة الذاتية.

المراجع والتكاملات​

  • دليل أوامر Sweepy وإعداداته: يسرد جميع الأوامر المتاحة في Sweepy، وإعدادات المستخدم، بالإضافة إلى مصادر الوظائف المدعومة.
  • تكامل Sweepy مع نظام MCP: يوضح كيفية ربط Sweepy مع خادم MCP الداخلي مع أدوات مثل Antigravity أو Claude Desktop أو VS Code.
  • دليل أدوات Sweppy MCP: يوفر معلومات عن الأدوات الثلاثة عشر المدعومة، ومعاملاتها، وبيانات الاستجابة التي تُرجعها.

فهرس وثائق Sweepy: يجمع جميع صفحات الوثائق، بما في ذلك تعليمات التثبيت، ونتائج أول عملية تحليل، وملاحظات المطورين، بالإضافة إلى دراسة حالة تتعلق بتصميم واجهة المستخدم.

مراجع الواجهة البرمجية الخارجية​

  • واجهة برمجية Stripe: دليل مفصل لبنية الدفع؛ صفحة واحدة لكل نقطة نهائية (endpoint)، مع صفحات منفصلة لشرح المفاهيم والبدء السريع في الاستخدام.
    • واجهات برمجية Balance
    • واجهات برمجية Payment Intent
    • واجهات برمجية Refund
  • واجهة برمجة التطبيقات لـ Blüdhaven Pets: إدارة الحيوانات الأليفة في المؤسسات، الترخيص البلدي، ومخزون التجزئة، موثقة وفقًا لعقد OpenAPI 3.1.
    • مرجع واجهة برمجة التطبيقات التفاعلي
    • نموذج المجال
    • مصادقة المستخدمين ونطاقات الوصول
    • تفاصيل الأخطاء والمشكلات
    • التصفح التدريجي للبيانات
    • حدود عدد الطلبات وآليات إعادة المحاولة
    • سياسات إصدار الإصدارات وتغييرها
    • الاستجابات التلقائية (Webhooks) والتوقيعات
    • طلبات الاختبار
    • حل المشكلات
    • عمليات احتجاز الحيوانات قبل التبني وإدارة التزامن
    • الرسوم والاستردادات
    • الامتثال والترخيص
  • واجهة برمجة التطبيقات لاستقبال السجلات من Datadog: واجهة برمجية لإرسال بيانات القياسات التقنية بشكل دفعي.
  • مرجع لمكتبة Sui TypeScript SDK:
    • SuiClient.getObject
    • SuiClient.multiGetObjects
    • SuiClient.getOwnedObjects

الوثائق المتعلقة بالهندسة والمفاهيم​

  • مقدمة حول واجهة برمجة التطبيقات لـ Stripe: نظرة عامة مفاهيمية على دورة حياة المدفوعات، المفاتيح المستخدمة، إعادة المحاولات، التصفح التدريجي للبيانات، وإدارة الإصدارات.
  • مفاهيم واجهة برمجة التطبيقات لـ Stripe: كيفية تحرك الأموال عبر خدمة Stripe، بالإضافة إلى السلوكيات المشتركة لكل نقطة النهاية (endpoint): المصادقة، القابلية لإعادة التنفيذ، الأخطاء، التصفح التدريجي للبيانات، إدارة الإصدارات، ووضع الاختبار.
  • دليل سريع لاستخدام واجهة برمجة التطبيقات لـ Stripe: شرح خطوات استقبال المدفوعات عبر البطاقات وتنفيذ الطلبات من خلال خدمة webhook مؤكدة.
  • تدفقات الأحداث وأنظمة مراقبة البيانات: نظرة عامة هندسية على معالجة التدفقات البيانية، توجيه الطلبات عبر الشبكة، وتحويل البيانات.
  • مراقبة متوازية للسحابة والذكاء الاصطناعي: دليل هندسي يقارن نماذج توجيه السجلات في الأنظمة المؤسسية.
  • الـ SuiClient: يشرح كيفية توجيه استعلامات الحالة (state queries) بواسطة عملاء RPC الموزعة.

رسائل الإرسال (Commit messages) وطلبات السحب​

  • إصلاح مشكلة عمليات نقل البيانات في المصفوفات المرتبة حسب ترتيب F: رسالة الإرسال ووصف طلب السحب من تمرين كتابي، مع إعادة إنتاج التعديل المقدم للسياق.
  • جعل الكود ak.mean قابلاً للتفاضل تحت بيئة JAX: رسالة الإرسال ووصف طلب السحب من تمرين كتابي، مع إعادة إنتاج التعديل المقدم للسياق.

دراسات حالة​

  • تصميم أداة Artie، مساعد توثيق الذكاء الاصطناعي: دراسة حالة هندسية تحلل هندسة الأوامر (prompt engineering)، أمان النماذج العميقة (LLM)، وبنية استرجاع المعلومات (RAG).
  • عندما يعني الرقم 92% أشياء مختلفة: دراسة حالة في مجال تصميم واجهات المستخدم تتناول ملصقات النتائج، خطوط الحالة، وتلميحات الأوامر في واجهة سطر الأوامر في تطبيق Sweepy.

لفحص مصادر Markdown الخام لهذه الوثائق، قم بتصفح مستودع GitHub.

نموذج عمل “الوثائق ككود”​

  • كتابة المحتوى باستخدام صيغة Markdown وMDX باستخدام أداة VS Code وAntigravity.
  • فحص جودة النصوص والأسلوب باستخدام أداة Vale.
  • التدويل والترجمة باستخدام أداة DeepL وLara
  • رسم مخططات هندسة الأنظمة باستخدام أداة Mermaid
  • كتابة وثائق المنتج لأداة سطر الأوامر وخادم إدارة المنتج (MCP) مع كل إصدار جديد
  • التحكم في الإصدارات ومراجعة الكود بشكل تعاوني باستخدام أدوات Git وGitHub
  • استكشاف والتحقق من صحة واجهات برمجة التطبيقات باستخدام أدوات Postman وSwagger/OpenAPI
  • إنشاء عقود واجهات برمجة التطبيقات وفقًا لمعايير OpenAPI 3.1 باستخدام أدوات مشتركة وتقنيات التقديم البصري
  • النشر المستمر للمحتوى باستخدام أداة Docusaurus

مكدس التقنيات​

  • Docusaurus: يقوم بإنشاء مواقع إلكترونية ثابتة (static sites)، وشرائط تنقل (navigation sidebars)، بالإضافة إلى نسخ مترجمة من المحتوى (localized versions).
  • VS Code: يوفر واجهة التحرير الرئيسية لكتابة ملفات Markdown وMDX.
  • Postman: يقوم بالتحقق من نهايات واجهات برمجة التطبيقات (API) ويولد أمثلة للطلبات والاستجابات.
  • OpenAPI 3.1 وScalar: يحدد عقد خدمات Blüdhaven Pets ويعرضه كمرجع تفاعلي مكون من ثلاثة أقسام.
  • Vale: تقوم بفحص النصوص التقنية لضمان التزامها بإرشادات وثائق مطوري جوجل (Google Developer Documentation Guidelines).
  • Git وGitHub: تتبع التغييرات في المشاريع وتقوم بنشر الموقع عبر هذه الأدوات.
  • Mermaid: تستخدم لعرض مخططات التدفق (flowcharts) ورسومات خطوط العمليات (data pipeline diagrams).
  • Python وMCP: تشغل محرك Sweepy والخادم الذي يربطه بمساعدي الذكاء الاصطناعي.
  • DeepL وLara: تقوم بترجمة الوثائق تلقائيًا إلى لغات أخرى.

كل صفحة في الموقع تحتوي على ملف من نوع Markdown أو MDX داخل نفس المستودع الخاص بالمشروع؛ يتم مقارنة النتائج المعروضة مع النص الأصلي.

كل عينة من النصوص تمر بنفس الخطوات: البحث، التصميم، الاختبار، المراجعة، ثم النشر.
