Instalación de Sweepy

Necesitas tres cosas en tu ordenador para poder ejecutar Sweepy:

  1. Python: el lenguaje de programación que hace funcionar el motor.
  2. Git: una herramienta que descarga el código del motor desde Internet.
  3. pip: un gestor de paquetes que instala las bibliotecas adicionales que necesita el motor. Los instaladores oficiales para Windows y macOS incluyen pip. Las distribuciones de Linux añaden pip a través del gestor de paquetes del sistema.
nota

Esta guía explica paso a paso todo el proceso para quienes nunca hayan abierto un terminal. Si ya tienes instalado Python 3.10 o una versión posterior y Git, pasa directamente al Paso 3.

Paso 1: Abre el terminal​

Un terminal, también conocido como «línea de comandos», es una ventana basada en texto en la que se escriben comandos. Aquí se introducen instrucciones para el ordenador en lugar de seleccionar iconos.

  • Windows
  • macOS
  • Linux

Pulsa la tecla Windows, escribe PowerShell y, a continuación, selecciona Windows PowerShell.

Terminal
Windows PowerShell
Copyright (C) Microsoft Corporation. All rights reserved.

PS C:\Users\YourName>

Pulsa Comando + Espacio, escribe Terminal y, a continuación, pulsa Intro.

Terminal
Last login: Mon Oct 19 14:40:23 on ttys000
yourname@MacBook-Pro ~ %

Pulsa Ctrl + Alt + T para abrir una ventana de terminal en la mayoría de las distribuciones de Linux.

Terminal
yourname@ubuntu:~$

La línea de comandos termina con un cursor parpadeante. Ese cursor indica que tu terminal está lista para recibir un comando.

Paso 2: Comprobar e instalar Python​

Sweepy requiere Python 3.10 o una versión posterior. Comprueba si ya lo tienes instalado.

Escribe este comando en tu terminal y pulsa Intro:

Terminal
python --version

En macOS y Linux, el comando es python3 --version.

Si ves «Python 3.10.x» o una versión superior, ya tienes Python. Pasa al Paso 3.

Si aparece un mensaje de error del tipo «No se reconoce "python"» o la versión es inferior a la 3.10, sigue los pasos de instalación que se indican a continuación.

  • Windows
  • macOS
  • Linux
  1. Visita la página de descargas de Python para Windows.
  2. Selecciona el enlace de descarga más reciente del instalador de Windows (64 bits).
  3. Ejecuta el archivo descargado.
  4. Este paso es fundamental. En la primera pantalla del instalador, marca la casilla titulada «Añadir python.exe a PATH» que aparece en la parte inferior. Al marcarla, Python se añade a tu PATH, de modo que el terminal pueda encontrarlo.
  5. Selecciona Instalar ahora y espera a que finalice la instalación.

A continuación, confirma la instalación en una nueva ventana de terminal:

Terminal
PS C:\Users\YourName> python --version
Python 3.13.1
precaución

Si omites la opción «Añadir python.exe a la variable PATH», tu terminal no reconocerá el comando python. Desinstala Python y, a continuación, vuelve a instalarlo con la casilla marcada.

  1. Visita la página de descargas de Python para macOS.
  2. Descarga el último instalador universal2 de macOS de 64 bits.
  3. Abre el archivo .pkg descargado y sigue las instrucciones de instalación.

A continuación, confirma la instalación en una nueva ventana de terminal:

Terminal
yourname@MacBook-Pro ~ % python3 --version
Python 3.13.1

Ejecuta estos dos comandos en tu terminal:

Terminal
sudo apt update
sudo apt install python3 python3-pip python3-venv
consejo

En Fedora o Red Hat Enterprise Linux, sustituye apt por dnf: sudo dnf install python3 python3-pip.

A continuación, confirma la instalación en una nueva ventana de terminal:

Terminal
yourname@ubuntu:~$ python3 --version
Python 3.12.3

Las pestañas de Windows, macOS y Linux concluyen con la misma comprobación. Cierra el terminal, ábrelo de nuevo y ejecuta el comando «version». Si el número de versión es 3.10 o superior, significa que Python está listo.

Paso 3: Descargar Sweepy​

Descargar los archivos de origen de Sweepy

Elige un método. Puedes usar Git, que se describe a continuación, o descarga un archivo ZIP desde la página de versiones de Sweepy.

Git copia los archivos del proyecto en tu ordenador y registra su historial. Ese historial permite que Sweepy se actualice por sí mismo. Los pasos siguientes usan Git.

  • Copia con Git. Ejecuta sweepy --update o usa el actualizador de Sweepy's Toolbox para descargar cada versión nueva.
  • Copia en ZIP. Descarga, descomprime y vuelve a ejecutar pip install -e . para cada versión. Las actualizaciones automáticas quedan desactivadas, porque un ZIP no tiene historial de Git del que descargar.
  • Nombre de la carpeta. Git crea una carpeta llamada sweepy. Un ZIP se descomprime en una carpeta como sweepy-main, así que ajusta el comando cd que aparece más adelante en este paso.

Elige el ZIP si solo quieres probar Sweepy una vez. Elige Git si piensas seguir usándolo.

Si encuentras un error, infórmalo en Issues y pega el comando que ejecutaste.

En primer lugar, comprueba si Git ya está instalado:

Terminal
git --version

Si ves un número de versión como git version 2.45.1, significa que tienes Git. Si aparece un error, instala Git:

  • Windows
  • macOS
  • Linux
  1. Visita git-scm.com/download/win.
  2. Descarga y ejecuta el instalador.
  3. Acepta todos los ajustes predeterminados y selecciona Instalar.
  4. Cierra y vuelve a abrir el terminal; a continuación, confirma:
Terminal
PS C:\Users\YourName> git --version
git version 2.45.1

Ejecuta este comando y macOS te pedirá que instales las herramientas de línea de comandos de Xcode, que incluyen Git:

Terminal
yourname@MacBook-Pro ~ % git --version
xcode-select: note: install requested for command line developer tools

Sigue las instrucciones que aparecen en pantalla para realizar la instalación y, a continuación, vuelve a ejecutar git --version. Si aparece un número de versión, significa que Git ya está listo.

Terminal
yourname@ubuntu:~$ sudo apt install git

A continuación, confirma:

Terminal
yourname@ubuntu:~$ git --version
git version 2.45.1

Ahora, descarga Sweepy ejecutando:

Terminal
git clone https://github.com/pvega62/sweepy.git

Esto creará una nueva carpeta llamada sweepy en tu ordenador. Accede a ella:

Terminal
cd sweepy
consejo

Git coloca la nueva carpeta en el directorio al que apuntaba tu terminal cuando ejecutaste el comando. En Windows, se abre una nueva ventana de PowerShell en C:\Users\TuNombre\.

Paso 4: Instalar las dependencias​

Sweepy necesita algunas bibliotecas adicionales para funcionar:

  • pymupdf: lee y extrae el texto de tu currículum en formato PDF.
  • python-docx: lee y convierte currículums en formato .docx.
  • python-jobspy: recopila información de las bolsas de empleo de forma segura sin necesidad de una clave API.
  • beautifulsoup4: analiza el código HTML de las fuentes Greenhouse, Lever, Workable y Built In.
  • reportlab: genera el informe en PDF con formato y enlaces en los que se puede hacer clic.
  • solicitudes: envía solicitudes web para comprobar si las URL siguen activas.
  • pyyaml y questionary: se encargan del asistente de configuración interactivo. prompt-toolkit proporciona los controles de teclado.
  • pandas: estructura los datos recopilados de las ofertas de empleo y genera archivos CSV para exportar a hojas de cálculo.
  • mcp y anyio: ejecutan el servidor opcional del Protocolo de Contexto de Modelos (Model Context Protocol) que conecta Sweepy con un asistente de IA.
Python 3.13

Si utilizas Python 3.13, instala primero las Herramientas de compilación de Microsoft C++ y selecciona la configuración «Desarrollo de escritorio con C++». Python 3.13 es una versión tan reciente que algunos paquetes, como pymupdf, pueden compilarse desde el código fuente y requerir esas herramientas. Omite este paso si utilizas Python 3.12 o una versión anterior.

Las pruebas automatizadas de Sweepy abarcan desde Python 3.10 hasta 3.12. Esas versiones siguen siendo las que ofrecen un funcionamiento más fluido.

Instala todos los paquetes con un solo comando:

Terminal
pip install -e .

Ese comando instala todas las dependencias y registra un comando sweepy en tu carpeta de scripts de Python. Vuelve a abrir el terminal una vez para que la variable PATH detecte la nueva carpeta. A partir de ese momento, ejecuta «sweepy --run» en lugar de «python swee.py --run». Ejecuta cualquiera de las dos opciones desde tu carpeta «sweepy».

El texto va pasando a medida que Python descarga e instala cada paquete. Cuando vuelve el cursor, la instalación ha finalizado.

consejo

¿Te ha aparecido el error «comando no encontrado» al ejecutar pip? Prueba con pip3 install -e .. En algunos sistemas, Python 3 utiliza pip3 como nombre del comando.

Comprueba tu instalación​

Realiza esta comprobación rápida para asegurarte de que todo se ha instalado correctamente:

Terminal
sweepy --version

Si tu shell no encuentra sweepy, vuelve a abrir el terminal o ejecuta python swee.py --version en su lugar. Verás lo siguiente:

Salida del terminal
Sweepy v3.0.0
Python 3.13.1 | pymupdf 1.28.2 | reportlab 5.0.1
Ready to sweep.

Si aparece ese mensaje, Sweepy ya está listo. Es posible que los números que aparezcan en tu equipo sean diferentes. Sweepy muestra la información de la versión de su archivo VERSION, y pip instala los paquetes que se corresponden con tu versión de Python.

En la segunda línea se indican las versiones de pymupdf y reportlab.

A continuación, configura tu perfil personalizado de búsqueda de empleo.
