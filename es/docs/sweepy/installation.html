Instalación de Sweepy

En este tutorial, aprenderá a instalar Sweepy en su ordenador. Necesita tres herramientas primero:

  1. Python: Es el motor que ejecuta el programa.
  2. Git: Descarga el código del programa desde Internet.
  3. pip: Instala las bibliotecas adicionales que necesita el programa. Los instaladores oficiales para Windows y macOS incluyen pip; las distribuciones de Linux lo añaden a través del administrador de paquetes del sistema.
nota

Esta guía le guiará paso a paso, incluso si nunca ha abierto un terminal antes. Si ya tiene instalado Python 3.10+ y Git, pase directamente a Paso 3.

Paso 1: Abre tu terminal​

Un terminal, también conocido como «línea de comandos», es una ventana de texto en la que escribes comandos. Aquí le das instrucciones al ordenador en lugar de seleccionar iconos.

  • Windows
  • macOS
  • Linux

Presione la tecla Windows, escriba PowerShell y luego seleccione Windows PowerShell.

Terminal
Windows PowerShell
Copyright (C) Microsoft Corporation. All rights reserved.

PS C:\Users\YourName>

Presione Comando + Espacio, escriba Terminal y luego presione Entrar.

Terminal
Last login: Mon Oct 19 14:40:23 on ttys000
yourname@MacBook-Pro ~ %

Presione Ctrl + Alt + T para abrir una ventana de terminal en la mayoría de las distribuciones de Linux.

Terminal
yourname@ubuntu:~$

La pantalla muestra un cursor parpadeante al final de la instrucción; ese cursor indica que el terminal está listo para recibir comandos.

Paso 2: Comprueba e instala Python​

Sweepy requiere Python 3.10 o una versión más reciente. Compruebe si ya lo tiene instalado.

Escriba este comando en su terminal y presione Entrar:

Terminal
python --version

En macOS y Linux, la comando es python3 --version.

Si ve Python 3.10.x o un número superior, ya cuenta con Python. Pase directamente a Paso 3.

Si ve un mensaje de error como 'python' is not recognized o una versión inferior a 3.10, siga los pasos de instalación que se indican a continuación.

  • Windows
  • macOS
  • Linux
  1. Visite la página de descargas de Python para Windows.
  2. Selecciona el enlace de descarga del instalador más reciente para Windows.
  3. Ejecute el archivo descargado.
  4. Este paso es crítico. En la primera pantalla del instalador, seleccione la casilla de verificación etiquetada “Añadir python.exe a PATH” que se encuentra en la parte inferior. Esta acción añade Python a su sistema, de modo que el terminal pueda encontrarlo fácilmente.
  5. Selecciona Instalar ahora y espera a que termine la instalación.

Luego confirme la instalación en una nueva ventana del terminal.

Terminal
PS C:\Users\YourName> python --version
Python 3.13.1
precaución

Si omite la opción “Añadir python.exe a PATH”, su terminal no reconocerá el comando python. Desinstale Python y reinstálelo seleccionando la opción correspondiente.

  1. Visite la página de descargas de Python para macOS.
  2. Descargue el último instalador universal para macOS de 64 bits.
  3. Abra el archivo .pkg descargado y siga las instrucciones de instalación.

Luego confirme la instalación en una nueva ventana del terminal.

Terminal
yourname@MacBook-Pro ~ % python3 --version
Python 3.13.1

Ejecute estos dos comandos en su terminal:

Terminal
sudo apt update
sudo apt install python3 python3-pip python3-venv
consejo

En Fedora o Red Hat Enterprise Linux, reemplace apt por dnf: sudo dnf install python3 python3-pip.

Luego confirme la instalación en una nueva ventana del terminal.

Terminal
yourname@ubuntu:~$ python3 --version
Python 3.12.3

Las opciones de instalación para Windows, macOS y Linux terminan con el mismo proceso de verificación. Cierre su terminal, ábralo de nuevo y ejecute el comando para verificar la versión de Python (número 3.10 o superior indica que está listo para usar).

Paso 3: Descarga Sweepy​

Descargar los archivos de origen de Sweepy

Elija un método de instalación: utilice Git (descrito a continuación) o descargue un archivo ZIP de la página de lanzamiento de Sweepy.

Git copia los archivos del proyecto a su computadora y registra su historial de cambios; este historial permite que Sweepy se actualice automáticamente. Los pasos siguientes utilizan Git.

  • Copiar con Git: Ejecute el comando sweepy --update o el herramienta de actualización del conjunto de herramientas (Toolbox) para descargar las nuevas versiones.
  • Copiar con archivo ZIP: Descargue el archivo ZIP, descomprímalo y ejecute de nuevo el comando pip install -e . para cada nueva versión. Las actualizaciones automáticas no se activarán si se utiliza un archivo ZIP, ya que no contiene información de historial de cambios.
  • Nombre de la carpeta: Git crea una carpeta llamada sweepy; el archivo ZIP se descomprime en una carpeta como sweepy-main; ajuste el comando cd según corresponda.

Elija el método de descarga según sus necesidades. Si planea seguir utilizando Sweepy, elige Git.

Si surge un error, abra un ticket de soporte y pegue el comando que ejecutó.

Primero, verifique si Git ya está instalado:

Terminal
git --version

Si ve un número de versión como git version 2.45.1, significa que está utilizando Git.

Si aparece un error, instale Git:

  • Windows
  • macOS
  • Linux
  1. Visite git-scm.com/download/win.
  2. Descargue e instale el programa.
  3. Acepte todas las configuraciones predeterminadas y haga clic en Instalar.
  4. Cierre y vuelva a abrir su terminal para confirmar la instalación.
Terminal
PS C:\Users\YourName> git --version
git version 2.45.1

Ejecute este comando; macOS le pedirá que instale las Herramientas de Línea de Comando de Xcode, que incluyen Git.

Terminal
yourname@MacBook-Pro ~ % git --version
xcode-select: note: install requested for command line developer tools

Siga las instrucciones en pantalla para completar la instalación y, a continuación, vuelva a ejecutar git --version. El aparecimiento de un número de versión indica que Git está listo para usar.

Terminal
yourname@ubuntu:~$ sudo apt install git

Confirme el proceso de instalación.

Terminal
yourname@ubuntu:~$ git --version
git version 2.45.1

Ahora, descargue Sweepy ejecutando el siguiente comando.

Terminal
git clone https://github.com/pvega62/sweepy.git

Esto creará una nueva carpeta llamada sweepy en su ordenador; navegue hasta ella.

Terminal
cd sweepy
consejo

Git colocará esta carpeta en el directorio al que apuntaba su terminal cuando ejecutó el comando. En Windows, se abrirá una nueva ventana de PowerShell dentro de C:\Users\YourName\.

Paso 4: Instala las dependencias​

Sweepy requiere varias bibliotecas adicionales para funcionar correctamente:

  • pymupdf: lee y extrae texto de tu currículo en formato PDF.
  • python-docx: lee y convierte los currículos (resumes) almacenados en archivos con la extensión .docx.
  • python-jobspy: recopila información de las bolsas de empleo de forma segura sin necesidad de una clave API.
  • beautifulsoup4: analiza el código HTML de las fuentes Greenhouse, Lever, Workable y Built In NYC.
  • reportlab: genera el informe en PDF con formato y enlaces en los que se puede hacer clic.
  • solicitudes: envía solicitudes web para comprobar si las URL siguen activas.
  • pyyaml y questionary: se encargan del asistente de configuración interactivo. prompt-toolkit proporciona los controles de teclado.
  • pandas: estructura los datos de los empleos recopilados y genera exportaciones en formato de hoja de cálculo CSV.
  • mcp y anyio: Ejecutan el servidor opcional del Protocolo de Contexto del Modelo (Model Context Protocol), que conecta a Sweepy con un asistente de inteligencia artificial.
Python 3.13

Si usas Python 3.13, instala primero las Herramientas de compilación de Microsoft C++ y selecciona la opción «Desarrollo de escritorio con C++». Python 3.13 es tan reciente que algunos paquetes, como pymupdf, pueden compilarse desde el código fuente y necesitar esas herramientas. Omite este paso si usas Python 3.12 o una versión anterior.

Las pruebas automatizadas de Sweepy abarcan las versiones de Python 3.10 a 3.12; estas son las que ofrecen el funcionamiento más estable y sin problemas.

Instala cada paquete con una sola comando:

Terminal
pip install -e .

Esa comando instala todas las dependencias y registra una entrada del tipo sweepy en la carpeta de tus scripts de Python. Vuelve a abrir tu terminal para que PATH detecte la nueva carpeta. A partir de entonces, ejecuta sweepy --run en lugar de python swee.py --run. Puedes ejecutar cualquiera de estas dos comandas desde la carpeta sweepy.

El texto se desplaza mientras Python descarga e instala cada paquete. Cuando el cursor vuelve a su posición inicial, la instalación está completa.

consejo

¿Recibió un error de “comando no encontrado” al usar pip? Intente usar pip3 install -e . en su lugar. En algunos sistemas, Python 3 utiliza pip3 como nombre del comando.

Comprueba tu instalación​

Realice esta rápida comprobación para asegurarse de que todo esté instalado correctamente:

Terminal
sweepy --version

Si tu shell no puede encontrar sweepy, reinicia el terminal o ejecuta python swee.py --version en su lugar. Verás un mensaje de confirmación.

Terminal output
Sweepy v3.1.0
Python 3.13.1 | pymupdf 1.28.2 | reportlab 5.0.1
Ready to sweep.

Cuando aparezca ese mensaje, significa que Sweepy está listo para ser utilizado. Ten en cuenta que los números que se muestren en tu dispositivo pueden ser diferentes; Sweepy imprime la información de la versión actual desde su archivo VERSION, y pip instala los paquetes compatibles con tu versión de Python.

La segunda línea muestra las versiones de pymupdf y reportlab.

A continuación, configure su perfil personalizado de búsqueda de empleo.
