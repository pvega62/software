Fuentes de extracción y plataformas compatibles

Sweepy encuentra empleos de dos maneras. Consulta directamente cuatro plataformas ATS públicas y una plataforma de empleo de Nueva York. También puede leer canales de agregadores a través de python-jobspy. Esta página enumera todas las fuentes y te muestra cómo orientar Sweepy hacia tu sector.

Fuentes predeterminadas​

De entrada, Sweepy revisa cinco fuentes deterministas y una ruta de agregador. Las fuentes deterministas usan endpoints públicos que cualquiera puede abrir. No necesitan cuenta, inicio de sesión ni servicio de pago.

FuenteClave de configuraciónArchivo semillaEndpoint
Greenhousesources.greenhouse.boardsdata/sources/greenhouse_boards.txtboards-api.greenhouse.io/v1/boards/{board}/jobs?content=true
Ashbysources.ashby.orgsdata/sources/ashby_orgs.txtapi.ashbyhq.com/posting-api/job-board/{org}
Leversources.lever.companiesdata/sources/lever_companies.txtapi.lever.co/v0/postings/{company}?mode=json
Workablesources.workable.slugsdata/sources/workable_slugs.txtapply.workable.com/api/v1/widget/accounts/{slug}
Built In NYCsources.builtinnyc.categoriesdata/sources/builtin_categories.txtbuiltinnyc.com/{category}
Glassdoorsources.jobspy.glassdoorNonemediante python-jobspy

Reglas de activación​

Sweepy ejecuta una fuente determinista cuando se cumplen estos dos ajustes:

  1. Configuras sources.<name>.enabled en true.
  2. Configuras platforms.<name> en true cuando existe un ajuste equivalente.

Ambas claves valen true por defecto.

Ten en cuenta estas excepciones:

  • Built In NYC no tiene la configuración platforms.builtinnyc. El motor solo respeta sources.builtinnyc.enabled. Cada ficha incluye empresa, lugar de trabajo, ubicación y salario de la página de listados. Configura sources.builtinnyc.detail_pages: true para leer también el texto completo de la publicación. Built In bloquea esas páginas con un desafío tras algunas peticiones, así que Sweepy se detiene ante el primer desafío.
  • Glassdoor funciona a través de python-jobspy y respeta sources.jobspy.glassdoor. No existe la clave platforms.glassdoor, por lo que solo esa clave sources lo desactiva.

Para desactivar una fuente, configura una de sus claves en false.

Si tu perfil es anterior a la v2.2.0​

aviso

Ahora Greenhouse y Lever se ejecutan por defecto. Sweepy cambió este comportamiento en la v2.2.0. Los perfiles existentes descubren las nuevas publicaciones a menos que desactives esas fuentes. El valor por defecto de las banderas no cambió.

Las banderas platforms.ashby: false, platforms.workable: false, platforms.greenhouse: false y platforms.lever: false ahora detienen esas fuentes semilla deterministas. Antes de la v2.2.0, solo filtraban resultados de python-jobspy.

Desactiva una fuente con sources.<name>.enabled: false o su platforms.<name>: false.

Cómo funcionan los archivos semilla​

Sweepy usa los archivos semilla en data/sources/ como respaldo cuando tu perfil deja vacías las listas de fuentes.

  • Una lista vacía, como boards: [], recurre al archivo semilla curado.
  • Una lista explícita anula las semillas por completo. Tu lista reemplaza a las semillas, por lo que el motor no fusionará ambas.

Tu lista gana. Tú eliges las plataformas y las categorías de empleo.

Ejemplos para tu campo​

Añade las plataformas ATS, organizaciones, empresas, slugs y categorías que te interesan en la sección sources de tu perfil.

    orgs:
      - "crosby"
      - "normlaw"
      - "hargrove-firm"
      - "lawhive"

      - "shegerianand-associates-1"

  builtinnyc:
    enabled: true
    categories:
      - "jobs/legal"
      - "jobs/legal/search/paralegal"

Plataformas personalizadas​

Registra los dominios ATS personalizados en platforms.custom. El motor lee cada enlace de empleo que descubre y lo compara con tus dominios. Sweepy enruta las coincidencias a su propio directorio de informes.

profiles/paralegal_nyc.yaml
platforms:
  custom:
    - name: "LawCrossing"
      domain: "lawcrossing.com"
      enabled: true
    - name: "Indeed Legal"
      domain: "indeed.com/legal"
      enabled: true

Cada entrada usa tres campos:

CampoObligatorioQué hace
nameSíLa etiqueta que Sweepy muestra para esta plataforma en los informes.
domainSíEl dominio web o ruta que el motor compara con el enlace de cada oferta.
enabledNoEstablécelo en false para mantener la entrada pero omitir la coincidencia. Por defecto es true.

Motores opcionales​

Sweepy incluye los motores ats y jobspy por defecto. Los motores opcionales añaden plataformas cuando los descargas.

MotorPlataformasAntes de instalar
hirehuntLinkedIn, Indeed, Naukri, Shine, Internshala, Unstop, Google Careers, Amazon, Meta, Apple, Netflix, MicrosoftNinguno
openrolesPlataformas de Greenhouse, Lever, Ashby y Workday que indiquesslugs en companies
jobdrop33 plataformas, incluyendo Google, Wellfound, Workday, iCIMS, Dice y USAJobsPasa --allow-engine-conflicts junto a JobSpy
apifyLinkedIn a través de un actor gestionadoAPIFY_TOKEN y facturación de Apify

Instala todos los motores compatibles a la vez:

Terminal
sweepy --install-engines all

El conjunto all omite JobDrop porque fija curl-cffi<0.8, mientras que JobSpy necesita curl_cffi>=0.16.2.

Para instalar JobDrop por separado:

Terminal
sweepy --install-engines jobdrop --allow-engine-conflicts

La opción Download job engines del asistente de configuración ejecuta las mismas instalaciones. Después, añade el motor en sources.enabled y configura las opciones de su plataforma:

profiles/paralegal_nyc.yaml
sources:
  enabled: [jobspy, ats, openroles]
  openroles:
    companies:
      - "figma"
      - "stripe"

Impacto en el ancho de banda​

Las plataformas de Greenhouse piden el contenido completo en una solicitud por plataforma al añadir ?content=true. Así, las descripciones, departamentos y metadatos salariales llegan listos para su evaluación. Algunas plataformas devuelven cientos de ofertas. Por eso, un barrido puede descargar algunas decenas de megabytes entre todas las plataformas configuradas.

Sweepy limita este consumo de tres maneras:

  • Filtra previamente las ofertas según los titles de tu perfil mientras normaliza cada registro.
  • Envía una solicitud por cada fuente configurada a la vez. Nunca lo hace en paralelo.
  • Hace una pausa durante el intervalo SWEEPY_SOURCE_DELAY entre solicitudes. Su valor por defecto es de 0.2 segundos.

Las listas de fuentes más pequeñas terminan más rápido. Si notas lento un barrido, recorta tus listas de fuentes primero.

Compatibilidad de plataformas​

Como Sweepy extrae HTML plano y se ejecuta sin un navegador headless, algunos tipos de plataforma devuelven menos datos que otros.

Tipo de plataformaEjemplosCompatibilidadAdvertencias
ATS públicoGreenhouse, Ashby, Lever, Workable, SmartRecruiters, Breezy HRTotalmente compatibleSweepy analiza las páginas de empleo estándar renderizadas en el servidor y comprueba que cada enlace responda correctamente.
SPA renderizadas en el clienteWorkday en myworkdayjobs.com, Oracle HCMLimitadaEstas plataformas renderizan las páginas de empleo con JavaScript del lado del cliente. Sin un navegador headless, las cargas útiles HTML iniciales pueden no tener descripciones.
Portales con autenticaciónHandshake, intranets corporativasNo compatibleEstos portales requieren cookies de sesión o credenciales SSO.
Agregadores anti-botsPlataformas con Cloudflare Turnstile o PerimeterXLímite de tasaLas solicitudes HTTP automatizadas pueden activar bloqueos HTTP 403 sin rotación de proxies.
nota

Aún puedes ver ofertas de Workday en los informes cuando el feed de un agregador las incluye. Sweepy valida el enlace y evalúa el puesto a partir de cualquier texto que contenga la carga útil.
