Referencia de la línea de comandos

Sweepy se instala con una sola comando: sweepy. Escribe esta cadena y presiona Entrar. Agrega opciones si el comando necesita más configuraciones que las predeterminadas; cada perfil, proceso de limpieza e informe comienza desde aquí.

Terminal
sweepy

Alex utiliza dos de estos comandos todas las mañanas: primero ejecuta --run para realizar la limpieza con el último perfil guardado, y luego --logs para obtener un informe si algo sale mal durante el proceso.

nota

Ejecuta cada comando desde la carpeta sweepy. Si cerraste el terminal desde el paso anterior, abrelo de nuevo y ejecuta primero cd sweepy.

Referencia de comandos​

Ejecuta sweepy sin ninguna opción para abrir la interfaz de inicio. Las tablas siguientes agrupan las opciones según la función que desempeñan.

Forma del comando

Ejecuta pip install -e . dentro de la carpeta sweepy; las páginas siguientes muestran la forma abreviada de este comando. Si tu shell no puede encontrar sweepy, abre el terminal o ejecuta python swee.py en su lugar.

Procesos de limpieza y perfiles​

IndicadorFunción
--runEjecuta una limpieza (sweep) con el último perfil guardado.
--profile <path>Ejecuta una limpieza (sweep) a partir de un perfil identificado por YAML.
--setupAbre la plataforma de búsqueda para realizar búsquedas y configurar perfiles.
--non-interactiveConstruye o actualiza un perfil basándose en parámetros específicos (flags) en lugar de preguntas al usuario. Utilícelo junto con --setup.

Sobrescripciones de una sola ejecución​

IndicadorFunción
--no-dedupePermite agrupar publicaciones duplicadas de diferentes foros en una sola operación de limpieza.
--include-seenTambién muestra los resultados de una limpieza anterior.
--reset-historyOlvida los publicaciones que ya se han reportado para el perfil.

Documentos​

IndicadorFunción
--docx <path>Convierte un archivo de tipo DOCX en PDF y luego sale del programa.
--convert <path>Convierte un documento compatible en PDF junto al archivo fuente y luego sale del programa.

Motores de búsqueda de empleo​

IndicadorFunción
--list-enginesLista cada motor, las tablas que lee y su estado de instalación.
--install-engines [names]Descarga cada motor opcional, o solo los motores que especifiques.
--allow-engine-conflictsInstala un motor cuyo “pin” (información de configuración) esté en conflicto con uno ya instalado; ignora ese motor. Utiliza esta opción junto con --install-engines.

Actualizaciones y versiones​

IndicadorFunción
--updateDescarga el código más reciente de Sweepy y reinstala las dependencias necesarias.
--check-updateInforma si existe una versión más nueva de Sweepy.
--versionMuestra la versión del motor y sus dependencias.

Registro de errores​

IndicadorFunción
--debugActiva el registro de errores bajo la opción logs/.
--log-dir <dir>Cambia la ubicación de la carpeta de registros de errores.
--logsImprime los últimos registros de errores.

Valores de configuración​

Estas opciones («flags») se llenan en un perfil cuando se introduce --setup. Cada valor debe corresponder a una opción específica; además, --name, --titles, --location y --resume siguen siendo obligatorias a menos que el perfil las especifique de forma diferente.

IndicadorFunción
--sources <names>Habilita estos motores.
--jobspy-sites <sites>Configura las tablas de JobSpy.
--hirehunt-sources <sources>Configura las fuentes de datos de HireHunt.
--jobdrop-sites <sites>Configura las tablas de JobDrop.
--openroles-companies <slugs>Establece los nombres de las empresas para OpenRoles.
--apify-actor <actor>Establece el ID del actor de Apify.
--timeout <seconds>Define el tiempo de espera para cada fuente de datos.
--cache-ttl <seconds>Establece la duración de la caché de datos descubiertos.
--no-cacheDesactiva la caché de descubrimiento de contenidos.
--history-days <days>Establece el número de días durante los cuales un contenido publicado no puede aparecer de nuevo.
--no-historyNotifica la aparición de cada nuevo contenido en cada ejecución del programa.
--job-tracking / --no-job-trackingActiva o desactiva las columnas de seguimiento de tareas en los archivos CSV.
--name <name>Define el nombre del perfil.
--titles <titles>Configura los títulos de los documentos objetivo.
--location <location>Determina la ubicación de los documentos objetivo.
--resume <path>Establece la ruta del archivo de currículo.
--portfolio <value>Agrega un portafolio del cual Sweepy puede extraer información; se aceptan URLs, archivos PDF locales, archivos en formato Markdown o texto. Puede repetirse para múltiples fuentes; ante cada fuente adicional, añada el prefijo TRACK= para asociarla a un único registro de currículo.
--portfolio-track <track>Establece la ruta del currículo (resume) para los valores de --portfolio sin el prefijo TRACK=.

Sweepy primero maneja los archivos con las etiquetas --logs, --version, --update, --check-update, --list-engines y --install-engines, y luego convierte los documentos correspondientes. A continuación se ejecuta la acción --setup; por último, se realiza el proceso de limpieza (sweep). Se ejecuta una tarea por comando.

Ejecute su último perfil utilizando el parámetro --run​

Guarde un perfil una vez y, a continuación, elimíne todos los demás con una sola comando breve. Sweepy almacena el último perfil que guardó en profiles/.last_profile y lo reutiliza posteriormente.

Terminal
sweepy --run

El programa busca los perfiles en el siguiente orden:

  1. La ruta especificada en profiles/.last_profile.
  2. El perfil más reciente se encuentra en profiles/.
  3. Los parámetros profiles/custom_profile.yaml, profiles/paralegal_nyc.yaml y config.sample.yaml.

Si ninguno de estos existe, Sweepy genera un error y le indica que revise el archivo --setup.

Cree un perfil utilizando el parámetro --setup​

El asistente abre la plataforma de búsqueda y te crea un perfil YAML.

Terminal
sweepy --setup
Placa de inicioPermite iniciar la limpieza con el perfil seleccionado.
Iniciar limpiezaEjecuta la acción de limpieza con el perfil elegido; una línea de estado le informa sobre el progreso hasta que se seleccione un perfil.
Cargar perfilLe permite elegir un perfil ya guardado para la próxima limpieza.
Caja de herramientas de SweepyAccede a las opciones de configuración del programa.
Crear perfilLe formula preguntas sencillas en español y luego guarda el nuevo perfil.
Ajustes de limpiezaPermite modificar el peso de las palabras clave, los límites de las tarjetas de crédito, el estilo de los informes, el comportamiento del historial de operaciones y las columnas de seguimiento de tareas en el archivo CSV.
Salir de SweepyGuarda tus cambios y regresa a la shell.

Sweepy's Toolbox contiene las siguientes opciones:

Entrada de la caja de herramientas¿Para qué sirve?
Editar un perfil existenteCarga un perfil desde profiles/ y te permite modificarlo, incluyendo la opción de activar o desactivar las columnas de seguimiento de tareas.
Gestionar motores de trabajoActivar o desactivar los motores y editar sus configuraciones.
Descargar motores de trabajoInstala los motores optativos después de que lo confirme.
Agregar o editar agregadoresActiva/desactiva fuentes de datos y gestiona agregadores personalizados.
Activar/desactivar el registro de depuraciónCambia el valor de debug del perfil.
Mostrar ayudaImprime instrucciones para el asistente (wizard).
Mostrar registros recientesImprime las entradas de registro de depuración más recientes.
Convertir un documento a PDF (bonus)Convierte un archivo de tipo DOCX, DOC, TXT, MD o PDF y lo devuelve al conjunto de herramientas.
Actualizar SweepyDescarga el código más reciente y reinstala las dependencias.
SalirCierra el asistente desde la caja de herramientas.

Puedes reiniciar el asistente en cualquier momento para crear un nuevo perfil o modificar uno ya existente. Los perfiles antiguos no se eliminan. La página Configurar Sweepy explica paso a paso todos los pasos necesarios.

Convertir un documento a PDF (extra)​

Convertir un documento a PDF: La Caja de Herramientas de Sweepy realiza la conversión incluso sin un perfil definido. Elige la opción Convertir un documento a PDF y proporciona la ruta del archivo a convertir

Proceso de conversión: Sweepy utiliza herramientas como python-docx y reportlab para generar el texto en formato PDF; en caso necesario, recurre a Microsoft Word.

Entrada¿Qué hace Sweepy?
.docxReconstruye el texto limpio utilizando python-docx y reportlab; en caso contrario, recurre a Microsoft Word.
.docSe procesa mediante Microsoft Word, que requiere el paquete docx2pdf.
.txt, .mdRenderiza el texto con títulos y viñetas.
.pdfPasa el archivo o lo copia a la ruta de salida que especifiques.

Sweepy emite una advertencia cuando se proporciona una ruta incorrecta y vuelve a mostrar el comando de inicio. Un error de ortografía hace que el usuario regrese al asistente de configuración.

Ir directamente a un perfil​

Añada --profile para abrir un perfil y editarlo directamente, sin pasar por el lanzador (launchpad).

Terminal
sweepy --setup --profile profiles/paralegal_nyc.yaml

El asistente inicializa la pantalla de revisión con los valores actuales de ese archivo.

Construir un perfil sin preguntas ni indicaciones adicionales​

Escriba un script para crear un perfil cuando necesite la misma configuración en todas las máquinas; incluya --setup --non-interactive y pase cada valor como una opción de configuración (flag).

Terminal
sweepy --setup --non-interactive `
  --name "Alex Rivera" `
  --titles "Technical Writer,UX Writer" `
  --location "New York, NY" `
  --resume C:\Users\Alex\sweepy\resume.pdf `
  --sources jobspy,openroles `
  --openroles-companies figma,stripe,notion `
  --timeout 120 --no-cache

Sweepy verifica cada motor (engine) activado antes de escribir el archivo. Si falta algún valor, muestra Error: y termina con el código 1. Si no se proporciona --profile, Sweepy genera el nombre del archivo a partir del nombre del usuario y su primer título; por ejemplo, el perfil de Alex se guarda en profiles/alex_rivera_technical_writer.yaml. Para actualizar un archivo existente, use --profile <path>.

Actualizaciones de Sweepy​

Actualizar Sweepy a través de la Caja de Herramientas de Sweepy (Sweepy’s Toolbox) realiza la misma operación de actualización.

Terminal
sweepy --update

Sweepy recupera el contenido del repositorio remoto indicado por origin, avanza rápidamente hasta la rama actual y ejecuta la acción especificada por python -m pip install -r requirements.txt. Se niega a ejecutar si los archivos bajo seguimiento contienen cambios no confirmados, por lo que nunca descarta las modificaciones locales. Es preferible utilizar el modo de solo lectura para verificar si existe alguna actualización.

Terminal
sweepy --check-update

Sobrescribir los parámetros de ejecución​

Enumera todos los motores, las placas que leen y su estado de instalación:

Actualizar Sweepy, en La caja de herramientas de Sweepy, ejecuta la misma actualización.

Terminal
sweepy --list-engines

Qué sucede durante una búsqueda:

Terminal
sweepy --install-engines all

El conjunto all omite la instalación de JobDrop mientras JobSpy mantiene su “pin” en conflicto. Instale JobDrop por separado utilizando --allow-engine-conflicts:

Terminal
sweepy --install-engines jobdrop --allow-engine-conflicts

Al instalar un motor, este queda desactivado. Añádalo a sources.enabled dentro de un perfil o utilízalo mediante --sources durante un proceso de configuración sin interfaz gráfica (headless setup). El comando finaliza con el código 1 si la instalación falla. Motores opcionales proporcionan información detallada sobre cada uno de ellos.

Ejecuta una limpieza (sweep) con --profile​

Mantén un perfil por ciudad o tipo de rol; luego dirige tu selección hacia el que desees con --profile. Sweepy se encarga del resto.

Terminal
sweepy --profile profiles/paralegal_nyc.yaml

Reemplace el nombre del archivo por el suyo propio. Utilice --run si desea que Sweepy utilice de nuevo el último perfil que guardó.

consejo

Almacene un perfil por ciudad o tipo de rol. Cambie el nombre del archivo para alternar entre las búsquedas.

Sobrescribir un resultado de ejecución​

--run y --profile aceptan tres modificaciones («overrides»). Cada una de ellas se aplica a ese comando sin afectar el perfil en sí.

Terminal
sweepy --run --no-dedupe
sweepy --run --include-seen
sweepy --run --reset-history

--no-dedupe mantiene la lista de cada tabla cuando dos tablas publican el mismo rol. Una función de “limpieza” (sweep) informa únicamente las nuevas publicaciones, y history.retention_days establece por defecto un período de visualización de cuatro días en el perfil. --include-seen también muestra las publicaciones ocultas. Ejecute --reset-history por separado para borrar ese historial y salir sin realizar ninguna limpieza.

¿Qué ocurre durante una limpieza?​

Cada ejecución sigue los mismos cinco pasos, en el mismo orden.

Etapa¿Qué ocurre?
1. Carga del perfilLee tu archivo YAML y verifica la configuración.
2. DescubrimientoEjecuta los scripts de recopilación de datos en las plataformas habilitadas y recoge los contenidos publicados.
3. ValidaciónElimina enlaces dañados y detecta redirecciones de tipo 404 “blandas”. Los posts que no pasen la verificación permanecen en el proceso de publicación.
4. Análisis de coincidencias de términosAnaliza el PDF de tu currículo o el contenido representado por DOCX en busca de términos comunes entre las diferentes posiciones, y luego genera una sugerencia de texto para cada solicitud de empleo.
5. GeneraciónCrea archivos PDF, CSV y JSON con fecha de creación. Añada png a sus formatos de exportación para las imágenes de página.

El terminal muestra cada etapa del proceso como [1/5] hasta [5/5] mientras se ejecuta. La opción “Running your first sweep” muestra el resultado completo de la primera ejecución.

Convierte un DOCX en un PDF utilizando un --docx​

Pásale un archivo de Word con la opción --docx. Sweepy lo convierte, guarda el PDF y se cierra.

Terminal
sweepy --docx path/to/resume.docx

A continuación, Sweepy te pide que elijas una ubicación para guardar el PDF.

Terminal output
Where should the PDF go? (leave blank to save next to the DOCX):

Pulsa Intro sin escribir nada y el PDF se guardará junto al archivo DOCX con el mismo nombre base. Si prefieres guardarlo en otro sitio, escribe la ruta completa. En cualquier caso, Sweepy mostrará PDF saved: y la ubicación final.

nota

Sweepy primero reconstruye el PDF a partir del texto indicado en DOCX. Si tu ordenador cuenta con Microsoft Word, Sweepy recurre al texto de docx2pdf para obtener una mayor similitud visual entre el resultado final y el documento original.

Convierte cualquier documento con --convert​

--convert se ejecuta sin solicitar instrucciones y genera el archivo PDF junto al archivo original. Apúntelo a un archivo de tipo .docx, .doc, .txt, .md o .pdf.

Terminal
sweepy --convert path/to/resume.docx
Terminal output
PDF saved: C:\Users\Alex\sweepy\resume.pdf

La salida mantiene el nombre del archivo original y cambia su extensión; por ejemplo, notes.md se convierte en notes.pdf, siempre dentro de la misma carpeta. Un archivo con la extensión .pdf ya existe, por lo que Sweepy informa sobre el cambio de nombre del archivo This file is already a PDF: sin modificarlo físicamente.

Entrada¿Qué hace Sweepy?
.docxReconstruye el texto limpio utilizando python-docx y reportlab; en caso contrario, recurre a Microsoft Word.
.docSe procesa mediante Microsoft Word, que requiere el paquete docx2pdf.
.txt, .mdRenderiza el texto con títulos y viñetas.
.pdfDeja el archivo sin modificar y muestra su ruta.

Si un archivo falta o no es compatible, se muestra el mensaje Error: y la ejecución termina con el código de error 1. Esto hace que la comando sea segura para usar en scripts y tareas programadas.

Una vez que el PDF esté disponible, dirija resume.path en su perfil hacia él y ejecute una sweep.

Compruebe su versión con --version​

Utilice este comando para confirmar que el motor y sus bibliotecas están instalados correctamente.

Terminal
sweepy --version
Terminal output
Sweepy v3.1.0
Python 3.13.1 | pymupdf 1.28.2 | reportlab 5.0.1
Ready to sweep.

Si pymupdf o reportlab indica que se debe leer el contenido de MISSING, reinstale sus dependencias. El paso correspondiente se explica en Instalación.

Activa el registro de depuración​

Los registros de depuración (debug logs) registran lo que hace el motor, paso a paso. Se pueden activar mediante una marca (flag), una configuración de perfil (profile setting) o una variable de entorno (environment variable).

MétodoDónde se configuraCuánto dura
--debugAgregue esta opción a su comando en el terminal.Solo tendrá efecto durante esa ejecución.
debug: trueAgregue esta opción a su perfil (YAML).Seguirá teniendo efecto en cada ejecución hasta que la elimine.
SWEEPY_DEBUG=1Establezca esta opción como una variable de entorno.Seguirá teniendo efecto en cada ejecución hasta que cierre el terminal.

Agregue esta opción a cualquier proceso de búsqueda.

Terminal
sweepy --debug --profile profiles/paralegal_nyc.yaml

O active permanentemente el registro de datos dentro de su perfil.

profiles/paralegal_nyc.yaml
# Write a rotating debug log under logs/ on every run.
debug: true

O establezca directamente la variable de entorno.

Terminal
$env:SWEEPY_DEBUG = "1"
sweepy --profile profiles/paralegal_nyc.yaml

En macOS o Linux, reemplace export SWEEPY_DEBUG=1 por el nombre correspondiente del elemento a buscar.

Sweepy guarda los registros (logs) en la carpeta de la aplicación, en la ubicación indicada por logs/. Para enviarlos a otro lugar, se utiliza --log-dir.

Terminal
sweepy --debug --log-dir C:\Users\Alex\sweepy-logs --profile profiles/paralegal_nyc.yaml

Para leer los registros más recientes sin abrir un archivo, ejecute el comando correspondiente.

Terminal
sweepy --logs
nota

El comando --logs imprime los contenidos de No debug logs found. Run Sweepy with --debug to enable logging. hasta que se genere un registro de depuración (debug log).

Programación de ejecuciones diarias​

Sweepy genera archivos de informe cuando encuentra nuevas publicaciones; incluye en el nombre del archivo el perfil utilizado, la fecha y la hora. En macOS o Linux, asegúrese de usar el nombre correcto del elemento a buscar.

Terminal
sweepy --profile profiles/paralegal_nyc.yaml

Cuando se ejecuta una búsqueda, Sweepy crea archivos de informe. En cada nombre del archivo de informe se incluyen el perfil, la fecha y la hora, como en paralegal_nyc_2026-10-08-081500.pdf y paralegal_nyc_2026-10-08-081500.csv. Una búsqueda que se ejecuta a través de MCP añade mcp al nombre, como en paralegal_nyc_mcp_2026-10-08-081500.pdf, para que puedas distinguir los dos caminos. La fecha y la hora provienen del reloj en export.timezone, que por defecto es local. Puedes establecerlo en UTC, un nombre IANA como America/New_York, o un desplazamiento como -05:00 para marcar los archivos con otra zona. Este sello evita que una búsqueda sobrepase a otra, por lo que results contiene toda la historia de tu búsqueda.

Sweeps informa únicamente sobre nuevas publicaciones, y por defecto recuerda cada publicación durante cuatro días. Cuando por la mañana no se encuentran nuevas publicaciones, el programa imprime No new postings since your last sweep y no genera archivos de informe. Lo mismo ocurre cuando todos los enlaces descubiertos han expirado.

Programación en Windows​

  1. Abra Task Scheduler desde el menú Inicio.
  2. Elija Crear Tarea Básica y denle un nombre como Sweepy morning sweep.
  3. Seleccione Daily y configure la hora de inicio.
  4. Escoja Start a program como acción.
  5. Configure el Program/script como el ejecutable Python correspondiente ((Get-Command python).Source).
  6. Configura Añadir argumentos con la ruta completa a swee.py más el perfil: "C:\Users\Alex\sweepy\swee.py" --profile profiles\paralegal_nyc.yaml.
  7. Establezca Start in en su carpeta sweepy. El motor encuentra el archivo profiles y lo escribe en la carpeta results.

Programación en macOS y Linux​

  1. Abra su archivo crontab utilizando crontab -e.
  2. Agregue una línea que ejecute el proceso de búsqueda a las 8:00 AM, según la zona horaria de su sistema.
Terminal
0 8 * * * cd /path/to/sweepy && python3 swee.py --profile profiles/paralegal_nyc.yaml

La parte cd es importante. El motor lee profiles y escribe results en relación con la carpeta desde la que lo ejecutas. Usa el python3 que instaló los paquetes de Sweepy. Pruébalo con python3 -c "import swee".

precaución

Una ejecución programada comienza sin abrir una ventana de terminal; por lo tanto, las configuraciones de la shell de sesiones anteriores no se aplican. Ejecute el comando manualmente una vez para confirmar que funciona antes de programarlo.
