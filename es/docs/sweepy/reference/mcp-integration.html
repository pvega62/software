Ejecutar Sweepy desde un asistente de IA con MCP

Esta conexión utiliza el Model Context Protocol, un lenguaje compartido que permite que los asistentes de IA interactúen con las herramientas instaladas en su computadora. Sweepy incluye un servidor MCP integrado. La comunicación se realiza a través de un protocolo específico, sin necesidad de abrir puertos de red.

Esa conexión utiliza el Model Context Protocol (MCP). El MCP es un lenguaje común que conecta a un asistente de inteligencia artificial con las herramientas instaladas en su ordenador. Sweepy incluye un servidor MCP integrado en server.py. Funciona a través del protocolo de transporte stdio, por lo que interactúa localmente con su dispositivo sin necesidad de abrir puertos de red.

nota

MCP es opcional. Sweepy funciona totalmente a través de comandos de terminal, sin ningún asistente de IA. El servidor añade una capa conversacional sobre el mismo motor. Además, incorpora el criterio y la inteligencia del modelo a la puntuación y el filtrado determinísticos que Sweepy ya lleva a cabo.

Antes de conectarte​

  • Complete la instalación para que Python y las dependencias de Sweepy estén listas. Los paquetes mcp y anyio llegan junto con requirements.txt.
  • Tenga en cuenta la ruta absoluta de server.py. Péguela en la configuración de su cliente.
  • Reinicie su cliente de IA después de cambiar su configuración MCP.

Herramientas disponibles​

Sweepy pone a disposición de tu asistente trece herramientas. Cada una de ellas devuelve un contenido (payload) representado por JSON y indica que es de solo lectura, puede causar cambios en los datos, es idéntica si se ejecuta varias veces, y pertenece al tipo “open-world” (puede interactuar con entornos abiertos o dinámicos).

HerramientaPara qué sirve
create_profileConstruye, valida y guarda un perfil (YAML) a partir de un PDF o un currículo (DOCX).
set_portfolioPermite adjuntar una URL de portafolio, un archivo o una lista de elementos a un perfil ya guardado.
run_sweepEjecuta el proceso en cinco etapas en segundo plano y almacena los resultados obtenidos.
get_sweep_statusEspera a que se realice una limpieza en curso y informa sobre su progreso.
get_jobsDevuelve las cartas que se encuentran en la sesión actual, ordenadas por puntuación.
submit_judgmentsReemplaza los campos determinísticos de una tarjeta con el juicio de tu asistente.
import_jobsAñade tareas que tu asistente ha verificado en otros lugares.
render_reportRenderiza los archivos PDF de la sesión actual.
get_resultsLee el resultado más reciente del análisis de datos del disco.
export_reportReconstruye archivos PDF, PNG, CSV o JSON a partir de un análisis (sweep) existente.
clear_historyOlvida los publicaciones reportadas para un perfil.
convert_documentConvierte un documento compatible en PDF.
convert_docxConvierte un currículo (DOCX) en un archivo PDF.

La referencia al herramienta MCP proporciona más detalles: enumera cada parámetro, su valor predeterminado y sugerencias sobre el comportamiento de la herramienta.

Elige los motores de búsqueda de empleo​

Cuando omite sources_config, create_profile activa la función incorporada de JobSpy. Motores ATS. También permite el uso de motores optativos que cuenten con una instalación funcional. Valores predeterminados válidos. La herramienta devuelve enabled_engines y engines_not_enabled. Para que pueda ver qué motores están funcionando y cuáles aún necesitan configuración.

OpenRoles busca solo en los foros de la empresa que hayas especificado. Añada los nombres cortos (slugs) de las empresas antes de realizar la búsqueda. Lo activas. Es posible que Apify genere cargos. Actívalo si lo deseas. Sweepy no instala los paquetes optativos automáticamente; no es necesario hacerlo. Cada elemento del informe muestra una de dos etiquetas de puntuación: Configuración, consentimiento para servicios pagados o restricciones de búsqueda.

Se debe pasar sources_config cuando se elijan los motores de forma explícita. Sweepy mantiene ese comportamiento. En lugar de agregar otros motores, se utiliza una selección preestablecida. Este JSON elige dos motores en particular.

{
  "enabled": ["jobspy", "openroles"],
  "openroles": {"companies": ["figma", "stripe"]}
}

Flujos de trabajo de una sola vez e híbridos​

Sweepy funciona en dos modos. Elige el que se adecúe a cuán autónoma quieres que sea la decisión del asistente.

Flujo de una sola vez. Tu asistente configura y ejecuta todo, y el motor evalúa cada rol basándose en la coincidencia de palabras clave del currículo.

create_profile -> run_sweep -> get_results -> export_report (optional)

Flujo híbrido y con estado persistente. Tu asistente revisa cada elemento («tarjeta») y emite su propio juicio antes de que se genere el informe.

run_sweep -> get_jobs -> submit_judgments -> render_report

Una operación de limpieza en tiempo real (live sweep) puede continuar ejecutándose incluso después de que se produzca un tiempo de espera (timeout) por parte del cliente. Cuando run_sweep devuelva el valor sweep_status: "running", llame a get_sweep_status con el valor job_id recibido, y espere hasta que esta función informe el resultado completed. Luego, continúe con la ejecución de get_jobs.

consejo

No se necesita un modelo de lenguaje grande (LLM) para elaborar un informe funcional. El herramienta run_sweep genera por sí sola el PDF completo de las tarjetas a partir de campos determinísticos, de la misma manera que lo haría una interfaz de comando tradicional.

Cada tarjeta muestra una de las dos etiquetas de puntuación:

  • NN% KEYWORD OVERLAP proviene del motor determinístico. Este compara el texto de su currículo con cada anuncio publicado.
  • “- NN% MATCH” proviene de tu asistente. Aparece cuando llamas a “submit_judgments” con un valor especificado por “match_pct”.

get_jobs devuelve resume_documents, el texto analizado de cada sección del currículo, junto a las tarjetas correspondientes. Tu asistente evalúa ese texto de la misma manera en que lo hace el sistema de selección automática (ATS) utilizado en el anuncio de empleo, y luego registra lo que un analizador convencional perdería al procesar ese mismo texto en concerns.

Verifica y completa los resultados del barrido​

Considera cada resultado de la búsqueda como un conjunto inicial y, a continuación, comprueba cada coincidencia con el Publicación. Después de run_sweep, inspeccione skipped_sources e informe los fallos en la fuente. Revisa los puestos de trabajo marcados con get_jobs y, a continuación, compara cada oferta con tu currículo. tus preferencias antes de que tu asistente envíe una recomendación del modelo LLM.

Si su asistente no dispone de herramientas de búsqueda, indique que los resultados pueden estar incompletos. Evite repetir el análisis con los mismos parámetros después de un error. en las páginas de empleo de las empresas o en su sistema de seguimiento de candidatos (ATS). También puede buscar puestos relevantes en Sweepy que se hayan pasado por alto, añade las ofertas verificadas que no sean duplicadas mediante import_jobs e incluye esos roles del informe con render_report. Tu asistente no debe inventarse Publicar información o completar detalles laborales faltantes con conjeturas.

El comprobador de URL de Sweepy mantiene algunos enlaces como no verificados cuando el servidor correspondiente bloquea el acceso. Limita las solicitudes o genera tiempos de espera. Un código de error 403 o 429 no demuestra que un contenido haya expirado. Confirma la situación antes de tomar ninguna acción. publicarla en una fuente de empleo accesible cuando sea posible, o considerarla como sin verificar. Si tu asistente no tiene ninguna herramienta de búsqueda, o si las fuentes siguen sin estar disponibles, Indicar que los resultados pueden estar incompletos. Evitar realizar una nueva revisión (o “sweep”) de los datos. Ajustes sin cambios después de un error.

Conexión a Antigravity o Claude Desktop​

Agregue “Sweepy” al archivo de configuración MCP de su cliente, cuyo nombre es mcp_config.json o claude_desktop_config.json dependiendo del cliente.

mcp_config.json
{
  "mcpServers": {
    "sweepy": {
      "command": "python",
      "args": [
        "/path/to/sweepy/server.py"
      ]
    }
  }
}

Reemplaza /path/to/sweepy por la ruta absoluta a tu carpeta Sweepy y reinicia el cliente. Una vez registrado, puedes solicitar trabajos de esta manera:

  • Crear un perfil en Sweepy para Alex que busque puestos de Redactor Técnico a distancia en Nueva York. El currículo se encuentra en path/to/resume.pdf.
  • Ejecuta una búsqueda con el perfil del escritor y muestra los 5 resultados más relevantes.
  • “Regenera el PDF a partir de la última acción realizada por ‘pedro_writer’ y guárdalo en el escritorio.”
  • “Convierta path/to/notes.md en un archivo PDF que se guarde junto al archivo original.”
Escribir fuera de la carpeta de Sweepy

Por defecto, cada herramienta de escritura permanece dentro de la carpeta “Sweepy”. Una solicitud para guardar el contenido en el escritorio fallará hasta que establezca la variable de entorno SWEEPY_ALLOW_EXTERNAL_WRITES en 1.

Conectarse a VS Code​

VS Code se conecta a los servidores MCP sin necesidad de ninguna extensión adicional.

  1. Abra la Paleta de Comandos y ejecute MCP: Add Server.
  2. Elija Comando (stdio), luego ingrese python como comando. Agregue la ruta absoluta a server.py como su argumento.
  3. Nombre el servidor como sweepy, luego elija el destino de configuración.
  4. Confirme que las herramientas de Sweepy aparezcan en el panel de chat, y luego llévelas desde allí.

Para un archivo de alcance del espacio de trabajo, agregue .vscode/mcp.json a su proyecto. El formato de VS Code utiliza un objeto servers de nivel superior:

.vscode/mcp.json
{
  "servers": {
    "sweepy": {
      "type": "stdio",
      "command": "python",
      "args": [
        "/path/to/sweepy/server.py"
      ]
    }
  }
}

Instala la habilidad /sweepy​

Sweepy ofrece una habilidad denominada /sweepy para herramientas de línea de comandos como Copilot CLI, Claude Code y Antigravity que permiten leer dichas habilidades. Copie la carpeta incluida en el paquete al directorio de habilidades de su herramienta correspondiente.

Terminal
cp -r skills/sweepy ~/.claude/skills/sweepy   # adjust to your tool's skills path

Registre el servidor MCP del apartado anterior y luego reinicie su herramienta. Los documentos describen tres flujos principales de funcionamiento.

  • Inicie una nueva recopilación de datos llamando a create_profile y luego a run_sweep.
  • Visualizar los resultados de una recopilación de datos (scrape) llamando a get_results para obtener los resultados principales y los planes de acción (playbooks), o a get_jobs para ver el conjunto completo de información.
  • Exporte los resultados a un archivo CSV llamando a export_report con formats=["csv"].

Esta habilidad también incluye soluciones alternativas para herramientas de línea de comando que no cuenten con soporte de MCP.

Terminal
sweepy --setup                         # interactive profile wizard
sweepy --profile profiles/your_profile.yaml
sweepy --docx resume.docx              # convert a DOCX resume to PDF
sweepy --convert notes.md              # convert any supported document to PDF

Configúralo todo con un solo comando​

Copie este texto y péguelo en cualquier sesión de línea de comandos de IA o en la ventana de chat de un entorno de desarrollo integrado (IDE).

Set up Sweepy on this machine. Complete these steps in order:

1. Clone or download the Sweepy repository.
2. Run `pip install -r requirements.txt` in the repository root.
3. Register `server.py` in the MCP configuration as a stdio server. Use the command `python` and args pointing at `server.py`.
4. Copy the `skills/sweepy` folder into the CLI's skills directory.
