Antes de empezar con la observabilidad paralela de la nube y la IA

Prepara las herramientas para el trabajo de canalizaciones y observabilidad. Configura la ingesta de registros de Datadog. Rastrea llamadas a modelos de lenguaje de gran tamaño en Galileo. Puedes usar ambas herramientas.

Flujos de trabajo incluidos​

Esta sección incluye dos flujos de trabajo:

  1. Ingesta y enrutamiento de registros operativos con Datadog

    • Recoge registros JSON de aplicaciones en la nube. Usa la API de ingesta de registros de Datadog. Aplica procesadores de canalización. Enruta los datos a destinos posteriores.

  2. Rastreo y evaluación de LLM con Galileo

    • Añade Galileo a los servicios de IA. Captura trazas e intervalos de llamada.

Sigue la documentación en el orden recomendado:

  1. Flujos de eventos y canalizaciones de observabilidad. Explora la arquitectura conceptual y cómo trabajan juntos Datadog y Galileo.
  2. Envía eventos con la API de ingesta de registros de Datadog. Aprende los parámetros del punto final, la autenticación y los esquemas de carga útil.
  3. Enruta registros de aplicaciones en la nube a una canalización. Sigue una guía práctica para enviar y verificar registros de una aplicación de ejemplo.

Herramientas que necesitas​

Ingesta de registros de Datadog​

  • cURL o Postman envía solicitudes de API a la API de ingesta de registros de Datadog.
  • Un terminal o shell funciona en macOS, Linux y Windows PowerShell.
  • jq valida las cargas útiles JSON antes de enviarlas. Esta herramienta es opcional, pero recomendada.

Rastreo de modelos de lenguaje de gran tamaño con Galileo​

  • Python 3.9+ o Node.js 18+ admite el SDK de Galileo.
  • pip o npm instala el SDK.
  • Python
  • TypeScript
pip install galileo
npm install galileo
  • Un editor de código admite VS Code, Cursor y Antigravity.

Público objetivo​

PerfilUso principal
Ingenieros de plataformaCrean y mantienen canalizaciones de registros de Datadog
Ingenieros de fiabilidad del sitio (SRE) y DevOpsNormalizan registros, reducen el ruido y configuran el enrutamiento y las alertas
Ingenieros de IA y aprendizaje automático (ML)Instrumentan servicios LLM y puntúan la calidad de los modelos con Galileo
Ingenieros de seguridadEnrutan registros de auditoría y autenticación a destinos de gestión de eventos e información de seguridad (SIEM)
DesarrolladoresEnvían registros de aplicaciones y rastrean llamadas a modelos de lenguaje de gran tamaño sin conocimientos profundos de infraestructura

Lo que ya deberías saber​

Esta documentación da por supuesto:

  • Conocimientos básicos de JSON
  • Soltura para ejecutar comandos de línea de comandos
  • Una comprensión general de registros, eventos o métricas
  • Conocimiento de entornos de nube o microservicios

La guía práctica explica las solicitudes POST paso a paso.

Datadog recoge registros. Registra errores. Enruta alertas.

Galileo recoge datos de IA. Registra las entradas del modelo. Registra las salidas del modelo. Mide la velocidad. Puntúa la calidad de la salida.

Juntas, estas herramientas cubren una aplicación moderna en la nube de extremo a extremo.
