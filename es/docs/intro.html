Introducción

Bienvenido a mi portafolio de escritura técnica​

Este sitio recoge ejemplos de documentación de software de mi portafolio de escritura técnica. Docusaurus genera cada página a partir de fuentes en formato Markdown y MDX. El conjunto abarca guías para desarrolladores, referencias a APIs, así como documentación de productos. Cada ejemplo también muestra el proceso de trabajo detrás de su creación.

  • Flujo de trabajo de Microsoft Word a GitHub Wiki con Writage. Una guía para escribir contenido en formato Markdown desde Word y luego enviar las revisiones del wiki a GitHub Desktop.

  • Ruta para conectar los registros de la aplicación en la nube a un flujo de trabajo. Procedimiento operativo para la ingesta y filtrado de datos telemétricos de aplicaciones en la nube.

Documentación de Sweepy para búsqueda de empleo​

Sweepy: Explora sistemas de seguimiento de candidatos y portales de empleo, y luego clasifica cada oferta en función del currículo del solicitante. Esta herramienta de Python es de código abierto e incluye un conjunto de documentación de 14 páginas que abarca la instalación, la configuración de perfiles y las opciones de exportación en formato PDF o CSV. También proporciona información sobre el servidor Model Context Protocol (MCP), que realiza las búsquedas desde un asistente de inteligencia artificial.

Comenzar​

  • Conoce a Sweepy. Explica qué hace Sweepy, las cinco etapas del proceso y cómo evalúa un currículo.
  • Instalación de Sweepy: Guía paso a paso para configurar Python, Git y el repositorio en Windows, macOS y Linux.
  • Configurar Sweepy. Crea un perfil de búsqueda con el asistente de configuración o con un archivo YAML.
  • Ejecutando tu primera “sweep”. Se describe el proceso desde la creación del perfil hasta la visualización de los avances del análisis.

Leer los resultados​

  • Comprender sus resultados: Describe en detalle la estructura de las tarjetas PDF, los porcentajes de coincidencia, las insignias de las aplicaciones y las columnas de seguimiento en archivos CSV.
  • Resúmenes y puntuaciones de coincidencia: Explica cómo se formatean los resúmenes y el proceso de cálculo de la puntuación en porcentajes.
  • Cómo Sweepy evalúa un currículo: Detalla el sistema de puntuación utilizado y lo que no puede medir con dicha puntuación.

Referencias e integraciones​

  • Referencia de comandos y configuraciones de Sweepy: Lista todos los comandos disponibles, las opciones de configuración y las fuentes de empleos soportadas.
  • Integración de Sweepy con MCP: Muestra cómo conectar el servidor incorporado de Sweepy con herramientas como Antigravity, Claude Desktop o VS Code.
  • Referencia de herramientas asociadas a Sweepy MCP: Describe las trece herramientas utilizadas en esta integración, sus parámetros y los datos devueltos por cada una.

Índice de la documentación de Sweepy: Recoge información sobre la instalación, el primer uso del software, notas para desarrolladores y estudios de caso relacionados con la experiencia de usuario.

Flujo de trabajo de “docs como código”​

  • Redacción de documentos en formato Markdown y MDX utilizando VS Code y Antigravity.
  • Verificación de la calidad del texto y su estilo mediante herramientas como Vale.
  • Internacionalización y traducción con DeepL y Lara.
  • Diagramación de arquitectura de sistemas con Mermaid.
  • Redacción de documentación del producto para una herramienta de línea de comandos y su servidor MCP en cada lanzamiento.
  • Control de versiones y revisión colaborativa de código con Git y GitHub.
  • Exploración y validación de APIs con Postman y Swagger/OpenAPI.
  • Creación de contratos OpenAPI 3.1 con esquemas compartidos y renderizado Scalable.
  • Despliegue continuo con Docusaurus.

Pila técnica​

  • Docusaurus: Genera sitios estáticos, barras laterales de navegación y versiones localizadas.
  • VS Code: Es la principal herramienta de edición para la creación de contenido en formato Markdown y MDX.
  • Postman: Valida los puntos finales de las APIs y genera ejemplos de solicitudes/respuestas.
  • OpenAPI 3.1 y Scalar: Definen el contrato de Blüdhaven Pets y lo presenta en una interfaz interactiva de tres paneles.
  • OpenAPI 3.1 y Scalar: Define el contrato de Blüdhaven Pets y lo presenta como una referencia interactiva en tres paneles.
  • Vale: Revisa el texto técnico para asegurarse de que cumpla con las directrices de la documentación de Google Developers.
  • Git y GitHub: Realiza el seguimiento de los cambios en las ramas y despliega el sitio web.
  • Mermaid: Genera diagramas de flujos de trabajo y de procesos de datos.
  • Python y MCP: Ejecuta el motor de análisis Sweepy, así como el servidor que lo conecta con asistentes inteligentes.
  • DeepL y Lara: Automatizan la traducción de la documentación a otros idiomas.
