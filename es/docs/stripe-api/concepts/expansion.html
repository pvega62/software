Expansión de objetos anidados

Una respuesta devuelve los objetos relacionados en forma de IDs, no como objetos completos. El parámetro expand reemplaza el ID por el objeto al que se refiere; así, una sola solicitud devuelve los datos necesarios en lugar de tres.

Lee una respuesta sin expandir​

{
  "id": "pi_3Rsx4dDtWMrPDtgt0mUrePJ9",
  "object": "payment_intent",
  "amount": 2120,
  "customer": "cus_QyJ8bT2vLk9mNp",
  "payment_method": "pm_1Rsx4dDtWMrPDtgt"
}

El campo customer contiene un ID. Al proporcionar ese ID a GET /v1/customers/{id}, se obtiene información sobre el cliente, lo que implica una segunda solicitud y un segundo viaje de datos.

Expande el campo​

Pase expand[] junto con el nombre del campo correspondiente; Stripe devolverá el objeto en formato directo.

curl -s -G https://api.stripe.com/v1/payment_intents/pi_3Rsx4dDtWMrPDtgt0mUrePJ9 \
  -u "$STRIPE_SECRET_KEY:" \
  -d "expand[]=customer"
{
  "id": "pi_3Rsx4dDtWMrPDtgt0mUrePJ9",
  "object": "payment_intent",
  "customer": {
    "id": "cus_QyJ8bT2vLk9mNp",
    "object": "customer",
    "email": "ada@example.com",
    "created": 1735689600
  }
}

El ID no desaparece, sino que se traslada a customer.id; por lo tanto, un cliente que solo lee IDs seguirá funcionando después de que se realice la expansión.

Despliega más de un nivel​

La notación de puntos permite acceder a objetos anidados. payment_method.card devuelve los detalles de la tarjeta dentro del método de pago.

curl -s -G https://api.stripe.com/v1/payment_intents/pi_3Rsx4dDtWMrPDtgt0mUrePJ9 \
  -u "$STRIPE_SECRET_KEY:" \
  -d "expand[]=customer" \
  -d "expand[]=payment_method.card"

La expansión se detiene después de cuatro niveles; cada nivel incrementa la cantidad de trabajo que realiza Stripe por solicitud. Un camino más complejo genera un error.

SolicitudResultado
expand[]=customerObjeto completo del cliente.
expand[]=payment_method.cardObjeto completo de la tarjeta dentro del método de pago.
expand[]=customer.default_sourceObjeto completo del cliente.
expand[]=customer.default_source.card.fingerprintRechazada. La expansión devuelve objetos; fingerprint es un valor escalar.

Decide cuándo expandirlos​

La expansión implica un mayor número de solicitudes y una mayor demora en la respuesta.

SituaciónUtiliza la expansión cuando sea necesario.
Renderizar una única transacción junto con sus detalles del clienteSí; una solicitud es más eficiente que dos.
Listar 100 cargos para un informeNo; el volumen de datos supera el tamaño óptimo.
Comprobar un campo relacionadoNo; lee el dato directamente desde el endpoint correspondiente.
Verificar un cargo en un handler de webhookA veces; obtén el objeto relacionado solo cuando sea necesario.
consejo

Amplíe tanto el contenido de POST como el de GET. Envíe expand[] en el cuerpo de la solicitud para omitir la lectura adicional después de crear un objeto.

Expandir dentro de una lista​

El parámetro expand[] funciona con los puntos finales de la lista; al expandir un objeto relacionado en una página de 100 elementos, dicho objeto se repite en cada fila, lo que aumenta el tamaño de la respuesta. Solo amplíe la lista cuando cada fila necesite los datos anidados.

Añade tus propios identificadores con metadata​

metadata almacena pares de clave-valor; úselo para vincular un objeto de Stripe con un registro en su propia base de datos.

curl https://api.stripe.com/v1/payment_intents \
  -u "$STRIPE_SECRET_KEY:" \
  -d "amount=2120" \
  -d "currency=usd" \
  -d "metadata[order_id]=ord_8842" \
  -d "metadata[tenant]=acme"
{
  "id": "pi_3Rsx4dDtWMrPDtgt0mUrePJ9",
  "metadata": {
    "order_id": "ord_8842",
    "tenant": "acme"
  }
}
  • Límites: 50 pares por objeto; 40 caracteres por clave y 500 por valor.
  • No se debe utilizar para información confidencial: El personal de Stripe puede acceder a los metadatos, y estos también se muestran en el panel de control y en las exportaciones.
  • Para eliminar un elemento, envíe una cadena vacía.
  • A veces es posible buscar en los metadatos: La búsqueda del panel de control los incluye, pero los filtros de la API no.
aviso

No incluya información de identificación personal en los metadatos, a menos que su política de datos lo permita. Nombres de clientes, direcciones de correo electrónico y fragmentos de tarjetas de crédito deben almacenarse en los campos proporcionados por Stripe. Un almacenamiento de texto libre no es el lugar adecuado para ellos.

Comprueba la expansión​

Envía la solicitud dos veces: una vez con expand[] y otra vez sin ella, y compara el campo customer. La respuesta no expandida devuelve una cadena de texto. La respuesta expandida devuelve un objeto que contiene el campo id.

curl -s -G https://api.stripe.com/v1/payment_intents/pi_3Rsx4dDtWMrPDtgt0mUrePJ9 \
  -u "$STRIPE_SECRET_KEY:" \
  -d "expand[]=customer" | jq '.customer | type'

La salida es "object". Al eliminar ese elemento, el mismo comando imprime "string".
