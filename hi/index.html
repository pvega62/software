Technical Writer और Documentation Architect

स्पष्ट, स्केलेबल और उच्च-प्रभाव वाले Documentation के माध्यम से जटिल कोड और तकनीक तथा डेवलपर की सफलता के बीच की दूरी को पाटना।

Documentation क्यों मायने रखता है

स्पष्ट Documentation का मतलब है खुश डेवलपर्स। जटिल API, वितरित सिस्टम और तीव्र नवाचार की दुनिया में, Documentation उत्पाद का प्राथमिक इंटरफ़ेस है। मैं ऐसे Documentation इकोसिस्टम बनाने में माहिर हूँ जो सपोर्ट टिकटों को कम करते हैं, ऑनबोर्डिंग के समय को कम करते हैं, और डेवलपर्स को तेज़ी से निर्माण करने के लिए सशक्त बनाते हैं।

मुख्य विशेषज्ञता

API और SDK Documentation

OpenAPI/Swagger का उपयोग करके जटिल API का दस्तावेजीकरण करने और व्यापक SDK गाइड बनाने में विशेषज्ञता, जो डेवलपर के लिए बाधाओं को कम करती हैं और एकीकरण को गति देती हैं।

Docs-as-Code वर्कफ़्लो

Git-आधारित Documentation वर्कफ़्लो, Markdown, और Docusaurus और Jekyll जैसे स्टैटिक साइट जनरेटर में निपुण, ताकि Documentation को स्रोत कोड के समान ही गंभीरता से लिया जा सके।

संकल्पनात्मक और दृश्य गाइड

आर्किटेक्चरल डायग्राम (Mermaid.js), SOPs, और गहन संकल्पनात्मक सामग्री में विशेषज्ञता, जो विविध तकनीकी दर्शकों के लिए जटिल सिस्टम डिज़ाइनों को स्पष्ट करती है।

आइए कुछ अद्भुत बनाएं। साथ मिलकर।

मैं वर्तमान में ऐसे अवसरों की तलाश में हूँ जहाँ मैं Docs-as-Code और डेवलपर अनुभव में अपनी विशेषज्ञता का उपयोग कर सकूँ।
