बैलेंस प्राप्त करें​

एक Stripe खाते का बैलेंस प्राप्त करें।

एंडपॉइंट: https://api.stripe.com/v1/balance

ऑपरेशन: GET

उदाहरण​

cURL उदाहरण:

curl -X GET `https://api.stripe.com/v1/balance` \
  -u <YOUR_SECRET_KEY>:

बैलेंस लेनदेन प्राप्त करें​

यह उन लेनदेन को लौटाता है जो Stripe खाते का बैलेंस बनाते हैं (उदाहरण के लिए, शुल्क, ट्रांसफर, भुगतान, रिफंड, आदि)। लेनदेन को क्रमबद्ध क्रम में लौटाया जाता है, जिसमें सबसे हाल के लेनदेन पहले दिखाई देते हैं।

एंडपॉइंट: https://api.stripe.com/v1/balance_transactions/{id}

ऑपरेशन: GET

उदाहरण​

cURL उदाहरण:

curl -X GET https://api.stripe.com/v1/balance_transactions/tr_1234567890 \
  -u <YOUR_SECRET_KEY>:
