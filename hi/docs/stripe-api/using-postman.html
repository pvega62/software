पोस्टमैन (Postman) का उपयोग स्ट्राइप एपीआई (Stripe API) से जुड़ने हेतु

इस पृष्ठ के अंत तक, आपके पास एक ‘स्ट्राइप कलेक्शन’ (Stripe Collection) एवं एक पोस्टमैन वातावरण (Postman Environment) होगा; यह वातावरण हर अनुरोध को आपकी एपीआई कुंजी (API Key) के साथ प्रमाणीकृत करेगा। आप एक अनुरोध भेजकर यह सुनिश्चित करेंगे कि स्ट्राइप उस कुंजी को स्वीकार करता है।

पोस्टमैन अनुरोध भेजता है एवं प्रतिक्रियाएँ दिखाता है। एक साझा कार्यस्थल (Shared Workspace) आपकी टीम को एक ही कलेक्शन पर रखता है।

कनेक्शन हेतु पूर्व-आवश्यकताएँ​

शुरू करने से पहले निम्नलिखित चीजें तैयार कर लें:

  • A Postman account.
  • एक स्ट्राइप (Stripe) खाता, जिसमें डैशबोर्ड तक पहुँच है।
  • https://api.stripe.com/ तक नेटवर्क पहुँच; यह स्ट्राइप (Stripe) API अनुरोधों का आधार पता है।

पोस्टमैन (Postman) सेटअप करें​

  1. Postman ऐप को डाउनलोड करें एवं इंस्टॉल करें।

  2. पोस्टमैन (Postman) ऐप खोलें एवं सेटअप प्रक्रिया पूरी करें।

    शीर्ष पर खोज क्षेत्र वाला पोस्टमैन वर्कस्पेस0)

खोज क्षेत्र में “Stripe” दर्ज करें, फिर “Stripe Developers” कार्यस्थल का चयन करें।

  1. “Collections” आइकन पर क्लिक करें, फिर नाम में सबसे नई तारीख वाला कलेक्शन चुनें।

    पोस्टमैन (Postman) के खोज परिणामों में स्ट्राइप डेवलपर्स (Stripe Developers) का वर्कस्पेस एवं तारीखयुक्त स्ट्राइप एपीआई संग्रह (Stripe API collections) सूचीबद्ध हैं।0)

अब आपके कार्यस्थल में “Collections” विभाग में वह कलेक्शन दिखाई देगा।

  1. स्ट्राइप हर API अनुरोध की पुष्टि एक API कुंजी के द्वारा करता है; यह कुंजी एक हेडर में भेजी जाती है।
  2. आपका खाता पहले से ही API कुंजियों से भरा हुआ होगा, इसलिए नई कुंजी जनरेट न करें। स्ट्राइप नए इंटीग्रेशनों के लिए प्रतिबंधित API कुंजियों का उपयोग करने की सलाह देता है, क्योंकि ये केवल आपके द्वारा चुने गए अधिकारों को ही प्रदान करती हैं।

प्रतिबंधित कुंजियाँ “rk_” से शुरू होती हैं, जबकि गुप्त कुंजियाँ (“secret keys”) “sk_” से शुरू होती हैं।

एक API कुंजी कॉपी करें​

स्ट्राइप (Stripe) प्रत्येक API अनुरोध की पुष्टि HTTPS के माध्यम से भेजे गए API कुंजी (API key) से करता है, एवं इस कुंजी को Authorization हेडर (header) से पढ़ता है। “बेसिक ऑथ” (Basic Auth) एवं “बेयरर टोकन” (Bearer token) दोनों ही विधियाँ काम करती हैं।

आपका खाता पहले से ही कुछ कुंजियों (keys) से लैस है; इसलिए आप किसी मौजूदा कुंजी की नकल करें, नई कुंजी जनरेट न करें। स्ट्राइप (Stripe) नए इंटीग्रेशनों (integrations) के लिए “प्रतिबंधित API कुंजियाँ” का उपयोग करने की सलाह देता है, क्योंकि ये केवल आपके द्वारा चुने गए अधिकारों (permissions) को ही प्रदान करती हैं। “गुप्त कुंजियाँ” (secret keys) भी काम करती हैं, लेकिन ये असीमित पहुँच (unrestricted access) प्रदान करती हैं। प्रतिबंधित कुंजियाँ “rk_” से शुरू होती हैं, जबकि गुप्त कुंजियाँ “sk_” से शुरू होती हैं। ये चरण दोनों प्रकार की कुंजियों के लिए लागू हैं।

  1. Stripe डैशबोर्ड खोलें, फिर Developers > API keys पर जाएँ।

  2. एक सीक्रेट कुंजी (secret key) प्राप्त करें, या अपनी आवश्यकताओं के अनुसार एक प्रतिबंधित कुंजी (restricted key) बनाएँ।

  3. कुंजी को क्लिपबोर्ड में कॉपी करें।

    नोट

अपनी API कुंजी को कभी भी अन्य उपयोगकर्ताओं के साथ साझा न करें। :::

  1. पोस्टमैन (Postman) ऐप पर वापस जाएँ।

  2. Environments पर क्लिक करें, फिर Add (+) पर क्लिक करें।

  3. Name फील्ड में नाम दर्ज करें (जैसे: Stripe API)。

  4. Variable सेल में secret_key दर्ज करें, फिर कॉपी की गई कुंजी को Current Value सेल में पेस्ट करें।

  5. Save पर क्लिक करें।

  6. Environment ड्रॉपडाउन मेनू से Stripe API चुनें।

ड्रॉपडाउन में अब Stripe API दिखाई दे रहा है। पोस्टमैन (Postman) आपकी कुंजी (key) हर अनुरोध (request) में जोड़ देता है।

कनेक्शन की जाँच करना​

ऐसा अनुरोध भेजें जिसके लिए आपकी कुंजी (key) आवश्यक हो। “बैलेंस” (Balance) एंडपॉइंट (endpoint) खाते का डेटा पढ़ता है। “200” प्रतिक्रिया यह साबित करती है कि कुंजी सही तरीके से काम कर रही है।

  1. फ़ोर्क किया गया संग्रह खोलें और /v1/balance जैसा GET अनुरोध चुनें।

  2. “Send” (भेजें) पर क्लिक करें।

    सफल प्रतिक्रिया

“200 OK” प्रतिक्रिया में “JSON” दिया जाता है; यह पुष्टि करता है कि स्ट्राइप (Stripe) ने कुंजी स्वीकार कर ली है। :::

त्रुटि प्रतिक्रिया

“401” प्रतिक्रिया का मतलब है कि पोस्टमैन (Postman) ने वैध कुंजी नहीं भेजी। यह जाँच लें कि वेरिएबल (variable) का नाम कलेक्शन के नाम से मेल खाता है, एवं यह भी जाँच लें कि “Current Value” में API कुंजी है, न कि पब्लिश करने योग्य कुंजी (publishable key)।

“403” प्रतिक्रिया का मतलब है कि कुंजी को उस एंडपॉइंट के लिए अनुमति नहीं है। डैशबोर्ड (Dashboard) में अनुमति दें, या ऐसी कुंजी का उपयोग करें जिसकी पहुँच अधिक हो।
