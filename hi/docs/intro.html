तकनीकी लेखन पोर्टफोलियो

यह पूरी तरह से मेरे तकनीकी लेखन पोर्टफोलियो के सॉफ्टवेयर-संबंधी नमूनों को समर्पित एक पोर्टफोलियो है। यह सॉफ्टवेयर दस्तावेज़ीकरण के नमूनों पर एक व्यापक नज़र डालता है, जो सभी Docusaurus का उपयोग करके पूरी तरह से Markdown में लिखे और प्रकाशित किए गए हैं। यहाँ आपको डेवलपर गाइड, API संदर्भ के उदाहरण और उन्हें बनाने के लिए उपयोग किए जाने वाले वर्कफ़्लो की जानकारी मिलेगी।

पोर्टफोलियो नेविगेशन​

डिलीवरेबल प्रकार और डोमेन द्वारा आयोजित दस्तावेज़ीकरण नमूनों का अन्वेषण करें:

डेवलपर और सिस्टम गाइड​

  • गूगल क्रोम में थीम इंस्टॉल और लागू करना। इंटरैक्टिव यूआई टैब और रिस्पॉन्सिव लेआउट के साथ ब्राउज़र अनुकूलन के लिए चरण-दर-चरण वॉकथ्रू।
  • Writage के साथ Microsoft Word से GitHub Wiki वर्कफ़्लो। Word में Markdown लिखने, GitHub Desktop के साथ Wiki क्लोन करने और संशोधनों को प्रकाशित करने के लिए एक गाइड।
  • Stripe API से कनेक्ट करने के लिए Postman का उपयोग करना। Postman में प्रमाणित करने और API अनुरोध भेजने के लिए एक व्यावहारिक गाइड।
  • Postman मॉक सर्वर बनाएं। वेबहुक एकीकरण और एपीआई स्कीमा का परीक्षण करने के लिए मॉक सर्वर कॉन्फ़िगर करने पर व्यावहारिक ट्यूटोरियल।
  • क्लाउड एप्लिकेशन लॉग्स को एक पाइपलाइन में रूट करें। क्लाउड ऐप टेलीमेट्री को अंतर्ग्रहण और फ़िल्टर करने के लिए एक मानक संचालन प्रक्रिया।
  • ऑब्जेक्ट डेटा कैसे प्राप्त करें। Sui TypeScript SDK के साथ RPC रीड क्वेरीज़ को समझाने वाला एक ट्यूटोरियल।
  • ट्रांज़ैक्शन भेजने के लिए राइट ऑपरेशन का उपयोग करना। प्रोग्राम करने योग्य लेनदेन पर हस्ताक्षर करने और प्रसारित करने के लिए एक डेवलपर गाइड।

एपीआई संदर्भ​

  • Stripe एपीआई दस्तावेज़ीकरण। फिनटेक और भुगतान बुनियादी ढांचे के लिए एपीआई संदर्भ दस्तावेज़।
    • बैलेंस एपीआई
    • भुगतान इरादा एपीआई
    • रिफंड एपीआई
  • Pet Store एपीआई दस्तावेज़ीकरण। OpenAPI 3.0 विनिर्देश के आधार पर तैयार किया गया मॉड्यूलर REST API संदर्भ।
    • पालतू जानवर एपीआई
    • स्टोर एपीआई
    • उपयोगकर्ता एपीआई
  • Datadog लॉग इनजेशन एपीआई। बैच टेलीमेट्री डेटा सबमिट करने के लिए स्ट्रीमिंग एपीआई संदर्भ।
  • Sui TypeScript SDK संदर्भ:
    • SuiClient.getObject
    • SuiClient.multiGetObjects
    • SuiClient.getOwnedObjects

वास्तुकला और वैचारिक दस्तावेज़ीकरण​

  • Stripe API का परिचय। वित्तीय बुनियादी ढांचे, मुख्य संस्थाओं और प्रमाणीकरण का वैचारिक अवलोकन।
  • Pet Store API का परिचय। Swagger/OpenAPI Petstore REST सेवा और प्रमाणीकरण योजनाओं का अवलोकन।
  • इवेंट स्ट्रीम और ऑब्जर्वेबिलिटी पाइपलाइन। स्ट्रीम प्रोसेसिंग, एज रूटिंग और डेटा परिवर्तन का वास्तुशिल्प अवलोकन।
  • ऑब्जर्वेबिलिटी पाइपलाइनों के साथ शुरुआत करने से पहले। एंटरप्राइज़ सिस्टम के लिए लॉग रूटिंग प्रतिमानों की तुलना करने वाली एक वास्तुशिल्प गाइड।
  • SuiClient आर्किटेक्चर। यह समझाने वाला एक मानसिक मॉडल कि वितरित RPC क्लाइंट स्थिति प्रश्नों को कैसे व्यवस्थित करते हैं।

कमिट संदेश और पुल अनुरोध​

  • NumPy एफ-ऑर्डर्ड ऐरे फिक्स। ऐरे मेमोरी लेआउट समस्याओं को हल करने वाला ओपन सोर्स पुल अनुरोध विवरण और कमिट संदेश।
  • JAX में ak.mean के माध्यम से विभेदन। Awkward Array में स्वचालित विभेदन समर्थन की व्याख्या करने वाला दस्तावेज़ीकरण और कमिट संदेश।

केस स्टडीज​

  • Ask Artie AI असिस्टेंट केस स्टडी। प्रॉम्प्ट इंजीनियरिंग, OWASP LLM सुरक्षा और RAG पुनर्प्राप्ति वास्तुकला का विश्लेषण करने वाला एक इंजीनियरिंग केस स्टडी।

इन दस्तावेज़ों के मूल Markdown स्रोतों का निरीक्षण करने के लिए, GitHub रिपॉजिटरी पर जाएं।

डॉक्स-एज़-कोड वर्कफ़्लो​

  • VS Code और Antigravity का उपयोग करके Markdown और MDX में लेखन
  • Vale के साथ गद्य और शैली गाइड लिंटिंग
  • DeepL और Lara के साथ अंतर्राष्ट्रीयकरण और अनुवाद
  • Mermaid के साथ सिस्टम आर्किटेक्चर आरेखों का निर्माण
  • Git और GitHub के साथ संस्करण नियंत्रण और सहयोगी कोड समीक्षा
  • Postman और Swagger/OpenAPI के साथ API अन्वेषण और सत्यापन
  • Docusaurus के साथ निरंतर परिनियोजन

तकनीकी स्टैक​

  • Docusaurus। स्थिर साइटें, नेविगेशन साइडबार और स्थानीयकृत संस्करण उत्पन्न करता है।
  • VS Code। Markdown और MDX लेखन के लिए प्राथमिक संपादक के रूप में कार्य करता है।
  • Postman। API समापन बिंदुओं को मान्य करता है और अनुरोध/प्रतिक्रिया उदाहरण उत्पन्न करता है।
  • Vale। Google डेवलपर दस्तावेज़ीकरण दिशानिर्देशों को लागू करने के लिए तकनीकी गद्य की समीक्षा करता है।
  • Git और GitHub। शाखा संस्करण नियंत्रण और साइट परिनियोजन का प्रबंधन करता है।
  • Mermaid। फ्लोचार्ट और डेटा पाइपलाइन आर्किटेक्चर आरेखों को प्रस्तुत करता है।
  • DeepL और Lara। कई भाषाओं में दस्तावेज़ीकरण अनुवाद को स्वचालित करते हैं।

यह वातावरण आधुनिक इंजीनियरिंग कंपनियों में उत्पादन डेवलपर पोर्टलों को सटीक रूप से दर्शाता है।

प्रत्येक नमूना एंड-टू-एंड दस्तावेज़ निर्माण को दर्शाता है: अनुसंधान, प्रारूपण, परीक्षण, समीक्षा और प्रकाशन।
