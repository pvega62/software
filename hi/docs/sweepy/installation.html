स्वीपी (Sweepy) की स्थापना

इस ट्यूटोरियल में, आप अपने कंप्यूटर पर स्वीपी (Sweepy) को इंस्टॉल करेंगे। इसके लिए आपको तीन उपकरणों की आवश्यकता होगी:

  1. पायथन (Python) – यह इंजन (engine) को चलाता है।
  2. गिट (Git) – यह इंटरनेट से इंजन का कोड डाउनलोड करता है।
  3. पिप (pip) – यह इंजन को आवश्यक अतिरिक्त लाइब्रेरियाँ (libraries) इंस्टॉल करता है। विंडोज़ एवं मैकओएस के लिए आधिकारिक इंस्टॉलरों में पिप (pip) शामिल है; लिनक्स डिस्ट्रिब्यूशनों में पिप सिस्टम पैकेज मैनेजर (system package manager) के माध्यम से उपलब्ध होता है।
नोट

यह गाइड उन लोगों के लिए है जिन्होंने पहले कभी टर्मिनल (terminal) नहीं खोला है। यदि आपके पास पहले से पायथन 3.10+ एवं गिट (Git) इंस्टॉल है, तो सीधे चरण 3 पर जाएँ।

चरण 1: अपना टर्मिनल खोलें​

टर्मिनल, जिसे कमांड प्रॉम्प्ट (command prompt) भी कहा जाता है, एक टेक्स्ट-आधारित विंडो है जहाँ आप कमांड टाइप करते हैं।

  • Windows
  • macOS
  • Linux

विंडोज़ कुंजी दबाएँ, PowerShell टाइप करें, फिर Windows PowerShell चुनें।

Terminal
Windows PowerShell
Copyright (C) Microsoft Corporation. All rights reserved.

PS C:\Users\YourName>

Command + Space दबाएँ, Terminal टाइप करें, फिर Enter दबाएँ।

Terminal
Last login: Mon Oct 19 14:40:23 on ttys000
yourname@MacBook-Pro ~ %

अधिकांश लिनक्स डिस्ट्रीब्यूशनों पर एक टर्मिनल विंडो खोलने के लिए Ctrl + Alt + T दबाएँ।

Terminal
yourname@ubuntu:~$

प्रॉम्प्ट में एक चमकता हुआ कर्सर होता है; यह दर्शाता है कि टर्मिनल कमांड देने के लिए तैयार है।

चरण 2: पाइथन की जाँच करें और इंस्टॉल करें​

“Sweepy” के लिए Python 3.10 या उससे नई संस्करण की आवश्यकता है। जाँचें कि क्या आपके पास पहले से ही पायथन है।

अपने टर्मिनल में निम्नलिखित कमांड टाइप करें एवं Enter दबाएँ:

Terminal
python --version

macOS एवं लिनक्स पर, कमांड है python3 --version।

यदि आपको Python 3.10.x या उससे अधिक का संस्करण दिखाई दे, तो पायथन पहले से ही आपके पास है; चरण 3 पर जाएँ।

यदि आपको कोई त्रुटि संदेश (जैसे 'python' is not recognized) या संस्करण (जैसे 3.10 से कम) दिखाई देता है, तो नीचे दिए गए इंस्टॉलेशन चरणों का पालन करें।

  • Windows
  • macOS
  • Linux
  1. विंडोज के लिए पायथन डाउनलोड पेज पर जाएँ।
  2. सबसे नया विंडोज इंस्टॉलर (64-बिट) डाउनलोड लिंक चुनें।
  3. डाउनलोड की गई फ़ाइल चलाएँ।
  4. यह चरण महत्वपूर्ण है: इंस्टॉलर के पहले स्क्रीन पर, नीचे दिए गए चेकबॉक्स (“Add python.exe to PATH”) को चुनें। इससे पायथन आपके सिस्टम में इंस्टॉल हो जाएगा।
  5. इंस्टॉल करें चुनें और इंस्टॉलेशन पूरा होने तक प्रतीक्षा करें।

फिर एक नई टर्मिनल विंडो में इंस्टॉलेशन की पुष्टि करें।

Terminal
PS C:\Users\YourName> python --version
Python 3.13.1
सावधानी

यदि आप “Add python.exe to PATH” को छोड़ देते हैं, तो आपका टर्मिनल python कमांड को पहचान नहीं पाएगा। पहले Python को अनइंस्टॉल करें, फिर चयनित विकल्पों के साथ इसे पुनः इंस्टॉल करें।

  1. macOS के लिए Python डाउनलोड पेज पर जाएँ।
  2. सबसे नया macOS 64-bit universal2 इंस्टॉलर डाउनलोड करें।
  3. डाउनलोड की गई .pkg फ़ाइल को खोलें एवं इंस्टॉलेशन के निर्देशों का पालन करें।

फिर एक नई टर्मिनल विंडो में इंस्टॉलेशन की पुष्टि करें।

Terminal
yourname@MacBook-Pro ~ % python3 --version
Python 3.13.1

अपने टर्मिनल में निम्नलिखित दो कमांड चलाएँ:

Terminal
sudo apt update
sudo apt install python3 python3-pip python3-venv
सुझाव

Fedora या Red Hat Enterprise Linux पर, apt को dnf से बदल दें: sudo dnf install python3 python3-pip।

फिर एक नई टर्मिनल विंडो में इंस्टॉलेशन की पुष्टि करें।

Terminal
yourname@ubuntu:~$ python3 --version
Python 3.12.3

Windows, macOS, एवं Linux पर इंस्टॉलेशन की पुष्टि हो जाएगी। अपना टर्मिनल बंद करें, फिर दोबारा खोलें एवं “version” कमांड चलाएँ; यदि संस्करण क्रमांक 3.10 या उससे अधिक है, तो Python इंस्टॉल हो चुका है।

चरण 3: Sweepy डाउनलोड करें​

Sweepy की सोर्स फ़ाइलें डाउनलोड करना

एक विधि चुनें। नीचे वर्णित Git का उपयोग करें, या Sweepy रिलीज पेज से एक ZIP फ़ाइल डाउनलोड करें।

Git, प्रोजेक्ट फ़ाइलों की प्रतियाँ आपके कंप्यूटर पर कॉपी करता है एवं उनका इतिहास रिकॉर्ड करता है; यह इतिहास Sweepy को खुद को अपडेट करने में मदद करता है। नीचे दिए गए चरण Git का उपयोग करते हैं।

  • Git का उपयोग करके फ़ाइलें कॉपी करें: sweepy --update चलाएँ या Toolbox अपडेटर का उपयोग करके प्रत्येक नई रिलीज़ को प्राप्त करें।
  • ZIP फ़ाइल का उपयोग करके फ़ाइलें कॉपी करें: प्रत्येक रिलीज़ के लिए फ़ाइल डाउनलोड करें, उन्हें अनज़िप करें, एवं फिर पुनः pip install -e . चलाएँ। स्वचालित अपडेट बंद रहेंगे, क्योंकि ZIP फ़ाइल में Git इतिहास नहीं होता।
  • फ़ोल्डर का नाम: Git, sweepy नामक एक फ़ोल्डर बनाता है; ZIP फ़ाइल, sweepy-main जैसे फ़ोल्डर में अनज़िप हो जाती है; इसलिए इस चरण में cd कमांड को समायोजित करें।

यदि आप केवल एक बार फ़ाइलें देखना चाहते हैं, तो ZIP फ़ाइल का उपयोग करें; यदि आप Sweepy का निरंतर उपयोग करने की योजना बना रहे हैं, तो Git का उपयोग करें।

यदि कोई त्रुटि आती है, तो एक समस्या (Issue) खोलें एवं उस कमांड को पेस्ट करें जिसे आपने चलाया था।

सबसे पहले, जाँच लें कि Git पहले से ही इंस्टॉल है या नहीं:

Terminal
git --version

यदि आपको कोई संस्करण-संख्या (जैसे git version 2.45.1) दिखाई देती है, तो आपके पास Git है।

यदि कोई त्रुटि आती है, तो Git इंस्टॉल करें:

  • Windows
  • macOS
  • Linux
  1. git-scm.com/download/win पर जाएँ।
  2. इंस्टॉलर डाउनलोड करके उसे चलाएँ।
  3. सभी डिफ़ॉल्ट सेटिंग्स को स्वीकार करें एवं Install (इंस्टॉल करें) पर क्लिक करें।
  4. अपना टर्मिनल बंद करें एवं फिर दोबारा खोलें; फिर पुष्टि करें।
Terminal
PS C:\Users\YourName> git --version
git version 2.45.1

यह कमांड चलाएँ, तथा macOS आपसे Xcode Command Line Tools को इंस्टॉल करने के लिए कहेगा; इसमें Git भी शामिल है।

Terminal
yourname@MacBook-Pro ~ % git --version
xcode-select: note: install requested for command line developer tools

स्क्रीन पर दिए गए निर्देशों का पालन करके इंस्टॉलेशन पूरा करें, फिर पुनः git --version पर क्लिक करें। यदि कोई संस्करण-नंबर दिखाई दे, तो इसका मतलब है कि Git इंस्टॉल हो चुका है।

Terminal
yourname@ubuntu:~$ sudo apt install git

अब, Sweepy को डाउनलोड करें।

Terminal
yourname@ubuntu:~$ git --version
git version 2.45.1

अब, निम्नलिखित कमांड चलाकर Sweepy डाउनलोड करें:

Terminal
git clone https://github.com/pvega62/sweepy.git

Git, उस नए फ़ोल्डर को उसी डायरेक्टरी में रख देगा जिस पर आपने कमांड चलाई थी। विंडोज़ पर, sweepy में एक नया PowerShell विंडो खुल जाएगा।

Terminal
cd sweepy
सुझाव

जब आप उस कमांड को चलाते हैं, तो Git नई फ़ोल्डर को उसी डायरेक्टरी में रखता है जिस पर आपका टर्मिनल इशारा कर रहा है। विंडोज़ पर, एक नया PowerShell विंडो C:\Users\YourName\ में खुल जाता है।

चरण 4: निर्भरताएँ स्थापित करें​

Sweepy काम करने के लिए कुछ अतिरिक्त लाइब्रेरियों (libraries) पर निर्भर है।

  • pymupdf: आपके रिज्यूमे पीडीएफ फाइल से टेक्स्ट पढ़ता है एवं उसे निकालता है।
  • python-docx: .docx के रिज्यूमे (resume) पढ़ता है एवं उन्हें परिवर्तित करता है।
  • python-jobspy: जॉब बोर्ड्स से डेटा सुरक्षित रूप से एकत्र करता है, बिना API कुंजी की आवश्यकता के।
  • beautifulsoup4: Greenhouse, Lever, Workable, एवं Built In NYC स्रोतों से डेटा प्राप्त करता है।
  • reportlab: क्लिककर खोले जा सकने वाले लिंक्स वाली स्टाइल्ड PDF रिपोर्ट तैयार करता है।
  • requests: वेब अनुरोध (web requests) भेजता है ताकि यह जाँचा जा सके कि URL अभी भी सक्रिय हैं या नहीं।
  • pyyaml एवं questionary: इंटरैक्टिव कॉन्फ़िगरेशन विजार्ड (interactive configuration wizard) को संचालित करते हैं; prompt-toolkit कीबोर्ड नियंत्रण प्रदान करता है।
  • pandas: एकत्रित डेटा को संरचित करता है एवं CSV फ़ाइलों में निर्यात करता है।
  • mcp एवं anyio: “Model Context Protocol” सर्वर चलाते हैं, जो Sweepy को AI असिस्टेंट से जोड़ता है।
Python 3.13

यदि आप Python 3.13 का उपयोग कर रहे हैं, तो पहले Microsoft C++ Build Tools को इंस्टॉल करें एवं “Desktop development with C++” कार्यभार (workload) का चयन करें। Python 3.13 इतना नया है कि कुछ पैकेज (जैसे pymupdf), स्रोत कोड से संकलित (compile) होने हेतु इन उपकरणों की आवश्यकता हो सकती है। Python 3.12 या पुराने संस्करणों पर इस चरण को छोड़ दें।

Sweepy के स्वचालित परीक्षण Python 3.10 से 3.12 तक के संस्करणों को कवर करते हैं।

हर पैकेज को एक ही कमांड से इंस्टॉल करें:

Terminal
pip install -e .

यह कमांड सभी निर्भरताओं को इंस्टॉल करती है एवं sweepy कमांड को आपकी “Python Scripts” फ़ोल्डर में पंजीकृत करती है। अपना टर्मिनल फिर से खोलें ताकि PATH नई फ़ोल्डर को पहचान सके। इसके बाद, python swee.py --run के बजाय sweepy --run को चलाएँ। sweepy फ़ोल्डर से कोई भी कमांड चलाएँ।

पायथन प्रत्येक पैकेज डाउनलोड एवं इंस्टॉल करता है, जैसे-जैसे टेक्स्ट स्क्रॉल होता जाता है। जब कर्सर वापस आता है, तो इंस्टॉलेशन पूरा हो जाता है।

सुझाव

क्या आपको pip के लिए “command not found” त्रुटि मिली? इसके बजाय pip3 install -e . का प्रयास करें। कुछ सिस्टमों पर, Python 3 में pip3 कमांड के रूप में उपयोग में आता है।

अपनी इंस्टॉलेशन की पुष्टि करें​

इस त्वरित जाँच को चलाकर यह सुनिश्चित करें कि सब कुछ सही तरीके से स्थापित हुआ है।

Terminal
sweepy --version

यदि आपका शेल (shell) sweepy नहीं पा पा रहा है, तो टर्मिनल को फिर से खोलें या python swee.py --version चलाएँ।

Terminal output
Sweepy v3.1.0
Python 3.13.1 | pymupdf 1.28.2 | reportlab 5.0.1
Ready to sweep.

यदि यह संदेश दिखाई देता है, तो समझें कि Sweepy तैयार है। आपके कंप्यूटर पर संख्याएँ अलग हो सकती हैं; Sweepy अपनी VERSION फ़ाइल से जानकारी प्रिंट करता है, और pip आपके पायथन संस्करण के अनुरूप पैकेज इंस्टॉल करता है।

दूसरी पंक्ति pymupdf एवं reportlab के संस्करणों को दर्शाती है।

अब, अपना व्यक्तिगत नौकरी-खोज प्रोफ़ाइल (personalized job search profile) सेट करें.
