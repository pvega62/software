Sweepy इंस्टॉल करना

Sweepy चलाने से पहले आपके कंप्यूटर पर तीन चीज़ें चाहिए:

  1. Python: वह प्रोग्रामिंग भाषा जिस पर इंजन चलता है।
  2. Git: वह टूल जो इंटरनेट से इंजन का कोड डाउनलोड करता है।
  3. pip: वह पैकेज मैनेजर जो इंजन की ज़रूरी अतिरिक्त लाइब्रेरी इंस्टॉल करता है। Windows और macOS के आधिकारिक इंस्टॉलर pip के साथ आते हैं। Linux वितरण pip को सिस्टम पैकेज मैनेजर से जोड़ते हैं।
नोट

यह गाइड हर चरण समझाती है, उस व्यक्ति के लिए भी जिसने कभी टर्मिनल नहीं खोला। अगर आपके पास पहले से Python 3.10+ और Git इंस्टॉल है, तो सीधे चरण 3 पर जाएँ।

चरण 1: अपना टर्मिनल खोलें​

टर्मिनल, जिसे कमांड प्रॉम्प्ट भी कहते हैं, एक टेक्स्ट-आधारित विंडो है जहाँ आप कमांड टाइप करते हैं। आइकन चुनने के बजाय आप यहाँ कंप्यूटर को निर्देश टाइप करते हैं।

  • Windows
  • macOS
  • Linux

Windows key दबाएँ, PowerShell टाइप करें, फिर Windows PowerShell चुनें।

टर्मिनल
Windows PowerShell
Copyright (C) Microsoft Corporation. All rights reserved.

PS C:\Users\YourName>

Command + Space दबाएँ, Terminal टाइप करें, फिर Enter दबाएँ।

टर्मिनल
Last login: Mon Oct 19 14:40:23 on ttys000
yourname@MacBook-Pro ~ %

अधिकांश Linux वितरणों पर टर्मिनल विंडो खोलने के लिए Ctrl + Alt + T दबाएँ।

टर्मिनल
yourname@ubuntu:~$

प्रॉम्प्ट एक टिमटिमाते कर्सर पर समाप्त होता है। यह कर्सर बताता है कि आपका टर्मिनल कमांड के लिए तैयार है।

चरण 2: Python जाँचें और इंस्टॉल करें​

Sweepy के लिए Python 3.10 या नया चाहिए। जाँचें कि क्या यह पहले से है।

यह कमांड अपने टर्मिनल में टाइप करें और Enter दबाएँ:

टर्मिनल
python --version

macOS और Linux पर कमांड python3 --version है।

अगर आपको Python 3.10.x या उससे ऊँचा दिखे, तो Python पहले से है। चरण 3 पर जाएँ।

अगर आपको 'python' is not recognized जैसा त्रुटि संदेश या 3.10 से नीचे का संस्करण दिखे, तो नीचे दिए इंस्टॉलेशन चरण अपनाएँ।

  • Windows
  • macOS
  • Linux
  1. Windows के लिए Python डाउनलोड पेज पर जाएँ।
  2. सबसे नया Windows installer (64-bit) डाउनलोड लिंक चुनें।
  3. डाउनलोड की गई फ़ाइल चलाएँ।
  4. यह चरण सबसे ज़रूरी है। इंस्टॉलर की पहली स्क्रीन पर नीचे "Add python.exe to PATH" लेबल वाला चेकबॉक्स चुनें। यह चेकबॉक्स Python को आपके PATH में जोड़ता है, जहाँ से टर्मिनल उसे ढूँढ पाता है।
  5. Install Now चुनें और इंस्टॉलेशन पूरा होने की प्रतीक्षा करें।

फिर एक नई टर्मिनल विंडो में इंस्टॉल की पुष्टि करें:

टर्मिनल
PS C:\Users\YourName> python --version
Python 3.13.1
सावधानी

अगर आप "Add python.exe to PATH" छोड़ देते हैं, तो आपका टर्मिनल python कमांड नहीं पहचानेगा। Python अनइंस्टॉल करें, फिर बॉक्स चुनकर दोबारा इंस्टॉल करें।

  1. macOS के लिए Python डाउनलोड पेज पर जाएँ।
  2. सबसे नया macOS 64-bit universal2 installer डाउनलोड करें।
  3. डाउनलोड की गई .pkg फ़ाइल खोलें और इंस्टॉलेशन के संकेतों का पालन करें।

फिर एक नई टर्मिनल विंडो में इंस्टॉल की पुष्टि करें:

टर्मिनल
yourname@MacBook-Pro ~ % python3 --version
Python 3.13.1

अपने टर्मिनल में ये दो कमांड चलाएँ:

टर्मिनल
sudo apt update
sudo apt install python3 python3-pip python3-venv
सुझाव

Fedora या Red Hat Enterprise Linux पर apt की जगह dnf इस्तेमाल करें: sudo dnf install python3 python3-pip।

फिर एक नई टर्मिनल विंडो में इंस्टॉल की पुष्टि करें:

टर्मिनल
yourname@ubuntu:~$ python3 --version
Python 3.12.3

Windows, macOS और Linux टैब एक ही जाँच पर समाप्त होते हैं। अपना टर्मिनल बंद करें, दोबारा खोलें, और वर्ज़न कमांड चलाएँ। 3.10 या उससे ऊँचा वर्ज़न नंबर मतलब Python तैयार है।

चरण 3: Sweepy डाउनलोड करें​

Sweepy की सोर्स फ़ाइलें डाउनलोड करना

एक तरीका चुनें। नीचे दिया गया Git इस्तेमाल करें, या Sweepy रिलीज़ पेज से ZIP फ़ाइल डाउनलोड करें।

Git प्रोजेक्ट की फ़ाइलें आपके कंप्यूटर पर कॉपी करता है और उनका इतिहास दर्ज करता है। इसी इतिहास से Sweepy खुद को अपडेट कर पाता है। नीचे दिए गए चरण Git का इस्तेमाल करते हैं।

  • Git कॉपी। हर नई रिलीज़ लाने के लिए sweepy --update चलाएँ या Sweepy's Toolbox का अपडेटर इस्तेमाल करें।
  • ZIP कॉपी। हर रिलीज़ के लिए फ़ाइल डाउनलोड करें, अनज़िप करें, और pip install -e . दोबारा चलाएँ। ऑटोमैटिक अपडेट बंद रहते हैं, क्योंकि ZIP में Git का कोई इतिहास नहीं होता जिससे अपडेट लाया जा सके।
  • फ़ोल्डर का नाम। Git sweepy नाम का फ़ोल्डर बनाता है। ZIP sweepy-main जैसे फ़ोल्डर में खुलता है, इसलिए इस चरण में आगे दिया गया cd कमांड बदलें।

एक बार देखने के लिए ZIP चुनें। अगर आप Sweepy आगे भी इस्तेमाल करेंगे, तो Git चुनें।

पहले जाँचें कि Git पहले से इंस्टॉल है या नहीं:

टर्मिनल
git --version

अगर आपको git version 2.45.1 जैसा वर्ज़न नंबर दिखे, तो Git मौजूद है। अगर त्रुटि दिखे, तो Git इंस्टॉल करें:

  • Windows
  • macOS
  • Linux
  1. साइट git-scm.com/download/win खोलें।
  2. इंस्टॉलर डाउनलोड करें और चलाएँ।
  3. सभी डिफ़ॉल्ट सेटिंग स्वीकार करें और Install चुनें।
  4. अपना टर्मिनल बंद करके दोबारा खोलें, फिर पुष्टि करें:
टर्मिनल
PS C:\Users\YourName> git --version
git version 2.45.1

यह कमांड चलाएँ। macOS आपको Xcode Command Line Tools इंस्टॉल करने का संकेत देगा, जिनमें Git शामिल है:

टर्मिनल
yourname@MacBook-Pro ~ % git --version
xcode-select: note: install requested for command line developer tools

इंस्टॉल के लिए स्क्रीन पर दिए संकेत का पालन करें, फिर git --version दोबारा चलाएँ। वर्ज़न नंबर मतलब Git तैयार है।

टर्मिनल
yourname@ubuntu:~$ sudo apt install git

फिर पुष्टि करें:

टर्मिनल
yourname@ubuntu:~$ git --version
git version 2.45.1

अब यह कमांड चलाकर Sweepy डाउनलोड करें:

टर्मिनल
git clone https://github.com/pvega62/sweepy.git

यह आपके कंप्यूटर पर sweepy नाम का नया फ़ोल्डर बनाता है। उसमें जाएँ:

टर्मिनल
cd sweepy
सुझाव

Git नया फ़ोल्डर उसी डायरेक्टरी में रखता है जहाँ कमांड चलाते समय आपका टर्मिनल था। Windows पर एक नई PowerShell विंडो C:\Users\YourName\ से शुरू होती है।

चरण 4: डिपेंडेंसी इंस्टॉल करें​

Sweepy को काम करने के लिए कुछ अतिरिक्त लाइब्रेरी चाहिए:

  • pymupdf: आपकी रिज़्यूमे PDF से टेक्स्ट पढ़ता और निकालता है।
  • python-docx: .docx रिज़्यूमे पढ़ता और बदलता है।
  • python-jobspy: बिना API कुंजी के जॉब बोर्ड को सुरक्षित रूप से स्क्रैप करता है।
  • beautifulsoup4: Greenhouse, Lever, Workable और Built In स्रोतों का HTML पार्स करता है।
  • reportlab: क्लिक करने योग्य लिंक के साथ स्टाइल की गई PDF रिपोर्ट बनाता है।
  • requests: URL अभी सक्रिय हैं या नहीं, यह जाँचने के लिए वेब रिक्वेस्ट भेजता है।
  • pyyaml & questionary: इंटरैक्टिव कॉन्फ़िगरेशन विज़ार्ड संभालते हैं। prompt-toolkit उसके कीबोर्ड नियंत्रण देता है।
  • pandas: स्क्रैप किए गए जॉब डेटा को व्यवस्थित करता है और CSV स्प्रेडशीट निर्यात बनाता है।
  • mcp & anyio: वैकल्पिक Model Context Protocol सर्वर चलाते हैं जो Sweepy को AI सहायक से जोड़ता है।
Python 3.13

अगर आप Python 3.13 इस्तेमाल करते हैं, तो पहले Microsoft C++ Build Tools इंस्टॉल करें और "Desktop development with C++" वर्कलोड चुनें। Python 3.13 इतना नया है कि कुछ पैकेज, जैसे pymupdf, सोर्स से कंपाइल हो सकते हैं और उन टूल की ज़रूरत रखते हैं। Python 3.12 या उससे पुराने पर यह चरण छोड़ दें।

Sweepy के स्वचालित टेस्ट Python 3.10 से 3.12 तक कवर करते हैं। ये संस्करण सबसे सहज रास्ता बने रहते हैं।

एक ही कमांड से हर पैकेज इंस्टॉल करें:

टर्मिनल
pip install -e .

यह कमांड हर डिपेंडेंसी इंस्टॉल करता है और आपके Python Scripts फ़ोल्डर में sweepy कमांड दर्ज करता है। अपना टर्मिनल एक बार दोबारा खोलें ताकि PATH नया फ़ोल्डर पकड़ ले। उसके बाद python swee.py --run के बजाय sweepy --run चलाएँ। दोनों रूप अपने sweepy फ़ोल्डर से चलाएँ।

जैसे-जैसे Python हर पैकेज डाउनलोड और इंस्टॉल करता है, टेक्स्ट स्क्रॉल होता जाता है। जब कर्सर लौट आए, इंस्टॉलेशन पूरा है।

सुझाव

क्या आपको pip के लिए "command not found" त्रुटि मिली? इसकी जगह pip3 install -e . आज़माएँ। कुछ सिस्टम पर Python 3 pip3 नाम से कमांड चलाता है।

अपना इंस्टॉलेशन सत्यापित करें​

सब कुछ ठीक इंस्टॉल हुआ है, यह पक्का करने के लिए यह त्वरित जाँच चलाएँ:

टर्मिनल
sweepy --version

अगर आपका शेल sweepy नहीं ढूँढ पाता, तो टर्मिनल दोबारा खोलें या इसकी जगह python swee.py --version चलाएँ। आपको यह दिखेगा:

टर्मिनल आउटपुट
Sweepy v3.0.0
Python 3.13.1 | pymupdf 1.28.2 | reportlab 5.0.1
Ready to sweep.

अगर यह संदेश दिखे, तो Sweepy तैयार है। आपकी मशीन पर अलग नंबर आ सकते हैं। Sweepy अपनी VERSION फ़ाइल से रिलीज़ छापता है, और pip आपके Python संस्करण से मेल खाते पैकेज इंस्टॉल करता है।

दूसरी पंक्ति pymupdf और reportlab के संस्करण बताती है।

अगला कदम, अपनी व्यक्तिगत जॉब सर्च प्रोफ़ाइल कॉन्फ़िगर करें।
