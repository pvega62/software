Sweepy सेटअप करना

आपने Sweepy इंस्टॉल कर लिया है! अब आपको एक प्रोफ़ाइल की आवश्यकता है।

एक कॉन्फ़िगरेशन प्रोफ़ाइल Sweepy को यह निर्दिष्ट करती है कि किन नौकरियों को खोजना है और उनका मूल्यांकन करने के लिए किस रिज़्यूमे का उपयोग करना है। यह आपके लक्ष्य स्थान को भी निर्धारित करती है।

एक प्रोफ़ाइल YAML प्रारूप में एक छोटी टेक्स्ट फ़ाइल होती है। YAML, जिसका उच्चारण 'कैमल' जैसा होता है, इंडेंटेशन, कोलन और लाइन ब्रेक के साथ डेटा को व्यवस्थित करता है। आपको कोड लिखने की ज़रूरत नहीं है: अगर आप किराने की सूची पढ़ सकते हैं, तो आप YAML पढ़ सकते हैं।

विकल्प A: इंटरैक्टिव सेटअप विज़ार्ड चलाएँ​

सेटअप विज़ार्ड साधारण उत्तरों से एक कामकाजी प्रोफ़ाइल बनाता है। यह प्रश्नावली से पहले सर्च लॉन्चपैड खोलता है और आपके लिए कॉन्फ़िगरेशन फ़ाइल लिखता है।

यह कमांड चलाएँ:

टर्मिनल
sweepy --setup

विज़ार्ड अपना बैनर प्रिंट करता है, फिर लॉन्चपैड। टाइलों के नीचे की स्थिति पंक्ति लोड की गई प्रोफ़ाइल दिखाती है, जैसे वर्तमान प्रोफ़ाइल: Alex Rivera / 4 शीर्षक / तैयार। अभी तक कुछ भी लोड न होने पर, यह वर्तमान प्रोफ़ाइल: कुछ भी लोड नहीं है / शुरू करने के लिए एक बनाएं पढ़ता है।

लॉन्चपैड छह टाइलें दिखाता है। स्टार्ट स्वीप लोडेड प्रोफ़ाइल को चलाता है। लोड प्रोफ़ाइल एक सहेजी गई खोज खोलता है। बिल्ड प्रोफ़ाइल एक नई खोज शुरू करता है और सरल-अंग्रेज़ी में प्रश्न पूछता है। स्वीप सेटिंग्स रैंकिंग, कार्ड और इतिहास को नियंत्रित करता है। **स्वीपी का टूलबॉक्स में प्रोफ़ाइल संपादन, इंजन प्रबंधन, एग्रीगेटर प्रबंधन, डिबग टॉगल, सहायता, हालिया लॉग, दस्तावेज़ रूपांतरण और अपडेट शामिल हैं। स्वीपी से बाहर निकलें आपके परिवर्तनों को सहेजता है और विज़ार्ड को बंद कर देता है।

कमांड संदर्भ प्रत्येक प्रविष्टि के पीछे के फ़्लैग्स की सूची देता है।

नया प्रोफ़ाइल बनाने या मौजूदा को संपादित करने के लिए किसी भी समय sweepy --setup को फिर से चलाएँ। विज़ार्ड उसी फ़ाइल में लिखता है जिसका वह नाम देता है और आपके अन्य प्रोफ़ाइल को वैसे ही छोड़ देता है।

लॉन्चपैड को छोड़ने और सीधे एक सहेजे गए प्रोफ़ाइल को संपादित करने के लिए, --profile फ़्लैग पास करें:

Terminal
sweepy --setup --profile profiles/paralegal_nyc.yaml

विकल्प बी: कॉन्फ़िग फ़ाइल को मैन्युअल रूप से संपादित करें​

अपनी सेटिंग्स सीधे टाइप करने के लिए, सैंपल टेम्पलेट को कॉपी करें और इसे नोटपैड या वीएस कोड जैसे प्लेन-टेक्स्ट एडिटर में खोलें। वर्ड प्रोसेसर का उपयोग करने से बचें, क्योंकि वे सीधे कोट्स को कर्ली कोट्स से बदल देते हैं और YAML को तोड़ देते हैं।

  • Windows
  • macOS / Linux
Terminal
copy config.sample.yaml profiles\alex_rivera_paralegal.yaml
notepad profiles\alex_rivera_paralegal.yaml
टर्मिनल
cp config.sample.yaml profiles/alex_rivera_paralegal.yaml
open profiles/alex_rivera_paralegal.yaml    # macOS
# या: nano profiles/alex_rivera_paralegal.yaml   # लिनक्स

एलेक्स की प्रोफ़ाइल​

विज़ार्ड इस फ़ाइल को profiles/alex_rivera_paralegal.yaml में लिखता है। # से शुरू होने वाली लाइनें टिप्पणियाँ हैं: वे प्रत्येक सेटिंग की व्याख्या करती हैं, और स्वीपी उन्हें अनदेखा कर देता है। आप किसी भी अनुभाग या सेटिंग को छोड़ देने पर स्वीपी एक डिफ़ॉल्ट भर देता है।

profiles/alex_rivera_paralegal.yaml
# ─────────────────────────────────────────────────
# स्वीपी — एलेक्स का पैरालीगल प्रोफ़ाइल
# ─────────────────────────────────────────────────

# आपका नाम (पीडीएफ रिपोर्ट हेडर में दिखाई देता है)
name: "एलेक्स रिवेरा"

# ─── नौकरी खोज सेटिंग्स ──────────────────────────
search:
  # हर उस नौकरी का शीर्षक सूचीबद्ध करें जिसे आप खोजना चाहते हैं।
  # इंजन इन सभी शीर्षकों को एक साथ खोजता है।
  titles:
    - "पैरालीगल"
    - "लीगल असिस्टेंट"
    - "लिटिगेशन सपोर्ट स्पेशलिस्ट"
    - "लीगल सेक्रेटरी"

  # आपका लक्षित शहर और राज्य।
  स्थान: "न्यूयॉर्क, एनवाई"

  # केवल रिमोट भूमिकाएँ देखने के लिए true पर सेट करें।
  # रिमोट, हाइब्रिड और ऑन-साइट भूमिकाएँ देखने के लिए false पर सेट करें।
  केवल-रिमोट: false

  # हाइब्रिड पदों को बाहर करने के लिए false पर सेट करें।
  include_hybrid: true

  # न्यूनतम वार्षिक वेतन फ़िल्टर (वैकल्पिक)।
  # वेतन फ़िल्टरिंग को छोड़ने के लिए इसे 0 पर छोड़ दें या इस लाइन को हटा दें।
  min_salary: 65000

# ─── रिज़्यूमे सेटिंग्स ─────────────────────────────
resume:
  # आपके कंप्यूटर पर आपके रिज़्यूमे PDF का पूरा पथ।
  # विंडोज पर, डबल बैकस्लैश (\\) या फॉरवर्ड स्लैश (/) का उपयोग करें।
  path: "Alex_Rivera_Resume.pdf"

  # मिलान प्रतिशत के लिए प्राथमिकता देने हेतु अनिवार्य कौशल।
  must_have_skills:
    - "Westlaw"
    - "LexisNexis"
    - "e-discovery"
    - "अनुबंध समीक्षा"
    - "कानूनी शोध"

  # भूमिकाओं को स्कोर करते समय कीवर्ड मिलान को कितना महत्व दें।
  # 1.0 = मानक वज़न। यदि आप चाहते हैं कि
  # सटीक कौशल मिलान स्कोर पर हावी हों तो इसे 2.0 तक बढ़ाएँ।
  keywords_weight: 1.5

# ─── प्लेटफ़ॉर्म सेटिंग्स ────────────────────────────
# प्रत्येक प्लेटफ़ॉर्म को सक्षम या अक्षम करने के लिए true या false पर सेट करें।
platforms:
  greenhouse: true
  ashby: true
  lever: true
  workable: true
  aggregators: false   # रिमोटिव, एडज़ुना जैसे मुफ़्त फ़ीड

  # वैकल्पिक: कस्टम एटीएस एंडपॉइंट या कंपनी करियर डोमेन
  custom:
    - name: "SmartRecruiters"

प्रीसेट प्रोफ़ाइल का उपयोग करना​

Sweepy में profiles/ फ़ोल्डर में उपयोग के लिए तैयार प्रोफ़ाइल प्रीसेट शामिल हैं। ये चार सामान्य खोजों को कवर करते हैं:

फ़ाइलकरियर पथखोजे गए शीर्षक
paralegal_nyc.yamlकानूनीपैरालीगल, लीगल असिस्टेंट, लिटिगेशन सपोर्ट स्पेशलिस्ट, लीगल सेक्रेटरी
frontend_developer.yamlसॉफ्टवेयर इंजीनियरिंगफ्रंट एंड डेवलपर, रिएक्ट डेवलपर, यूआई इंजीनियर
tech_writer.yamlतकनीकी लेखनतकनीकी लेखक, यूएक्स लेखक, सामग्री डिजाइनर
template_custom.yamlकोई भी करियरनमूना शीर्षक जिन्हें आप बदल सकते हैं। प्रत्येक सेटिंग में एक टिप्पणी है।

प्रीसेट का उपयोग करने के लिए, जब आप एक स्वीप चलाते हैं तो उसका फ़ाइलनाम पास करें:

Terminal
sweepy --profile profiles/frontend_developer.yaml

:::सुझाव आप जितनी चाहें उतनी प्रोफ़ाइल बना सकते हैं। आप जिस भी जॉब टाइटल वेरिएशन या शहर को लक्षित करते हैं, उसके लिए एक अलग प्रोफ़ाइल स्टोर करें। --profile फ़्लैग का उपयोग करके उनमें तुरंत स्विच करें। :::

विकल्प C: चैट असिस्टेंट के साथ स्वचालित करें​

एक चैट असिस्टेंट आपके लिए प्रोफ़ाइल बना सकता है और स्वीप्स चला सकता है। Sweepy में एक अंतर्निहित मॉडल कॉन्टेक्स्ट प्रोटोकॉल (MCP) सर्वर शामिल है, इसलिए असिस्टेंट आपकी प्रोफाइल को सीधे पढ़ता और लिखता है। MCP इंटीग्रेशन गाइड में Antigravity, Claude Desktop, और VS Code के लिए क्लाइंट सेटअप शामिल है, और MCP टूल संदर्भ में Sweepy के सभी टूल सूचीबद्ध हैं।

हर सेटिंग देखें​

कॉन्फ़िगरेशन संदर्भ में हर वह सेटिंग सूचीबद्ध है जिसे कोई प्रोफ़ाइल स्वीकार करती है, debug और resume.tracks से लेकर sources.* और report.* तक। जब आप अपनी प्रोफ़ाइल संपादित कर रहे हों तो इसे खुला रखें।

देखें कि Sweepy नौकरियों के लिए कहाँ देखता है​

Sweepy डिफ़ॉल्ट रूप से चार सार्वजनिक आवेदक ट्रैकिंग सिस्टम को क्वेरी करता है। उस समूह में Greenhouse, Ashby, Lever और Workable शामिल हैं। यह Built In NYC, एक न्यूयॉर्क जॉब बोर्ड को भी क्वेरी करता है। जब आपका प्रोफ़ाइल उन्हें सक्षम करता है, तो LinkedIn, Indeed, Glassdoor, और ZipRecruiter से आने वाले एग्रीगेटर फ़ीड python-jobspy के माध्यम से चलते हैं।

वैकल्पिक इंजन बोर्ड जोड़ते हैं। विकल्प हैं HireHunt, OpenRoles, JobDrop, और Apify। OpenRoles को चलने से पहले एक कंपनी सूची की आवश्यकता होती है। Apify को एक APIFY_TOKEN की आवश्यकता होती है। JobDrop का JobSpy की निर्भरता पिन के साथ टकराव है। सेटअप विज़ार्ड का डाउनलोड जॉब इंजन विकल्प उन्हें इंस्टॉल करता है।

स्रोत और प्लेटफ़ॉर्म पेज वैकल्पिक इंजन, सीड फ़ाइलें, कस्टम प्लेटफ़ॉर्म प्रविष्टियों, और संगतता चेतावनियों को कवर करता है।
