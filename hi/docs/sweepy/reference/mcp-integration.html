MCP से AI सहायक में Sweepy चलाएँ

एक AI सहायक आपके लिए Sweepy चला सकता है। आप बताते हैं कि कौन सी भूमिका चाहिए, और सहायक आपकी ओर से Sweepy को बुलाता है, बजाय आपसे टर्मिनल कमांड टाइप कराने के।

यह कनेक्शन Model Context Protocol (MCP) इस्तेमाल करता है। MCP एक साझा भाषा है जो AI सहायक को आपके कंप्यूटर पर इंस्टॉल टूल इस्तेमाल करने देती है। Sweepy में server.py में एक अंतर्निहित MCP सर्वर आता है। वह stdio ट्रांसपोर्ट पर चलता है, इसलिए वह आपके क्लाइंट से स्थानीय रूप से बात करता है और कोई नेटवर्क पोर्ट नहीं खोलता।

नोट

MCP वैकल्पिक है। Sweepy बिना किसी AI सहायक के, पूरी तरह टर्मिनल कमांड से काम करता है। सर्वर उसी इंजन के ऊपर एक बातचीत की परत जोड़ता है। वह Sweepy की नियतात्मक स्कोरिंग और फ़िल्टरिंग में मॉडल का मूल्यांकन और बुद्धि भी जोड़ता है।

जोड़ने से पहले​

  • इंस्टॉलेशन पूरा करें ताकि Python और Sweepy की डिपेंडेंसी मौजूद हों। mcp और anyio पैकेज requirements.txt के साथ आते हैं।
  • server.py का पूरा पथ नोट करें। आप वही पथ अपने क्लाइंट के कॉन्फ़िगरेशन में पेस्ट करते हैं।
  • MCP कॉन्फ़िगरेशन बदलने के बाद अपना AI क्लाइंट दोबारा शुरू करें।

उपलब्ध टूल​

Sweepy आपके सहायक को बारह टूल देता है। हर टूल JSON payload लौटाता है और read-only, destructive, idempotent तथा open-world संकेत घोषित करता है।

टूलयह क्या करता है
create_profilePDF या DOCX रिज़्यूमे से YAML प्रोफ़ाइल बनाता, सत्यापित करता और सहेजता है।
run_sweepपाँच-चरणीय पाइपलाइन पृष्ठभूमि में चलाता है और नियतात्मक कार्ड रखता है।
get_sweep_statusचल रहे स्वीप पर प्रतीक्षा करता है और उसकी प्रगति बताता है।
get_jobsमौजूदा सत्र में रखे कार्ड स्कोर के क्रम में लौटाता है।
submit_judgmentsकार्ड के नियतात्मक फ़ील्ड आपके सहायक के मूल्यांकन से बदल देता है।
import_jobsआपके सहायक द्वारा कहीं और सत्यापित नौकरियाँ जोड़ता है।
render_reportमौजूदा सत्र से कार्ड PDF रेंडर करता है।
get_resultsडिस्क से सबसे हाल का स्वीप नतीजा पढ़ता है।
export_reportमौजूदा स्वीप से PDF, PNG, CSV या JSON फ़ाइलें दोबारा बनाता है।
clear_historyएक प्रोफ़ाइल की रिपोर्ट की गई पोस्टिंग भुला देता है।
convert_documentसमर्थित दस्तावेज़ को PDF में बदलता है।
convert_docxDOCX रिज़्यूमे को PDF में बदलता है।

MCP टूल संदर्भ और गहराई में जाता है। वह हर पैरामीटर, डिफ़ॉल्ट, payload और व्यवहार संकेत सूचीबद्ध करता है।

जॉब सर्च इंजन चुनें​

जब आप sources_config नहीं देते, तब create_profile अंतर्निहित JobSpy और ATS इंजन चालू करता है। यह उन वैकल्पिक इंजन को भी चालू करता है जिनकी इंस्टॉल काम करती है और डिफ़ॉल्ट मान्य हैं। टूल enabled_engines और engines_not_enabled लौटाता है, ताकि आप देख सकें कि कौन से इंजन चलते हैं और किन्हें अभी सेटअप चाहिए।

OpenRoles केवल उन्हीं कंपनी बोर्ड को खोजता है जो आप सूचीबद्ध करते हैं। उसे चालू करने से पहले कंपनी slug जोड़ें। Apify पर शुल्क लग सकता है। चाहें तो उसे चालू करें। Sweepy वैकल्पिक पैकेज अपने आप इंस्टॉल नहीं करता। आपको हर सर्च के लिए इंजन चुनने की ज़रूरत नहीं। स्पष्ट रूप से तभी चुनें जब किसी इंजन को सेटअप, सशुल्क सेवा की सहमति या सर्च बाधा चाहिए।

जब आप इंजन स्पष्ट रूप से चुनें, तब sources_config दें। Sweepy उसी चयन को रखता है, दूसरे इंजन नहीं जोड़ता। यह JSON दो इंजन चुनता है:

{
  "enabled": ["jobspy", "openroles"],
  "openroles": {"companies": ["figma", "stripe"]}
}

एक-बार और हाइब्रिड टूल फ़्लो​

Sweepy दो तरीकों से चलता है। वह चुनें जो मेल खाए कि आप सहायक से कितना फ़ैसला कराना चाहते हैं।

एक-बार फ़्लो। आपका सहायक सब कुछ कॉन्फ़िगर और चलाता है, और इंजन हर भूमिका को रिज़्यूमे के कीवर्ड मेल से स्कोर करता है।

create_profile -> run_sweep -> get_results -> export_report (optional)

हाइब्रिड stateful फ़्लो। आपका सहायक हर कार्ड देखता है और रिपोर्ट बनने से पहले अपना मूल्यांकन देता है।

run_sweep -> get_jobs -> submit_judgments -> render_report

क्लाइंट का टाइमआउट होने के बाद भी चलता स्वीप चलता रह सकता है। जब run_sweep sweep_status: "running" लौटाए, तब लौटाए गए job_id के साथ get_sweep_status बुलाएँ, जब तक वह completed न बताए। फिर get_jobs के साथ आगे बढ़ें।

सुझाव

काम करने वाली रिपोर्ट के लिए LLM की ज़रूरत नहीं। अकेला run_sweep टूल नियतात्मक फ़ील्ड से पूरा कार्ड PDF रेंडर करता है, ठीक टर्मिनल स्वीप की तरह।

हर कार्ड दो में से एक स्कोर लेबल दिखाता है:

  • NN% KEYWORD OVERLAP नियतात्मक इंजन से आता है। यह आपके रिज़्यूमे टेक्स्ट की तुलना हर पोस्टिंग से करता है।
  • NN% MATCH आपके सहायक से आता है। यह तब दिखता है जब आप submit_judgments को match_pct मान के साथ बुलाते हैं।

स्वीप नतीजे सत्यापित करें और पूरे करें​

हर स्वीप नतीजे को शुरुआती सेट मानें, फिर हर मिलान को पोस्टिंग के सामने सत्यापित करें। run_sweep के बाद skipped_sources देखें और स्रोत विफलताएँ बताएँ। get_jobs से भूमिकाएँ देखें, फिर आपके सहायक के LLM मूल्यांकन देने से पहले हर पोस्टिंग की तुलना आपके रिज़्यूमे और बताई गई पसंद से करें।

जब आपके सहायक के पास वेब या सर्च टूल हों, तब उससे कहें कि होनहार भूमिकाएँ नियोक्ता के करियर पेज या उनके ATS पर सत्यापित करे। वह ऐसी संबंधित भूमिकाएँ भी खोज सकता है जो Sweepy से छूट गईं, सत्यापित और गैर-डुप्लिकेट पोस्टिंग import_jobs से जोड़ सकता है, और उन भूमिकाओं को render_report से रिपोर्ट में शामिल कर सकता है। आपका सहायक पोस्टिंग गढ़े नहीं और छूटी नौकरी जानकारी अनुमान से न भरे।

Sweepy का URL जाँचकर्ता कुछ URL असत्यापित रखता है जब कोई host पहुँच रोकता है, दर सीमा लगाता है या टाइमआउट हो जाता है। 403 या 429 यह साबित नहीं करता कि पोस्टिंग समाप्त हो गई। जहाँ संभव हो, लिस्टिंग को किसी सुलभ नियोक्ता स्रोत पर पुष्टि करें, या उसे असत्यापित मानें। अगर आपके सहायक के पास सर्च टूल न हो, या स्रोत पहुँच से बाहर रहें, तो बताएँ कि नतीजे अपूर्ण हो सकते हैं। त्रुटि के बाद बिना बदले सेटिंग के स्वीप दोहराने से बचें।

Antigravity या Claude Desktop से जोड़ना​

Sweepy को अपने क्लाइंट की MCP कॉन्फ़िगरेशन फ़ाइल में जोड़ें, जिसका नाम क्लाइंट के अनुसार mcp_config.json या claude_desktop_config.json होता है:

mcp_config.json
{
  "mcpServers": {
    "sweepy": {
      "command": "python",
      "args": [
        "/path/to/sweepy/server.py"
      ]
    }
  }
}

/path/to/sweepy की जगह अपने Sweepy फ़ोल्डर का पूरा पथ दें, फिर क्लाइंट दोबारा शुरू करें। पंजीकरण के बाद आप ऐसे काम माँग सकते हैं:

  • "Alex के लिए Sweepy प्रोफ़ाइल बनाएँ जो New York में रिमोट Technical Writer भूमिकाएँ खोजे। रिज़्यूमे path/to/resume.pdf पर है।"
  • "writer प्रोफ़ाइल के साथ स्वीप चलाएँ और शीर्ष 5 मिलान दिखाएँ।"
  • "पिछले pedro_writer स्वीप से PDF दोबारा बनाएँ और उसे Desktop पर सहेजें।"
  • "path/to/notes.md को मूल फ़ाइल के बगल में PDF में बदलें।"
Sweepy फ़ोल्डर के बाहर लिखना

हर लिखने वाला टूल डिफ़ॉल्ट रूप से आपके Sweepy फ़ोल्डर के अंदर रहता है। Desktop में सहेजने का अनुरोध तब तक विफल रहता है जब तक आप SWEEPY_ALLOW_EXTERNAL_WRITES environment variable को 1 पर सेट न करें।

VS Code से जोड़ना​

VS Code बिना किसी अतिरिक्त एक्सटेंशन के MCP सर्वर से जुड़ता है:

  1. Command Palette खोलें और MCP: Add Server चलाएँ।
  2. Command (stdio) चुनें, फिर कमांड के रूप में python दर्ज करें। उसके आर्ग्युमेंट के रूप में server.py का पूरा पथ जोड़ें।
  3. सर्वर का नाम sweepy रखें, फिर कॉन्फ़िगरेशन का गंतव्य चुनें।
  4. पुष्टि करें कि Sweepy टूल चैट पैनल में दिखते हैं, फिर वहीं से उन्हें बुलाएँ।

वर्कस्पेस-स्कोप वाली फ़ाइल के लिए अपने प्रोजेक्ट में .vscode/mcp.json जोड़ें। VS Code फ़ॉर्मैट शीर्ष स्तर का servers ऑब्जेक्ट इस्तेमाल करता है:

.vscode/mcp.json
{
  "servers": {
    "sweepy": {
      "type": "stdio",
      "command": "python",
      "args": [
        "/path/to/sweepy/server.py"
      ]
    }
  }
}

/sweepy स्किल इंस्टॉल करें​

Sweepy Copilot CLI, Claude Code, Antigravity और skills पढ़ने वाले अन्य कमांड-लाइन टूल के लिए /sweepy स्किल देता है। बंडल किया गया फ़ोल्डर अपने टूल की skills डायरेक्टरी में कॉपी करें:

टर्मिनल
cp -r skills/sweepy ~/.claude/skills/sweepy   # adjust to your tool's skills path

पिछले खंड से MCP सर्वर पंजीकृत करें, फिर अपना टूल दोबारा शुरू करें। स्किल तीन मुख्य फ़्लो दस्तावेज़ित करती है:

  • नया स्क्रैप शुरू करें create_profile, फिर run_sweep बुलाकर।
  • स्क्रैप के नतीजे देखें शीर्ष मिलान और प्लेबुक के लिए get_results, या पूरे कार्ड सेट के लिए get_jobs बुलाकर।
  • नतीजे CSV फ़ाइल में निर्यात करें export_report को formats=["csv"] के साथ बुलाकर।

स्किल उन कमांड-लाइन टूल के लिए fallback भी कवर करती है जिनमें MCP समर्थन नहीं:

टर्मिनल
sweepy --setup                         # interactive profile wizard
sweepy --profile profiles/your_profile.yaml
sweepy --docx resume.docx              # convert a DOCX resume to PDF
sweepy --convert notes.md              # convert any supported document to PDF

एक प्रॉम्प्ट से सब कुछ सेट करें​

यह प्रॉम्प्ट कॉपी करें और किसी भी AI कमांड-लाइन सत्र या IDE चैट में पेस्ट करें:

Set up Sweepy on this machine. Complete these steps in order:

1. Clone or download the Sweepy repository.
2. Run `pip install -r requirements.txt` in the repository root.
3. Register `server.py` in the MCP configuration as a stdio server. Use the command `python` and args pointing at `server.py`.
4. Copy the `skills/sweepy` folder into the CLI's skills directory.
