getObject

32バイトの16進数オブジェクトIDを指定して、1つのSuiオブジェクトのオンチェーン詳細情報とメタデータを取得します。

  • クラス: getObject

  • パッケージ: SuiClient

  • パッケージ: @mysten/sui/client

シグネチャ​

Signature
client.getObject(input: GetObjectParams): Promise<SuiObjectResponse>

パラメータ​

このメソッドは1つのオブジェクトを受け取ります。そのオブジェクトには以下のプロパティが含まれています。

パラメータ型必須説明
idstringはい0x123... のような32バイトの16進数オブジェクトIDです。
optionsSuiObjectDataOptionsいいえレスポンスデータフィールドのためのフラグです。各フラグはデフォルトでfalseに設定されています。

SuiObjectDataOptions​

デフォルトでは、getObjectはID、バージョン、およびダイジェストを返します。より多くのデータを取得するには、各フラグをtrueに設定してください。

オプション説明
showType0x2::coin::Coin<0x2::sui::SUI> のような「Move」タイプを返します。
showContent解析された「Move」データフィールドを返し、これにはオブジェクトの内部状態が含まれます。
showOwnerこのアイテムの所有情報を含む住所またはオブジェクトを返します。
showDisplayUIレンダリング用の標準メタデータを返します。このメタデータには、名前、説明、画像URLが含まれます。
showStorageRebateオブジェクトに関連するストレージリベートを返します。
showBcsクライアントサイドでのデコード用の生のバイナリ・カノニカルシリアル化データを返します。
showPreviousTransactionこのオブジェクトを変更した最後のトランザクションのディジットを返します。

戻り値​

Promise を返し、それは SuiObjectResponse に解決されます。レスポンスには成功またはエラーデータが含まれます：

SuiObjectResponse envelope
┌─────────────────────────────────────────────────────────────┐
│                     SuiObjectResponse                       │
├──────────────────────────────┬──────────────────────────────┤
│   Success: `response.data`   │    Error: `response.error`   │
│   - objectId, version        │    - code: "notExists"       │
│   - type, digest             │    - code: "deleted"         │
│   - content, owner, display  │    - object_id               │
└──────────────────────────────┴──────────────────────────────┘

成功時のレスポンス：data​

オブジェクトが存在する場合、その data プロパティには SuiObjectData が格納されています。

Response: success
{
  "data": {
    "objectId": "0x...",
    "version": "10",
    "digest": "...",
    "type": "0x2::coin::Coin<0x2::sui::SUI>", 
    "content": {                             
       "dataType": "moveObject",
       "fields": { "balance": "1000000000" }
    },
    "owner": {                                
       "AddressOwner": "0xabc..." 
    }
  }
}

エラー応答: error​

トランザクションによってオブジェクトが削除された場合や、別のオブジェクト内に格納された場合に error プロパティに詳細が返されます。ID が存在しない場合も同様に詳細が返されます。

Response: error
{
  "error": {
    "code": "notExists",
    "object_id": "0x..."
  }
}

使用例​

オブジェクトが存在するかどうかを確認する​

この軽量なクエリはデータフィールドをリクエストしません。ディジットとバージョン番号のみを返します。

checkExists.js
const response = await client.getObject({
    id: '0x123...'
});

if (response.error) {
    console.log("Object doesn't exist.");
} else if (response.data) {
    console.log("Object exists at version:", response.data.version);
} else {
    console.log("The response didn't include object data.");
}

非代替性トークン（NFT）のメタデータと表示フィールドを取得する​

このリクエストでは showContent をチェーン上のフィールドに、showDisplay をUIアセットの取得に設定します。

fetchNFT.js
const nft = await client.getObject({
    id: '0x123...',
    options: {
        showContent: true,
        showDisplay: true
    }
});

if (nft.data) {
    const name = nft.data.content?.fields?.name;
    const imageUrl = nft.data.display?.data?.image_url;
    console.log(`NFT Name: ${name}, Image: ${imageUrl}`);
} else {
    console.warn("Item failed to load:", nft.error);
}

オブジェクトの所有権を確認する​

このコードを使用して、特定のアカウントアドレスがアイテムを管理しているかどうかを確認します。

verifyOwnership.js
const item = await client.getObject({
    id: '0x123...',
    options: { showOwner: true }
});

const owner = item.data?.owner;

if (owner && owner.AddressOwner === '0xMyAddress...') {
    console.log("You own this item.");
}

よくあるエラー​

エラーコード原因解決策
notExistsオブジェクトIDに有効な16進数が含まれているが、ネットワークでオブジェクトが見つからない。ID を確認するか、以前のトランザクションでオブジェクトが削除されていないことを確認してください。
deletedトランザクションによってオブジェクトが削除されたり、アクティブ状態から除外されたりした。削除されたオブジェクトの履歴データは getObject では取得できません。
invalid_paramオブジェクトIDの16進数形式が不正です。ID が 0x で始まり、長さが正しいことを確認してください。
