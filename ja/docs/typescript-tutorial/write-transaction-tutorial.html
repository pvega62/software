トランザクションを送信するための「write」操作の使用

初めてSuiデータを変更する際にはこのチュートリアルを参照してください。

資金が準備されたSui devnetウォレットと、基本的なNode.jsのセットアップが必要です。

Suiトークンを転送するスクリプトを作成し、ガス（gas）や署名（signature）がトランザクションをサポートする仕組みも学びましょう。

はじめに​

SuiClientを使用してデータを照会できます。この読み取り操作には料金はかかりません。

今、Suiトークンを転送するために書き込み操作を実行してください。この変更はチェーン上の状態を更新するため、以下の2つの要件を満たす必要があります：

  1. リクエストに署名する。 署名によって資金の所有権が証明されます。
  2. ガスを支払う。 少額のSuiトークンがネットワークによるトランザクション処理の対価として支払われます。

前提条件​

このチュートリアルを実行するには以下が必要です：

  • 資金が入ったウォレットを使用してください。ウォレットには12語からなるリカバリーフレーズとSuiのdevnetトークンが必要です。Suiのファウンテン、SuiのDiscordファウンテン、または対応するウォレットを通じて無料でトークンを入手できます。
  • Ed25519キーペアパッケージ： @mysten/sui トランザクションに署名するためのものです。

必要に応じて必要なパッケージをインストールしてください。

Terminal
npm install @mysten/sui
警告

キーはアプリケーションコード内に保存しないでください。.envのような環境変数を使用してください。

デモではリカバリーフレーズをメモリ内に保存します。絶対にGitHubに保存しないでください。

1. 依存関係をインポートし、クライアントを設定する​

transfer.jsという名前のファイルを作成し、ネットワーク通信用にSuiClient、トランザクション署名用にEd25519Keypairをインポートしてください。

transfer.js
import { SuiClient, getFullnodeUrl } from '@mysten/sui/client';
import { Ed25519Keypair } from '@mysten/sui/keypairs/ed25519';
import { Transaction } from '@mysten/sui/transactions';

// 1. Connect to Devnet
const client = new SuiClient({ url: getFullnodeUrl('devnet') });

// 2. Load your Wallet (The Sender)
// REPLACE THIS with your actual 12-word mnemonic phrase
const MNEMONIC = "word1 word2 word3 ... word12"; 
const keypair = Ed25519Keypair.deriveKeypair(MNEMONIC);
const senderAddress = keypair.getPublicKey().toSuiAddress();

console.log(`📦 Sender Address: ${senderAddress}`);
ヒント

トランザクションを送信する前に、送信者アドレスにはガスの支払いに使用するテストトークンが必要です。ターミナルから表示されたSender Addressをコピーし、SuiフェイントからDevnetトークンを請求してください。またはSui Discordに参加し、#devnet-faucetチャンネルでトークンを請求してください。

2. トランザクションを構築する​

Suiでは、原始的なコマンドを送信するのではなく、トランザクションを構築します。トランザクションとは、ネットワークが実行すべき一連のアクションをまとめたものです。

tx.splitCoinsコマンドを使用して、主要なガスコインから特定の金額を分離します。

transfer.js
// 3. Define the Recipient
const RECIPIENT = '0x9999...'; // Replace with a friend's address or a burn address

// 4. Create the Transaction Container
const tx = new Transaction();

// Split 1000 MIST (The smallest unit of SUI) from the gas coin
const [coinToSend] = tx.splitCoins(tx.gas, [1000]);

// Transfer the split coin to the recipient
tx.transferObjects([coinToSend], RECIPIENT);

3. トランザクションに署名し、送信する​

このステップでは、チェーン上でトランザクションを実行する前にガス代を計算し、支払います。

signAndExecuteTransaction を呼び出すと、SuiClient が実行されます：

  1. このメソッドはガス代を見積もり、計算コストを算出し、必要なガス予算を設定します。
  2. このメソッドはトランザクションに署名し、keypair が状態変更を承認します。
  3. このメソッドはトランザクションをリモートプロシージャコール（RPC）を通じてネットワークに送信します。
transfer.js
async function sendTransaction() {
    try {
        console.log("📝 Signing and submitting transaction...");

        const result = await client.signAndExecuteTransaction({
            signer: keypair,
            transaction: tx,
        });

        console.log("✅ Transaction Submitted!");
        console.log(`Digest (Tracking ID): ${result.digest}`);
        
    } catch (error) {
        console.error("❌ Transaction Failed:", error);
    }
}

sendTransaction();

このトランザクションにおける「ガス」の仕組み​

ガス代を手動で計算する必要はありません。

  • SDK が自動的にガス代を見積もり、トランザクションを実行するのに十分な予算を設定します。
  • SDK はウォレットから Sui コインを選択し、ガス代を支払うためにウォレット内に一定量の Sui コインを残しておいてください。

期待される出力​

成功した後、スクリプトは トランザクションダイジェスト を出力します。このダイジェストを使用してトランザクションの状況を追跡できます：

Terminal output
📦 Sender Address: 0x123...
📝 Signing and submitting transaction...
✅ Transaction Submitted!
Digest (Tracking ID): 5T7x...9B2a

ダイジェストをコピーし、Suiscan で検索してください。

エクスプローラーにはトランザクションの永久的な記録が表示され、ガス使用量や確認状況、トランザクションの効果も記載されます。

次のステップ​

最初のオンチェーン書き込みトランザクションを完了したので、次に以下を行ってください：

  • オブジェクトデータの取得方法 を読んで、受取人が新たに受け取ったオブジェクトを確認してください。
  • SuiClient アーキテクチャ を参照して、Sui ノードやクラークの概念モデルを理解してください。
  • getObject API リファレンス を調べて、トランザクションの詳細な効果やオブジェクトの構造を確認してください。
