初回スイープを実行する

設定プロファイルを作成しました。初めての自動求人スイープを実行する時です。

スイープを実行する​

sweepy のクローンがあるフォルダーでターミナルを開きます。前の手順からターミナルを閉じた場合は、開き直して sweepy に戻ります。

ターミナル
cd sweepy

プロファイルを指定してエンジンを実行します。

ターミナル
sweepy --profile profiles/paralegal_nyc.yaml

Sweepy は paralegal_nyc.yaml を profiles フォルダーに同梱しています。短い形式も使えます。

ターミナル
sweepy --run

--run は最後に保存したプロファイルを再利用します。

ヒント

ウィザードでプロファイルを作った場合、Sweepy は profiles/alex_rivera_paralegal.yaml として保存しています。ファイル名はあなたの名前と最初の職種を組み合わせたものです。同梱のプリセットの代わりにそのパスを使ってください。

ターミナル出力の読み方​

Sweepy は作業中にリアルタイムの進捗メッセージを表示します。操作は要りません。見守って待つだけです。

次のターミナル出力は、Alex のパラリーガル向けスイープのものです。あくまで例として扱ってください。正確な件数、ファイル名、スコアは実行のたびに変わります。

スイープには数分かかります。時間はインターネットの速度、キャッシュの状態、プラットフォームの数によって変わります。

スイープの段階​

段階起きること注目する点
プロファイルの読み込みYAML の設定ファイルを読み取ります職種と勤務地がプロファイルと一致するか確認します
検出各応募者追跡システムのプラットフォームに検索リクエストを送ります各プラットフォームが返した生の求人件数を表示します
検証すべてのリンクを確認し、無効な求人を取り除きます検証できない求人は残し、unverified と表示します
採点履歴書から用語を抽出し、各求人を採点します用語の件数とスコアの範囲を表示します
生成PDF のカードディレクトリ、CSV エクスポート、その他有効な形式を組み立てますエンジンがレポートを保存したファイルパスを表示します
注記

Sweepy は、プラットフォームがハード 404 かソフト 404 ページを返したとき、および接続に失敗したときに求人を削除します。 レート制限、ボット遮断、一時的なサーバーエラー、タイムアウトは求人の有無を何も示しません。 これらの場合は 401、403、408、425、429、500、502、503、504 を返すか、まったく応答しません。 Sweepy は求人を実行に残し、unverified と表示します。

ファイルの場所を確認する​

スイープが終わったら、Sweepy のインストール先にある results フォルダーを開きます。

ターミナル
Get-ChildItem results

ディレクトリには、今日の日付と時刻が付いたファイルが並びます。ファイル名は 24 時間制で実行時刻を記録します。Windows はファイルの時刻をローカルタイムゾーンで表示するため、時計の値が数時間ずれることがあります。

ターミナル出力
    Directory: C:\Users\Alex\sweepy\results

Mode                 LastWriteTime         Length Name

-a---          10/21/2026 1:06 AM          19065 paralegal_nyc_2026-10-21-050656.pdf
-a---          10/21/2026 1:06 AM         215694 paralegal_nyc_2026-10-21-050656.csv
Windows ですぐに開く

ファイルエクスプローラーで PDF ファイルをダブルクリックするか、ターミナルで次のコマンドを実行するとすぐに開けます。

ターミナル
start results\paralegal_nyc_2026-10-21-050656.pdf

日次のスイープを実行する​

Sweepy は日次のスイープに対応しています。新しい求人を取り込むため、毎朝同じコマンドを実行します。

ターミナル
sweepy --run

新しい求人が見つかった実行では、ファイル名に日付と時刻が付きます。そのため、新しい実行が前回の結果を上書きすることはありません。新しい求人がない場合、実行は No new postings since your last sweep と表示し、results はそのまま残します。時間がたつと、results フォルダーに求職活動の履歴が積み上がります。

日次スイープを自動化する

Windows では、毎朝 8:00 にスイープを実行するスケジュールタスクを作成できます。macOS と Linux では cron ジョブを使います。コマンドラインリファレンスで両方の方法を説明しています。

初めての自動スイープは完了しました。次は PDF を開きます。マッチ率と色のバッジを確認してください。
