初めてのスウィーピー（Sweepy）実行

ご自身の設定プロファイルを作成しました。このチュートリアルでは、初めてのスウィープ処理を実行し、生成されたレポートを確認します。

スウィープの実行​

  1. sweepyのクローンが保存されているフォルダでターミナルを開きます。前のステップ以降にターミナルを閉じた場合は、再度開いてsweepyに戻ってください。

    Terminal
    cd sweepy

  2. 自分のプロファイルを使用してエンジンを実行します。

    Terminal
    sweepy --profile profiles/paralegal_nyc.yaml

Sweepyはprofilesフォルダ内にparalegal_nyc.yamlを含んでいます。短縮形でも使用可能です。

Terminal
sweepy --run

--runは最後に保存したプロファイルを再利用します。

ヒント

ウィザードを使ってプロファイルを作成した場合、Sweepyはそれをprofiles/alex_rivera_paralegal.yamlという名前で保存します。この名前はご自身の名前と最初の職務タイトルを組み合わせたものです。プリセットのパスの代わりにこのパスを使用してください。

スウィープにかかる時間は、インターネットの速度、キャッシュ状態、およびプラットフォームの数によって異なります。

スウィープの各段階​

階段行われる処理注目すべきポイント
プロフィールの読み込みYAML設定ファイルを読み取るプロフィールのタイトルや所在地が一致しているか確認
検索各応募者追跡システムに検索リクエストを送信する各プラットフォームから返された未加工の投稿数を表示
検証すべてのリンクをチェックし、無効な投稿を削除する検証不能な投稿はunverifiedとしてマークする
スコア付け履歴書からキーワードを抽出し、各職務のスコアを算出するキーワードの使用頻度とスコア範囲を表示
生成PDFカードディレクトリやCSVファイルなどの出力フォーマットを作成するレポートが保存されるファイルパスを表示
注記

Sweepyは、プラットフォームから「ハード404」または「ソフト404」エラーが返された場合、または接続が失敗した場合に投稿を削除する。 レート制限、ボットブロック、一時的なサーバーエラー、タイムアウトは投稿の有効性について何の情報も提供しない。 これらのケースでは、401、403、408、425、429、500、502、503、504のエラーコードが返されるか、または全く応答がない。 Sweepyは投稿内容を実行中に保持し、それをunverifiedとしてマークします。

ファイルの場所を確認する​

スウィーピング処理が終了したら、Sweepyのインストール先にあるresultsフォルダを開きます。

Terminal
Get-ChildItem results

そのディレクトリには、今日の日時が記載されたファイルが表示されます。ファイル名には、export.timezoneで設定されたタイムゾーン（デフォルトではコンピュータの時計）に基づく実行時間が記録されています。

Windows でのクイックオープン

ファイルエクスプローラーでPDFファイルをダブルクリックするか、ターミナルで以下のコマンドを実行してすぐに開きます。

Terminal
start results\paralegal_nyc_2026-10-21-010656.pdf

毎日のスウィーピング処理の実行​

Sweepyでは毎日のスウィーピング処理がサポートされています。新しい投稿を取得するために、毎朝同じコマンドを実行してください。

Terminal
sweepy --run

新しい投稿が見つかると、ファイル名に日時が追加されます。そのため、新しい実行でも以前の結果を上書きすることはありません。新しい投稿がない場合は、No new postings since your last sweepが表示され、resultsはそのまま残ります。時間が経つにつれて、resultsフォルダにはジョブ検索の完全な履歴が蓄積されます。

毎日のスイープを自動化

Windowsでは、毎朝8時にスウィーピング処理を実行するスケジュールタスクを作成できます。macOS/Linuxではcronジョブを使用します。コマンドラインの参考では、これらの方法の両方について説明しています。

最初の自動化スウィーピング処理が完了しました。次に、PDFファイルを開いてマッチング結果とカラーバッジを確認してください。
