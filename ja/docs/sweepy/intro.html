Sweepyについて

Sweepyは複数の採用プラットフォームでの仕事探しを自動化します。1つのコマンドで求人情報を収集し、ユーザーの履歴書を読み込みます。その後、各求人情報をユーザーのスキルと照合してスコアを付け、毎日のマッチングレポートを作成します。

Sweepyは設定ファイルによってユーザーのニーズに合わせて動作します。「パラリーガル（Paralegal）」や「アナリスト（Analyst）」、「コーディネーター（Coordinator）」などの職種を選択できます。

アレックスについて​

このガイドではアレックスに沿って進めます。アレックスは政治学の学位を取得したばかりで、ニューヨーク市でパラリーガルや法律アシスタントの仕事を探しています。アレックスは端末を使ったこともなく、コードを書いたこともなく、YAMLファイルを見たこともありません。

このガイドでは、設定から完全に自動化された仕事探しのプロセスまでをアレックスと一緒に進めます。Sweepyは実際の履歴書と照合して最も適した求人情報を選び、毎日使用できるPDFディレクトリを作成します。

注記

Sweepyを使うにはプログラミング経験は必要ありません。このガイドでは最初からすべての手順を説明します。

主な機能​

Sweepyは次の仕事をより迅速に見つけるために必要なすべてを提供します：

  • マルチプラットフォーム検索：Greenhouse、Ashby、Lever、Workableといった公開求人情報を掲載している4つのシステムをスキャンします。また、Built In NYCの求人情報やLinkedIn、Indeed、Glassdoor、ZipRecruiterの情報も読み込みます。
  • スマートな履歴書評価機能：履歴書のPDFまたはWordファイルを読み取り、保有するスキル情報を抽出します。Sweepyは各求人情報を対応する履歴書データと照合し、その評価を行います。この処理にはAPIキーや有料サービスは不要です。
  • リンクのチェック機能：求人情報を表示する前に、リンクが正常に機能しているかを確認します。リンクがエラー（「gone status」、ソフト404ページ、接続エラー）を返した場合、その求人情報は報告書から除外されます。レート制限やボットブロック、サーバーエラーにより報告書内に残った求人情報にはunverifiedというマークが付きます。
  • 毎日のPDFレポート：処理結果を高密度なPDF形式で出力します。1ページには最大6件の求人情報が表示され、クリック可能なリンクや給与範囲、色分けされたバッジが含まれます。
  • パイプライン追跡スプレッドシート：各求人情報の詳細情報（1,000文字分）とJSONファイルをCSV形式で出力します。このCSVには応募日、状況、面接段階、提示された給与額、提示日、フォローアップ日、連絡先、メモなどの情報が含まれます。Sweepyは同じプロフィールの再処理時にも入力したデータを保持します。CSVはMicrosoft Excel、Google Sheets、Notionで開くことができます。PDFには応募用のクリックリンクが含まれており、スプレッドシートにはPDFに表示されない求人情報も含めた全ての処理内容が記録されています。

動作の仕組み​

成功的な処理には5つのステップがあります：

  1. プロフィールを読み込んでください。 Sweepyは設定ファイルを読み取り、そこに記載されている職務名、所在地、履歴書のパス情報を取得します。
  2. 役割を探す。 Sweepyは、採用プラットフォームや求人情報を検索し、マッチする求人を探します。
  3. リンクの有効性を確認する。 Sweepyはすべてのリンクをチェックし、エラー状態になっているリンク、404エラーが表示されるページ、または接続エラーが発生するリンクを含む投稿は除外する。検証不能なリンクを持つ投稿は処理対象として残り、その旨がマークされる。 0.
  4. スコアの算出方法：Sweepyはあなたの履歴書（PDFまたはWordファイル）を解析し、各職務に対して重み付けされたマッチング率を計算します。
  5. レポートの生成：Sweepyは処理結果をスタイリングされたPDFやCSV形式に変換し、またはJSONを通じて出力します。

制限事項​

Sweepyは設計上、職業市場のごく狭い範囲のみを対象としています。Model Context Protocol (MCP) サーバーを介して言語モデルと連携させることで、モデルが自動的に処理の詳細を決定します。SoloウィザードおよびMCPの両方で同じ結果が表示される場合、その制限はSweepyの両バージョンに共通して適用されます。

制限事項SoloウィザードMCPサーバー使用時対策
マッチスコアご自身の履歴書と求人情報の間で共有されているキーワードの数を表示します。カードには「KEYWORD OVERLAP」と表示されます。「submit_judgments」では自分でパーセンテージを設定し、その値がカードに表示されます。「MATCH」は、申請者追跡システムが履歴書を解析する方法でモデルがスコアを算出した結果です。Sweep Settingsタイルから「resume.keywords_weight」をクリックし、「resume.synonyms」でグループを手動で追加します。ウィザードは同義語の処理も任せてくれます。
給与と福利厚生構造化されたボードフィールドや求人情報から取得した給与範囲を表示します。福利厚生については常に「Not disclosed」と記載されます。「submit_judgments」にはいずれかの値が記載されます。CSVファイルのエクスポート時には「comp」および「benefits」の列を必ず埋めてください。
バッジおよびアプリの形式エンジン内にある固定キーワードリストから「Amber」または「Slate」を判別する。submit_judgmentsにより、両方のフィールドが上書きされる。バッジを信頼する前に、実際の投稿内容と照合して確認してください。
概要、要件、および申込みのヒント投稿内容からテキストを抽出し、自分の履歴書と照合して評価します。submit_judgmentsではこれらを書き換え、render_reportではカスタムのプレイブックを受け付けます。CSV内のフィールドを編集するか、JSONでデータをエクスポートします。
テキストの読み取りPDFファイルおよびWordファイル内のテキストデータを読み取る。スキャン結果からは評価対象となる情報は得られない。モデルはこのテキストデータを解析し、必要なスキル情報を抽出する。自分のスキルをresume.must_have_skillsに記載する。「ウィザードの必須スキル」の項目でこれについて説明されている。
見積もり範囲名前の付けられた42社の企業情報に加え、5つの「Built In NYC」カテゴリーも対象となります。import_jobs を使用すると、どこからでもロール（役割）を追加できます。「sources.greenhouse.boards」「sources.ashby.orgs」「sources.lever.companies」「sources.workable.slugs」にターゲットを追加してください。
ジョブフィード有効にするまでは表示されません。各フィードは、過去3日間の各タイトルについて最大25件の投稿を返します。同じスイッチを使用して切り替えます。sources.jobspy内でサイトを切り替えることができます（例：glassdoor）。
リンクチェック接続エラーにより投稿が削除されます。同じです。JSONのエクスポートを保持し、会社のサイトで主要なターゲットを再確認してください。
PDFの長さPDFの容量を24枚分に制限する。同じ。report.max_cardsを設定する。値が0の場合、この制限は解除され、CSVおよびJSONによってすべてのロールがエクスポートされる。
スクレイパーの脆弱性ボードのマークアップが変更されたり、レート制限が厳格になったりすると動作しなくなる。同じ。--debugを使用して実行し、その後--logsを使用してソースエラーをリストアップする。ソースエラーがあってもスキャン処理は停止しない。

ガイドロードマップ​

このガイドでは4つのステップを順に説明します：

  1. コンピューターにSweepyをインストールします。インストール方法を参照してください。
  2. 個別の求人検索プロフィールを設定します（例：Alexのニューヨーク市のパラリーガル向けプロフィール）。Sweepyの設定方法を参照してください。
  3. 初めての自動化求人スキャンを実行し、その動作を確認します。初回スキャンを参照してください。
  4. カスタムPDFレポートを読んで、マッチスコアやバッジ、応募戦略を理解します。結果の解釈方法を参照してください。
Sweepy の保存場所

Sweepyはオープンソースです。ソースコードを閲覧したり、Issueで不具合を報告したり、ReleasesからZIPファイルをダウンロードしたりできます。GitHubではアカウントなしでもこれらすべてにアクセスできます。
