Sweepyのご紹介

Sweepyは、多数の採用プラットフォームにわたる求人検索を自動化します。1つのコマンドで、募集中の求人を収集し、あなたの履歴書を読み込みます。その後、Sweepyは各求人情報をあなたのスキルと照らし合わせて評価し、毎日のマッチングレポートを作成します。

Sweepyは設定ファイルを通じて、あなたのキャリアパスに合わせて調整されます。「パラリーガル」、「アナリスト」、「コーディネーター」などの職種を選択してください。

アレックスを紹介​

このガイドでは、アレックスの事例を参考に進めていきます。アレックスは政治学の学位を取得して卒業したばかりで、ニューヨーク市でパラリーガルやリーガルアシスタントの職を探しています。 アレックスは、ターミナルを使ったことも、コードを書いたことも、YAMLファイルを見たことさえありません。

このガイドでは、セットアップから完全に自動化された求人検索まで、あなたとアレックスを導きます。Sweepyは、実際の履歴書に基づいて最も適合度の高い求人を評価し、毎日使えるPDF形式の求人一覧を作成します。

注記

Sweepy を使用するのにプログラミングの経験は一切必要ありません。このガイドでは、すべてのステップをゼロから解説します。

機能​

Sweepy には、次の仕事をもっと早く見つけるために必要な機能がすべて揃っています：

  • マルチプラットフォーム検索：公開求人掲示板を運営する4つの応募者追跡システム（Greenhouse、Ashby、Lever、Workable）をスキャンします。また、「Built In New York City」の掲示板も読み込み、設定を有効にすれば、LinkedIn、Indeed、Glassdoor、ZipRecruiterのフィードも読み込みます。
  • スマート履歴書スコアリング：履歴書のPDFまたはWordファイルを読み取り、スキルを抽出します。Sweepyは各求人情報を1つの履歴書トラックに割り当て、そのトラックの履歴書と照らし合わせてスコアを算出します。このエンジンは、APIキーや有料サービスを必要とせずに動作します。
  • リンク切れのフィルタリングは、求人が表示される前にすべての求人をチェックします。リンクが「存在しない」ステータス、ソフト404ページ、または接続エラーを返した場合、Sweepyはその求人を除外します。レート制限、ボットブロック、サーバーエラーが発生した場合でも、その求人はレポートに残り、unverified とマークされます。
  • 日次PDFレポートは、結果を高密度なPDFディレクトリにまとめます。各ページにはデフォルトで6枚のカードが表示され、クリック可能なリンク、公開されている給与範囲、色分けされたバッジが含まれます。
  • パイプライントラッカー用スプレッドシートは、各カードの全フィールドと1,000文字の求人要約を含むCSVファイル、および他のツール用のJSONファイルをエクスポートします。CSVファイルの末尾には、応募日、ステータス、面接段階、内定、フォローアップ日、担当者、メモといった求人追跡用の列が含まれています。 Sweepyは、同じプロファイルに対するその後のスウィープでも、入力した値を引き継ぎます。CSVファイルはMicrosoft Excel、Google Sheets、またはNotionで開くことができます。PDFは、クリック可能な応募リンク付きの、順位付けされた一覧表示を提供します。スプレッドシートには、PDFカードの表示制限を超えた求人を含め、パイプライン全体が記録されます。

仕組み​

スウィープが正常に実行されるには、以下の5つの段階を経ます：

  1. プロフィールの読み込み。 Sweepyは、職種、勤務地、履歴書の保存場所が記載された設定ファイルを読み込みます。
  2. 求人の検出。 Sweepyは、採用プラットフォームや求人フィードに対してクエリを実行し、条件に一致する求人情報を検索します。
  3. リンクの検証。 Sweepyはすべてのリンクをチェックし、「アクセス不可」ステータス、ソフト404ページ、または接続エラーが返される求人情報を除外します。リンクが検証できない求人情報は、unverified とマークされたまま処理対象となります。
  4. 一致度を評価します。 Sweepyは履歴書のPDFまたはWordファイルを解析し、各求人に対する加重一致率を算出します。
  5. レポートを生成します。 Sweepyは結果をスタイリングされたPDFにまとめ、CSVまたはJSON形式でエクスポートします。

制限事項​

Sweepyは、設計上、求人市場の限られた分野のみを対象としています。Model Context Protocol (MCP) サーバー を通じて言語モデルと連携させると、モデルが機械的なデフォルト処理を引き継ぎます。 SoloウィザードとMCPサーバーの両方で同様の挙動が報告される場合、その制限はSweepyの両方のバージョンに影響します。

制限事項SoloウィザードMCPサーバー使用時回避策
一致スコア履歴書と求人情報の共通キーワードをカウントします。カードには KEYWORD OVERLAP と表示されます。submit_judgments が独自のパーセンテージを設定し、カードには MATCH と表示されます。モデルは、応募者追跡システム（ATS）が解析するのと同じ方法で、解析済みの履歴書を評価します。Sweep Settings タイルから resume.keywords_weight を引き上げ、resume.synonyms グループを手動で追加してください。ウィザードでは同義語の設定はユーザーに委ねられます。
給与と福利厚生構造化された掲示板フィールドまたは求人文から読み取った、開示済みの給与範囲を表示します。 福利厚生は常に Not disclosed と表示されます。submit_judgments はどちらの値も提供します。CSV エクスポートの comp および benefits 列に値を入力してください。
バッジと応募形式エンジン内の固定キーワードリストから Amber または Slate を推論します。submit_judgments は両方のフィールドを上書きします。バッジを信頼する前に、実際の求人情報と照らし合わせて確認してください。
概要、要件、応募のヒント求人情報からテキストを抽出し、あなたの履歴書に対して評価を行います。submit_judgments によって書き換えられ、render_report ではカスタムプレイブックが使用可能です。CSV または JSON エクスポート内のフィールドを編集してください。
履歴書のテキストPDF および Word ファイルのテキストレイヤーを読み取ります。スキャンデータの場合、スコアリング対象となる情報は得られません。モデルはビジョン技術を用いてスキャンデータを読み取り、スキルを抽出します。スキルは resume.must_have_skills にリストアップしてください。ウィザードの「必須スキル」ステップでこれを行います。
カバー範囲41の指定企業掲示板と、5つの「Built In NYC」カテゴリをクエリします。import_jobs は、あらゆるソースからの求人情報を追加します。sources.greenhouse.boards、sources.ashby.orgs、sources.lever.companies、または sources.workable.slugs にターゲットを追加してください。
求人フィード有効にするまでは無効です。各フィードは、過去3日間の各職種につき最大25件の求人情報を返します。同じスイッチ。sources.jobspy 配下のサイト（例：glassdoor）をオン／オフします。
リンクチェック接続エラーが発生すると、その求人情報は除外されます。同様。JSON エクスポートを保持し、企業サイトで主要なターゲットを再確認してください。
PDF の長さPDF を 24 カードに制限します。同様。report.max_cards を設定してください。値を 0 にすると制限が解除され、CSV および JSON エクスポートにはすべての職種が一覧表示されます。
スクレイパーの脆弱性求人掲示板がマークアップを変更したり、レート制限を厳格化したりすると動作しなくなります。同様です。--debug、続いて --logs オプションを指定して実行し、ソースエラーを一覧表示してください。ソースエラーが発生しても、スキャンは停止しません。

ガイドのロードマップ​

このガイドでは、以下の4つの手順を解説します：

  1. コンピュータに Sweepy をインストールします。インストール を参照してください。
  2. アレックスのニューヨーク市のパラリーガルプロフィールのような、自分専用の求人検索プロフィールを設定します。Sweepy の設定 を参照してください。
  3. 初めての自動求人検索を実行し、その動作を確認します。最初の検索を参照してください。
  4. カスタムPDFレポートを確認し、マッチスコア、バッジ、応募戦略について理解しましょう。結果の理解を参照してください。
Sweepyの所在

Sweepyはオープンソースです。 ソースコードを確認したり、Issuesで不具合のあるボードを報告したり、 リリースからZIPファイルをダウンロードできます。GitHubでは、アカウントがなくてもこれら3つすべてにアクセスできます。
