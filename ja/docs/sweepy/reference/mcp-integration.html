AIアシスタントとMCPを使ってSweepyを実行する

AIアシスタントが代わりにSweepyを実行してくれる。必要な役割を説明すると、アシスタントが端末コマンドの入力を求める代わりにSweepyを呼び出す。

この接続には**モデルコンテキストプロトコル（MCP）**が使用される。MCPは、AIアシスタントとコンピューターにインストールされたツールをつなぐための共通言語です。Sweepyにはserver.pyに内蔵されたMCPサーバーがあり、stdioを介して動作するため、ネットワークポートを開くことなくローカルで通信が可能です。

注記

MCPはオプションです。AIアシスタントなしでも端末コマンドだけでSweepyを完全に利用できる。ただし、MCPを使用すると会話機能が追加され、Sweepyが既に実行している決定的なスコアリングやフィルタリング処理にモデルの判断や知能が加わる。

接続する前に​

  • インストールを完了し、PythonおよびSweepyの依存関係が確立される。mcpおよびanyioパッケージはrequirements.txtと共に到着する。
  • server.pyの絶対パスに注意してください。そのパスをクライアントの設定に貼り付けてください。
  • MCP設定を変更した後は、AIクライアントを再起動してください。

利用可能なツール​

Sweepyはアシスタントに13個のツールを提供します。それぞれのツールはJSONというペイロードを返し、読み取り専用（read-only）、破壊的な操作が可能（destructive）、同一操作を繰り返しても結果は変わらない（idempotent）、およびオープンワールド環境で動作する（open-world）という特性を持っています。

ツール機能
create_profilePDFやDOCXの履歴書からYAMLプロフィールを構築し、検証した後に保存します。
set_portfolio保存されたプロフィールにポートフォリオのURL、ファイル、またはアイテムリストを添付する。
run_sweep5段階のパイプラインをバックグラウンドで実行し、結果を確定的な形で保存する。
get_sweep_status実行中の処理を待機し、その進捗状況を報告する。
get_jobs現在のセッションで保持されているカードをスコア順に表示します。
submit_judgmentsカードの決定的な情報をあなたのアシスタントの判断に置き換えます。
import_jobsアシスタントが他の場所で確認したジョブを追加します。
render_report現在のセッションからカードのPDFをレンダリングします。
get_resultsディスクから最新のスウィープ結果を読み取る。
export_report既存のデータからPDF、PNG、CSV、またはJSON形式のファイルを再構築する。
clear_historyあるプロフィールの報告された投稿を忘れてしまう。
convert_documentサポートされているドキュメントをPDF形式に変換します。
convert_docxDOCX形式の履歴書をPDFに変換します。

MCPツールの参考情報では、各パラメーター、デフォルト値、ペイロード、動作のヒントなどが詳しく説明されています。

求人エンジンの選択​

sources_configを省略すると、create_profileによって組み込みのJobSpyが有効になります。 ATSエンジン。また、正常に動作するインストール環境を備えたオプションのエンジンも利用可能で、 有効なデフォルト値。このツールはenabled_enginesおよびengines_not_enabledを返します。 OpenRoles は、ユーザーが登録した企業の取締役会のみを検索します。検索対象の企業名を「slug」形式で先頭に追加してください。

Sweepyには2つの処理モードがあります。アシスタントにどれだけの決定権を与えたいかに応じてモードを選択してください。 一回限りの処理: アシスタントがすべての設定を行い、各求人情報と履歴書のキーワードの一致度に基づいてスコアを付けます。 ハイブリッド処理: アシスタントが各求人情報を確認し、レポートを生成する前に独自の判断を行います。 設定、有料サービスの同意、または検索条件。

エンジンを明示的に指定する場合は、sources_config を渡してください。Sweepy はその設定を保持します 各求人情報カードには2種類のスコアラベルが表示されます：

これにより、どのエンジンが動作しているか、どのエンジンがまだ設定が必要かを確認できます。

{
  "enabled": ["jobspy", "openroles"],
  "openroles": {"companies": ["figma", "stripe"]}
}

ワンショットおよびハイブリッドのツールフロー​

Sweepyには2つの動作パターンがあります。アシスタントにどの程度判断を任せたいかによって、適切なパターンを選んでください。

ワンショットフロー。 アシスタントがすべてを設定・実行し、エンジンが履歴書のキーワードの重複度に基づいて各役割の適性を評価します。

create_profile -> run_sweep -> get_results -> export_report (optional)

ハイブリッドなステートフルフロー。 アシスタントが各カードを確認し、レポートが生成される前に独自の判断を下します。

run_sweep -> get_jobs -> submit_judgments -> render_report

クライアントのタイムアウト後でも、ライブスキャン処理は継続される。run_sweepがsweep_status: "running"を返した場合、返されたjob_idを使ってget_sweep_statusを呼び出し、completedが報告されるまで処理を続ける。その後、get_jobsに進む。

ヒント

実用的なレポートを作成するにはLLM（大規模言語モデル）は必要ありません。run_sweepツールだけで、決定的なデータから完全なカードPDFを生成できます。これはターミナルでの処理と全く同じです。

各カードには、2つのスコアラベルのうちの1つが表示されています。

  • NN% KEYWORD OVERLAP は、決定論的エンジンによって算出されます。これは、あなたの履歴書の本文と各求人情報を照合して比較するものです。
  • NN% MATCHはあなたのアシスタントから来ます。submit_judgmentsにmatch_pctの値を指定して呼び出すと表示されます。

get_jobsはresume_documentsを返します、これはカードの隣にある各レジュメトラックの解析済みテキストです。あなたのアシスタントはそのテキストを掲載物のATSが解析する方法でスコア付けし、concernsでパーサーが失うものを記録します。

スウィープ処理の結果を確認し、補足情報を追加する​

すべてのスウィーピー（Sweepy）の検索結果を初期データとして扱い、その後各マッチング結果を投稿内容と照合する。 run_sweep の後で skipped_sources を確認し、ソースに問題がある場合は報告する。 get_jobs を使って求人内容を確認した上で、自分の履歴書や希望条件と比較する。 アシスタントがLLM（大規模言語モデル）による判断を下す前に、これらの情報を確認する。

アシスタントがウェブや検索ツールを備えている場合は、有望な求人情報を 雇用主のキャリアページや採用管理システム（ATS）。また、Sweepyを使って関連する職種を検索することもできる。 見落としたものは、import_jobs を通じて重複がないことが確認済みの投稿を追加し、以下を含める レポート内のそれらの役割を render_report で指定してください。アシスタントは、勝手に 掲示内容や欠落している仕事の詳細を推測で埋めることは禁止されています。

SweepyのURLチェッカーでは、ホストがアクセスをブロックした場合に一部のURLを未検証のままにします。 リクエストを制限したり、タイムアウトさせたりする。403や429のエラーが投稿が期限切れになったことを意味するわけではない。確認が必要です。 可能であれば、信頼できる雇用情報源に掲載されている情報を使用する。そうでない場合は、その情報を適切に扱う。 未確認。アシスタントに検索ツールがない場合、または情報源にアクセスできない場合は、 結果に不完全な部分がある可能性があることを明記してください。同じスキャン処理を繰り返すことは避けてください。 エラー発生後も設定が変更されない。

AntigravityまたはClaude Desktopに接続する​

クライアントに応じて、mcp_config.jsonまたはclaude_desktop_config.jsonと名付けられたクライアントのMCP設定ファイルにSweepyを追加してください。

mcp_config.json
{
  "mcpServers": {
    "sweepy": {
      "command": "python",
      "args": [
        "/path/to/sweepy/server.py"
      ]
    }
  }
}

/path/to/sweepyを自分のSweepyフォルダーの絶対パスに置き換えてから、クライアントを再起動してください。登録が完了すると、次のような依頼を行うことができます：

  • アレックスのために「Sweepy」プロフィールを作成し、ニューヨークでリモートワーク可能なテクニカルライターの職を探します。履歴書はpath/to/resume.pdfにあります。
  • 「ライタープロファイルを使用してスキャンを実行し、上位5件のマッチング結果を表示してください。」
  • 「pedro_writerによる前回のスウィープからPDFを再生成し、デスクトップに保存してください。」
  • 「path/to/notes.mdを元のファイルの隣にPDF形式に変換する。」
Sweepy フォルダーの外への書き込み

すべての書き込みツールはデフォルトで「Sweepy」フォルダ内に保持されます。デスクトップに保存するようなリクエストは、SWEEPY_ALLOW_EXTERNAL_WRITES環境変数を1に設定するまで実行されません。

VS Codeへの接続​

VS Codeは追加の拡張機能なしでMCPサーバーに接続できます。

  1. コマンドパレットを開き、MCP: Add Serverを実行します。
  2. **Command (stdio)**を選択し、コマンドとしてpythonを入力します。引数としてserver.pyの絶対パスを指定します。
  3. サーバーにsweepyという名前を付け、設定先を選択します。
  4. チャットパネルにSweepyのツールが表示されたら、そこからそれらを呼び出します。

ワークスペース固有のファイルについては、.vscode/mcp.jsonをプロジェクトに追加します。VS Codeの形式では、トップレベルのserversオブジェクトが使用されます。

.vscode/mcp.json
{
  "servers": {
    "sweepy": {
      "type": "stdio",
      "command": "python",
      "args": [
        "/path/to/sweepy/server.py"
      ]
    }
  }
}

/sweepy スキルをインストールする​

Sweepyは、Copilot CLI、Claude Code、Antigravity、およびその他スキルを読み取るコマンドラインツール向けに/sweepyというスキルを提供しています。このバンドルされたフォルダーを、ご使用のツールのスキルディレクトリにコピーしてください。

Terminal
cp -r skills/sweepy ~/.claude/skills/sweepy   # adjust to your tool's skills path

前のセクションで登録したMCPサーバーを使用して、ツールを再起動してください。このドキュメントでは3つの主要な処理フローについて説明しています。

  • create_profile を呼び出して 新しいスクレイピングを開始 し、続いて run_sweep を呼び出します。
  • スクレイピングの結果を表示するには、上位のマッチ結果やプレイブックについては get_results を、カードセット全体については get_jobs を呼び出してください。
  • formats=["csv"] を指定して export_report を呼び出すことで、結果を CSV ファイルにエクスポートします。

このスキルには、MCPのサポートがないコマンドラインツールへの代替手段も含まれています。

Terminal
sweepy --setup                         # interactive profile wizard
sweepy --profile profiles/your_profile.yaml
sweepy --docx resume.docx              # convert a DOCX resume to PDF
sweepy --convert notes.md              # convert any supported document to PDF

一つのプロンプトですべてを設定する​

このプロンプトをコピーし、任意のAIコマンドラインセッションやIDEのチャットに貼り付けてください。

Set up Sweepy on this machine. Complete these steps in order:

1. Clone or download the Sweepy repository.
2. Run `pip install -r requirements.txt` in the repository root.
3. Register `server.py` in the MCP configuration as a stdio server. Use the command `python` and args pointing at `server.py`.
4. Copy the `skills/sweepy` folder into the CLI's skills directory.
