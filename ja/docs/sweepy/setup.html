Sweepyのセットアップ

Sweepyのインストールが完了しました！次にプロフィールを作成する必要があります。このガイドではそのプロフィールを作成し、初回の検索を開始します。

設定プロフィールでは、検索対象の場所、検索する職種名、およびそれらの職種を評価するための履歴書を指定します。

プロフィールとはYAML形式の小さなテキストファイルです。インデント、コロン、改行を使ってデータを整理します。コードを書く必要はありません。食料品リストが読めれば、YAMLも読めます。

オプション A：対話型のセットアップウィザードを実行する​

セットアップウィザードは、入力した情報から実用的なプロフィールを自動生成します。アンケートの前に検索画面を開き、設定ファイルも自動的に作成します。

次のコマンドを実行してください：

Terminal
sweepy --setup

ウィザードはバナーを表示した後、検索画面を開きます。タイルの下にあるステータスラインには読み込まれたプロフィールが表示されます（例：Current profile: Alex Rivera / 4 titles / Ready）。まだ何も読み込まれていない場合はCurrent profile: none loaded / build one to startが表示されます。

検索画面には6つのタイルが表示されます。Start Sweepをクリックすると読み込まれたプロフィールで検索が開始されます。Load Profileをクリックすると保存された検索条件が再利用されます。Build Profileをクリックすると新しい検索が開始され、平易な英語で質問がされます。Sweep Settingsではランキングや表示内容、履歴の設定が可能です。Sweepy's Toolboxではプロフィールの編集、エンジンの管理、アグリゲータの管理、デバッグ機能のオン/オフ、ヘルプ、最近のログの確認、ドキュメントの変換、アップデートなどが行えます。Exit Sweepyをクリックすると変更内容が保存され、ウィザードが閉じます。

コマンドリファレンスには各コマンドの詳細な説明が記載されています。

ヒント

新しいプロファイルを作成したり、既存のプロファイルを編集したりするには、いつでもsweepy --setupを実行してください。ウィザードは指定されたファイルにデータを書き込み、他のプロファイルには影響しません。

ランチパッドをスキップして保存されたプロファイルを直接編集するには、--profileフラグを指定してください。

Terminal
sweepy --setup --profile profiles/paralegal_nyc.yaml

方法 B: 設定ファイルを手動で編集する​

設定内容を直接入力するには、サンプルテンプレートをコピーしてNotepadやVS Codeなどのプレーンテキストエディタで開いてください。ワードプロセッサは直引き引用符を曲引き引用符に置き換えたり、YAMLの構文を破壊したりするため避けてください。

  • Windows
  • macOS / Linux
Terminal
copy config.sample.yaml profiles\alex_rivera_paralegal.yaml
notepad profiles\alex_rivera_paralegal.yaml
Terminal
cp config.sample.yaml profiles/alex_rivera_paralegal.yaml
open profiles/alex_rivera_paralegal.yaml    # macOS
# or: nano profiles/alex_rivera_paralegal.yaml   # Linux

アレックスのプロフィール​

ウィザードはこのファイルをprofiles/alex_rivera_paralegal.yamlに書き込みます。#で始まる行はコメントであり、Sweepyはこれらを無視します。省略したセクションや設定についてはSweepyがデフォルト値を自動的に設定します。

profiles/alex_rivera_paralegal.yaml
# ─────────────────────────────────────────────────
# Sweepy — Alex's Paralegal Profile
# ─────────────────────────────────────────────────

# Your name (appears in the PDF report header)
name: "Alex Rivera"

# ─── Job Search Settings ──────────────────────────
search:
  # List every job title you want to find.
  # The engine searches for ALL of these titles simultaneously.
  titles:
    - "Paralegal"
    - "Legal Assistant"
    - "Litigation Support Specialist"
    - "Legal Secretary"

  # Your target city and state.
  location: "New York, NY"

  # Set to true to ONLY see remote roles.
  # Set to false to see remote, hybrid, and on-site roles.
  remote_only: false

  # Set to false to exclude hybrid positions.
  include_hybrid: true

  # Minimum annual salary filter (optional).
  # Leave as 0 or remove this line to skip salary filtering.
  min_salary: 65000

# ─── Resume Settings ─────────────────────────────
resume:
  # The full path to your resume PDF on your computer.
  # On Windows, use double backslashes (\\) or forward slashes (/).
  path: "Alex_Rivera_Resume.pdf"

  # Must-have skills to prioritize for the match percentage.
  must_have_skills:
    - "Westlaw"
    - "LexisNexis"
    - "e-discovery"
    - "Contract Review"
    - "Legal Research"

  # How heavily to weigh keyword matches when scoring roles.
  # 1.0 = standard weight. Increase to 2.0 if you want
  # exact skill matches to dominate the score.
  keywords_weight: 1.5

# ─── Platform Settings ────────────────────────────
# Set each platform to true or false to enable or disable it.
platforms:
  greenhouse: true
  ashby: true
  lever: true
  workable: true
  aggregators: false   # Free feeds like Remotive, Adzuna

  # Optional: custom ATS endpoints or company career domains
  custom:
    - name: "SmartRecruiters"
      domain: "smartrecruiters.com"
      enabled: true
    - name: "Breezy HR"
      domain: "breezy.hr"
      enabled: true

# ─── Export Settings ──────────────────────────────
export:
  # Comma-separated list of output formats.
  # Options: pdf, csv, json
  format: "pdf,csv"

  # Where to save the output files.
  # The engine creates this folder if it does not exist.
  output_dir: "results"
注意

**Windows上では：**YAML内のパスにダブルバックスラッシュ（\\）またはフォワードバックスラッシュ（/）を使用してください。シングルバックスラッシュ（\）はYAMLのフォーマットを破壊します。

✅ 正解："C:\\Users\\Alex\\Documents\\resume.pdf"または"C:/Users/Alex/Documents/resume.pdf"

❌ 間違い："C:\Users\Alex\Documents\resume.pdf"

プリセットプロファイルの使用​

Sweepyはprofiles/フォルダに事前に用意されたプロファイルプリセットを含んでいます。これら4つのプロファイルはよく使われる検索機能をカバーしています。

ファイルキャリアパス検索した職種
paralegal_nyc.yaml法務パラリーガル、法務アシスタント、訴訟サポートスペシャリスト、法務秘書
frontend_developer.yamlソフトウェアエンジニアリングフロントエンド開発者、React開発者、UIエンジニア
tech_writer.yamlテクニカルライティングテクニカルライター、UXライター、コンテンツデザイナー
template_custom.yamlその他の職種例として挙げた職種名です。各設定にはコメントが付いています。

プリセットを使用するには、実行時にそのファイル名を指定してください。

Terminal
sweepy --profile profiles/frontend_developer.yaml
ヒント

好きなだけプロフィールを作成できます。対象とする職種や都市ごとに異なるプロフィールを保存し、--profileフラグを使ってすぐに切り替えられます。

オプション C：Antigravity デスクトップアプリを使った自動化​

Google AntigravityはAIエージェント向けの無料デスクトップアプリです。Model Context Protocol（MCP）を使用してSweepyに接続し、端末を開かずにチャット内で求人を検索できます。

なぜMCP経由でSweepyを実行するのか？​

  • 資格を分析する。 Geminiは求人情報全体を読み取り、不足しているスキルを特定します。一方、端末からの検索では単語の一致のみが確認されます。
  • Googleアカウントの割り当てられたクォータを利用する。 Antigravity内で標準的なGoogleアカウントの使用量を消費するため、サードパーティのAPIサブスクリプションが不要になります。
  • チャットから検索を開始する。 目標となるロールを会話形式のプロンプトで指定すると、Antigravityがプロフィールと最終的なPDFレポートを生成する。

クイックセットアップ​

AntigravityでSweepyを設定するには、検索ツール用のMCPサーバーと/sweepyショートカット用のスキルの2つが必要です。

Antigravityのダウンロード

最新版は、公式のAntigravityページからダウンロードしてください。

方法 1：エージェントに尋ねる​

Antigravityデスクトップアプリを開き、チャットを開始し、以下のプロンプトを送信する：

「Sweepyの設定をお手伝いします：python <PATH_TO_SWEEPY>/server.pyでローカルのMCPサーバーを登録し、<PATH_TO_SWEEPY>/skills/sweepyからスキルをインストールしてください。」

Antigravityが設定情報を書き出し、スキルファイルをシステムに追加します。

方法 2：手動での設定​

以下の手順に従ってアプリを自分で設定してください：

  1. MCPサーバーの追加：

    • Antigravityデスクトップで、設定（歯車アイコン）＞MCPサーバーを開きます。
    • Sweepyサーバーを追加する：
      • 名称: sweepy
      • コマンド: python
      • 引数: ["<PATH_TO_SWEEPY>/server.py"]

  2. スキルのインストールを行ってください。 このスキルファイルにより、/sweepyメニューショートカットが利用可能になります。

    • コンピュータの「スキル」フォルダを開いてください。
      • Windows: Win+Rを押し、その後%USERPROFILE%\.gemini\config\skillsを入力してください。
      • macOS: FinderでCmd+Shift+Gを押し、その後~/.gemini/config/skillsを入力してください。
    • sweepyフォルダーをsweepy/skills/sweepyからそのskillsディレクトリに直接コピーしてください。
    • Antigravityデスクトップアプリを再起動してください。

  3. 検索を実行してください。 チャットに /sweepy と入力するか、直接次のように尋ねてください：

    C:/path/to/resume.pdfにある私の履歴書からプロフィールを作成し、「リモートテクニカルライター」の職種を検索して、初回のスキャンを実行します。

VS Codeなどの他のクライアントを設定するには、MCP統合リファレンスを参照してください。

Sweepyが求人情報を検索する場所を確認する​

デフォルトで4つの公開求人追跡システムをスキャンします。これらにはGreenhouse、Ashby、Lever、Workableが含まれます。また、ニューヨークの求人情報サイトであるBuilt In NYCもスキャン対象です。プロフィール設定により、LinkedIn、Indeed、Glassdoor、ZipRecruiterからのデータもpython-jobspyを介して集約されます。

オプションのエンジンを追加すると、求人サイトが追加されます。 オプションには、HireHunt、OpenRoles、JobDrop、Apifyがあります。OpenRolesは実行前に企業リストが必要です。ApifyにはAPIFY_TOKENが必要です。JobDropはJobSpyの依存関係ピンと競合します。セットアップウィザードの**「ジョブエンジンをダウンロード」**オプションを選択すると、これらがインストールされます。

「ソースとプラットフォーム」ページでは、オプションとなるエンジン、シードファイル、カスタムプラットフォームの情報、および互換性に関する注意事項が紹介されています。

あなたのプロフィールが準備完了しました。最初のスキャンを実行する時です。
