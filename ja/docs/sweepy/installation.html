Sweepyのインストール

このチュートリアルでは、コンピューターにSweepyをインストールします。まず3つのツールが必要です：

  1. Python：エンジンを実行するための言語です。
  2. Git：インターネットからエンジンのコードをダウンロードするためのツールです。
  3. pip：エンジンが必要とする追加ライブラリをインストールするためのツールです。WindowsおよびmacOS向けの公式インストーラーにはpipが含まれています。Linuxディストリビューションでは、システムパッケージマネージャーを通じてpipがインストールされます。
注記

このガイドは、端末を使ったことがない人でも分かりやすいように、各ステップを順を追って説明しています。Python 3.10以上およびGitが既にインストールされている場合は、ステップ3に進んでください。

ステップ1：端末を開く​

端末（コマンドプロンプトとも呼ばれる）は、コマンドを入力するためのテキストベースのウィンドウです。アイコンを選択する代わりに、ここにコマンドを入力します。

  • Windows
  • macOS
  • Linux

Windowsキーを押し、「PowerShell」と入力してから「Windows PowerShell」を選択します。

Terminal
Windows PowerShell
Copyright (C) Microsoft Corporation. All rights reserved.

PS C:\Users\YourName>

Command + Spaceを押し、「Terminal」と入力してから「Enter」を押します。

Terminal
Last login: Mon Oct 19 14:40:23 on ttys000
yourname@MacBook-Pro ~ %

ほとんどのLinuxディストリビューションでは、Ctrl + Alt + Tを押してターミナルウィンドウを開きます。

Terminal
yourname@ubuntu:~$

プロンプトの最後には点滅するカーソルが表示されます。このカーソルは、コマンドの入力を待っている状態を示します。

ステップ2：Pythonの確認とインストール​

SweepyではPython 3.10以降が必要です。すでにインストールされているか確認してください。

ターミナルに以下のコマンドを入力し、Enterを押してください：

Terminal
python --version

macOSおよびLinuxでは、このコマンドはpython3 --versionです。

Python 3.10.x以上のバージョンが表示されれば、Pythonはすでにインストールされています。ステップ3に進んでください。

'python' is not recognizedのようなエラーメッセージや3.10未満のバージョンが表示された場合は、以下のインストール手順に従ってください。

  • Windows
  • macOS
  • Linux
  1. Windows用Pythonダウンロードページにアクセスしてください。
  2. 最新の**Windows用インストーラー（64ビット）**のダウンロードリンクを選択してください。
  3. ダウンロードしたファイルを実行してください。
  4. このステップは非常に重要です。 インストーラーの最初の画面で、下部にある「python.exeをPATHに追加する」チェックボックスにチェックを入れてください。これにより、Pythonがターミナルで利用可能になります。
  5. 「今すぐインストール」を選択し、インストールが完了するのを待ちます。

その後、新しいターミナルウィンドウでインストールが正しく行われたかを確認します。

Terminal
PS C:\Users\YourName> python --version
Python 3.13.1
注意

「python.exeをPATHに追加する」をスキップすると、ターミナルではpythonコマンドが認識されません。Pythonをアンインストールした後、チェックボックスを選択して再度インストールしてください。

  1. macOS用のPythonダウンロードページにアクセスします。
  2. 最新のmacOS 64ビットユニバーサルインストーラーをダウンロードします。
  3. ダウンロードした.pkgファイルを開き、インストールの手順に従ってください。

その後、新しいターミナルウィンドウでインストールが正しく行われたかを確認します。

Terminal
yourname@MacBook-Pro ~ % python3 --version
Python 3.13.1

ターミナルで以下の2つのコマンドを実行します。

Terminal
sudo apt update
sudo apt install python3 python3-pip python3-venv
ヒント

FedoraやRed Hat Enterprise Linuxの場合は、aptの代わりにdnfを使用してください：sudo dnf install python3 python3-pip。

その後、新しいターミナルウィンドウでインストールが正しく行われたかを確認します。

Terminal
yourname@ubuntu:~$ python3 --version
Python 3.12.3

Windows、macOS、Linuxのいずれの場合も、インストール完了後にターミナルを閉じてから再度開き、「version」というコマンドを実行します。バージョン番号が3.10以上であればPythonのインストールが完了しています。

ステップ3：Sweepyをダウンロードする​

Sweepy のソースファイルをダウンロードする

いずれかの方法を選択してください。以下に説明するGitを使用するか、SweepyのリリースページからZIPファイルをダウンロードしてください。

Gitはプロジェクトファイルをコンピューターにコピーし、その履歴を記録します。この履歴によりSweepyは自動的に更新されます。以下の手順ではGitを使用します。

  • Gitによるコピー: sweepy --updateを実行するか、Toolboxアップデーターを使用して新しいリリースを取得します。
  • ZIPファイルによるコピー: 各リリースごとにZIPファイルをダウンロードし、解凍した後、再びpip install -e .を実行します。ZIPファイルにはGitの履歴が含まれていないため、自動更新は機能しません。
  • フォルダ名: Gitはsweepyという名前のフォルダを作成します。ZIPファイルはsweepy-mainなどのフォルダ内に解凍されるため、この手順の後でcdコマンドを適切に調整してください。

一時的に確認する場合はZIPファイルを選択してください。Sweepyを継続して使用する場合はGitを選択してください。

エラーが発生した場合は、問題を報告し、実行したコマンドを貼り付けてください。

まず、Gitが既にインストールされているかを確認してください：

Terminal
git --version

「git version 2.45.1」のようなバージョン番号が表示されれば、Gitがインストールされています。

エラーが発生した場合は、Gitをインストールしてください：

  • Windows
  • macOS
  • Linux
  1. git-scm.com/download/winにアクセスしてください。
  2. インストーラーをダウンロードして実行してください。
  3. すべてのデフォルト設定を受け入れて、「インストール」を選択します。
  4. ターミナルを閉じてから再度開き、確認を行います。
Terminal
PS C:\Users\YourName> git --version
git version 2.45.1

このコマンドを実行すると、macOSからXcodeコマンドラインツールのインストールが求められます。このツールにはGitも含まれています。

Terminal
yourname@MacBook-Pro ~ % git --version
xcode-select: note: install requested for command line developer tools

画面上の指示に従ってインストールを完了したら、再びgit --versionを実行してください。バージョン番号が表示されればGitのインストールが完了です。

Terminal
yourname@ubuntu:~$ sudo apt install git

その後、確認を行います。

Terminal
yourname@ubuntu:~$ git --version
git version 2.45.1

次に、以下のコマンドを実行してSweepyをダウンロードします。

Terminal
git clone https://github.com/pvega62/sweepy.git

これにより、コンピューター上に「sweepy」という名前の新しいフォルダが作成されます。そのフォルダに移動してください。

Terminal
cd sweepy
ヒント

Gitは、コマンドを実行した時にターミナルが指していたディレクトリにこの新しいフォルダを配置します。Windowsでは、「C:\Users\YourName\」内で新しいPowerShellウィンドウが起動します。

ステップ4：依存関係のインストール​

Sweepyが正常に動作するためにはいくつかの追加ライブラリが必要です。

  • pymupdf: レジュメのPDFファイルからテキストを読み取り、抽出します。
  • python-docx: .docx形式の履歴書を読み取り、変換します。
  • python-jobspy: APIキーなしで求人サイトの情報を安全にスクレイピングする。
  • beautifulsoup4: Greenhouse、Lever、Workable、Built In NYCのソースからHTMLデータを解析する。
  • reportlab: クリック可能なリンク付きのスタイル付けされたPDFレポートを生成する。
  • requests: URLがまだ有効かどうかを確認するためのWebリクエストを送信する。
  • pyyaml & questionary: インタラクティブな設定ウィザードを処理する。prompt-toolkitがキーボード操作を提供する。
  • pandas: スクレイプした求人情報を整理し、CSVスプレッドシートとして出力する。
  • mcp & anyio: SweepyをAIアシスタントに接続するオプションのModel Context Protocolサーバーを実行する。
Python 3.13

Python 3.13を使用する場合は、まずMicrosoft C++ Build Toolsをインストールし、「Desktop development with C++」ワークロードを選択してください。Python 3.13は新しいバージョンなので、pymupdfのような一部のパッケージはソースからコンパイルする必要があり、これらのツールが必要になることがあります。Python 3.12以前のバージョンではこの手順をスキップしてください。

Sweepyの自動テストはPython 3.10から3.12までを対象としています。これらのバージョンが最も安定しています。

すべてのパッケージは1つのコマンドでインストールできます。

Terminal
pip install -e .

そのコマンドにより、すべての依存関係がインストールされ、Python Scriptsフォルダにsweepyコマンドが登録されます。ターミナルを一度再起動して、PATHが新しいフォルダを認識できるようにしてください。その後は、python swee.py --runの代わりにsweepy --runを実行してください。どちらのコマンドもsweepyフォルダから実行できます。

Pythonが各パッケージをダウンロード・インストールするにつれてテキストがスクロールします。カーソルが元の位置に戻ると、インストールが完了です。

ヒント

pipに対して「コマンドが見つかりません」というエラーが発生しましたか？その場合はpip3 install -e .を試してください。一部のシステムでは、Python 3ではpip3がコマンド名として使用されています。

インストール状況を確認してください。​

以下の簡単なチェックを実行して、すべてが正しくインストールされているかを確認してください：

Terminal
sweepy --version

シェルでsweepyが見つからない場合は、ターミナルを再起動するかpython swee.py --versionを実行してください。その後、以下のようなメッセージが表示されます：

Terminal output
Sweepy v3.1.0
Python 3.13.1 | pymupdf 1.28.2 | reportlab 5.0.1
Ready to sweep.

そのメッセージが表示されたら、Sweepyの準備ができました。使用しているマシンによって数字が異なる場合があります。SweepyはVERSIONファイルからリリース情報を表示し、pipは使用しているPythonバージョンに適したパッケージをインストールします。

2行目にはpymupdfおよびreportlabのバージョン情報が表示されます。

次に、パーソナライズされた求人検索プロフィールを設定してください。
