Sweepy のインストール

Sweepy を実行する前に、パソコンに 3 つのものが必要です。

  1. Python: エンジンを動かすプログラミング言語です。
  2. Git: エンジンのコードをインターネットから取得するツールです。
  3. pip: エンジンが必要とする追加ライブラリをインストールするパッケージマネージャーです。Windows と macOS の公式インストーラーには pip が含まれます。Linux ディストリビューションでは、システムのパッケージマネージャーから pip を追加します。
注記

このガイドは、ターミナルを一度も開いたことがない人向けにすべての手順を説明します。Python 3.10 以上と Git がすでにある場合は、ステップ 3 に進んでください。

ステップ 1: ターミナルを開く​

ターミナルはコマンドプロンプトとも呼ばれ、コマンドを入力するテキストベースのウィンドウです。アイコンを選ぶ代わりに、ここでコンピューターに指示を入力します。

  • Windows
  • macOS
  • Linux

Windows キーを押し、PowerShell と入力して、Windows PowerShell を選択します。

ターミナル
Windows PowerShell
Copyright (C) Microsoft Corporation. All rights reserved.

PS C:\Users\YourName>

Command + Space を押し、Terminal と入力して、Enter を押します。

ターミナル
Last login: Mon Oct 19 14:40:23 on ttys000
yourname@MacBook-Pro ~ %

ほとんどの Linux ディストリビューションでは、Ctrl + Alt + T を押すとターミナルのウィンドウが開きます。

ターミナル
yourname@ubuntu:~$

プロンプトの末尾に点滅するカーソルがあります。そのカーソルは、ターミナルがコマンドを受け付ける準備ができていることを示します。

ステップ 2: Python を確認してインストールする​

Sweepy には Python 3.10 以降が必要です。すでにあるかどうかを確認します。

ターミナルで次のコマンドを入力し、Enter を押します。

ターミナル
python --version

macOS と Linux では、コマンドは python3 --version です。

Python 3.10.x 以上が表示されたら、Python はすでにあります。ステップ 3 に進んでください。

'python' is not recognized のようなエラーメッセージが出る場合、または 3.10 未満のバージョンが出る場合は、次のインストール手順に進みます。

  • Windows
  • macOS
  • Linux
  1. Windows 用 Python のダウンロードページにアクセスします。
  2. 最新の Windows installer (64-bit) のダウンロードリンクを選びます。
  3. ダウンロードしたファイルを実行します。
  4. この手順は重要です。 インストーラーの最初の画面で、下部にある "Add python.exe to PATH" というラベルのチェックボックスを選びます。このチェックボックスは Python を PATH に追加し、ターミナルから見つけられるようにします。
  5. Install Now を選び、インストールが終わるまで待ちます。

次に、新しいターミナルのウィンドウでインストールを確認します。

ターミナル
PS C:\Users\YourName> python --version
Python 3.13.1
注意

"Add python.exe to PATH" を飛ばすと、ターミナルは python コマンドを認識しません。Python をアンインストールし、チェックボックスを選んでインストールし直してください。

  1. macOS 用 Python のダウンロードページにアクセスします。
  2. 最新の macOS 64-bit universal2 installer をダウンロードします。
  3. ダウンロードした .pkg ファイルを開き、インストールの案内に従います。

次に、新しいターミナルのウィンドウでインストールを確認します。

ターミナル
yourname@MacBook-Pro ~ % python3 --version
Python 3.13.1

ターミナルで次の 2 つのコマンドを実行します。

ターミナル
sudo apt update
sudo apt install python3 python3-pip python3-venv
ヒント

Fedora または Red Hat Enterprise Linux では、apt を dnf に置き換えます: sudo dnf install python3 python3-pip。

次に、新しいターミナルのウィンドウでインストールを確認します。

ターミナル
yourname@ubuntu:~$ python3 --version
Python 3.12.3

Windows、macOS、Linux の各タブは同じ確認で終わります。ターミナルを閉じて開き直し、バージョンのコマンドを実行します。3.10 以上のバージョン番号が表示されれば、Python の準備は完了です。

ステップ 3: Sweepy をダウンロードする​

Sweepy のソースファイルをダウンロードする

どちらか一方の方法を選びます。以下で説明する Git を使うか、Sweepy のリリースページ から ZIP ファイルをダウンロードします。

Git はプロジェクトのファイルをパソコンにコピーし、その履歴を記録します。この履歴があるため、Sweepy は自分で更新できます。以下の手順では Git を使います。

  • Git で取得した場合。 sweepy --update を実行するか、Sweepy's Toolbox の更新機能で新しいリリースを取り込みます。
  • ZIP で取得した場合。 リリースごとにダウンロード、解凍を行い、pip install -e . をもう一度実行します。ZIP には取り込める Git の履歴がないため、自動更新は無効のままです。
  • フォルダー名。 Git は sweepy というフォルダーを作成します。ZIP は sweepy-main のようなフォルダーに展開されるため、この手順の後半にある cd コマンドを調整します。

一度試すだけなら ZIP を選びます。今後も Sweepy を使い続けるなら Git を選びます。

まず、Git がすでにインストールされているか確認します。

ターミナル
git --version

git version 2.45.1 のようなバージョン番号が表示されたら、Git はあります。エラーが表示されたら、Git をインストールします。

  • Windows
  • macOS
  • Linux
  1. git-scm.com/download/win にアクセスします。
  2. インストーラーをダウンロードして実行します。
  3. 既定の設定をすべて受け入れ、Install を選択します。
  4. ターミナルを閉じて開き直し、確認します。
ターミナル
PS C:\Users\YourName> git --version
git version 2.45.1

このコマンドを実行すると、macOS が Xcode Command Line Tools のインストールを促します。このツールには Git が含まれます。

ターミナル
yourname@MacBook-Pro ~ % git --version
xcode-select: note: install requested for command line developer tools

画面の案内に従ってインストールし、git --version をもう一度実行します。バージョン番号が表示されれば Git の準備は完了です。

ターミナル
yourname@ubuntu:~$ sudo apt install git

次に確認します。

ターミナル
yourname@ubuntu:~$ git --version
git version 2.45.1

続いて、次のコマンドを実行して Sweepy をダウンロードします。

ターミナル
git clone https://github.com/pvega62/sweepy.git

これで、パソコンに sweepy という新しいフォルダーができます。そのフォルダーに移動します。

ターミナル
cd sweepy
ヒント

Git は、コマンドを実行したときにターミナルが指していたディレクトリに新しいフォルダーを作ります。Windows では、新しい PowerShell のウィンドウは C:\Users\YourName\ で始まります。

ステップ 4: 依存パッケージをインストールする​

Sweepy は動作にいくつかの追加ライブラリを使います。

  • pymupdf: 履歴書の PDF からテキストを読み取って抽出します。
  • python-docx: .docx 形式の履歴書を読み取って変換します。
  • python-jobspy: API キーなしで求人サイトから安全にデータを取得します。
  • beautifulsoup4: Greenhouse、Lever、Workable、Built In の各ソースから HTML を解析します。
  • reportlab: クリックできるリンク付きの整形された PDF レポートを生成します。
  • requests: URL が有効かどうかを確認するためにウェブリクエストを送信します。
  • pyyaml と questionary: 対話形式の設定ウィザードを担います。prompt-toolkit がそのキーボード操作を提供します。
  • pandas: 取得した求人データを構造化し、CSV スプレッドシートのエクスポートを組み立てます。
  • mcp と anyio: Sweepy を AI アシスタントに接続する任意の Model Context Protocol サーバーを実行します。
Python 3.13

Python 3.13 を使う場合は、先に Microsoft C++ Build Tools をインストールし、"Desktop development with C++" ワークロードを選びます。Python 3.13 は新しく、pymupdf などの一部のパッケージがソースからコンパイルされ、これらのツールを必要とする場合があります。Python 3.12 以前ではこの手順を飛ばしてください。

Sweepy の自動テストは Python 3.10 から 3.12 までを対象にしています。これらのバージョンが最もスムーズな道です。

1 つのコマンドですべてのパッケージをインストールします。

ターミナル
pip install -e .

このコマンドはすべての依存パッケージをインストールし、Python の Scripts フォルダーに sweepy コマンドを登録します。PATH が新しいフォルダーを認識するように、ターミナルを一度開き直します。以後は python swee.py --run の代わりに sweepy --run を実行します。どちらの形式も sweepy フォルダーから実行します。

Python が各パッケージをダウンロードしてインストールする間、テキストが流れます。カーソルが戻れば、インストールは完了です。

ヒント

pip で "command not found" エラーが出ましたか。代わりに pip3 install -e . を試してください。システムによっては、Python 3 のコマンド名が pip3 です。

インストールを確認する​

すべてが正しくインストールされたかを確かめるため、次の簡単な確認を実行します。

ターミナル
sweepy --version

シェルが sweepy を見つけられない場合は、ターミナルを開き直すか、代わりに python swee.py --version を実行します。次のように表示されます。

ターミナル出力
Sweepy v3.0.0
Python 3.13.1 | pymupdf 1.28.2 | reportlab 5.0.1
Ready to sweep.

このメッセージが表示されれば、Sweepy は準備完了です。お使いの環境では異なる数字が表示されます。Sweepy は VERSION ファイルからリリースを出力し、pip は Python のバージョンに合ったパッケージをインストールします。

2 行目は pymupdf と reportlab のバージョンを示します。
