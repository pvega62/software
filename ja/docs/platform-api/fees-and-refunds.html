里親縁組手数料、預金金、および返金について

Blüdhaven Petsの里親申請書には4つの費用項目があります。各項目にはそれぞれ異なる返金規則が適用されます。店舗スタッフおよびチェックアウトシステムのインテグレーション担当者は、正しい規則を適用する必要があります。そうでない場合、月末の精算が正しく行えません。

申請にかかる費用項目​

項目フィールド金額返金可能か
配置料placement_fee_cents15,000はい、対象期間内に
予約デポジットreservation_deposit_cents5000いいえ
市の許可証license_fee_cents2500いいえ、動物管理部門に移管されました
小売用品supplies_subtotal_cents種類は様々はい、未開封のもののみ

このプラットフォームでは、動物が引き取られるたびに一度引き取り料金が請求されます。2匹の動物を引き取る家庭は、それぞれの動物にかかる受け入れ費用、予防接種費用、マイクロチップの費用があるため、2回の引き取り料金を支払う必要があります。

予約金​

50ドルの予約デポジットを支払うと、30分間の動物の預かり期間が予定された引き取り日に変更されます。デポジットはいかなる場合でも返金されません。このデポジットは、その動物を里親募集用のエリアから外しておくための費用として使用され、他の里親候補者が待機することになるような無計画な予約を防ぐためのものです。

デポジットは移転可能です。里親候補者が14日以内に別の動物に変更した場合、プラットフォームは元のデポジット額を新しい申請に適用します。古い予約情報はDELETE /adoptions/holds/{holdId}を使用して解除し、新しい動物についてはPOST /adoptions/holdsに連絡し、元の申請IDをnotesで伝えてください。カウンセラーがレビュー中にデポジット額を返金します。

保証金の没収

予定された引き取り日に来られなかった里親候補者は、24時間の猶予期間が過ぎるとデポジット額を失います。その動物は再びAVAILABLEの状態に戻り、申請状況はCANCELLED_NO_SHOWに移行します。

市のライセンス料金​

報告時にはこの点に注意してください。ライセンス料金は申請書の合計金額に含まれますが、返金対象の収入には含まれません。

返金対象期間​

このプラットフォームでは、ウィンドウの期間はアプリケーション内のsubmitted_atから計算され、ピックアップ日からではありません。

ウィンドウアプリケーションの状態返金が発行されたか
submitted_atから48時間以内受け取り前配置料および未開封の小売用品
submitted_atから48時間後～7日以内受け取り前所定の手数料の50％および未開封の小売用品
受け取り後、いつでもどの州でも申請は返金不可となります。代わりにキャンセル処理を行ってください。
医学的な不適格どの州でも所定の里親募集料金（デポジット含む）が全額返金されます

医学的な不適格による処理の優先順位​

里親募集後で引き取り前に獣医師が不適格な状態を発見した場合、プラットフォームはすべての期限規定を無効とします。APIは申請時の総額（デポジット含む）を返金し、その動物をMEDICAL_QUARANTINEに移動させます。

この処理を実行するにはPOST /refundsとreason: MEDICAL_DISQUALIFICATIONが必要です。リクエストには、有効な証明書で解決されるveterinary_record_idが必要です。

返金の理由​

reasonには4つの値が設定されており、どの理由が該当するかは「窓口表」で決定されます。

reason使用場面返金内容
CANCELLATION_INSIDE_48H里親が48時間以内にキャンセルした場合里親募集料金および未開封の用品
CANCELLATION_AFTER_48H里親が48時間以降にキャンセルした場合里親募集料金の50％および未開封の用品
RETAIL_SUPPLIES_ONLY未開封の用品のみが返金される場合未開封の用品
MEDICAL_DISQUALIFICATION里親募集前に獣医師が不適格な状態を発見した場合申請時の総額（デポジット含む）が返金されます。veterinary_record_idが必要です。

返金の手続き​

Issue a partial placement-fee refund
curl -X POST https://api.bludhavenpets.com/v1/refunds \
  -H "Authorization: Bearer $BLUDHAVEN_TOKEN" \
  -H "Idempotency-Key: 8f14e45f-ceea-467f-a1c2-3d4e5f607182" \
  -H "Content-Type: application/json" \
  -d '{
    "application_id": "app_2026_1188",
    "amount_cents": 10000,
    "reason": "CANCELLATION_AFTER_48H",
    "refund_retail_supplies": true
  }'

この回答では、設置料金と資材費用の区分が確認されています。

    "license_fee_cents": 2500
  },

  "settles_at": "2026-11-19T14:00:00Z"
}

返金のタイミング​

カードによる返金は3〜5営業日で処理されます。ストアクレジットの場合は即時に処理されます。POST /refundsを利用するにはadmin:adoptionsの範囲が必要なため、お金が振り込まれる前にカウンセラーの承認が必要です。

settles_atのタイムスタンプは処理システムの見積もりに基づいています。経過時間から推測するのではなくstatusを確認し、申請を終了する前にrefund.settledのWebフックの通知を待ってください。

再実行可能性（Idempotency）​

返金リクエストにはIdempotency-Keyが必要です。同じキーで再試行した場合、2回目の返金ではなく元の返金データが200ステータスで返されます。キーは24時間後に有効期限を迎えます。

金額、理由、または申請内容に変更があった場合のみ新しいキーを送信してください。異なる内容でキーを再利用すると422 idempotency_key_reuseの状態が返されます。
