アドオプションの保留処理と並行処理

Blüdhaven Petsは、3つの実店舗とオンラインポータルを通じてペットの里親募集を行っています。店頭のカウンセラーとオンライン申請者が同時に同一のペットにアクセスすることが可能です。APIは原子レベルの予約ロックを実施し、二重予約を防ぎます。

30分の保留の仕組み​

申請者が面接を開始したりオンラインでチェックアウトを開始したりすると、クライアントアプリケーションは一時的な保留処理をリクエストしなければなりません：

応募者が面接を開始したり、オンラインでの決済手続きを開始したりした際には、クライアントアプリケーション側で一時保留をリクエストする必要があります：

  • Diagram
  • ASCII
[Available Animal] ──► POST /adoptions/holds ──► [30-Minute Hold Granted]
                             │
                             ▼ (Second concurrent request)
                    [HTTP 409 Conflict]
  1. 状態確認：APIは動物がstatus: "AVAILABLE"を格納していることを確認し、health_record.spay_neuter_certifiedからtrueを読み取ります。
  2. ロックの作成：APIはAdoptionHoldのレコードを書き込み、動物の状態をRESERVED_HOLDに設定します。
  3. 有効期限（TTL）。サーバーは、作成からちょうど1,800秒後に、変更不可能な有効期限のタイムスタンプを割り当てます。
  4. 解像度（Resolution）
    • 申請者が書類を提出し、養子縁組料を支払った場合、スタッフは申請書を提出し、保留状態はCONVERTEDに移行します。
    • 30分経過しても処理が完了しない場合、自動化されたバックグラウンドプロセスがEXPIREDのホールド状態を解除し、動物をAVAILABLEに戻します。

予約の保留処理​

动物および申請者の識別子を含むPOSTリクエストを/adoptions/holdsに送信します。

cURL
curl -X POST https://api.bludhavenpets.com/v1/adoptions/holds \
  -H "Authorization: Bearer <STAFF_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "animal_id": "pet_krypto_210",
    "applicant_id": "usr_9921bc",
    "notes": "In-person consultation at the Downtown adoption floor"
  }'

対応成功​

201 Created

Response
{
  "id": "hld_77a28f",
  "animal_id": "pet_krypto_210",
  "applicant_id": "usr_9921bc",
  "branch_id": "loc_harbor_04",
  "status": "ACTIVE",
  "created_at": "2026-11-17T07:45:00Z",
  "expires_at": "2026-11-17T08:15:00Z",
  "seconds_remaining": 1782
}

409 競合による衝突の処理​

他のスタッフメンバーやオンライン申請者が先にその動物を申請した場合、エンドポイントはRFC 9457のProblemDetails規格に従ってHTTP409 Conflictを返します。

409 Conflict Response
{
  "type": "https://api.bludhavenpets.com/errors/adoption-hold-conflict",
  "title": "Adoption Hold Conflict",
  "status": 409,
  "detail": "Animal pet_krypto_210 is currently reserved under active hold hld_77a28f expiring at 2026-11-17T08:15:00Z.",
  "instance": "/adoptions/holds"
}

早期にリリースを開始する​

面接が失敗した瞬間、または応募者が退出した瞬間にカウンセラーはロックを解除する。そうでなければ、その動物は残りの30分間、他の里親には見えない状態のままとなる。

cURL
curl -X DELETE https://api.bludhavenpets.com/v1/adoptions/holds/hld_77a28f \
  -H "Authorization: Bearer <STAFF_TOKEN>"

204 No Contentによりリリースが確認され、その動物はすぐにAVAILABLEに戻ります。すでに申請済みのアプリケーションは409に戻されます。なぜなら、リリースでは既に提出されたアプリケーションを取り消すことはできないからです。

推奨されるクライアント復旧フロー​

  1. detailメッセージを解析するか、対象の動物プロフィールを確認してください。
  2. アクティブなホールド状態でexpires_atを確認してください。
  3. お客様が待機を希望される場合は、有効な保留期間が終了しても変更がない場合に通知される通知キューに参加するようお願いします。
  4. 同じ種類で気質プロフィールが一致する代替の同伴動物をご提案します。
