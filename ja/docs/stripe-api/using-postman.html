Postmanを使ってStripe APIに接続する

このページを終えると、ForkしたStripeコレクションと、すべてのリクエストをAPIキーで認証するPostman環境が手元に揃います。1つのリクエストを送信して、Stripeがキーを受け付けることを確認します。

Postmanはリクエストを送信し、レスポンスを表示します。共有ワークスペースを使うと、チームが同じコレクションを使えます。

接続の前提条件​

開始する前に、次の項目を用意します：

  • Postmanアカウント。
  • DashboardにアクセスできるStripeアカウント。
  • https://api.stripe.com/へのネットワークアクセス。これはStripe APIリクエストのベースアドレスです。

Postmanのセットアップ​

  1. Postmanアプリをダウンロードしてインストールします。

  2. Postmanアプリを開き、セットアップを完了します。

    ワークスペースの概要が表示され、ウィンドウの上部に検索フィールドがあります。

  3. 検索フィールドに「Stripe」と入力し、Stripe Developersワークスペースを選択します。

    検索結果にStripe Developersワークスペースが表示されます。その下の行にはStripe Developers APIsと表示されます。

  4. Collectionsアイコンを選択し、名前に最も新しい日付が付いたコレクションを選びます。

  5. Forkを選択して、コレクションを自分のワークスペースに追加します。

    ForkしたコレクションがワークスペースのCollectionsに表示されます。

APIキーのコピー​

StripeはすべてのAPIリクエストをAPIキーで認証します。キーはHTTPSで送信し、StripeはAuthorizationヘッダーからキーを読み取ります。Basic Authとベアラートークンのどちらも使えます。

アカウントにはキーが用意されているため、新しく生成するのではなく既存のキーをコピーします。Stripeは新しい連携には制限付きAPIキーを推奨します。選択した権限だけを付与できるためです。シークレットキーも使え、無制限のアクセスを付与します。制限付きキーはrk_で始まり、シークレットキーはsk_で始まります。次の手順はどちらの種類にも対応します。

  1. Stripe Dashboardに移動し、アカウントを作成します。

  2. Developers > API keysを開き、シークレットキーを表示するか、リクエストに必要な権限を持つ制限付きキーを作成します。

  3. キーを選択してクリップボードにコピーします。

    注記

    APIキーを他のユーザーと共有しないでください。

  4. Postmanアプリに戻ります。

  5. Environmentsを選択し、**Add (+)**を選択します。

  6. Nameフィールドに名前を入力します（例：Stripe API）。

  7. Variableセルにsecret_keyと入力し、コピーしたキーをCurrent Valueセルに貼り付けます。

  8. Saveを選択します。

  9. Environmentドロップダウンメニューを選択し、Stripe APIを選びます。

    ドロップダウンにStripe APIが表示されます。Postmanは各リクエストにキーを追加します。

接続の確認​

キーを必要とするリクエストを送信します。balanceエンドポイントはアカウントデータを読み取ります。200レスポンスが返れば、キーが機能していることを確認できます。

  1. Forkしたコレクションを開き、GETリクエスト（/v1/balanceなど）を選択します。

  2. Sendを選択します。

    成功レスポンス

    200 OKレスポンスはJSONを返し、Stripeがキーを受け付けたことを示します。

    エラーレスポンス

    401レスポンスは、Postmanが有効なキーを送信しなかったことを意味します。変数名がコレクションの変数名と一致しているか確認します。Current Valueに公開可能キーではなくAPIキーが入っていることも確認します。

    403レスポンスは、キーにそのエンドポイントの権限がないことを意味します。Dashboardで権限を付与するか、より広いアクセス権を持つキーに切り替えます。
