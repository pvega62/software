クラウドデータパイプラインドキュメント

最新のオブザーバビリティパイプラインのアーキテクチャ設計と運用のルーティングを習得します。このコレクションでは、詳細なインジェクションAPIリファレンス、高精度な図解、回復力のあるイベントストリームを構築するための標準的な運用手順の組み合わせを通じて、イベント駆動型のデータフローを紹介します。

📄️開始する前に

Datadog ログパイプラインおよび Galileo 大規模言語モデル（LLM）オブザーバビリティを利用するための前提条件、ツール、およびコンテキスト。

📄️イベントストリームとオブザーバビリティパイプライン

イベントストリーム、オブザーバビリティパイプラインのアーキテクチャ、およびDatadogとGalileoが最新のテレメトリスタックにどのように適合するかについての概念的な概要。

📄️ログ取り込みAPI

ログやイベントデータをDatadogに送信して処理、パイプラインルーティング、およびダウンストリーム配信を行うためのAPIリファレンス。

📄️クラウドアプリログのルーティング

クラウドアプリからパイプラインにJSONログを送信し、取り込みを確認するためのステップバイステップガイド。

📄️Postman模擬サーバーの作成

Datadog Log Ingestion APIをシミュレートするためのPostman模擬サーバーをセットアップします。ライブデータを送信せずに、リクエスト形式やパイプラインのワークフローをテストします。
