使用写操作发送交易

适用于首次进行 Sui 数据修改的操作。

您需要一个已充值（有资金）的 Sui devnet 钱包，并具备基本的 Node.js 开发环境。

编写脚本来转移 Sui 代币，并了解“gas”和签名在交易中的作用。

引言​

您可以使用 SuiClient 来查询数据。此读取操作不收取任何费用。

现在，执行一次写操作以转移 Sui 代币。由于此操作会更新链上状态，因此必须满足以下两个条件：

  1. 签署请求：您的签名证明您拥有这些资金。
  2. 支付 gas 费用：一小笔 Sui 费用用于补偿网络处理交易。

先决条件​

要运行本教程，请准备：

  • 使用一个已充值（有资金）的钱包。您的钱包需要一个由12个单词组成的恢复短语（recovery phrase），以及Sui的devnet代币。您可以通过Sui的挖矿工具、Sui的Discord挖矿工具，或兼容的钱包来免费获取这些代币。
  • Ed25519密钥对包： 使用该密钥对（@mysten/sui）来签署交易。

如有需要，请安装相关包。

Terminal
npm install @mysten/sui
注意

将密钥存储在应用程序代码之外，应通过环境变量（如.env）来管理这些密钥。

演示代码会将恢复短语存储在内存中，切勿将其保存到 GitHub 上。

1. 导入依赖项并配置客户端​

创建一个名为 transfer.js 的文件。导入 SuiClient 用于网络通信，以及 Ed25519Keypair 用于签署交易。

transfer.js
import { SuiClient, getFullnodeUrl } from '@mysten/sui/client';
import { Ed25519Keypair } from '@mysten/sui/keypairs/ed25519';
import { Transaction } from '@mysten/sui/transactions';

// 1. Connect to Devnet
const client = new SuiClient({ url: getFullnodeUrl('devnet') });

// 2. Load your Wallet (The Sender)
// REPLACE THIS with your actual 12-word mnemonic phrase
const MNEMONIC = "word1 word2 word3 ... word12"; 
const keypair = Ed25519Keypair.deriveKeypair(MNEMONIC);
const senderAddress = keypair.getPublicKey().toSuiAddress();

console.log(`📦 Sender Address: ${senderAddress}`);
提示

在发送交易之前，您的发送者地址需要测试代币来支付网络费用。请从终端中复制打印出的 Sender Address，然后从 Sui 水龙头 获取 Devnet 代币。或者加入 Sui Discord，并在 #devnet-faucet 频道中请求代币。

2. 构建交易​

在 Sui 中，应使用 Transaction 对象而非原始命令来执行操作。交易包含了网络需要执行的全部步骤。

使用 tx.splitCoins 命令从您的主要加密货币中提取指定数量的代币。

transfer.js
// 3. Define the Recipient
const RECIPIENT = '0x9999...'; // Replace with a friend's address or a burn address

// 4. Create the Transaction Container
const tx = new Transaction();

// Split 1000 MIST (The smallest unit of SUI) from the gas coin
const [coinToSend] = tx.splitCoins(tx.gas, [1000]);

// Transfer the split coin to the recipient
tx.transferObjects([coinToSend], RECIPIENT);

3. 签署并提交交易​

在执行链上交易之前，此步骤会先计算并支付所需的“gas”费用。

  3. 下一步：
transfer.js
async function sendTransaction() {
    try {
        console.log("📝 Signing and submitting transaction...");

        const result = await client.signAndExecuteTransaction({
            signer: keypair,
            transaction: tx,
        });

        console.log("✅ Transaction Submitted!");
        console.log(`Digest (Tracking ID): ${result.digest}`);
        
    } catch (error) {
        console.error("❌ Transaction Failed:", error);
    }
}

sendTransaction();

了解此交易中的“gas”（费用）​

您无需手动计算燃油费用。

  • 该SDK会自动估算交易所需的费用，并设置足够的预算来支付这笔费用。
  • 该 SDK 会从您的钱包中选取一定数量的 Sui 硬币。请在钱包中保留一些 Sui 硬币，以支付交易手续费（即“gas”费用）。

预期输出​

成功执行后，脚本会打印出一份交易摘要（Transaction Digest）。请使用该摘要来追踪相关交易信息。

Terminal output
📦 Sender Address: 0x123...
📝 Signing and submitting transaction...
✅ Transaction Submitted!
Digest (Tracking ID): 5T7x...9B2a

复制该摘要内容，并在 Suiscan 上进行搜索。

探索器会显示永久性记录，其中包含燃气使用情况、确认状态以及交易产生的影响。

下一步操作​

现在您已经完成了您的第一次链上写入交易：

  • 阅读如何获取对象数据，以查看接收者新收到的对象内容。
  • 查阅 SuiClient 架构，了解 Sui 节点（nodes）和管理员（clerks）的概念模型。
  • 查阅getObject API参考文档，以查询详细的交易效果和对象结构信息。
