使用 Postman 连接到 Stripe API

学习完本页内容后，您将拥有一个已配置好的 Stripe 数据集以及一个能够使用您的 API 密钥进行身份验证的 Postman 环境。您需要发送一个请求以确认 Stripe 接受了该密钥。

Postman 会发送请求并显示响应结果；共享的工作区可确保团队成员使用相同的数据集进行协作。

连接前提条件​

开始之前，请准备好以下内容：

  • 一个 Postman 账户。
  • 一个具有仪表盘访问权限的 Stripe 账户。
  • 对于发送 Stripe API 请求所需的网络连接（即地址 https://api.stripe.com/）。

设置 Postman​

  1. 下载并安装 Postman 应用程序。
  2. 打开 Postman 应用程序并完成设置流程。

在搜索框中输入 “Stripe”，然后选择 “Stripe Developers” 工作区。

  1. 选择 “Collections” 图标，再选择名称中日期最新的集合。

您可以在自己的工作区的 “Collections” 部分看到这个被复制的集合。

  1. 选择 Collections 图标，然后选择名称中包含最新日期的集合。
  2. 选择“Fork”按钮，将这个集合添加到您自己的工作空间中。

您会在工作区的“Collections”（收藏夹）中看到这个被分叉的集合。

复制一个 API 密钥​

Stripe 使用 API 密钥来验证每个 API 请求；该密钥通过 HTTPS 发送，并从 Authorization 标头中读取。Basic Auth 和 bearer tokens 都可以被使用来进行身份验证。

您的账户中已经包含了API密钥，因此可以直接使用现有的密钥，无需重新生成。Stripe建议为新集成使用受限型API密钥（这类密钥仅授予您指定的权限）；当然，使用通用型API密钥（secret_key）也可以实现无限制访问。受限型密钥以“rk_”开头，而通用型密钥以“sk_”开头。这些步骤适用于这两种类型的密钥。

  1. 打开 Stripe 控制台，然后进入 开发者 > API 密钥。

  2. 查看现有的秘密密钥，或根据您的需求创建一个新的、具有相应权限的密钥。

  3. 选择需要复制的密钥，并将其复制到剪贴板中。

    备注

切勿 将您的 API 密钥分享给其他用户。 :::

  1. 返回到 Postman 应用程序。
  2. 选择 环境（Environment），然后点击 添加 (+)。
  3. 在 名称（Name）字段中输入一个名称，例如 Stripe API。
  4. 在 变量（Variable）单元格中输入 secret_key，然后将复制的密钥粘贴到 当前值（Current Value）单元格中。

  1. 点击 保存（Save）。
  2. 从 环境 下拉菜单中选择 Stripe API。

此时下拉菜单中会显示 Stripe API。Postman 会将您的密钥自动应用于所有请求中。

验证连接​

发送一个需要使用您的 API 密钥的请求。该请求会读取账户数据；如果收到 200 类型的响应，说明密钥有效。

  1. 打开分支后的代码库（forked collection），然后选择一个 GET 类型的请求（例如 /v1/balance）。

  2. 点击 “发送”（Send）。

    成功响应

如果收到 200 OK 类型的响应，说明 Stripe 已成功接受该密钥。 :::

错误响应

如果收到 401 类型的响应，说明 Postman 未发送有效的密钥：请确认变量名与代码库中的名称一致，并确保 “当前值”（Current Value）中存储的是 API 密钥（而非可用于公开的密钥）。

如果收到 403 类型的响应，说明该密钥没有访问该端点的权限：请在控制面板（Dashboard）中授予相应权限，或更换为具有更广泛访问权限的密钥。
