扩展嵌套对象

响应结果以对象 ID 的形式返回相关对象，而非完整的对象结构。expand 参数会将指定的 ID 替换为该对象的实际内容，因此一个请求即可获取所有数据（而非多个请求）。

阅读未展开的响应​

{
  "id": "pi_3Rsx4dDtWMrPDtgt0mUrePJ9",
  "object": "payment_intent",
  "amount": 2120,
  "customer": "cus_QyJ8bT2vLk9mNp",
  "payment_method": "pm_1Rsx4dDtWMrPDtgt"
}

customer 字段中存储的是对象 ID；将该 ID 传递给 GET /v1/customers/{id} 可获取客户信息，但这需要额外发起一次请求（即两次网络请求）。

展开某个字段​

将字段名称作为参数传递给 expand[]，Stripe 会直接返回该字段的内容。

curl -s -G https://api.stripe.com/v1/payment_intents/pi_3Rsx4dDtWMrPDtgt0mUrePJ9 \
  -u "$STRIPE_SECRET_KEY:" \
  -d "expand[]=customer"
{
  "id": "pi_3Rsx4dDtWMrPDtgt0mUrePJ9",
  "object": "payment_intent",
  "customer": {
    "id": "cus_QyJ8bT2vLk9mNp",
    "object": "customer",
    "email": "ada@example.com",
    "created": 1735689600
  }
}

对象 ID 并不会被删除，而是会被移到 customer.id 中；因此即使进行了扩展操作，仅读取对象 ID 的客户端仍能正常工作。

展开多个层级​

点表示法可用于访问嵌套对象；payment_method.card 会返回支付方式中的具体卡片详情。

curl -s -G https://api.stripe.com/v1/payment_intents/pi_3Rsx4dDtWMrPDtgt0mUrePJ9 \
  -u "$STRIPE_SECRET_KEY:" \
  -d "expand[]=customer" \
  -d "expand[]=payment_method.card"

扩展操作最多支持四层嵌套；超过四层会导致错误。

请求结果
expand[]=customer客户的完整信息。
expand[]=payment_method.card支付方式中的完整卡片信息。
expand[]=customer.default_source客户的完整来源信息（即相关数据）。
expand[]=customer.default_source.card.fingerprint请求被拒绝；扩展操作会返回多个对象，而 fingerprint 则表示返回的是一个标量值。

决定何时进行数据扩展（即是否获取更多详细信息）​

数据扩展会增加响应的数据量，同时也会延长处理时间。

情况是否需要使用数据扩展功能
同时显示一笔支付记录及其对应的客户信息是的。一次请求比多次请求更高效。
为报告列出100笔交易记录不行。这样会导致数据量过大，超出有效处理范围。
检查某个相关字段的值不需要。可以从相关接口直接读取该字段的值。
在Webhook处理程序中验证交易记录有时需要。当处理程序需要时，再获取相关数据即可。
提示

扩展 POST 和 GET 的功能。在创建对象后，通过请求体传递 expand[] 参数以跳过后续的读取操作。

在列表内部进行扩展操作​

expand[] 参数适用于列表端点；如果在包含 100 个项目的页面上扩展相关对象，该对象会重复显示在每一行中，从而导致响应数据量增加。仅当每行确实需要嵌套数据时才进行列表扩展。

使用元数据添加自定义标识符​

metadata 用于存储键值对，可将Stripe对象与您的数据库中的记录关联起来。

curl https://api.stripe.com/v1/payment_intents \
  -u "$STRIPE_SECRET_KEY:" \
  -d "amount=2120" \
  -d "currency=usd" \
  -d "metadata[order_id]=ord_8842" \
  -d "metadata[tenant]=acme"
{
  "id": "pi_3Rsx4dDtWMrPDtgt0mUrePJ9",
  "metadata": {
    "order_id": "ord_8842",
    "tenant": "acme"
  }
}
  • 限制： 每个对象最多可存储 50 对键值对；每个键的长度不得超过 40 个字符，每个值的长度不得超过 500 个字符。
  • 注意安全： Stripe工作人员可以查看这些元数据，且这些元数据也会显示在控制面板和导出文件中。
  • 删除操作： 发送空字符串即可删除相关条目。
  • 可搜索性： 控制面板支持元数据搜索，但API列表过滤器可能不支持。
注意

除非数据政策允许，否则请勿将个人身份信息放入元数据中（如客户姓名、电子邮件地址和卡片信息）。这些信息应存储在Stripe提供的字段中，而非自由文本存储区。

验证扩展效果​

将请求发送两次：一次包含 expand[]，另一次不包含 expand[]；然后比较两次响应中的 customer 字段。

curl -s -G https://api.stripe.com/v1/payment_intents/pi_3Rsx4dDtWMrPDtgt0mUrePJ9 \
  -u "$STRIPE_SECRET_KEY:" \
  -d "expand[]=customer" | jq '.customer | type'

输出内容为 “"object"”。如果移除该标志，相同的命令会输出 “"string"”。
