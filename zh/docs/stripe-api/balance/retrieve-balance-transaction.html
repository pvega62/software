查询余额交易记录

一旦Stripe创建了余额交易记录，该记录就不会被修改。当收费状态发生变化或退款完成时，Stripe会生成新的交易记录而非修改原有记录。

GET https://api.stripe.com/v1/balance_transactions/{id}

账本的不可变性

示例​

参数​

  • cURL
  • Node.js
  • Python
cURL
curl -X GET https://api.stripe.com/v1/balance_transactions/txn_1NirD82eZvKYlo2CIvbtLWuY \
  -u "sk_test_51Mz0...:"
Node.js
import Stripe from 'stripe';
const stripe = new Stripe(process.env.STRIPE_SECRET_KEY);

const txn = await stripe.balanceTransactions.retrieve(
  'txn_1NirD82eZvKYlo2CIvbtLWuY'
);
console.log(`Net amount: ${txn.net} ${txn.currency}`);
Python
import os
import stripe

stripe.api_key = os.environ["STRIPE_SECRET_KEY"]

txn = stripe.BalanceTransaction.retrieve("txn_1NirD82eZvKYlo2CIvbtLWuY")
print(f"Net amount: {txn.net} {txn.currency}")

路径变量​

参数类型是否必填描述
id字符串必填项余额交易标识符，以前缀 txn_ 开头。

查询参数​

参数类型是否必填描述
expand[]字符串数组可选用于展开相关对象；使用 expand[]=source 可返回完整的收费（Charge）或退款（Refund）对象。

回复​

代码状态描述
200已通过返回余额交易对象。
400OK返回余额交易对象。
401Bad Request客户发送了格式错误的交易ID或无效的扩展参数。
404Unauthorized未提供或密钥已过期。

200: OK

响应属性​

属性类型描述
id字符串交易记录的唯一标识符，前缀为 txn_。
object字符串常量标识符；始终返回 balance_transaction。
amount整数账户变动的总额（以最小货币单位计）；正数表示收入，负数表示退款或支出。
available_on时间戳表示资金可支付的 Unix 纪元时间戳。
created时间戳表示 Stripe 生成该账务事件的 Unix 纪元时间戳。
currency字符串由三个小写字母组成的货币代码（例如 usd）。
fee整数Stripe 扣除的总处理费用（以最小货币单位计）。
fee_details对象数组收费的详细明细，包括 Stripe 的处理费和应用费用。
net整数账户净变动额（计算方式为 amount 减去 fee）。
reporting_category字符串会计分类类别（包括 charge、refund 或 payout）。
source字符串资金来源的标识符（ch_、re_、po_）；可展开为完整对象信息。
status字符串结算状态。取值为 available 或 pending。

错误响应​

HTTP 状态错误类型代码解决方案
404invalid_request_errorresource_missing验证 txn_ ID 是否存在于当前环境中（生产模式或测试模式）。

404: Not Found

Response
{
  "error": {
    "type": "invalid_request_error",
    "code": "resource_missing",
    "message": "No such balance transaction: txn_invalid9999",
    "param": "id"
  }
}

幂等性与对账​

  • 幂等性不适用于读取操作。
  • 在财务对账中，通过汇总所有交易的 net 值来计算总净结算金额，而不是直接跟踪各项费用。

相关端点​

  • 查询余额：查看已结算和待处理的货币金额。
  • 资金流动概念：费用计算及结算时间线的详细说明。
