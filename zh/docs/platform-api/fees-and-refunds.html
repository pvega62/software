领养费用、押金及退款政策

Blüdhaven Pets的领养申请包含四项费用项目，每项费用都有相应的退款规则。门店工作人员和结账系统必须正确应用相应的规则；否则，月底时将无法完成费用对账。

应用程序成本项目​

项目名称字段名数量是否可退款
安置费placement_fee_cents15000元是，需在资格窗口期内支付
预订押金reservation_deposit_cents5000元不需要
市政许可证license_fee_cents2500元已转让给动物管理部门
零售用品supplies_subtotal_cents价格不定只限未开封的商品

该平台对每次动物被领养收取一次安置费用。如果一个家庭领养了两只动物，则需要支付两次安置费用，因为每只动物都需要单独承担接收、接种疫苗以及植入微芯片的费用。

预订押金​

支付50美元的预订押金可将动物的暂留时间从30分钟延长为预定取动物时间。该押金在任何情况下均不可退还，其用途是用于支付暂时将动物从领养区移出的费用，并防止那些可能影响其他领养者的投机性预订行为。

预订押金是可以转移的。如果领养者在14天内更换领养的动物，平台会将原押金应用于新的领养申请中。请使用DELETE /adoptions/holds/{holdId}取消旧的暂留安排，然后拨打POST /adoptions/holds联系新动物的领养流程，并在notes中提供原申请的编号。工作人员会在审核过程中将押金退还给领养者。

押金没收

如果领养者错过了预定的取动物时间，在24小时的宽限期过后，押金将被没收。动物将重新被放入待领养状态（AVAILABLE），原领养申请也会转为待处理状态（CANCELLED_NO_SHOW）。

市政许可费用​

在报告中需明确这一点：许可费用会显示在领养申请的总费用中，但不计入可退还的收入范围内。

退款资格期限​

该平台从应用程序中的 submitted_at 开始计算窗口时间，而非从数据采集日期开始计算。

| 窗口 | 应用程序状态 | 是否已退款 | 布吕德黑文市收取25美元的许可证费用。布吕德黑文宠物公司代表市政府收取该费用，并每月上缴。该费用绝不会通过API退还给领养人。当领养被取消时，平台会向动物管制部门注销许可证记录，并通过市政府（而非支付处理商）发放退款。 |---|---|---| | 在 submitted_at 之后的 0 至 48 小时内 | 提货前 | 需支付安置费用以及未开封的零售用品费用。 | | 在 submitted_at 之后的 48 小时至 7 天内 | 提货前 | 需支付安置费用的 50% 以及未开封的零售用品费用。 | | 在取货后，无论何时； | 无论商品处于何种状态； | 该订单将无法退款，应办理退货手续。 | | 医学原因导致的资格取消 | 任何州 | 需支付全部安置费用（包括押金） |

医疗不合格情况的处理：​

当兽医在动物被安置后、被领养前发现存在导致取消资格的情况时，平台将豁免所有时间窗口规则。API 将退还申请的全部金额（包括押金），并将该动物状态变更为 MEDICAL_QUARANTINE。

使用 POST /refunds 和 reason: MEDICAL_DISQUALIFICATION 触发此处理流程。该请求需要一个结果为“证书已审核通过”的 veterinary_record_id。

退款原因​

退款流程：根据具体情况选择相应的退款理由（由“时间表”字段决定）。

reason 接受四个值。具体使用哪个值由窗口表格来决定。

reason说明返回内容
CANCELLATION_INSIDE_48H如果领养者在领取前的48小时内取消领养，需支付安置费用以及未使用的物资费用。安置费用加上未开封的物资费用
CANCELLATION_AFTER_48H如果领养者在领取物品前的48小时内取消领养，需支付安置费用的50%以及所有未开封的物资费用。安置费用的 50% 加上未开封的物资费用
RETAIL_SUPPLIES_ONLY只有采购的物资被退回未开封的物资
MEDICAL_DISQUALIFICATION兽医在接动物前发现其存在不符合领养条件的健康问题总费用（已包含押金）；需要veterinary_record_id（进一步确认或处理）。

发放退款​

Issue a partial placement-fee refund
curl -X POST https://api.bludhavenpets.com/v1/refunds \
  -H "Authorization: Bearer $BLUDHAVEN_TOKEN" \
  -H "Idempotency-Key: 8f14e45f-ceea-467f-a1c2-3d4e5f607182" \
  -H "Content-Type: application/json" \
  -d '{
    "application_id": "app_2026_1188",
    "amount_cents": 10000,
    "reason": "CANCELLATION_AFTER_48H",
    "refund_retail_supplies": true
  }'

回复内容明确了“安置费”与“物资费用”之间的区分。

退款时间​

信用卡退款需三个至五个工作日到账。商店积分则会立即到账。POST /refunds 需要 admin:adoptions 权限范围，因此资金划转前需由顾问批准该请求。

settles_at 中的时间戳反映的是处理系统的预估时间。请参考 status 的信息，切勿根据实际经过时间自行判断；在关闭申请前，请务必等待 refund.settled 微服务触发的通知。

幂等性​

退款请求必须包含 Idempotency-Key 参数。如果使用相同的参数重新提交请求，系统会返回原始的退款信息（状态为 200），而不会再次进行退款。参数的有效期为24小时。

仅在金额、原因或申请内容发生变化时才发送新的密钥。如果使用相同的密钥但上传的内容不同，系统会返回错误信息（422 idempotency_key_reuse）。
