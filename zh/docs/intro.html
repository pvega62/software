Sweepy 工具的职位搜索功能说明​

Sweepy：该工具会查询求职者跟踪系统和招聘网站，并根据求职者的简历对职位信息进行排名。Sweepy 是一个开源项目，附带 14 页的文档资料，内容包括安装方法、配置设置以及数据导出（PDF 或 CSV 格式）。同时，它还介绍了用于执行搜索任务的 Model Context Protocol (MCP) 服务器。

入门指南​

  • 了解 Sweepy 的工作原理：解释 Sweepy 的功能、数据处理流程（共五个阶段），以及它如何评估求职者的简历质量。
  • 在 Windows、macOS 和 Linux 上安装 Sweepy：指导用户如何在这些操作系统上配置 Python 环境、Git 以及代码仓库。
  • 配置 Sweepy：可通过设置向导或 YAML 文件来构建搜索配置文件。
  • 首次运行 Sweepy：详细说明从创建搜索配置到查看搜索结果的全过程。

查看搜索结果​

  • 解读搜索结果：解析 PDF 格式的搜索结果展示方式、匹配成功率、申请者的评分信息，以及 CSV 格式的追踪数据列内容。
  • 简历与匹配分数：介绍简历的格式要求，以及从简历到匹配百分比的评分流程。
  • Sweepy如何对简历进行评分：解释每个评分百分比背后的匹配逻辑，以及评分系统无法衡量的因素。

“文档即代码”的工作流程​

  • 使用VS Code和Antigravity工具以Markdown及MDX格式编写文档。
  • 通过Vale工具对文档的排版和风格进行校验。
  • 使用 DeepL 和 Lara 进行国际化与翻译工作。
  • 使用 Mermaid 绘制系统架构图。
  • 随着每次产品发布，为命令行工具及其管理控制台（MCP）服务器编写相应的文档。
  • 通过 Git 和 GitHub 实现版本控制及代码协作审查。
  • 利用 Postman 和 Swagger/OpenAPI 探索并验证 API 接口。
  • 使用共享模式和 Scalar 工具编写 OpenAPI 3.1 合同，并将其渲染为交互式界面。
  • 通过 Docusaurus 实现持续部署。

技术栈​

  • Docusaurus：用于生成静态网站、导航侧边栏以及多语言版本。
  • VS Code：作为 Markdown 和 MDX 编写的主要编辑工具。
  • Postman：用于验证 API 端点并生成请求/响应示例。
  • OpenAPI 3.1 和 Scalar：用于定义 Blüdhaven Pets 的接口规范，并将其以交互式方式呈现。
  • Vale: 用于检查技术文档是否符合 Google 开发者文档指南的标准。
  • Git 和 GitHub: 用于跟踪代码库中的变更，并负责网站的部署。
  • Mermaid: 用于生成流程图和数据管道图。
  • Python 和 MCP: 负责运行 Sweepy 清理工具，以及将其与人工智能助手连接的工具服务器。
  • DeepL 和 Lara: 用于将文档自动翻译成其他语言。

每个页面的源文件（Markdown 或 MDX 格式）都存储在同一个代码库中；生成的渲染结果会与原始文本进行对比。

所有示例文档都遵循相同的开发流程：从研究、起草到测试、审核，最后发布。
