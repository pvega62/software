安装 Sweepy

在本教程中，您将在电脑上安装 Sweepy。首先需要三个工具：

  1. Python：用于运行 Sweepy 的引擎。
  2. Git：用于从互联网下载 Sweepy 的代码。
  3. pip：用于安装 Sweppy 所需的额外库。Windows 和 macOS 的官方安装程序中已包含 pip；Linux 发行版则通过系统包管理器添加 pip。
备注

本指南会详细指导从未使用过终端的用户完成整个安装过程。如果您已经安装了 Python 3.10 或更高版本以及 Git，请直接跳到 步骤 3。

步骤 1：打开终端​

终端（也称为命令提示符）是一个基于文本的窗口，在这里您可以输入命令。您需要在这里输入指令来操作电脑，而不是选择图标。

  • Windows
  • macOS
  • Linux

按下 Windows 键，输入 PowerShell，然后选择 Windows PowerShell。

Terminal
Windows PowerShell
Copyright (C) Microsoft Corporation. All rights reserved.

PS C:\Users\YourName>

按下 Command + Space，输入 Terminal，然后按 Enter。

Terminal
Last login: Mon Oct 19 14:40:23 on ttys000
yourname@MacBook-Pro ~ %

在大多数 Linux 发行版中，按下 Ctrl + Alt + T 可以打开终端窗口。

Terminal
yourname@ubuntu:~$

终端提示符末尾会有一个闪烁的光标，表示它已准备好接收命令。

步骤 2：检查并安装 Python​

Sweepy 需要 Python 3.10 或更高版本。请检查您是否已经安装了该版本。

在终端中输入以下命令并按 Enter：

Terminal
python --version

在 macOS 和 Linux 上，该命令为 python3 --version。

如果显示 “Python 3.10.x” 或更高版本，说明您已经安装了 Python，请直接跳到 步骤 3。

如果您看到类似 'python' is not recognized 的错误信息，或者系统版本低于 3.10，请按照以下安装步骤进行操作。

  • Windows
  • macOS
  • Linux
  1. 访问 Windows 版本的 Python 下载页面。
  2. 选择最新的 64 位 Windows 安装程序 下载链接。
  3. 运行下载的文件。
  4. 此步骤非常重要：在安装程序的第一个界面中，选中底部标记为 “Add python.exe to PATH” 的复选框。该复选框会将 Python 添加到系统的路径中，以便终端能够找到它。
  5. 选择 Install Now（立即安装），等待安装完成。

然后在新的终端窗口中再次确认安装结果。

Terminal
PS C:\Users\YourName> python --version
Python 3.13.1
警告

如果您跳过了“将 python.exe 添加到 PATH”这一步，终端将无法识别 python 命令。请卸载 Python，然后重新安装（并确保选中相应的安装选项）。

  1. 访问 macOS 版本的 Python 下载页面。
  2. 下载最新的 macOS 64 位通用版安装程序。
  3. 打开下载的 .pkg 文件，按照安装提示进行操作。

然后在新的终端窗口中再次确认安装结果。

Terminal
yourname@MacBook-Pro ~ % python3 --version
Python 3.13.1

在终端中运行以下两条命令：

Terminal
sudo apt update
sudo apt install python3 python3-pip python3-venv
提示

在 Fedora 或 Red Hat Enterprise Linux 系统上，将 apt 替换为 dnf（即运行 sudo dnf install python3 python3-pip）。

然后在新的终端窗口中再次确认安装结果。

Terminal
yourname@ubuntu:~$ python3 --version
Python 3.12.3

在 Windows、macOS 和 Linux 系统中，所有与 Python 版本相关的操作（如使用 version 命令）的格式都是相同的。请关闭终端，重新打开它，然后运行 version 命令。如果显示的版本号为 3.10 或更高，说明 Python 已经安装完成并可以使用了。

第三步：下载 Sweepy​

下载 Sweepy 的源文件

选择一种下载方式：可以使用下面介绍的 Git 方法，或者从 Sweepy 的发布页面 下载 ZIP 文件。

Git 会将项目文件复制到您的电脑上，并记录其版本历史；这些历史记录有助于 Sweepy 自动更新。以下步骤均基于 Git 进行操作：

  • 使用 Git 下载： 运行 sweepy --update 命令或使用工具箱中的更新工具来获取最新版本。
  • 使用 ZIP 文件下载： 下载 ZIP 文件，解压后再次运行 pip install -e . 命令以安装 Sweppy。不过请注意：ZIP 文件不包含 Git 版本历史记录，因此无法自动更新。
  • 文件夹名称： Git 会创建一个名为 sweepy 的文件夹；ZIP 文件解压后会生成一个名为 sweepy-main 的文件夹，因此请在后续步骤中调整 cd 命令的相关参数。

如果您只是临时使用 Sweepy，可以选择 ZIP 文件；如果您打算长期使用它，请选择 Git 下载方式。

如果遇到错误，请 提交问题 并附上您实际运行的命令内容。

首先检查是否已经安装了 Git：

Terminal
git --version

如果看到类似 git version 2.45.1 的版本号，说明 Git 已经安装完毕。

如果看到错误信息，请先安装 Git：

  • Windows
  • macOS
  • Linux
  1. 访问 git-scm.com/download/win。
  2. 下载并运行安装程序。
  3. 接受所有默认设置并点击 “Install”。
  4. 关闭终端，重新打开它，然后确认：
Terminal
PS C:\Users\YourName> git --version
git version 2.45.1

运行此命令，macOS会提示您安装Xcode命令行工具（其中包含Git）。

Terminal
yourname@MacBook-Pro ~ % git --version
xcode-select: note: install requested for command line developer tools

按照屏幕上的提示进行安装，然后再次运行git --version。如果出现版本号，说明Git已安装完成。

Terminal
yourname@ubuntu:~$ sudo apt install git

接下来，请确认安装结果。

Terminal
yourname@ubuntu:~$ git --version
git version 2.45.1

现在，通过运行相应命令来下载Sweepy软件。

Terminal
git clone https://github.com/pvega62/sweepy.git

此操作会在您的电脑上创建一个名为sweepy的新文件夹。请进入该文件夹。

Terminal
cd sweepy
提示

Git会将新文件夹放置在您运行命令时终端所指向的目录中；在Windows系统中，还会在C:\Users\YourName\文件夹内打开一个新的PowerShell窗口。

第4步：安装依赖库​

Sweepy需要一些额外的库才能正常运行：

  • pymupdf: 用于读取并提取简历PDF文件中的文本内容。
  • python-docx: 用于读取和转换 .docx 格式的简历文件。
  • 可以通过一条命令安装所有依赖库：
  • 在Python下载和安装各个库的过程中，屏幕上会显示进度条。当光标返回时，安装即已完成。
  • reportlab: 用于生成包含可点击链接的格式化 PDF 报告。

  • 验证安装结果​

  • 运行以下命令，确认所有依赖库都已正确安装：
  • pandas: 用于处理抓取到的工作数据，并生成 CSV 格式的电子表格文件。
  • mcp 和 anyio: 运行可选的 Model Context Protocol 服务器，该服务器用于将 Sweepy 与 AI 助手连接起来。
Python 3.13

如果您使用的是 Python 3.13, 请先安装 Microsoft C++ Build Tools, 并选择 “Desktop development with C++” 工作负载。由于 Python 3.13 是较新的版本, 某些包（如 pymupdf）可能需要通过源代码进行编译, 因此需要这些工具。在 Python 3.12 及更低版本上可以跳过此步骤。

Sweepy的自动化测试覆盖了Python 3.10到3.12版本。这些版本是目前最稳定、最适合使用的Python版本。

通过一个命令安装所有软件包：

Terminal
pip install -e .

这个命令会自动安装所有所需的依赖库，并在您的 Python Scripts 文件夹中创建一个名为 sweepy 的文件。请再次打开终端，以便 PATH 能识别到新的文件夹结构。从现在开始，请使用 sweepy --run 命令代替 python swee.py --run 命令来执行相关操作；无论从哪个文件夹执行，都可以使用这两个命令。

当 Python 下载并安装每个包时，文本会自动滚动显示。当光标回到屏幕顶部时，安装过程就完成了。

提示

当您尝试使用 pip 时，是否收到了“命令未找到”的错误？请尝试使用 pip3 install -e .。在某些系统中，Python 3 使用 pip3 作为该命令的名称。

验证您的安装是否完成​

执行这个快速检查，以确认所有软件都已正确安装：

Terminal
sweepy --version

如果您的 shell 无法找到 sweepy，请重新打开终端或运行 python swee.py --version。此时您会看到相关提示信息。

Terminal output
Sweepy v3.1.0
Python 3.13.1 | pymupdf 1.28.2 | reportlab 5.0.1
Ready to sweep.

如果出现该提示信息，说明 Sweepy 已经准备就绪。不过请注意：不同设备上的版本号可能有所不同。Sweepy 会从 VERSION 文件中读取版本信息，并通过 pip 安装与您的 Python 版本相匹配的包。

第二行会显示 pymupdf 和 reportlab 的具体版本号。
