认识 Sweepy

Sweepy 可跨多个招聘平台自动执行职位搜索。一条命令即可收集空缺职位并读取你的简历。随后 Sweepy 将每个职位与你的技能比对评分，并生成每日匹配报告。

Sweepy 通过配置文件适配你的求职方向。你可选择律师助理、分析师或协调员等职位名称。

认识 Alex​

本指南全程跟随 Alex 一起操作。Alex 刚刚获得政治学学位，希望在纽约市寻找律师助理和法律助理职位。Alex 从未使用过终端，没有写过代码，甚至没打开过 YAML 文件。

本指南带你与 Alex 从安装配置一路走到全自动职位扫描。Sweepy 会用真实简历为最匹配的职位评分，并生成一份可每日使用的 PDF 目录。

备注

使用 Sweepy 无需任何编程经验。本指南从零讲解每一个步骤。

功能​

Sweepy 提供快速找到下一份工作所需的全部能力：

  • 多平台搜索扫描 Greenhouse、Ashby、Lever 和 Workable 这四套承载公开招聘网站的申请人跟踪系统。它还会读取 Built In New York City 招聘网站，并在你启用后读取 LinkedIn、Indeed、Glassdoor 和 ZipRecruiter 职位源。
  • 智能简历评分读取你的 PDF 或 Word 简历并提取技能。Sweepy 将每个职位分配到一条简历轨道，再按该轨道的简历评分。引擎运行时不需要 API 密钥或付费服务。
  • 失效链接过滤在你看到职位之前逐一检查。当链接返回已失效状态、soft-404 页面或连接错误时，Sweepy 丢弃该职位。限流、机器人拦截和服务器错误会保留职位并标记为 unverified，仍写入报告。
  • 每日 PDF 报告将结果汇编成高密度 PDF 目录。每页默认容纳六张卡片，含可点击链接、公开薪资区间和彩色徽标。
  • 流水线跟踪表导出包含全部卡片字段外加 1,000 字符职位摘录的 CSV，并另附供其他工具使用的 JSON 文件。CSV 末尾是求职跟踪列，涵盖投递日期、状态、面试阶段、录用、跟进日期、联系人和备注。同一配置文件的后续扫描会沿用你填写的值。你可在 Microsoft Excel、Google Sheets 或 Notion 中打开 CSV。PDF 适合按排名通读一遍，并可直接点击申请链接。表格记录整条流水线，包括超出 PDF 卡片上限的职位。

工作原理​

一次成功的扫描包括五个阶段：

  1. 加载配置文件。 Sweepy 读取配置文件，其中包含你的职位名称、地点和简历路径。
  2. 发现职位。 Sweepy 向招聘平台和职位源查询匹配的职位。
  3. 验证链接。 Sweepy 检查每个链接，丢弃返回已失效状态、soft-404 页面或连接错误的职位。链接无法验证的职位保留在本轮扫描中，标记为 unverified。
  4. 匹配评分。 Sweepy 解析你的 PDF 或 Word 简历，为每个职位计算加权匹配度。
  5. 生成报告。 Sweepy 将结果汇编为带样式的 PDF 以及 CSV 或 JSON 导出文件。

限制​

Sweepy 按设计只覆盖就业市场的一小部分。通过 模型上下文协议（MCP）服务器 接入语言模型后，模型接管机械化的默认行为。当独立向导列与 MCP 列描述相同行为时，该限制同时影响 Sweepy 的两个版本。

限制独立向导搭配 MCP 服务器变通方法
匹配度统计简历与职位之间共有的关键词。卡片显示 KEYWORD OVERLAP。submit_judgments 自行设定百分比，卡片显示 MATCH。在扫描设置板块提高 resume.keywords_weight，并手动添加 resume.synonyms 组。向导不会代你处理同义词。
薪资与福利打印从招聘网站结构化字段或职位文本中读取的公开薪资区间。福利一律显示 Not disclosed。submit_judgments 可提供这两项取值。在 CSV 导出文件里填写 comp 和 benefits 列。
徽标与应用格式依据引擎内固定的关键词列表推断 Amber 或 Slate。submit_judgments 覆盖这两个字段。信任徽标前，先对照线上职位核实。
摘要、任职要求与申请建议提取职位文本并与你的简历比对评分。submit_judgments 重写这些内容，render_report 接受自定义策略指南。在 CSV 或 JSON 导出文件中编辑相应字段。
简历文本读取 PDF 和 Word 文件的文本层。扫描件提取不到可供评分的内容。模型通过视觉识别读取扫描件并传入技能。在 resume.must_have_skills 中列出技能。向导的必备技能步骤可完成这项操作。
覆盖范围查询 41 个指定的公司招聘网站，外加 5 个 Built In NYC 分类。import_jobs 可追加任意来源的职位。向 sources.greenhouse.boards、sources.ashby.orgs、sources.lever.companies 或 sources.workable.slugs 添加目标。
职位源默认关闭，需你手动启用。每个职位源按职位名称返回最近 3 天内最多 25 条职位。使用同一开关。在 sources.jobspy 下切换网站，例如 glassdoor。
链接检查连接错误会剔除该职位。同上。保留 JSON 导出文件，并在公司官网复查重点目标。
PDF 长度PDF 最多 24 张卡片。同上。设置 report.max_cards。值为 0 时取消上限，CSV 和 JSON 导出文件会列出所有职位。
抓取器脆弱性招聘网站更改页面结构或收紧限流时会失效。同上。先用 --debug 运行，再用 --logs 列出源错误。源错误不会中断扫描。

指南路线图​

本指南包含四个步骤：

  1. 安装 Sweepy 到你的电脑。参见安装。
  2. 配置个性化的职位搜索配置文件，例如 Alex 的纽约市律师助理配置文件。参见设置 Sweepy。
  3. 运行第一次自动职位扫描，观察执行过程。参见首次扫描。
  4. 阅读自定义 PDF 报告，理解匹配度、徽标和申请策略。参见理解结果。
