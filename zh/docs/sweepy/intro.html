了解 Sweepy

Sweepy 可自动在多个招聘平台上为您进行求职。只需一条指令，即可收集空缺职位并读取您的简历。随后，Sweepy 会根据您的技能对每个职位进行评分，并生成每日匹配报告。

您可通过配置文件让 Sweepy 适应您的职业发展路径。选择职位名称，例如“律师助理”、“分析师”或“协调员”。

认识 Alex​

在本指南中，您将跟随 Alex 的脚步。Alex 刚刚获得政治学学位，希望在 纽约市 寻找 律师助理 和 法律助理 职位。 Alex 从未使用过终端、编写过代码，甚至_连 YAML 文件都没见过_。

本指南将带领您和 Alex 从初始设置到实现完全自动化的职位筛选。Sweepy 会根据真实的简历对最匹配的职位进行评分，并生成一份您可以每天使用的 PDF 目录。

备注

使用 Sweepy 无需任何编程经验。本指南将从零开始详细讲解每个步骤。

功能​

Sweepy 为您提供更快找到下一份工作的所有必要工具：

  • 多平台搜索：扫描 Greenhouse、Ashby、Lever 和 Workable 这四大拥有公开职位板的应聘者跟踪系统。它还会读取 Built In New York City 职位板，并在您开启相应功能后，同步 LinkedIn、Indeed、Glassdoor 和 ZipRecruiter 的职位源。
  • 智能简历评分：读取您的简历 PDF 或 Word 文件并提取技能信息。Sweepy 会将每条职位发布与特定简历路径匹配，然后根据该路径中的简历对其进行评分。该引擎运行无需 API 密钥或付费服务。
  • 失效链接过滤功能会在您查看前检查每条招聘信息。当链接返回“页面不存在”状态、软404页面或连接错误时，Sweepy会剔除该招聘信息。若因速率限制、机器人屏蔽或服务器错误导致无法获取，该招聘信息仍会保留在您的报告中，并标记为 unverified。
  • 每日 PDF 报告 将您的结果汇总成一份信息密集的 PDF 目录。每页默认显示六张卡片，包含可点击的链接、公开的薪资范围以及颜色编码的徽章。
  • 招聘流程跟踪电子表格 导出包含所有卡片字段以及 1,000 个字符职位摘要的 CSV 文件，同时提供供其他工具使用的 JSON 文件。CSV 文件末尾设有职位跟踪列，包括申请日期、状态、面试阶段、录用通知、跟进日期、联系人及备注。 Sweepy 会将您输入的值保留下来，供后续对同一个人资料的扫描使用。您可以在 Microsoft Excel、Google 表格或 Notion 中打开该 CSV 文件。PDF 文件提供一次按排名排序的浏览体验，并包含可点击的申请链接。电子表格则记录了整个招聘流程，包括超出 PDF 卡片容量限制的职位。

工作原理​

一次成功的扫描包含五个阶段：

  1. 加载您的个人资料。 Sweepy 会读取您的配置文件，其中包含您的职位名称、工作地点和简历路径。
  2. 发现职位。 Sweepy 会查询招聘平台和职位信息源，寻找匹配的招聘信息。
  3. 验证链接。 Sweepy 会检查每个链接，并剔除返回“已失效”状态、软 404 页面或连接错误的职位。链接无法验证的职位仍保留在处理流程中，并标记为 unverified。
  4. 计算匹配度。 Sweepy 会解析您的简历 PDF 或 Word 文件，并为每个职位计算加权匹配百分比。
  5. 生成报告。 Sweepy 将结果汇总为格式化的 PDF 文件，并导出为 CSV 或 JSON 格式。

限制​

Sweepy 设计上仅覆盖了就业市场的一个狭窄领域。通过 模型上下文协议 (MCP) 服务器 将其与语言模型配对后，该模型将接管机械性的默认操作。 当“Solo 向导”和 MCP 列显示相同的行为时，该限制将同时影响 Sweepy 的这两个版本。

限制Solo 向导配合 MCP 服务器解决方法
匹配分数统计简历与职位描述中共同出现的关键词数量。卡片显示为 KEYWORD OVERLAP。submit_judgments 自行设定百分比，卡片显示为 MATCH。该模型会按照应聘者跟踪系统（ATS）解析简历的方式对解析后的简历进行评分。从 Sweep 设置 板块提高 resume.keywords_weight 的权重，并手动添加 resume.synonyms 组。向导将同义词的处理交由您自行决定。
薪资与福利显示公开的薪资范围，该范围来自结构化招聘信息字段或职位发布文本。 福利栏始终显示为 Not disclosed。submit_judgments 会提供其中任一值。在 CSV 导出文件中填充 comp 和 benefits 列。
徽章和申请格式根据引擎中的固定关键词列表推断为 Amber 或 Slate。submit_judgments 会覆盖这两个字段。在采信徽章信息前，请与实时职位发布内容进行核对。
摘要、要求及申请提示从职位发布中提取文本，并根据您的简历进行评分。submit_judgments 会重写这些内容，而 render_report 支持自定义操作手册。请在 CSV 或 JSON 导出文件中编辑这些字段。
简历文本读取 PDF 和 Word 文件的文本层。扫描文件将无法获取任何内容进行评分。模型通过视觉技术读取扫描件，并将技能信息传递进来。在 resume.must_have_skills 中列出您的技能。向导中的“必备技能”步骤涵盖了这一点。
覆盖范围查询 41 个指定公司招聘板以及 5 个“Built In NYC”类别。import_jobs 可从任何来源追加职位。将目标添加到 sources.greenhouse.boards、sources.ashby.orgs、sources.lever.companies 或 sources.workable.slugs 中。
职位信息源默认关闭，需手动启用。每个信息源最多返回过去 3 天内每个职位标题下的 25 条招聘信息。同上开关。在 sources.jobspy 下切换网站，例如 glassdoor。
链接验证若出现连接错误，该职位信息将被剔除。同上。保留 JSON 导出文件，并在公司网站上重新检查您的主要目标职位。
PDF 长度将 PDF 限制为 24 张卡片。同上。设置 report.max_cards。值为 0 时将取消限制，您的 CSV 和 JSON 导出文件将列出所有职位。
抓取器不稳定性当招聘平台更改标记语言或收紧速率限制时，抓取器会失效。同上。先使用 --debug 运行，再使用 --logs 列出源错误。源错误绝不会中断抓取过程。

指南路线图​

本指南将分四个步骤进行：

  1. 在您的计算机上安装 Sweepy。请参阅 安装。
  2. 配置个性化的职位搜索配置文件，例如 Alex 的纽约市律师助理配置文件。请参阅 设置 Sweepy。
  3. 运行您的首次自动化职位搜索，并观察其运行过程。请参阅 首次搜索。
  4. 阅读您的自定义 PDF 报告，了解匹配分数、徽章和申请策略。请参阅 理解结果。
Sweepy 的托管位置

Sweepy 是开源软件。 阅读源代码，在问题中报告故障测试板，或从 发布页面下载 ZIP 文件。GitHub 允许您无需账户即可访问以上三项内容。
