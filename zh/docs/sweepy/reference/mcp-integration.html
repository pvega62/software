通过 MCP 从 AI 助手运行 Sweepy

AI 助手可以为您运行 Sweepy。您只需描述所需的角色，助手便会代表您调用 Sweepy，而无需您手动输入终端命令。

该连接使用 模型上下文协议 (MCP)。 MCP 是一种通用语言，允许 AI 助手使用您计算机上安装的工具。Sweepy 在 server.py 中内置了 MCP 服务器。它通过 stdio 传输协议运行，因此仅在本地与您的客户端通信，不会打开网络端口。

备注

MCP 是可选的。即使不使用任何 AI 助手，Sweepy 也能完全通过终端命令运行。服务器在同一引擎之上添加了一层对话功能。它还为 Sweepy 原本执行的确定性评分和过滤过程，融入了模型的判断力和智能。

连接前准备​

  • 完成 安装，确保 Python 和 Sweepy 的依赖项已就位。mcp 和 anyio 包已包含在 requirements.txt 中。
  • 记下 server.py 的绝对路径。将该路径粘贴到客户端的配置中。
  • 修改 AI 客户端的 MCP 配置后，请重启该客户端。

可用工具​

Sweepy 向您的助手提供了十二种工具。每种工具都会返回一个 JSON 有效载荷，并声明了只读、破坏性、幂等和开放世界等提示。

工具功能说明
create_profile根据 PDF 或 DOCX 格式的简历构建、验证并保存 YAML 个人资料。
run_sweep在后台运行五阶段处理流程，并存储确定性卡片。
get_sweep_status等待正在运行的扫描任务并报告其进度。
get_jobs返回当前会话中持有的卡片，按分数排序。
submit_judgments用您的助手的判断结果替换卡片中的确定性字段。
import_jobs追加助手在其他地方已验证的任务。
render_report将当前会话中的卡片渲染为 PDF 文件。
get_results从磁盘读取最新的扫描结果。
export_report根据现有扫描结果重新生成 PDF、PNG、CSV 或 JSON 文件。
clear_history清除某个配置文件中已报告的职位发布记录。
convert_document将受支持的文档转换为 PDF。
convert_docx将 DOCX 格式的简历转换为 PDF。

MCP 工具参考 提供了更详细的说明。其中列出了每个参数、默认值、有效负载以及行为提示。

选择职位搜索引擎​

当您省略 sources_config 时，create_profile 会启用内置的 JobSpy 和 ATS 引擎。它还会启用那些已成功安装且 具有有效默认设置的可选引擎。 该工具会返回 enabled_engines 和 engines_not_enabled， 以便您查看哪些引擎已运行，哪些仍需配置。

OpenRoles 仅搜索您列出的公司招聘板。在 启用该引擎前，请添加公司别名。Apify 可能会产生费用。如需使用，请自行启用。 Sweepy 不会自动安装可选包。您无需 在每次搜索时都选择引擎。仅当某个引擎需要 配置、需同意付费服务或存在搜索限制时，才需显式选择。

显式选择引擎时，请传递 sources_config。Sweepy 将保留该 选择，而非添加其他引擎。 以下 JSON 示例选定了两个引擎：

{
  "enabled": ["jobspy", "openroles"],
  "openroles": {"companies": ["figma", "stripe"]}
}

单次执行和混合工具流程​

Sweepy 支持两种运行模式。请根据您希望助手参与决策的程度选择合适的模式。

单次执行流程。 您的助手负责配置并运行所有操作，引擎根据简历关键词的重合度对每个职位进行评分。

create_profile -> run_sweep -> get_results -> export_report（可选）

混合有状态流程。 您的助手会在报告生成前审查每张卡片并给出自己的判断。

run_sweep -> get_jobs -> submit_judgments -> render_report

实时扫描在客户端超时后仍可继续运行。当 run_sweep 返回 sweep_status: "running" 时，请使用返回的 job_id 调用 get_sweep_status，直到其报告 completed 为止。然后继续执行 get_jobs。

:::提示 生成有效报告并不需要大型语言模型（LLM）。仅凭 run_sweep 工具即可根据确定性字段生成完整的卡片 PDF，这与终端扫描完全相同。 :::

每张卡片会显示以下两种评分标签之一：

  • NN% KEYWORD OVERLAP 来自确定性引擎。它将您的简历文本与每个职位发布进行比对。
  • NN% MATCH 来自您的助手。当您在调用 submit_judgments 时传入 match_pct 值，该标签便会出现。

get_jobs 返回 resume_documents，即每条简历轨道的解析文本，位于卡片旁边。您的助手会按照职位发布方 ATS 的解析方式对该文本进行评分，并将解析器可能遗漏的内容记录在 concerns 中。

验证并补充扫描结果​

将每次扫描结果视为初始集合，然后对照职位发布信息验证每条匹配结果。 在 run_sweep 之后，检查 skipped_sources 并报告来源错误。 使用 get_jobs 审查职位，然后在助手提交 LLM 判定之前，将每条职位发布信息与您的简历及 声明的偏好进行对比。

当您的助手具备网络或搜索工具时，请它通过 雇主的招聘页面或其 ATS 验证有潜力的职位。它还可以搜索 Sweepy 遗漏的相关职位，通过 import_jobs 添加经过验证且不重复的招聘信息，并使用 render_report 将 这些职位纳入报告。 您的助手绝不能编造 职位信息，也不可用猜测来填补缺失的职位细节。

当主机阻止访问、限制 请求频率或发生超时时，Sweepy 的 URL 检查器会将部分 URL 标记为未验证。403 或 429 状态码并不证明该职位已过期。 请尽可能 在可访问的雇主来源上确认该职位信息，否则将其视为 未验证。如果您的助手没有搜索工具，或者来源仍然无法访问， 请说明结果可能不完整。出现错误后，请避免在 设置未更改的情况下重复扫描。

连接到 Antigravity 或 Claude Desktop​

将 Sweepy 添加到客户的 MCP 配置文件中，该文件根据客户端的不同，命名为 mcp_config.json 或 claude_desktop_config.json：

mcp_config.json
{
  "mcpServers": {
    "sweepy": {
      "command": "python",
      "args": [
        "/path/to/sweepy/server.py"
      ]
    }
  }
}

将 /path/to/sweepy 替换为您 Sweepy 文件夹的绝对路径，然后重启客户端。注册完成后，您可以像这样分配任务：

  • “为 Alex 创建一个 Sweepy 用户档案，用于搜索纽约地区的远程技术撰稿人职位。简历位于 path/to/resume.pdf。”
  • “使用该撰稿人档案运行一次搜索，并显示前 5 个匹配结果。”
  • “根据上次 pedro_writer 扫描结果重新生成 PDF，并将其保存到桌面。”
  • “将 path/to/notes.md 转换为 PDF，并保存到原始文件旁边。”
在 Sweepy 文件夹外写入文件

默认情况下，所有写入工具都位于您的 Sweepy 文件夹内。除非将 SWEEPY_ALLOW_EXTERNAL_WRITES 环境变量设置为 1，否则保存到桌面的请求将失败。

连接到 VS Code​

VS Code 无需额外扩展即可连接到 MCP 服务器：

  1. 打开命令面板并运行 MCP: Add Server。
  2. 选择 Command (stdio)，然后将命令输入为 python。将其参数设置为 server.py 的绝对路径。
  3. 将服务器命名为 sweepy，然后选择配置目标位置。
  4. 确认 Sweepy 工具已出现在聊天面板中，然后从该处调用它们。

对于工作区范围内的文件，请将 .vscode/mcp.json 添加到项目中。VS Code 格式使用顶级 servers 对象：

.vscode/mcp.json
{
  "servers": {
    "sweepy": {
      "type": "stdio",
      "command": "python",
      "args": [
        "/path/to/sweepy/server.py"
      ]
    }
  }
}

安装 /sweepy 技能​

Sweepy 为 Copilot CLI、Claude Code、Antigravity 以及其他支持读取技能的命令行工具提供了 /sweepy 技能。请将打包好的文件夹复制到您所用工具的技能目录中：

终端
cp -r skills/sweepy ~/.claude/skills/sweepy   # 根据您工具的技能路径进行调整

注册上一节中提到的 MCP 服务器，然后重启您的工具。该技能记录了三个核心流程：

  • 通过调用 create_profile，然后调用 run_sweep 来启动新的抓取任务。
  • 查看抓取结果：调用 get_results 获取顶级匹配项和操作手册，或调用 get_jobs 获取完整的卡片集。
  • 将结果导出为 CSV 文件：调用 export_report 并指定 formats=["csv"]。

该技能还涵盖了不支持 MCP 的命令行工具的备用方案：

终端
sweepy --setup # 交互式配置文件向导
sweepy --profile profiles/your_profile.yaml
sweepy --docx resume.docx # 将 DOCX 格式的简历转换为 PDF
sweepy --convert notes.md # 将任何受支持的文档转换为 PDF

通过一条提示语完成所有设置​

复制此提示并将其粘贴到任何 AI 命令行会话或 IDE 聊天窗口中：

在此机器上设置 Sweepy。请按顺序完成以下步骤：
1. 克隆或下载 Sweepy 代码库。
2. 在代码库根目录下运行 `pip install -r requirements.txt`。
3. 在 MCP 配置中将 `server.py` 注册为 stdio 服务器。使用 `python` 命令，并将参数指向 `server.py`。
4. 将 `skills/sweepy` 文件夹复制到 CLI 的技能目录中。
