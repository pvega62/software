运行第一次扫描

配置文件已创建完成。现在运行第一次自动职位扫描。

运行扫描​

在存放 sweepy 克隆的文件夹中打开终端。如果上一步之后关闭了终端，请重新打开并返回 sweepy：

终端
cd sweepy

用你的配置文件运行引擎：

终端
sweepy --profile profiles/paralegal_nyc.yaml

Sweepy 在 profiles 文件夹中自带 paralegal_nyc.yaml。也可使用简写形式：

终端
sweepy --run

--run 复用你上次保存的配置文件。

提示

如果你用向导构建了配置文件，Sweepy 会将其保存为 profiles/alex_rivera_paralegal.yaml。该名称由你的姓名和第一个职位名称组合而成。请使用该路径，而不是自带的预设。

一次扫描需要几分钟，具体取决于网络速度、缓存状态和平台数量。

扫描阶段​

阶段发生的事情需要关注的内容
配置文件加载读取你的 YAML 配置文件确认职位名称和地点与配置文件一致
发现职位向每个申请人跟踪系统平台发送搜索请求显示每个平台返回的原始职位数量
验证链接检查每个链接，剔除失效职位保留无法验证的职位并标记为 unverified
评分从简历中提取词条并为每个职位评分显示词条数量和分数区间
生成报告生成 PDF 卡片目录、CSV 导出文件以及任何其他已启用的格式显示引擎保存报告的文件路径
备注

当平台返回硬 404 或 soft-404 页面，或连接失败时，Sweepy 会删除该职位。 限流、机器人拦截、临时服务器错误和超时不能说明职位的真实状态。 这些情况返回 401、403、408、425、429、500、502、503 或 504，或完全没有响应。 Sweepy 保留该职位并标记为 unverified。

找到你的文件​

扫描结束后，打开 Sweepy 安装目录中的 results 文件夹。

终端
Get-ChildItem results

该目录显示带今天日期和时间戳的文件。文件名以 24 小时制记录运行时间。Windows 按本地时区显示文件时间，因此钟点值可能相差几小时：

终端输出
    Directory: C:\Users\Alex\sweepy\results

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a---          10/21/2026 1:06 AM          19065 paralegal_nyc_2026-10-21-050656.pdf
-a---          10/21/2026 1:06 AM         215694 paralegal_nyc_2026-10-21-050656.csv
在 Windows 上快速打开

在文件资源管理器中双击该 PDF 文件，或在终端中运行以下命令立即打开：

终端
start results\paralegal_nyc_2026-10-21-050656.pdf

每日运行扫描​

Sweepy 支持每日扫描。每天早晨运行同一命令即可捕获新职位：

终端
sweepy --run

每次发现新职位的运行都会在文件名中标记日期和时间，因此新一轮不会覆盖之前的结果。没有新职位时，该次运行打印 No new postings since your last sweep，且不改动 results。随着时间推移，results 文件夹会积累完整的求职历史。

自动执行每日扫描

在 Windows 上，你可以创建计划任务，每天上午 8:00 运行扫描。在 macOS/Linux 上，使用 cron 作业。命令行参考 介绍这两种方法。
