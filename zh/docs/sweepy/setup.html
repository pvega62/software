配置 Sweepy

您已安装 Sweepy！现在需要创建一个配置文件。

配置个人资料会向 Sweepy 指定需要查找的职位以及用于评估简历的标准，同时还会设置您的目标工作地点。

个人资料是一个 YAML 格式的小型文本文件。YAML（发音与“camel”押韵）通过缩进、冒号和换行来组织数据。 您无需编写代码：只要能读懂购物清单，就能读懂 YAML。

方案 A：运行交互式设置向导​

设置向导会根据您的简单回答生成一个可用的配置文件。它会在问卷调查之前打开搜索启动平台，并为您生成配置文件。

运行以下命令：

终端
sweepy --setup

向导会先显示其标题栏，随后显示启动面板。磁贴下方的状态行会显示已加载的配置文件，例如 当前配置文件：Alex Rivera / 4 个标题 / 已就绪。若尚未加载任何配置文件，则显示为 当前配置文件：未加载任何配置文件 / 请构建一个以开始。

启动平台显示六个磁贴。开始扫描 运行已加载的配置文件。加载配置文件 打开已保存的搜索。创建配置文件 启动新搜索并提出自然语言问题。扫描设置 控制排名、卡片和历史记录。Sweepy 工具箱包含配置文件编辑、引擎管理、聚合器管理、调试开关、帮助、最近日志、文档转换和更新功能。退出 Sweepy 会保存您的更改并关闭向导。

命令参考 列出了每个条目对应的参数。

方案 B：手动编辑配置文件​

若要直接输入设置，请复制示例模板，并在记事本或 VS Code 等纯文本编辑器中打开。请避免使用文字处理软件，因为它们会将直引号替换为花括号引号，从而导致 YAML 格式错误。

  • Windows
  • macOS / Linux
终端
copy config.sample.yaml profiles\alex_rivera_paralegal.yaml
notepad profiles\alex_rivera_paralegal.yaml
终端
cp config.sample.yaml profiles/alex_rivera_paralegal.yaml
open profiles/alex_rivera_paralegal.yaml    # macOS
# 或：nano profiles/alex_rivera_paralegal.yaml   # Linux

Alex 的配置文件​

向导会将此文件写入 profiles/alex_rivera_paralegal.yaml。 以 # 开头的行是注释：它们解释了每个设置，Sweepy 会忽略这些注释。对于您未填写的任何部分或设置，Sweepy 会自动填入默认值。

profiles/alex_rivera_paralegal.yaml
# ─────────────────────────────────────────────────
# Sweepy — 亚历克斯的法律助理个人资料
# ─────────────────────────────────────────────────

# 您的姓名（显示在 PDF 报告的页眉中）
name: "Alex Rivera"

# ─── 职位搜索设置 ──────────────────────────
search:
  # 列出您想要查找的所有职位名称。
  # 搜索引擎将同时搜索所有这些职位名称。
  titles:
    - "法律助理"
    - "法律助理"
    - "诉讼支持专员"
    - "法律秘书"

  # 目标城市和州。
  location: "纽约, NY"

  # 设置为 true 仅显示远程职位。
  # 设置为 false 显示远程、混合办公和现场职位。
  remote_only: false

  # 设置为 false 以排除混合办公职位。
  include_hybrid: true

  # 最低年薪筛选条件（可选）。
  # 保留为 0 或删除此行以跳过薪资筛选。
  min_salary: 65000

# ─── 简历设置 ─────────────────────────────
resume:
  # 您电脑上简历 PDF 文件的完整路径。
  # 在 Windows 系统中，请使用双反斜杠（\\) 或正斜杠（/）。
  path: "Alex_Rivera_Resume.pdf"

  # 计算匹配度时需优先考虑的必备技能。
  must_have_skills:
    - "Westlaw"
    - "LexisNexis"
    - "e-discovery"
    - "合同审查"
    - "法律研究"

  # 在职位评分时，关键词匹配的权重设置。
  # 1.0 = 标准权重。若希望
  # 技能的精确匹配在评分中占据主导地位，可将其调高至 2.0。
  keywords_weight: 1.5

# ─── 平台设置 ────────────────────────────
# 将各平台设置为 true 或 false 以启用或禁用该平台。
platforms:
  greenhouse: true
  ashby: true
  lever: true
  workable: true
  aggregators: false   # 免费招聘源，如 Remotive、Adzuna

  # 可选：自定义 ATS 端点或公司招聘域名
  custom:
    - name: "SmartRecruiters"
 domain: "smartrecruiters.com"
 enabled: true
    - name: "Breezy HR"
 domain: "breezy.hr"
 enabled: true

# ─── 导出设置 ──────────────────────────────
export:
  # 以逗号分隔的输出格式列表。
  # 选项：pdf, csv, json
  format: "pdf,csv"

  # 输出文件的保存位置。
  # 如果该文件夹不存在，引擎会自动创建。
  output_dir: "results"

:::注意 在 Windows 系统中： YAML 路径中请使用双反斜杠（\\）或正斜杠（/）。单个反斜杠（\）会破坏 YAML 格式。

✅ 正确："C:\\Users\\Alex\\Documents\\resume.pdf" 或 "C:/Users/Alex/Documents/resume.pdf"

❌ 错误："C:\Users\Alex\Documents\resume.pdf"

:::

使用预设配置文件​

Sweepy 在 profiles/ 文件夹中提供了可直接使用的配置文件预设。以下四个预设涵盖了常见的搜索场景：

文件职业路径搜索职位
paralegal_nyc.yaml法律律师助理、法律助理、诉讼支持专员、法律秘书
frontend_developer.yaml软件工程前端开发工程师、React 开发工程师、UI 工程师
tech_writer.yaml技术写作技术撰稿人、用户体验撰稿人、内容设计师
template_custom.yaml任何职业可自行替换的职位示例。每个配置均附有注释。

要使用预设配置，请在运行扫描时传入其文件名：

终端
sweepy --profile profiles/frontend_developer.yaml

:::提示 您可以创建任意数量的配置文件。针对不同的职位名称变体或目标城市，分别保存不同的配置文件。使用 --profile 参数即可即时在它们之间切换。 :::

方案 C：使用聊天助手实现自动化​

聊天助手可以为您构建配置文件并运行扫描。 Sweepy 内置了模型上下文协议（MCP）服务器，因此聊天助手可以直接读取和写入您的个人资料。 MCP 集成指南 介绍了 Antigravity、Claude Desktop 和 VS Code 的客户端配置，而 MCP 工具参考 列出了 Sweepy 的所有工具。

查阅所有设置​

配置参考 列出了个人资料支持的所有设置，从 debug 和 resume.tracks 到 sources.* 和 report.*。在编辑个人资料时，请保持该页面打开。

查看 Sweepy 搜索职位的位置​

默认情况下，Sweepy 会查询四个公开的求职者跟踪系统。该组包括 Greenhouse、Ashby、Lever 和 Workable。它还会查询纽约招聘网站 Built In NYC。 当您的个人资料启用聚合器时，来自 LinkedIn、Indeed、Glassdoor 和 ZipRecruiter 的数据将通过 python-jobspy 处理。

可选引擎可添加更多招聘平台。可选引擎包括 HireHunt、OpenRoles、JobDrop 和 Apify。OpenRoles 在运行前需要提供公司列表。Apify 需要 APIFY_TOKEN。JobDrop 与 JobSpy 的依赖项固定版本存在冲突。 设置向导中的 下载职位引擎 选项可安装这些引擎。

源代码与平台 页面介绍了可选引擎、种子文件、自定义平台条目以及兼容性注意事项。

您的配置文件已准备就绪。现在是时候运行首次扫描了。
