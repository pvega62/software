设置 Sweepy

Sweepy 已安装完成！接下来你需要一个配置文件。

配置文件告诉 Sweepy 要查找哪些职位，以及用哪份简历为这些职位评分。它还设定目标地点。

配置文件是一个 YAML 格式的小型文本文件。YAML 通过缩进、冒号和换行组织数据，读音与 camel 押韵。你无需编写代码：能看懂购物清单，就能看懂 YAML。

方式 A：运行交互式设置向导​

设置向导通过简单问答生成可用的配置文件。它先打开搜索启动台，随后进入问卷，并替你写入配置文件。

运行以下命令：

终端
sweepy --setup

向导先打印横幅，再显示启动台。板块下方的状态行显示已加载的配置文件，例如 Current profile: Alex Rivera / 4 titles / Ready。尚未加载任何配置文件时，该行显示 Current profile: none loaded / build one to start。

启动台显示六个板块。启动扫描运行已加载的配置文件。加载配置文件打开已保存的搜索。构建配置文件新建搜索，并用通俗问题收集信息。扫描设置控制排名、卡片和历史记录。Sweepy 工具箱包含配置文件编辑、引擎管理、聚合器管理、调试开关、帮助、最近日志、文档转换和更新。退出 Sweepy 保存更改并关闭向导。

命令参考 列出每个条目背后的命令行参数。

提示

随时可以重新运行 sweepy --setup 来新建或编辑配置文件。向导只写入它指定的文件，不影响其他配置文件。

要跳过启动台直接编辑已保存的配置文件，请加上 --profile 参数：

终端
sweepy --setup --profile profiles/paralegal_nyc.yaml

方式 B：手动编辑配置文件​

要直接输入设置，请复制示例模板，并用记事本或 VS Code 等纯文本编辑器打开。不要使用文字处理软件，它们会把直引号替换为弯引号，从而破坏 YAML。

  • Windows
  • macOS / Linux
终端
copy config.sample.yaml profiles\alex_rivera_paralegal.yaml
notepad profiles\alex_rivera_paralegal.yaml
终端
cp config.sample.yaml profiles/alex_rivera_paralegal.yaml
open profiles/alex_rivera_paralegal.yaml    # macOS
# or: nano profiles/alex_rivera_paralegal.yaml   # Linux

Alex 的配置文件​

向导将文件写入 profiles/alex_rivera_paralegal.yaml。以 # 开头的行是注释：它们解释各项设置，Sweepy 会忽略。你遗漏的任何区段或设置，Sweepy 都会填入默认值。

profiles/alex_rivera_paralegal.yaml
# ─────────────────────────────────────────────────
# Sweepy — Alex's Paralegal Profile
# ─────────────────────────────────────────────────

# Your name (appears in the PDF report header)
name: "Alex Rivera"

# ─── Job Search Settings ──────────────────────────
search:
  # List every job title you want to find.
  # The engine searches for ALL of these titles simultaneously.
  titles:
    - "Paralegal"
    - "Legal Assistant"
    - "Litigation Support Specialist"
    - "Legal Secretary"

  # Your target city and state.
  location: "New York, NY"

  # Set to true to ONLY see remote roles.
  # Set to false to see remote, hybrid, and on-site roles.
  remote_only: false

  # Set to false to exclude hybrid positions.
  include_hybrid: true

  # Minimum annual salary filter (optional).
  # Leave as 0 or remove this line to skip salary filtering.
  min_salary: 65000

# ─── Resume Settings ─────────────────────────────
resume:
  # The full path to your resume PDF on your computer.
  # On Windows, use double backslashes (\\) or forward slashes (/).
  path: "Alex_Rivera_Resume.pdf"

  # Must-have skills to prioritize for the match percentage.
  must_have_skills:
    - "Westlaw"
    - "LexisNexis"
    - "e-discovery"
    - "Contract Review"
    - "Legal Research"

  # How heavily to weigh keyword matches when scoring roles.
  # 1.0 = standard weight. Increase to 2.0 if you want
  # exact skill matches to dominate the score.
  keywords_weight: 1.5

# ─── Platform Settings ────────────────────────────
# Set each platform to true or false to enable or disable it.
platforms:
  greenhouse: true
  ashby: true
  lever: true
  workable: true
  aggregators: false   # Free feeds like Remotive, Adzuna

  # Optional: custom ATS endpoints or company career domains
  custom:
    - name: "SmartRecruiters"
      domain: "smartrecruiters.com"
      enabled: true
    - name: "Breezy HR"
      domain: "breezy.hr"
      enabled: true

# ─── Export Settings ──────────────────────────────
export:
  # Comma-separated list of output formats.
  # Options: pdf, csv, json
  format: "pdf,csv"

  # Where to save the output files.
  # The engine creates this folder if it does not exist.
  output_dir: "results"
警告

在 Windows 上： YAML 路径中请使用双反斜杠（\\）或正斜杠（/）。单个反斜杠（\）会破坏 YAML 格式。

✅ 正确："C:\\Users\\Alex\\Documents\\resume.pdf" 或 "C:/Users/Alex/Documents/resume.pdf"

❌ 错误："C:\Users\Alex\Documents\resume.pdf"

使用预设配置文件​

Sweepy 在 profiles/ 文件夹中提供开箱即用的预设配置文件。以下四个覆盖常见搜索：

文件职业方向搜索的职位名称
paralegal_nyc.yaml法律律师助理、法律助理、诉讼支持专员、法律秘书
frontend_developer.yaml软件工程前端工程师、React 开发工程师、UI 工程师
tech_writer.yaml技术写作技术文档工程师、UX 文案、内容设计师
template_custom.yaml任意职业供你替换的示例职位名称。每项设置都有注释。

要使用预设，请在运行扫描时传入其文件名：

终端
sweepy --profile profiles/frontend_developer.yaml
提示

你可以创建任意数量的配置文件。为每种职位名称变体或目标城市各存一份。使用 --profile 参数即可随时切换。

方式 C：借助聊天助手实现自动化​

聊天助手可以替你构建配置文件并运行扫描。Sweepy 内置模型上下文协议（MCP）服务器，助手可直接读写你的配置文件。MCP 集成指南 介绍 Antigravity、Claude Desktop 和 VS Code 的客户端设置，MCP 工具参考 列出 Sweepy 的全部工具。

查阅全部设置​

配置参考 列出配置文件支持的全部设置，从 debug 和 resume.tracks 到 sources.* 和 report.*。编辑配置文件时请保持打开。

了解 Sweepy 的职位来源​

Sweepy 默认查询四套公开的申请人跟踪系统，即 Greenhouse、Ashby、Lever 和 Workable。它还会查询纽约招聘网站 Built In NYC。当配置文件启用时，来自 LinkedIn、Indeed、Glassdoor 和 ZipRecruiter 的聚合职位源通过 python-jobspy 运行。

可选引擎可增加招聘网站。可选项为 HireHunt、OpenRoles、JobDrop 和 Apify。OpenRoles 运行前需要公司列表。Apify 需要 APIFY_TOKEN。JobDrop 与 JobSpy 的依赖版本锁定冲突。设置向导的下载职位引擎选项可安装这些引擎。

职位源与平台 页面介绍可选引擎、种子文件、自定义平台条目和兼容性注意事项。

配置文件已就绪。现在可以运行第一次扫描。
